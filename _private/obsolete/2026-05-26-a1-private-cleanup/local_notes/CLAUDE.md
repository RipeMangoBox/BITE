# CLAUDE.md

## 通用规则

- 优先编辑现有文件，不要重写整个文件
- 不要重复阅读已读过且未被编辑的文件
- 输出追求简洁，推理过程必须详尽
- 书写paperAnalysis引用时以[[路径|缩写]]呈现
- Markdown 表格中不要直接写 `[[路径|缩写]]`，也不要把一个本地引用拆到多个表格单元格里
- 如果表格内容需要引用本地 analysis md，优先改写为列表/小节；若必须保留表格，则单元格内只写缩写或纯文本，完整本地引用统一放到表格下方的 `References` / `相关文献` 列表中，并仍使用 `[[路径|缩写]]`

## 代码规范

- 嵌套层级不超过 4 层
