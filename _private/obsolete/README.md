# Obsolete Private Material

This directory holds private material that is no longer part of the active
ResearchFlow analysis chain, batch workspace, provenance, deployment notes, or
maintenance workflow.

Policy:

- Prefer moving historically useful but inactive material here instead of
  deleting it.
- Do not place active batch manifests, analysis-chain versions, run outputs,
  parser evidence, deployment instructions, credentials, or sync provenance
  here.
- Each dated cleanup bundle should include its own README explaining why the
  material was moved.
