AI 读了 200 篇论文，关掉窗口什么都没留下

你有没有过这种感觉——用 AI 读了一堆论文，聊得很开心，关掉窗口什么都没留下。换个 agent 又要从头喂背景，换个工具之前的分析全部作废。 💡 科研最大的浪费，不是时间，而是读过的论文没变成可复用的知识。 这就是我做 ResearchFlow 的原因。 🔍 它到底是什么？ 本地科研知识库 + AI assistant + 多 Agent 共享的证据层。 不是"帮你写论文"的工具，而是解决更上游的问题：你的 AI 做决策时，手里有没有结构化的、可检索的论文证据？ 🧠 三个核心理念： 1.Knowledge First — 先组织好知识和证据，再让后续动作建立在这层之上，先有证据再做决策。 2.纯 Markdown，零依赖，零锁定 — 本地文件夹 + Markdown + CSV，知识资产完全在自己手里。 3.多 Agent 共享 Research Memory — 不管你用什么 AI 工具，只要能读文件就能接入同一份知识库。不挑工具，不绑平台。 ⚙️ 它能做什么？ 一条完整的知识管线：收集 → 下载 → 分析 → 建索引 → 检索/对比/brainstorm/review 1. 从网页、会议列表、GitHub awesome 仓库批量收集论文 2. 自动下载 PDF 并解析为结构化 Markdown 笔记 3. 按任务、方法、venue 建立可检索的知识索引 4. 论文对比、idea 生成、方案收敛、审稿人压测 5. 改代码前先检索依据，每次修改有据可循 不是建完知识库就结束，后面是从知识到决策到产出的完整能力链。 🪶 更像方法论，不是平台。 平台会变，模型会变，但积累下来的 research memory 能一直复用。架构不限于科研——迁移到前端开发、行业研究同样成立。 ✨ 不是论文管理器，不是提示词合集，不是闭源平台。它是科研工作流的本地知识基础设施——让知识沉淀成 research memory，让任何 AI agent 都能站在同一份证据层上工作。 🔗 GitHub：https://github.com/RipeMangoBox/ResearchFlow 开源免费，纯 Markdown 零依赖，全平台支持。觉得"知识层比一次性生成更重要"，欢迎 Star ⭐
