## 核心方法与创新机理

HY3D-Bench 的核心贡献并非提出新的生成模型架构，而是构建了一套系统性的数据整理与合成流水线，从数据质量、结构粒度和类别多样性三个维度重塑了 3D 资产生成的训练与评估生态。其背后驱动逻辑直指一个被长期忽视的瓶颈：**现有大规模 3D 资产库（如 Objaverse）虽然体量庞大，但充斥着噪声网格、非流形几何、缺乏统一朝向和结构标注，且类别分布严重不均**，导致生成模型在训练时被迫学习低质量信号，评估时又缺乏标准化基准。HY3D-Bench 通过三条互补的数据处理管线——全量级处理、部件级处理和合成数据生成——将这一瓶颈转化为可控的质量杠杆，使同等规模的模型能够逼近甚至匹敌更大模型的性能。

### 全量级数据处理：从原始资产到训练就绪格式

全量级数据管线是整个生态的基础层，目标是将来源混杂的原始 3D 资产统一转化为“训练就绪”（training-ready）的标准化格式。该管线包含三个串联步骤，形成严格的质量过滤链：

**数据渲染与格式转换**是入口关卡。原始资产来自不同建模工具和采集流程，存在格式异构、朝向不一致、材质定义缺失等问题。管线采用人工标注与自动化转换相结合的策略，将所有资产统一转换为单帧静态网格表示，并强制对齐朝向坐标系。这一步不仅消除了格式碎片化，更为后续的多视图渲染提供了统一的相机设置基准——每个资产在标准化视角下被渲染为高保真图像，形成“网格-渲染图”配对，直接服务于图像条件生成模型的训练。

**资产过滤**环节针对网格本身的质量缺陷进行剔除。具体而言，管线检测并移除以下类型的劣质资产：面片数过低（几何退化）、非流形边或顶点（拓扑非法）、存在孤立漂浮碎片（分割错误）、以及纹理映射严重扭曲的样本。过滤后的资产池在几何完整性和视觉保真度上得到第一轮保障。

**后处理**是管线中技术密度最高的环节，承担两项关键任务。其一是**水密化**（watertight mesh generation）：对通过过滤的网格执行全局水密处理，消除孔洞、缝隙和非流形结构，确保每个资产都是封闭的、可定向的流形曲面。这一步骤对下游任务至关重要——无论是 SDF 场学习、体素化还是物理仿真，都依赖水密网格作为输入。其二是**点云采样**：从水密网格表面采样两类点云——尖锐边缘点云（sharp edge point clouds）和随机表面点云（random surface point clouds），前者捕捉几何细节，后者提供均匀覆盖。这两种点云随后被送入 3D VAE 的编码器进行特征提取，构成生成模型训练的特征基础。

这一管线的因果效应链清晰可循：格式统一 → 朝向对齐 → 质量过滤 → 水密化 → 点云采样，每一步都为下一步提供更高质量的输入。最终产出的 252k 高质量资产构成了 HY3D-Bench 的全量级训练集，其类别分布覆盖了从常见家具到稀有器物的广泛范畴（见原始论文的类别分布图），为生成模型提供了比原始 Objaverse 更干净、更一致的监督信号。

### 部件级数据处理：从整体网格到结构化分解

如果说全量级管线解决了“资产质量”问题，部件级管线则直击“结构粒度”这一更精细的瓶颈。传统 3D 资产通常以单一网格形式存储，缺乏对物体内部组成结构的显式标注，导致生成模型难以学习部件级别的语义对应关系，也限制了下游应用（如交互式编辑、部件替换、细粒度检索）的可能性。

HY3D-Bench 的部件级管线采用**基于拓扑连通性的拆分-合并策略**，在不依赖人工标注的前提下自动提取部件分解。具体流程如下：

**拆分阶段**：对每个水密网格执行连通组件分析（connected component analysis），将网格中拓扑不连通的区域识别为独立部件。这一步能够自动分离出如椅子的四条腿、靠背和座面等天然分离的几何单元。

**合并阶段**：单纯的连通组件分析会产生大量过细的碎片——例如一个装饰性雕刻可能被拆分为数十个微小面片。管线引入合并策略，基于几何邻近性、共面性和语义启发式规则，将过度碎片化的组件聚合成有意义的部件。论文特别指出，在人体模型类别中，部件分布呈现 16、34、35 的显著峰值，这源于共享相同几何结构但纹理各异的人形模型——这一观察验证了合并策略在保持结构一致性方面的有效性。

**独立水密化**：合并完成后，每个部件作为独立网格执行单独的水密处理，并生成对应的 2D 分割掩码（mask）。这意味着每个部件不仅拥有封闭的几何表示，还与多视图渲染中的像素级区域建立了精确对应。

最终产出的 240k 部件级资产为生成模型提供了前所未有的结构监督：模型不再仅仅学习“这是一把椅子”，而是学习“椅子由靠背、座面、四条腿组成，且这些部件之间存在特定的空间关系和连接约束”。这一 changed slot 将 3D 生成从整体形状建模推向了结构化组合建模，为细粒度可控生成打开了通道。

### 合成数据生成：从真实采集到 AIGC 驱动的长尾补全

全量级和部件级管线解决了数据质量问题，但无法克服 Objaverse 等真实资产库固有的类别分布不均——长尾类别（如稀有乐器、专业工具、特殊器皿）的样本数量严重不足，限制了生成模型对多样化概念的覆盖能力。HY3D-Bench 的第三条管线引入**AIGC 驱动的合成范式**，通过三步级联生成 125k 长尾类别资产，形成对真实数据的有效补充。

**第一步：文本扩增（Text-to-Text）**。从目标长尾类别的基础名称出发，利用大语言模型（LLM）进行语义扩展，生成丰富的描述性文本提示。例如，从“巴洛克式烛台”这一基础概念，LLM 可衍生出“带有卷曲藤蔓纹饰的银质三枝烛台”、“洛可可风格镀金单枝烛台”等变体，在语义空间中进行可控的多样性膨胀。

**第二步：图像生成（Text-to-Image）**。将扩展后的文本提示送入 Qwen-Image 模型，并通过 LoRA 微调使生成图像更贴近 3D 资产的视觉特征分布（如干净背景、标准化光照、正交视角倾向）。这一步将文本多样性转化为视觉多样性，为后续 3D 重建提供多视角的条件图像。

**第三步：3D 生成（Image-to-3D）**。以生成的图像为输入，调用 HY3D-3.0 模型进行网格重建。由于合成图像天然具有干净背景和一致光照，这一步骤的 3D 重建质量显著高于从“野生”图像出发的通用重建。

合成管线的核心设计哲学是**闭环质量保障**：每一步的输出都经过质量筛选（文本相关性检查、图像美学评分、网格水密性验证），只有通过全部关卡的数据才进入最终数据集。这种级联过滤机制有效抑制了 AIGC 管线的误差累积——LLM 的语义漂移、扩散模型的结构失真、3D 重建的几何塌缩等问题在逐层筛选中被大幅削减。合成数据的类别分布图显示，其覆盖了 5 个细粒度长尾类别，有效填补了真实数据的分布空白。

### 评估框架：标准化测试与公平对比

数据生态的完整性需要评估框架来验证。HY3D-Bench 提供了一套标准化测试协议：从数据集中精选 400 个高质量对象构成测试集，覆盖多样化的类别和几何复杂度。评估指标采用 Uni3D-I 和 ULIP-I——两者均度量生成 3D 资产与输入条件图像之间的 2D-3D 语义一致性，前者基于 Uni3D 模型的跨模态嵌入，后者基于 ULIP 模型的点云-图像对齐能力。

评估框架的设计体现了对公平性的严格考量：所有对比方法（Michelangelo、Craftsman、Trellis、Hunyuan3D 2.1）均使用公开模型或可复现配置进行测评，测试集和指标统一，避免了因数据划分或评估协议差异导致的不公平比较。这一标准化基准填补了 3D 生成领域长期缺乏统一评测平台的空白。

### 关键公式与模块因果关系

HY3D-Bench 的数据管线直接服务于 Hunyuan3D 系列生成模型，理解其训练与推理路径有助于把握数据质量如何转化为模型性能。生成模型的核心架构包含两个关键组件：

**3D VAE 编码-解码**。给定从水密网格表面采样的点云 $P \in \mathbb{R}^{N \times (3 + C)}$（其中 $C$ 为表面法向量），3D VAE 编码器 $\mathcal{E}$ 将其压缩为潜在向量集 $Z$，解码器 $\mathcal{D}$ 则从 $Z$ 重建 SDF 场：

$$Z = \mathcal{E}(P), \quad F_{sdf} = \mathcal{D}(Z)$$

这一公式揭示了水密化处理的因果价值：非水密网格的表面法向量存在歧义（内外方向不确定），会直接污染点云输入特征 $C$，进而导致 VAE 学习到不一致的几何表示。HY3D-Bench 的水密化处理从源头消除了这一误差，使 VAE 能够学习到几何上更精确的潜在空间。

**流匹配训练目标**。扩散模型（基于 DiT 架构）以图像编码器（如 DINO-v2）提取的条件嵌入 $c$ 为指导，通过流匹配目标将噪声 $x_0$ 逐步变换为数据 $x_1$：

$$\mathbb{E}_{t, x_0, x_1, c} \left\| v_\theta(x, t, c) - (x_1 - x_0) \right\|_2^2$$

这里的条件嵌入 $c$ 来自多视图渲染图像——而渲染质量直接取决于网格的水密性和纹理完整性。HY3D-Bench 的高质量渲染图确保了条件信号的清洁度，使扩散模型能够更准确地建立图像-几何对应关系。在推理阶段，给定输入图像，模型通过反向流匹配从噪声中逐步解码出潜在向量集 $Z$，再经 VAE 解码器恢复为 SDF 场，最终通过 Marching Cubes 提取显式网格。

### 模块间的因果链总结

三条数据管线与生成模型训练之间形成了清晰的因果闭环：全量级管线的水密化保证了 VAE 编码器输入的点云法向量一致性，进而提升潜在空间质量；部件级管线的结构分解为模型提供了细粒度的部件语义监督，使生成结果具备结构化特征；合成数据管线弥补了长尾分布缺口，增强了模型对稀有概念的泛化能力。评估框架则作为反馈回路，量化验证数据质量改进对模型性能的实际增益——实验结果表明，在 HY3D-Bench 数据上训练的 Hunyuan3D-2.1-Small（832M 参数）在 Uni3D-I 和 ULIP-I 指标上分别达到 0.3606 和 0.2424，与更大规模的 Trellis 模型（0.3641/0.2454）几乎持平，且显著优于同等规模的 Craftsman（0.3351），这 0.0255 的 Uni3D-I 增益正是数据质量杠杆的直接体现。
