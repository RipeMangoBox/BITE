## 实验与关键发现

Hunyuan3D Studio 的实验评估覆盖了管线中三个核心可量化模块：零件级3D分割与分解、语义UV展开，以及多边形重拓扑。由于系统整体面向端到端游戏资产生产，各模块的评估基准、指标和对比基线差异较大，以下按模块分别呈现关键结果与消融发现。

### 零件级分割与分解

**P^3-SAM 分割性能。** 在 PartObjectarverse-Tiny 基准上，P^3-SAM 在三种设定下均大幅超越先前方法（Table 1）：无连通性约束的完全分割 mIoU 达 59.88，有连通性约束下达 81.14，交互式分割达 51.23。在水密版本（watertight）PartObjectarverse-Tiny 上，无连通性和交互式设定分别取得 55.35 和 49.11 的 mIoU（Table 2）。有连通性约束下 81.14 的 AVG mIoU 是当前该基准上的最佳结果，表明 P^3-SAM 的特征提取器、三个分割头与 IoU 预测头的联合设计有效捕获了点云的局部几何与全局语义。

**X-Part 形状分解性能。** 在 ObjaversePart-Tiny 上，X-Part 实现了当前最优的形状分解质量（Table 1）：Chamfer Distance 低至 0.11，F-score@0.1 达 0.80，F-score@0.5 达 0.71。该结果验证了 X-Part 以边界框作为提示（而非直接使用分割结果）来引导扩散生成的设计选择——这一策略有效缓解了过拟合，使生成的零件在语义合理性和结构一致性上均优于基线方法。

### 语义UV展开

SeamGPT 在两个公开基准上进行了定量评估，并以用户研究补充了主观质量判断。

**面扭曲指标。** 在 FAM Benchmark 上，SeamGPT 取得平均面扭曲 13.04 的最低值（Table fam-bench）；在 Toys4K Benchmark 上，平均面扭曲进一步降至 1.95（Table toys4k-bench）。两个基准上 SeamGPT 均优于 XAtlas、Nuvo、FAM 和 Edge-CLS 等传统与学习型 UV 展开方法。面扭曲直接反映 UV 展开对网格几何的保真度，数值越低意味着纹理映射时的拉伸和形变越小，这对游戏引擎中的纹理采样质量至关重要。

**用户研究。** 在边界质量和可编辑性的主观评估中（Table 1），SeamGPT 分别获得 4.00 和 4.02 的平均评分（满分 5 分），在所有对比方法中最高。这表明自回归接缝生成策略不仅降低了面扭曲，还产出了更符合艺术家偏好的切割边界——接缝位置自然、易于后续纹理编辑。

**消融实验揭示三个关键设计选择。** 第一，点云采样策略：沿网格边和顶点采样点云（而非面心或随机采样）能使生成的接缝自然贴合网格拓扑结构（Figure 1），这是 SeamGPT 接缝质量优于基线的重要因果因素。第二，编码器选择：点云编码器显著优于网格编码器（Figure 2），说明直接从点云学习形状上下文比从网格拓扑中提取特征更有利于接缝预测任务。第三，自回归解码器中接缝序列的层次分解（段→点→坐标）使得模型能灵活控制切割粒度：通过调节接缝长度参数，用户可在粗粒度和细粒度切割之间切换，且同一输入可生成多样化的有效接缝方案（Figure 3）。

### 多边形重拓扑

PolyGen 采用 Hourglass Transformer 自回归架构，并引入 Masked DPO（M-DPO）后训练阶段来精调低质量区域。消融实验（Figure 6）直接对比了预训练与后训练阶段的输出质量：M-DPO 后训练显著增强了网格完整性（Row #1）、面连接性（Row #2），并大幅减少了破损面（Row #3）。这表明在自回归逐面生成框架下，仅靠预训练的交叉熵损失难以保证拓扑一致性，而 M-DPO 通过聚焦低质量区域的强化优化，有效补足了这一短板。

在分布外泛化测试中（Figure 7），PolyGen 面对密集、复杂且未见过的输入网格仍能保持较高的几何保真度和曲面连续性，重建质量优于现有多边形生成方法。此外，PolyGen 还展示了零件感知的生成能力（Figure 8）：当输入为已分割为多个零件的形状时，模型可在不额外微调的情况下，分别以各零件的部分点云为条件生成对应的低面数网格，这为管线中零件级生成与重拓扑的衔接提供了灵活性。

### 动画模块

动画模块的骨骼生成与蒙皮权重质量通过与 UniRig（Zhang et al., 2025）的定性对比展示（Figure animation_result）。在通用角色输入上，Hunyuan3D Studio 生成的骨骼结构和蒙皮变形效果与 UniRig 可比，但该模块目前缺乏定量基准评估，其在不同体型、拓扑复杂度角色上的鲁棒性边界尚需进一步验证。

### 适用边界与待验证问题

整体来看，Hunyuan3D Studio 在零件分割、UV 展开和重拓扑三个模块上提供了较充分的定量证据，但在以下方面存在证据缺口：

1. **端到端管线整体评估缺失。** 各模块独立评估虽展示了组件优势，但缺少从输入图像到游戏引擎可部署资产的完整管线级指标（如端到端耗时、资产在引擎中的渲染帧率、LOD 兼容性等），这使得“游戏就绪”这一核心主张缺乏系统级验证。

2. **动画模块定量评估缺失。** 骨骼生成和蒙皮仅通过定性对比展示，缺少在标准基准（如 Mixamo 或自定义测试集）上的数值指标（如蒙皮权重误差、关节旋转误差），其实际可用性需要人工验证。

3. **纹理合成与编辑模块无独立实验。** 尽管管线包含 PBR 纹理集生成和 4K 材质球生成能力，但分析材料中未提供该模块的定量评估或用户研究，其与 UV 展开的协同效果（如接缝处纹理连续性）也未经验证。

4. **概念设计模块的生成质量依赖上游模型。** 图像风格化基于 Qwen-Image-Edit + LoRA，姿态标准化基于 FLUX.1-dev DiT，这些模块的性能受限于基底模型的能力边界，但论文未报告风格保真度或姿态标准化准确率的独立指标。
