## 核心方法与创新机理

### 问题瓶颈与设计动机

传统游戏3D资产生成流程存在一个根本性矛盾：AI辅助建模工具（如文本/图像到3D生成）能快速产出高面数几何，但这些几何资产缺乏游戏引擎所需的技术规范——包括低多边形拓扑、合理的UV展开、PBR材质以及骨骼绑定。现有方法各自为战，仅处理孤立子任务，且产出物之间缺乏元数据传递，导致从概念设计到引擎部署仍需大量人工介入。**Hunyuan3D Studio** 的核心设计目标就是打破这一瓶颈：构建一个端到端、模块化且元数据可传递的AI管道，使单一图像输入即可产出满足游戏技术标准的完整3D资产。

### 管道架构与模块间的因果链路

系统由七个核心模块串联构成，每个模块的输出不仅作为下游模块的输入，还携带关键的语义和几何元数据，形成信息不衰减的因果链：

1. **可控图像生成** → 对输入图像进行风格化和姿态标准化，输出规范化的多视角参考图像。
2. **高保真几何生成** → 基于扩散模型从单/多视图像重建高面数三角网格。
3. **部件级3D生成（P³-SAM + X-Part）** → 自动将网格分割为功能部件，并为每个部件生成结构一致的独立几何。
4. **多边形生成（PolyGen）** → 将高面数网格自动重拓扑为低面数、边流结构化的游戏就绪网格。
5. **语义UV展开（SeamGPT）** → 上下文感知地生成切割接缝，并展开UV以高效利用纹理空间。
6. **纹理合成与编辑** → 生成PBR纹理集（漫反射、法线、粗糙度等），支持多模态编辑。
7. **动画模块** → 自动生成骨骼和蒙皮权重，输出可动画资产。

关键因果链路在于：**部件分割（模块3）的语义标签直接指导PolyGen（模块4）的分部件重拓扑，而PolyGen输出的低面数网格拓扑又为SeamGPT（模块5）的语义感知切割提供了几何约束**。这种元数据传递机制使得整个流程不再是独立模型的简单拼接，而是一个信息连续流动的生成系统。

### 核心创新一：PolyGen——基于强化后训练的自回归重拓扑

传统重拓扑依赖手工操作或经典几何算法（如Instant Meshes），难以在保持几何保真度的同时生成符合游戏规范的边流结构。**PolyGen** 采用两阶段框架从根本上改变了这一范式。

**预训练阶段**：使用Hourglass Transformer作为自回归骨干网络，将网格生成形式化为逐面（face-by-face）的令牌序列预测问题。输入为ShapeVAE编码器从高面数网格采样得到的点云 $`\{\mathbf{x}_i=(\mathbf{P}_i,\mathbf{N}_i)\mid\mathbf{P}_i,\mathbf{N}_i\in\mathbb{R}^3\}`$（包含3D位置和表面法线），经Vector-Set Transformer压缩为紧凑的形状潜变量 $`\mathbf{z}`$。解码器以点云令牌 $`c_p`$ 为条件，通过交叉注意力层逐令牌预测网格面序列，训练目标为最大化网格令牌的条件概率：

$$L(\theta) = \prod_{i=1}^{|m|} p(m_{i} | m_{1:i-1}, c_p;\theta)$$

**后训练阶段——Masked DPO（M-DPO）**：预训练模型在分布外几何上容易产生破损面、不完整网格和连接性错误。M-DPO通过构造偏好对 $`(\mathcal{M}_{\mathcal{P}}^+, \mathcal{M}_{\mathcal{P}}^-)`$（高质量网格与低质量网格），并仅在低质量区域施加掩码，使模型聚焦于修复拓扑缺陷。其目标函数为：

$$\mathcal{L}_{\text{M-DPO}}(\pi_\psi; \pi_{\text{ref}}) = -\mathbb{E}_{(\mathcal{P}, \mathcal{M}_{\mathcal{P}}^+, \mathcal{M}_{\mathcal{P}}^-) \sim \mathcal{D}} \left[ \log \sigma \left( \beta \mathcal{L}^+(\mathcal{P}, \mathcal{M}_{\mathcal{P}}^+) - \beta \mathcal{L}^-(\mathcal{P}, \mathcal{M}_{\mathcal{P}}^-) \right) \right]$$

其中 $`\pi_\psi`$ 为当前策略，$`\pi_{\text{ref}}`$ 为参考策略，$`\beta`$ 控制偏好强度。掩码机制确保仅对破损区域进行梯度更新，避免对已生成良好区域的干扰。这一设计使得PolyGen在分布外密集网格上仍能保持几何保真度和表面连续性（Figure 7），并支持分部件独立重拓扑而无需额外微调（Figure 8）。

### 核心创新二：SeamGPT——语义感知的自回归UV展开

传统UV展开工具（如XAtlas）仅基于几何曲率进行切割，忽略了语义边界，导致接缝穿过视觉敏感区域，增加纹理绘制的难度。**SeamGPT** 将UV切割重新定义为接缝序列的自回归生成问题。

**序列化表示**：接缝被层次化分解为段→点→坐标的序列：

$$S = \{s^1, s^2, \ldots s^{N_s}\} = \{p^1_h, p^1_t, p^2_h, p^2_t, \ldots, p^{N_h}_t, p^{N_h}_t\} = \{x^1_h, y^1_h, z^1_h, x^1_t, y^1_t, z^1_t, \ldots, x^{N_s}_t, y^{N_s}_t, z^{N_s}_t\}$$

其中 $`s^i`$ 为第 $`i`$ 个接缝段，$`p_h^i`$ 和 $`p_t^i`$ 分别为段的起点和终点。整个序列的联合概率通过因果Transformer逐坐标预测：

$$P(S) = \prod_{i=1}^{6N_s} P(c_i | c_{<i})$$

**架构设计**：点云编码器提取全局形状上下文，因果Transformer解码器按坐标轴顺序生成接缝坐标（Figure 9）。消融实验表明，沿边和顶点采样点云（而非均匀体素采样）能生成自然符合网格拓扑的接缝（Figure 1），且点云编码器优于网格编码器（Figure 2）。SeamGPT还支持通过控制接缝长度来调节切割粒度，并能生成多样化的有效接缝（Figure 3），为艺术家提供灵活选择。

### 核心创新三：部件级生成——从分割到结构一致分解

部件级生成由两个互补模块构成：

**P³-SAM**：在点云域实现3D部分分割，包含特征提取器、三个分割头（全自动无连通性、全自动有连通性、交互式）和一个IoU预测头。特征提取器基于Point Transformer架构，IoU预测头用于评估分割质量并支持交互式修正。

**X-Part**：可扩散框架，将部件生成从分割结果提升为结构一致的形状分解。其关键设计是使用包围盒（bounding box）而非分割掩码作为条件提示，有效缓解了训练过拟合。包围盒编码了部件的位置和尺度信息，扩散模型在此条件下生成几何完整、语义合理的独立部件，支持后续的独立编辑和动画绑定。

### 训练与推理路径

**训练流程**：各模块独立训练，但共享统一的点云表示格式。PolyGen的预训练使用大规模3D资产数据集，后训练M-DPO阶段通过构造合成破损数据构建偏好对。SeamGPT使用艺术家标注的接缝数据训练自回归Transformer。P³-SAM在PartObjectarverse数据集上训练，X-Part在ObjaversePart上训练扩散模型。

**推理流程**：输入图像首先经过风格化和姿态标准化（使用FLUX.1-dev DiT，以角色参考图像作为条件注入），生成多视角规范化视图。几何生成模块基于扩散模型输出高面数网格。P³-SAM自动分割部件，X-Part可选地进一步分解。PolyGen对整体或分部件进行重拓扑，输出低面数网格。SeamGPT在低面数网格上生成语义接缝并展开UV。纹理模块基于扩散模型生成PBR材质，动画模块自动绑定骨骼。整个流程端到端自动化，无需人工干预即可产出游戏就绪资产。
