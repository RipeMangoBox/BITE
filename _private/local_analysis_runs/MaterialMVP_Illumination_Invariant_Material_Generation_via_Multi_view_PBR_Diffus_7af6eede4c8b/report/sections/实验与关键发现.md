## 实验与关键发现

### 主结果：定量对比

MaterialMVP 在 Objaverse 子集（176 个物体）上与当前最优方法进行了全面定量对比，评估指标涵盖纹理质量（FID、CMMD）、语义一致性（CLIP-I、CLIP-FID）和感知相似度（LPIPS）。对比方法分为两类：仅文本条件方法（**Text2Tex**、**SyncMVD**、**Paint-it**）和图像条件方法（**Paint3D**、**TexGen**）。

如表 1（tab: comparisons）所示，MaterialMVP 在所有指标上均取得最优结果。以最强的图像条件基线 **Paint3D**（Zeng et al., CVPR 2024）为参照：CLIP-FID 从 26.86 降至 **24.78**（Δ −2.08），FID 从 176.9 降至 **168.5**（Δ −8.4），CMMD 从 2.400 降至 **2.191**（Δ −0.209）。语义保持方面，CLIP-I 从 0.8871 提升至 **0.9207**（Δ +0.0336），LPIPS 从 0.1261 降至 **0.1211**（Δ −0.005）。这些指标覆盖了纹理真实感、与参考图像的一致性以及多视图感知质量三个维度，表明 MaterialMVP 在图像引导的 PBR 纹理生成任务上全面超越现有方法。

值得注意的是，MaterialMVP 作为单阶段方法，显著优于两阶段方案 **SuperMat**。后者先估计材质后生成纹理，但常将玻璃或金属渲染成塑料质感（见 Figure 7a），说明端到端联合学习对 PBR 材质属性的准确建模至关重要。

### 定性对比：光照不变性与多视图一致性

在文本条件生成对比中（Figure 5, fig: t_comparison），MaterialMVP 展现出明显优势：Text2Tex 和 SyncMVD 的输出存在纹理模糊和光照残留问题，Paint-it 的图案对齐出现偏差，而 MaterialMVP 生成的纹理具有清晰的图案连贯性和一致的光照表现。

在图像条件生成对比中（Figure 6, fig: i_comparison），Paint3D 和 TexGen 在复杂光照条件下难以忠实跟随参考图像的语义，且前后视图纹理不一致。MaterialMVP 则能够准确捕捉参考图像的材质属性，同时在不同视点下保持纹理的空间一致性。

重光照实验（Figure 8, fig: re-light）进一步验证了 MaterialMVP 生成 PBR 材质的光照不变性。将生成的纹理置于多种环境光照下渲染，结果展现出准确的物理行为：金属度与粗糙度通道正确响应环境光变化，反照率图无光照残留，证明了模型有效解耦了材质属性与输入图像的光照信息。

### 消融实验：关键设计的因果验证

消融实验（Figure 7, fig: ablation）验证了三个核心设计的作用：

**（a）单阶段 vs. 两阶段生成**：将 MaterialMVP 的单阶段端到端方案替换为两阶段 SuperMat 管线后，材质估计出现系统性偏差，金属和玻璃材质被错误渲染为漫反射塑料质感。这表明反照率与 MR 通道的联合生成能够避免分阶段处理引入的误差累积。

**（b）一致性损失移除**：移除训练中的 $\mathcal{L}_{\text{cons}}$ 后，模型频繁将非金属材质（如木材、织物）错误预测为高金属度。这一现象揭示了核心因果机制：一致性损失通过约束两个参考图像（具有微小视角和光照差异）的噪声预测一致，迫使模型学习光照不变的材质表示。缺少该约束时，模型倾向于将光照变化误判为金属反射。

**（c）多通道对齐注意力（MCAA）替换**：将 MCAA 替换为标准权重共享注意力后，反照率与 MR 图在细节区域出现明显不对齐，导致最终渲染纹理模糊。这验证了 MCAA 的设计逻辑：反照率通道保留参考交叉注意力以维持纹理细节，MR 通道通过残差连接 $z_{MR}^{new} = z_{MR} + \text{Attn}_{albedo}$ 从反照率特征继承空间结构，从而在不引入额外参数的前提下实现通道间精确对齐。

### 适用边界与局限

论文未明确讨论方法的局限性，但综合实验设置可推断以下适用边界：

**数据依赖**：模型在 Objaverse 和 Objaverse-XL 的 70,000 个高质量 3D 资产上训练，耗时约 180 GPU 天。对于训练分布之外的几何拓扑（如极度非流形网格）或材质类型（如半透明、次表面散射材质），生成质量可能下降，但论文未提供相关验证。

**参考图像约束**：一致性训练策略要求参考图像对具有小幅相机方位角差异（$\pm 15^\circ$），这在训练阶段通过数据筛选保证。但在推理阶段，当输入参考图像的视角与目标生成视角差异过大时，模型的多视图一致性表现缺乏定量评估。

**PBR 模型简化**：方法采用标准的反照率-金属度-粗糙度（Albedo-Metallic-Roughness）模型，未涉及透射、透明涂层等扩展 PBR 属性。对于需要这些属性的应用场景（如玻璃器皿、车漆），生成能力受限。

**评估覆盖度**：定量评估基于 176 个物体的 Objaverse 子集，样本规模有限。且主要指标（FID、CLIP-FID 等）在 2D 渲染图上计算，对 3D 几何一致性的直接度量不足。用户感知研究或 3D 感知指标的缺失是需要手动验证的评估盲区。
