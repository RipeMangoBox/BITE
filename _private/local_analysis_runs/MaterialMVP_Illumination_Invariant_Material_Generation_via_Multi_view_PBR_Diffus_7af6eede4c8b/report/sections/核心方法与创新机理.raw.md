## 核心方法与创新机理

### 问题背景与核心瓶颈

为三维网格生成高质量 PBR 纹理是计算机图形学中的关键任务，其难点在于需要同时生成反照率（Albedo）、金属度（Metallic）和粗糙度（Roughness）三张物理上解耦的材质贴图。现有基于扩散模型的方法虽然取得了显著进展，但在图像引导的多视图 PBR 纹理生成中仍面临三个核心瓶颈：

1. **光照与材质纠缠**：参考图像中的光照信息极易泄漏到反照率图中，导致生成的反照率含有高光残留，破坏了 PBR 材质的物理正确性。
2. **多视图不稳定性**：参考图像的微小视角或光照变化会引起输出纹理的大幅波动，前后视图之间缺乏材质一致性。
3. **通道特征不对齐**：反照率通道与金属度-粗糙度（MR）通道在生成过程中缺乏有效的特征对齐机制，导致纹理模糊和空间伪影。

这些瓶颈的本质在于：标准扩散模型的训练范式天然倾向于记忆参考图像中的光照模式，而非学习光照不变的材质表示。MaterialMVP 通过两个核心创新——一致性正则化训练策略和双通道材质生成框架——从训练范式和架构设计两个层面系统性地解决了上述问题。

### 整体框架

MaterialMVP 是一个端到端的单阶段框架，其输入为一个三维网格和一张参考图像，输出为多视图一致的 PBR 纹理贴图（反照率图、金属度图和粗糙度图）。框架的核心流程如下：

1. **几何编码**：三维网格以法线图（Normal Map）和位置图（Position Map）的形式输入，编码到潜在空间后与噪声潜在变量按通道拼接，作为 U-Net 的输入。
2. **参考注意力编码**：参考图像通过 Reference Attention 模块提取信息丰富的潜在特征，为纹理生成提供语义和外观引导。
3. **多视图 PBR 扩散**：基于多视图扩散模型框架，在去噪过程中通过跨视图注意力机制同步生成多个视角的 PBR 贴图。
4. **双通道材质生成**：反照率通道和 MR 通道通过多通道对齐注意力（MCAA）和可学习材质嵌入进行分离生成与特征对齐。

### 核心创新一：一致性正则化训练策略

一致性正则化训练是 MaterialMVP 实现光照不变材质生成的核心机制。其关键洞察在于：如果模型真正学习到了材质属性而非光照模式，那么对于同一物体在微小视角和光照差异下的两张参考图像，模型的噪声预测应该保持一致。

#### 参考图像对构建

训练时，MaterialMVP 不使用单张参考图像，而是构建参考图像对 $(I_1, I_2)$。对于给定的第一张参考图像 $I_1$，候选对的选择策略为：

$$\mathcal{S}(I_1) = \{I \in \mathcal{I} \mid \phi_c(I) \in \{\phi_c(I_1), \phi_c(I_1) \pm 15^\circ\}\}$$

其中 $\phi_c(I)$ 表示图像 $I$ 的相机方位角。该约束确保 $I_2$ 与 $I_1$ 的相机方位角差异不超过 $15^\circ$，从而产生小幅的视角和光照扰动。这种精心设计的图像对既提供了足够的差异性来驱动一致性学习，又避免了过大的视角变化导致内容不对齐。

#### 损失函数设计

训练损失由两项组成：

**PBR 损失**：标准的扩散去噪损失，作用于第一张参考图像条件下的噪声预测：

$$\mathcal{L}_{\text{pbr}} = \mathbb{E}_{\epsilon \sim \mathcal{N}(0,1), t}[\|\epsilon - \epsilon_t^1\|_2^2]$$

其中 $\epsilon$ 是真实噪声，$\epsilon_t^1$ 是以 $I_1$ 为条件的模型噪声预测，$t$ 为扩散时间步。

**一致性损失**：强制两个参考图像条件下的噪声预测保持一致：

$$\mathcal{L}_{\text{cons}} = \mathbb{E}_t[\|\epsilon_t^1 - \epsilon_t^2\|_2^2]$$

其中 $\epsilon_t^2$ 是以 $I_2$ 为条件的噪声预测。该损失的关键作用在于：当光照或视角发生微小变化时，模型必须输出相同的去噪方向，从而迫使模型学习光照不变的材质表示，而非记忆参考图像中的光照模式。

**总损失**为两者的加权组合：

$$\mathcal{L} = (1 - \lambda)\mathcal{L}_{\text{pbr}} + \lambda \mathcal{L}_{\text{cons}}, \quad \lambda = 0.1$$

$\lambda = 0.1$ 的权重设置体现了以重建质量为主、一致性约束为辅的设计理念——一致性损失作为正则项，在不损害纹理生成质量的前提下，有效消除光照残留并增强多视图稳定性。

#### 训练与推理路径

训练时，网络依次处理 $I_1$ 和 $I_2$，分别计算噪声预测 $\epsilon_t^1$ 和 $\epsilon_t^2$，然后通过 $\mathcal{L}_{\text{pbr}}$ 保证重建质量，通过 $\mathcal{L}_{\text{cons}}$ 强制预测一致性。推理时仅需单张参考图像，无需图像对，模型已通过一致性训练内化了光照不变材质表示。

### 核心创新二：双通道材质生成框架

PBR 材质的反照率通道和 MR 通道具有本质不同的特性：反照率需要严格跟随参考图像的纹理和语义内容，而 MR 通道描述的是与纹理内容相对独立的物理属性（金属度、粗糙度）。基于这一观察，MaterialMVP 设计了双通道材质生成框架，其核心组件包括多通道对齐注意力（MCAA）和可学习材质嵌入。

#### 多通道对齐注意力（MCAA）

MCAA 的设计遵循一个清晰的因果逻辑：反照率通道保留参考引导，MR 通道从反照率继承空间结构。

**反照率通道**保留标准的参考图像交叉注意力：

$$\text{Attn}_{albedo} = \text{Softmax}\left(\frac{Q_{albedo} K_{ref}^T}{\sqrt{d}}\right) \cdot V_{ref}$$

其中 $Q_{albedo}$ 来自反照率通道的查询向量，$K_{ref}$ 和 $V_{ref}$ 来自参考图像特征的键和值向量。这一设计确保反照率纹理在语义和空间布局上忠实跟随参考图像。

**MR 通道**则放弃直接接收参考图像信息，转而通过残差连接从反照率注意力继承空间一致性：

$$z_{MR}^{new} = z_{MR} + \text{Attn}_{albedo}$$

其中 $z_{MR}$ 是 MR 通道的原始特征，$\text{Attn}_{albedo}$ 是反照率通道的交叉注意力输出。这一残差更新机制的核心优势在于：

- **解耦光照影响**：MR 通道不直接接触参考图像，避免了光照信息通过交叉注意力泄漏到 MR 图中。
- **空间对齐**：通过残差连接继承反照率注意力的空间结构，确保 MR 图与反照率图在细节区域（如纹理边界、图案边缘）精确对齐，消除模糊和伪影。
- **参数高效**：无需引入额外的交叉注意力模块或增加参数量，仅通过特征层面的残差连接实现通道间对齐。

#### 可学习材质嵌入

为进一步捕捉反照率和 MR 纹理的独特分布特性，MaterialMVP 为两个通道分别引入了可学习材质嵌入。这些嵌入作为通道特定的先验信息注入 U-Net，帮助模型区分反照率（通常包含丰富的纹理和颜色变化）与 MR 图（通常为低频的物理属性图）的生成模式差异，从而消除因分布不匹配导致的伪影。

### 模块间的因果关系

MaterialMVP 各模块之间存在紧密的因果依赖关系：

1. **一致性正则化训练 → 光照不变材质表示**：图像对训练和 $\mathcal{L}_{\text{cons}}$ 迫使模型忽略光照变化，学习纯粹的材质属性，这是解决光照-材质纠缠的根本机制。
2. **MCAA 中的反照率注意力保留 → 纹理语义忠实性**：反照率通道保留参考交叉注意力，确保生成的纹理在内容和布局上跟随参考图像。
3. **MCAA 中的 MR 残差连接 → 通道对齐与解耦**：MR 通道通过 $\text{Attn}_{albedo}$ 的残差继承，在不接触参考图像的条件下获得空间一致性，同时避免了光照信息污染。
4. **可学习材质嵌入 → 分布匹配与伪影消除**：通道特定的嵌入帮助模型适配反照率和 MR 的不同统计特性，减少生成伪影。

### Changed Slots 总结

相对于现有方法，MaterialMVP 在以下关键设计点上进行了创新：

| 设计槽位 | 基线方法 | MaterialMVP 方案 | 因果作用 |
|---------|---------|-----------------|---------|
| 训练范式 | 单参考图像训练 | 图像对训练 + $\mathcal{L}_{\text{cons}}$ 一致性损失 | 消除光照残留，增强多视图稳定性 |
| MR 通道条件机制 | 直接接收参考图像条件 | 放弃直接参考条件，通过反照率注意力残差继承空间信息 | 解耦光照影响，保持通道对齐 |
| 材质生成架构 | 共享注意力或两阶段管线 | 双通道生成 + MCAA + 可学习材质嵌入 | 端到端联合学习，消除通道不对齐伪影 |

这些 changed slots 共同构成了 MaterialMVP 的核心创新链条：训练层面的光照解耦（一致性正则化）与架构层面的通道解耦（MCAA）相互配合，前者从优化目标上消除光照纠缠，后者从信息流设计上阻断光照泄漏路径，最终实现了光照不变、多视图一致、通道对齐的高质量 PBR 纹理生成。
