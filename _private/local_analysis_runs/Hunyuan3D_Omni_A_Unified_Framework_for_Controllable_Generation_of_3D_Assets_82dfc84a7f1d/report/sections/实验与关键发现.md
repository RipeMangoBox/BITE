## 实验与关键发现

Hunyuan3D-Omni 的实验验证主要依赖定性可视化评估，目前尚未提供系统的定量指标对比和消融研究。论文通过多组控制条件下的生成结果展示了方法在几何对齐、细节恢复和结构完整性方面的显著改进。以下从四个控制模态分别梳理关键发现。

### 点云控制：解决单视图歧义与遮挡恢复

点云控制是 Hunyuan3D-Omni 最核心的实验验证场景。在仅使用单张图像作为输入时，基线模型 Hunyuan3D 2.1 生成的几何体常出现扭曲、比例失调和细节丢失等问题，这源于单视图三维重建的固有几何模糊性。当引入完整的点云作为额外控制信号后，扩散模型能够有效利用点云提供的显式几何先验来约束生成过程。

实验结果表明，提供完整点云条件可以**有效解决单视图输入的歧义性**，并**恢复被遮挡的内部结构**（Figure 11）。这意味着模型不再仅依赖图像语义推断不可见区域的几何，而是通过点云直接获取了完整的三维结构信息。在深度投影点云和扫描点云的条件下，模型同样表现出改进的对齐精度和细节恢复能力，相较于仅图像输入的生成结果，几何扭曲程度明显降低。

### 体素控制：尺度对齐与细节增强

体素作为另一种显式三维表示，其控制效果主要体现在两个层面。第一，体素条件能够**确保生成物体与真实几何在尺度上正确对齐**，避免仅图像输入时常见的尺寸偏差问题。第二，体素所提供的体积占用信息有助于**恢复精细的几何细节**（Figure 12），这些细节在纯图像条件下往往被平滑化或丢失。

体素控制的优势在于其提供了物体的体积先验，使得扩散模型在去噪过程中能够区分物体的内部与外部区域，从而生成更合理的表面拓扑结构。

### 包围盒控制：尺度调整与几何激活

包围盒控制展现出两种实用能力。在尺度调整方面，给定不同尺寸的包围盒，模型可以**生成不同尺度的同一类物体**（Figure 2），这为三维资产生成提供了直观的尺寸控制手段。

更值得关注的是包围盒的**几何激活效应**。当单图像条件生成失败、模型倾向于产生薄片状或退化的几何体时，包围盒信号可以注入一个激活线索，促使生成网络输出有效的网格（Figure 10）。这一发现表明，即使是最粗糙的空间范围约束，也能在扩散过程中起到关键的引导作用，防止生成过程陷入不良的局部最优。

### 骨骼控制：姿态对齐与风格保持

骨骼姿态控制实验展示了模型在**多样化姿态和输入风格下生成精确对齐几何体**的能力（Figure 1）。通过提供骨骼关节的三维坐标作为条件，模型能够将生成物体的姿态约束到指定骨架结构上，同时保持输入图像的风格特征。

这一能力的实现依赖于困难感知采样策略。训练过程中，骨骼姿态被归类为"更难"的控制信号，采样器会偏向选择骨骼条件进行训练，从而确保模型充分学习从稀疏骨架到完整几何的映射关系。

### 训练策略的有效性

论文强调了渐进式困难感知采样策略的关键作用。该策略在训练时从四种控制模态中按样本选择一种，并通过偏向更难信号（如骨骼姿态）同时抑制简单信号（如点云）的采样概率，来促进鲁棒的多模态融合。虽然未提供该策略的消融实验数据，但从各控制模态均能有效工作的定性结果来看，这一策略是统一框架成功的重要支撑。

### 实验局限与适用边界

需要明确指出，当前实验验证存在以下局限：

1. **缺乏定量评估**：论文未报告任何定量指标（如 Chamfer Distance、F-Score、IoU 等），也未与现有可控三维生成方法进行数值对比。所有结论均基于定性可视化，证据强度有限。

2. **无消融实验**：未对统一控制编码器的设计选择（如位置嵌入的必要性、类型嵌入的维度、重复操作的效果）进行消融验证，也未对比困难感知采样策略与均匀采样的差异。

3. **控制类型受限**：当前仅支持点云、体素、包围盒和骨骼四种控制类型，尚未扩展到文本描述等更灵活的条件形式。对于需要语义级控制的场景，模型的适用性有限。

4. **数据集与泛化性未说明**：实验使用的自定义数据集（Hunyuan3D 2.1 + PoseMaster 数据）的规模和分布未详细披露，模型在不同领域数据上的泛化能力有待验证。

综上，Hunyuan3D-Omni 在定性层面展示了统一控制框架的可行性和有效性，但要确立其在可控三维生成领域的优势地位，仍需补充系统的定量实验和消融研究。
