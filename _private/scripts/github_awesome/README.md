# scripts/github_awesome

从 `_private/PaperBite/` 提升的可复用工具脚本。

| 脚本 | 用途 |
|------|------|
| `search_awesome_repos.py` | 搜索 GitHub awesome 仓库候选（GitHub API + 网页回退） |
| `snapshot_repo_readmes.py` | 增量抓取仓库 README 快照（SHA256 / etag 去重） |
| `strict_complete_tier1_logs.py` | 多源链接补全（arXiv + Semantic Scholar + 网页） |
| `paperbite_sync_download.py` | 多源 PDF 下载（arXiv + OpenReview + DOI，并发下载） |

数据目录仍在 `_private/PaperBite/github_awesome/`，脚本默认路径可能需要调整。
