# paperIDEAs

This directory stores downstream research outputs produced on top of the
ResearchFlow knowledge base.

Typical contents include:

- brainstorm notes
- focused plans and scoped roadmaps
- reviewer-style stress tests
- comparison writeups
- linked implementation notes
Suggested conventions:

- keep reusable outputs here rather than one-off chat transcripts
- prefer date-prefixed filenames such as `YYYY-MM-DD_topic.md`
- organize long-running projects into subfolders when needed
Useful entry points:

- `目录.md`: full markdown index for all idea notes
- `2026-04-16_motion-productization-shared-frame.md`: shared background for productization / agentic notes
- `2026-04-16_long-horizon-planning-local-repair-shared-frame.md`: shared background for long-horizon planning / repair notes
- `2026-04-16_structured-alignment-multi-level-control-shared-frame.md`: shared background for alignment / control notes
