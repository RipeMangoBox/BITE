# Motion 文本语义与指令对齐：2024+ 工作脉络

## 核心结论

2024 年后的 text-to-motion alignment 已经从“整句文本条件下生成一段动作”的粗粒度匹配，分化成四条更细的路线：

1. **动作单元/局部语义对齐**：让 motion token、motion segment、local action 或 body-part motion 与文本 token、动作短语、语义标签建立局部对应。代表是 [[analysis/CVPR_2026/MoLingo_Motion_Language_Alignment_for_Text_to_Human_Motion_Generation.md|MoLingo (CVPR_2026)]] 的 SAE、[[analysis/WACV_2026/SegMo_Segment-aligned_Text_to_3D_Human_Motion_Generation.md|SegMo (WACV_2026)]] 的 segment 对齐、[[analysis/WACV_2026/ATM_Enhanced_Alignment_for_Text-to-Motion_Generation.md|ATM (WACV_2026)]] 的局部语义代理、[[analysis/ECCV_2024/Local_Action-Guided_Motion_Diffusion_Model_for_Text-to-Motion_Generation.md|Local Action-Guided (ECCV_2024)]] 的 local action 引导、[[analysis/arxiv_2025/CASIM_Composite_Aware_Semantic_Injection_for_Text_to_Motion_Generation.md|CASIM (arxiv_2025)]]/[[analysis/arxiv_2026/MultiAct_Text-to-Motion_Generation_from_Composite_Text_via_Tailored_Attention_Guidance.md|MultiAct (arxiv_2026)]]/[[analysis/arxiv_2026/Motion-Adapter_A_Diffusion_Model_Adapter_for_Text-to-Motion_Generation_of_Compound_Actions.md|Motion-Adapter (arxiv_2026)]] 的 token/action/body-part 注意力控制。
2. **指令与推理式对齐**：把文本提示拆成动作计划、CoT、interleaved text-motion instruction 或 open-vocabulary atomic motion，再让生成器按计划执行。代表是 [[analysis/ICLR_2026/Motion_R1_Enhancing_Motion_Generation_via_Decomposed_CoT_and_Reinforcement_Learning_Binding.md|Motion-R1 (ICLR_2026)]]、[[analysis/arxiv_2026/UniMo_Unified_Motion_Generation_and_Understanding_with_Chain_of_Thought.md|UniMo (arxiv_2026)]]、[[analysis/arxiv_2025/OmniMoGen.md|OmniMoGen (arxiv_2025)]]、[[analysis/arxiv_2025/Think_Before_You_Move_Latent_Motion_Reasoning_for_Text-to-Motion_Generation.md|Think Before You Move (arxiv_2025)]]、[[analysis/CVPR_2026/Open_the_Motion_Door_Atomic_Motion_Decomposition_and_Recomposition_for_Open_Vocabulary_Motion_Generation.md|Open the Motion Door (CVPR_2026)]]、[[analysis/arxiv_2026/Plan_Dont_Pose_Long_Composite_Motion_Generation_with_Text-Aligned_BFM.md|Plan, Don't Pose (arxiv_2026)]]。
3. **采样/模态分布对齐**：不一定改变训练语义空间，而是在扩散反向过程、流匹配路径、VQ codebook 几何或重建误差场中引导生成分布靠近文本一致、动作真实的区域。代表是 [[analysis/AAAI_2026/ReAlign_Text_to_Motion_Generation_via_Step_Aware_Reward_Guided_Alignment.md|ReAlign (AAAI_2026)]]、[[analysis/arxiv_2026/MoGeFlow_Flowing_Through_Motion_Codebook_Geometry_for_Text-to-Motion_Generation.md|MoGeFlow (arxiv_2026)]]、[[analysis/arxiv_2026/Reconstruction-Anchored_Diffusion_Model_for_Text-to-Motion_Generation.md|Reconstruction-Anchored Diffusion (arxiv_2026)]]、[[analysis/arxiv_2026/MultiAct_Text-to-Motion_Generation_from_Composite_Text_via_Tailored_Attention_Guidance.md|MultiAct (arxiv_2026)]] 的推理时注意力 guidance。
4. **偏好/RL 后训练对齐**：用 VLM、检索器、TMR、物理 verifier 或人类偏好代理构造 reward/preference，再通过 DPO、IPO、PPO、DDPO、GRPO、EasyTune 等优化生成器。代表是 [[analysis/CVPR_2025/AToM_Aligning_Text_to_Motion_Model_at_Event_Level_with_GPT_4Vision_Reward.md|AToM (CVPR_2025)]]、[[analysis/arxiv_2024/MoDiPO_text-to-motion_alignment_via_AI-feedback-driven_Direct_Preference_Optimization.md|MoDiPO (arxiv_2024)]]、[[analysis/arxiv_2024/MotionRL_Align_Text-to-Motion_Generation_to_Human_Preferences_with_Multi-Reward_Reinforcement_Learning.md|MotionRL (arxiv_2024)]]、[[analysis/NEURIPS_2025/SoPo_Text_to_Motion_Generation_Using_Semi_Online_Preference_Optimization.md|SoPo (NEURIPS_2025)]]、[[analysis/arxiv_2026/MotionRFT_Unified_Reinforcement_Fine-Tuning_for_Text-to-Motion_Generation.md|MotionRFT (arxiv_2026)]]、[[analysis/arxiv_2025/HY_Motion_1_0_Scaling_Flow_Matching_Models_for_Text_To_Motion_Generation.md|HY-Motion (arxiv_2025)]]、[[analysis/WACV_2026/No_MoCap_Needed_Post-Training_Motion_Diffusion_Models_with_Reinforcement_Learning_using_Only_Textual_Prompts.md|No MoCap Needed (WACV_2026)]]、[[analysis/arxiv_2026/PhysMoDPO_Physically-Plausible_Humanoid_Motion_with_Preference_Optimization.md|PhysMoDPO (arxiv_2026)]]。

对你提到的担心，结论是：**[[analysis/CVPR_2026/CMDM_HP.md|CMDM-HP (CVPR_2026)]]/MAC-VAE 不是简单“整段文本到整段动作”的黑箱拟合，但它也不是 [[analysis/CVPR_2026/MoLingo_Motion_Language_Alignment_for_Text_to_Human_Motion_Generation.md|MoLingo (CVPR_2026)]] 式显式 motion-token semantic labeling**。[[analysis/CVPR_2026/CMDM_HP.md|CMDM-HP (CVPR_2026)]] 通过因果潜在空间、word-level DistilBERT 条件、Part-TMR 表征对齐、因果 DiT/FSS 去做流式与表示级语义对齐；它缓解了整段 pair 对齐的欠约束，但没有像 SAE 那样给每个 motion token 绑定 BABEL frame-level semantic label。因此两者的差别是“因果序列表示对齐”与“局部 token-label 语义监督”的差别。

## [[analysis/CVPR_2026/CMDM_HP.md|CMDM-HP (CVPR_2026)]] 与 [[analysis/CVPR_2026/MoLingo_Motion_Language_Alignment_for_Text_to_Human_Motion_Generation.md|MoLingo (CVPR_2026)]] 的差异

[[analysis/CVPR_2026/MoLingo_Motion_Language_Alignment_for_Text_to_Human_Motion_Generation.md|MoLingo (CVPR_2026)]] 的核心是 **SAE = VAE latent motion token + frame-level semantic label embedding**。它利用 BABEL frame-level label 和 T5 label embedding，对每个运动潜在 token 施加余弦语义对齐；再用 multi-token cross-attention 增强文本条件。这条路线的优点是局部语义锚点清晰，适合分析“哪个 motion token 表示哪个动作语义”；弱点是依赖可获得的动作标签/分段标注，开放域语义覆盖受标签体系限制。

[[analysis/CVPR_2026/CMDM_HP.md|CMDM-HP (CVPR_2026)]]/MAC-VAE 的核心是 **因果 latent representation + text-motion representation alignment**。KB 中 [[analysis/CVPR_2026/CMDM_HP.md|CMDM-HP (CVPR_2026)]] 的 `core_operator` 指向“语义对齐的因果潜在空间、因果扩散强制、帧级采样调度”，`primary_logic` 指向“在运动-语言对齐的因果潜在空间中融合扩散质量与自回归因果性”。它不是直接给 token 贴 label，而是在 VAE latent、Part-TMR 表征、word embedding 与因果生成过程之间建立更适合 streaming/autoregressive generation 的表示空间。

所以 [[analysis/CVPR_2026/CMDM_HP.md|CMDM-HP (CVPR_2026)]] 不应被理解为只学“整句-整段”的映射。更准确地说，它主要在**序列因果结构和全局/表征级 text-motion pair alignment**上解决 streaming generation；但如果研究问题是“动作单元是否被显式语义命名、能否局部替换/诊断/修复”，[[analysis/CVPR_2026/MoLingo_Motion_Language_Alignment_for_Text_to_Human_Motion_Generation.md|MoLingo (CVPR_2026)]]/[[analysis/WACV_2026/SegMo_Segment-aligned_Text_to_3D_Human_Motion_Generation.md|SegMo (WACV_2026)]]/[[analysis/WACV_2026/ATM_Enhanced_Alignment_for_Text-to-Motion_Generation.md|ATM (WACV_2026)]]/[[analysis/ECCV_2024/Local_Action-Guided_Motion_Diffusion_Model_for_Text-to-Motion_Generation.md|Local Action-Guided (ECCV_2024)]] 更接近这条问题线。

这些工作把 T2M 从“caption-to-motion”推向“instruction-following motion model”。[[analysis/ICLR_2026/Motion_R1_Enhancing_Motion_Generation_via_Decomposed_CoT_and_Reinforcement_Learning_Binding.md|Motion-R1 (ICLR_2026)]] 自动生成 decomposed CoT，并用 GRPO 绑定格式、运动相似和语义相似奖励。[[analysis/arxiv_2026/UniMo_Unified_Motion_Generation_and_Understanding_with_Chain_of_Thought.md|UniMo (arxiv_2026)]] 用渲染视频和 VLM 产生 motion-consistent CoT，再以 GRPO 优化 motion token group。[[analysis/arxiv_2025/OmniMoGen.md|OmniMoGen (arxiv_2025)]] 把多种动作任务统一为 interleaved text-motion instruction，并用 SFT + GRPO 训练统一自回归模型。

**[[analysis/arxiv_2025/CASIM_Composite_Aware_Semantic_Injection_for_Text_to_Motion_Generation.md|CASIM (arxiv_2025)]] / [[analysis/arxiv_2026/Exploring_Motion-Language_Alignment_for_Text-driven_Motion_Generation.md|Exploring MLA (arxiv_2026)]] / [[analysis/arxiv_2026/MultiAct_Text-to-Motion_Generation_from_Composite_Text_via_Tailored_Attention_Guidance.md|MultiAct (arxiv_2026)]] / [[analysis/arxiv_2026/Motion-Adapter_A_Diffusion_Model_Adapter_for_Text-to-Motion_Generation_of_Compound_Actions.md|Motion-Adapter (arxiv_2026)]]**  
这一组关注复合文本中“哪些词被忽略”。[[analysis/arxiv_2025/CASIM_Composite_Aware_Semantic_Injection_for_Text_to_Motion_Generation.md|CASIM (arxiv_2025)]] 用 composite-aware text encoder 和 dynamic text-motion aligner，让每帧关注所有文本 token。[[analysis/arxiv_2026/Exploring_Motion-Language_Alignment_for_Text-driven_Motion_Generation.md|Exploring Motion-Language Alignment (arxiv_2026)]] 指出 cross-attention 容易出现 attention sink，并用 sink-mask/sink-ctrl 调节。[[analysis/arxiv_2026/MultiAct_Text-to-Motion_Generation_from_Composite_Text_via_Tailored_Attention_Guidance.md|MultiAct (arxiv_2026)]] 在推理时增强 underrepresented token 的 cross-attention，并用 ParamGate 选择参数。[[analysis/arxiv_2026/Motion-Adapter_A_Diffusion_Model_Adapter_for_Text-to-Motion_Generation_of_Compound_Actions.md|Motion-Adapter (arxiv_2026)]] 用解耦 attention map 生成 body-part structural mask，在去噪早期引导复合动作。

**[[analysis/WACV_2026/SegMo_Segment-aligned_Text_to_3D_Human_Motion_Generation.md|SegMo (WACV_2026)]] / [[analysis/WACV_2026/ATM_Enhanced_Alignment_for_Text-to-Motion_Generation.md|ATM (WACV_2026)]] / [[analysis/ECCV_2024/Local_Action-Guided_Motion_Diffusion_Model_for_Text-to-Motion_Generation.md|Local Action-Guided (ECCV_2024)]] / [[analysis/VISUAL_INTELLIGENCE_2026/Temporal_Consistency-Aware_Text-to-Motion_Generation.md|TCA-T2M (VISUAL_INTELLIGENCE_2026)]]**  
[[analysis/WACV_2026/SegMo_Segment-aligned_Text_to_3D_Human_Motion_Generation.md|SegMo (WACV_2026)]] 把文本和 motion 分成语义一致 segment，做样本内段级对比。[[analysis/WACV_2026/ATM_Enhanced_Alignment_for_Text-to-Motion_Generation.md|ATM (WACV_2026)]] 挖掘 inter-motion 语义矛盾和 intra-motion 局部语义代理，在没有局部文本标注时细化对齐边界。[[analysis/ECCV_2024/Local_Action-Guided_Motion_Diffusion_Model_for_Text-to-Motion_Generation.md|Local Action-Guided (ECCV_2024)]] 把全局描述拆成 local actions，用图注意力学习每个局部动作的 guidance weight，并在扩散能量函数中施加动作级引导。[[analysis/VISUAL_INTELLIGENCE_2026/Temporal_Consistency-Aware_Text-to-Motion_Generation.md|TCA-T2M (VISUAL_INTELLIGENCE_2026)]] 用 temporal cycle consistency 对齐同类动作的时序阶段，使 VQ-VAE latent 捕捉更稳定的动作语义核心。

**[[analysis/WACV_2025/ReinDiffuse_Crafting_Physically_Plausible_Motions_with_Reinforced_Diffusion_Model.md|ReinDiffuse (WACV_2025)]] / [[analysis/WACV_2026/No_MoCap_Needed_Post-Training_Motion_Diffusion_Models_with_Reinforcement_Learning_using_Only_Textual_Prompts.md|No MoCap Needed (WACV_2026)]] / [[analysis/arxiv_2026/PhysMoDPO_Physically-Plausible_Humanoid_Motion_with_Preference_Optimization.md|PhysMoDPO (arxiv_2026)]]**  
这条线偏物理与后训练。[[analysis/WACV_2025/ReinDiffuse_Crafting_Physically_Plausible_Motions_with_Reinforced_Diffusion_Model.md|ReinDiffuse (WACV_2025)]] 把 MDM 重参数化为高斯策略，用 PPO 优化滑步、浮空、穿地等物理 reward。[[analysis/WACV_2026/No_MoCap_Needed_Post-Training_Motion_Diffusion_Models_with_Reinforcement_Learning_using_Only_Textual_Prompts.md|No MoCap Needed (WACV_2026)]] 用 DDPO 和 TMR 语义相似度 reward，只靠 textual prompts 后训练 motion diffusion。[[analysis/arxiv_2026/PhysMoDPO_Physically-Plausible_Humanoid_Motion_with_Preference_Optimization.md|PhysMoDPO (arxiv_2026)]] 用 WBC 作为黑盒物理 verifier 构造偏好数据，再用 DPO 优化生成器，使生成动作在物理跟踪后仍保持任务一致。

## 研究空缺

**1. 局部语义监督仍不够闭环。**  
[[analysis/CVPR_2026/MoLingo_Motion_Language_Alignment_for_Text_to_Human_Motion_Generation.md|MoLingo (CVPR_2026)]] 有 token-label 对齐，[[analysis/WACV_2026/SegMo_Segment-aligned_Text_to_3D_Human_Motion_Generation.md|SegMo (WACV_2026)]]/[[analysis/WACV_2026/ATM_Enhanced_Alignment_for_Text-to-Motion_Generation.md|ATM (WACV_2026)]]/[[analysis/ECCV_2024/Local_Action-Guided_Motion_Diffusion_Model_for_Text-to-Motion_Generation.md|Local Action-Guided (ECCV_2024)]] 有 segment/local action 线索，但多数 RL/preference 工作仍在 sequence/event reward 层面优化。局部动作错因很难被 reward 分解出来。

**2. text token 与 motion unit 的边界不稳定。**  
MATE、[[analysis/WACV_2026/SegMo_Segment-aligned_Text_to_3D_Human_Motion_Generation.md|SegMo (WACV_2026)]]、[[analysis/WACV_2026/ATM_Enhanced_Alignment_for_Text-to-Motion_Generation.md|ATM (WACV_2026)]] 都在处理局部文本与 motion segment 的对应，但这依赖分段、检索、attention 或弱监督代理。对于复合动作、并行动作、身体部位动作，边界误差会直接污染 alignment signal。

**3. 推理式 planning 与执行语义之间存在断层。**  
[[analysis/ICLR_2026/Motion_R1_Enhancing_Motion_Generation_via_Decomposed_CoT_and_Reinforcement_Learning_Binding.md|Motion-R1 (ICLR_2026)]]、[[analysis/arxiv_2026/UniMo_Unified_Motion_Generation_and_Understanding_with_Chain_of_Thought.md|UniMo (arxiv_2026)]]、[[analysis/arxiv_2025/OmniMoGen.md|OmniMoGen (arxiv_2025)]]、[[analysis/arxiv_2025/Think_Before_You_Move_Latent_Motion_Reasoning_for_Text-to-Motion_Generation.md|Think Before You Move (arxiv_2025)]] 能让模型更会“解释”和“规划”，但 CoT/latent plan 是否逐项落到 motion primitive 上，仍需要局部可验证指标。

**4. 采样期 guidance 与训练期语义空间尚未统一。**  
[[analysis/AAAI_2026/ReAlign_Text_to_Motion_Generation_via_Step_Aware_Reward_Guided_Alignment.md|ReAlign (AAAI_2026)]]、[[analysis/arxiv_2026/MultiAct_Text-to-Motion_Generation_from_Composite_Text_via_Tailored_Attention_Guidance.md|MultiAct (arxiv_2026)]]、[[analysis/arxiv_2026/Reconstruction-Anchored_Diffusion_Model_for_Text-to-Motion_Generation.md|Reconstruction-Anchored Diffusion (arxiv_2026)]]、[[analysis/arxiv_2026/MoGeFlow_Flowing_Through_Motion_Codebook_Geometry_for_Text-to-Motion_Generation.md|MoGeFlow (arxiv_2026)]] 能在采样轨迹中修正分布，但 guidance 多半依赖外部 reward、attention 或 codebook geometry。它们改善输出，却不一定让内部 motion representation 获得稳定语义结构。

**5. 奖励目标之间存在冲突。**  
语义一致、自然性、物理可行、风格、速度、轨迹约束不总是同向。[[analysis/arxiv_2024/MotionRL_Align_Text-to-Motion_Generation_to_Human_Preferences_with_Multi-Reward_Reinforcement_Learning.md|MotionRL (arxiv_2024)]]/[[analysis/NEURIPS_2025/SoPo_Text_to_Motion_Generation_Using_Semi_Online_Preference_Optimization.md|SoPo (NEURIPS_2025)]]/[[analysis/arxiv_2026/MotionRFT_Unified_Reinforcement_Fine-Tuning_for_Text-to-Motion_Generation.md|MotionRFT (arxiv_2026)]]/[[analysis/arxiv_2025/HY_Motion_1_0_Scaling_Flow_Matching_Models_for_Text_To_Motion_Generation.md|HY-Motion (arxiv_2025)]] 试图做多目标折中，但还缺少能解释“哪一个动作单元牺牲了哪一个目标”的诊断工具。

**6. 评估仍偏全局。**  
R-Precision、FID、MModality、TMR similarity、VLM score 能反映整体质量，但对“文本里第二个动作是否发生”“左手动作是否对应正确 token”“两个动作是否时间上先后正确”这类局部 alignment 仍不敏感。

## 对后续选题的启发

如果目标是做出区别于现有工作的贡献，最有价值的问题不是再做一个全局 reward，而是把 **local semantic unit、causal temporal phase、reward credit assignment** 串起来：

- 用 [[analysis/CVPR_2026/MoLingo_Motion_Language_Alignment_for_Text_to_Human_Motion_Generation.md|MoLingo (CVPR_2026)]]/[[analysis/WACV_2026/SegMo_Segment-aligned_Text_to_3D_Human_Motion_Generation.md|SegMo (WACV_2026)]]/[[analysis/ECCV_2024/Local_Action-Guided_Motion_Diffusion_Model_for_Text-to-Motion_Generation.md|Local Action-Guided (ECCV_2024)]] 这类局部语义信号定义 motion unit；
- 用 [[analysis/CVPR_2026/CMDM_HP.md|CMDM-HP (CVPR_2026)]]/[[analysis/VISUAL_INTELLIGENCE_2026/Temporal_Consistency-Aware_Text-to-Motion_Generation.md|TCA-T2M (VISUAL_INTELLIGENCE_2026)]] 这类因果/时序结构约束 motion unit 的时间演化；
- 用 [[analysis/AAAI_2026/ReAlign_Text_to_Motion_Generation_via_Step_Aware_Reward_Guided_Alignment.md|ReAlign (AAAI_2026)]]/[[analysis/arxiv_2026/MotionRFT_Unified_Reinforcement_Fine-Tuning_for_Text-to-Motion_Generation.md|MotionRFT (arxiv_2026)]]/[[analysis/WACV_2026/No_MoCap_Needed_Post-Training_Motion_Diffusion_Models_with_Reinforcement_Learning_using_Only_Textual_Prompts.md|No MoCap Needed (WACV_2026)]] 这类 reward-guided 或 RL 后训练，把全局 reward 分解到 token、segment、body part 或 temporal phase；
- 最后用局部 evaluation 验证复合 prompt 中每个动作单元是否被生成、顺序是否正确、身体部位是否正确、属性是否没有泄漏。

这条路线相比“整段文本-整段动作偏好优化”更可能回答你关心的问题：模型到底有没有学到动作单元语义，而不是只学会在整体嵌入空间中靠近文本。
