# Idea Vault

`obsidian-vault/ideas/` stores downstream idea notes, focused plans, reviewer
critiques, and experiment-planning records.

The public repository tracks this guide only. Personal idea notes should stay
local unless they are intentionally exported as share-ready Markdown.
