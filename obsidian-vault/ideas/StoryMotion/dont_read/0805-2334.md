当前版本相比 v2-pre 已经有明显进步，但从全量统计看，**问题已经不再是“怎么把相邻 interval 多合并一点”，而是“什么才应该被称为一个 Camera event”**。H0/H1 的统计几乎一致，S2/S3 把同轴 gap 从 1 放宽到 2/3 step 也只带来约 0.3–0.5 个百分点的改善，B2 再放宽跨轴边界只能多获得约 3 个百分点，而且已经有异阶段过合并风险。这说明继续调 hysteresis、gap 或 B1/B2，不可能从根本上把 captionable 样本的 `K≤6` 从约 88% 提升到可靠水平。

最需要修改的是当前这条隐含等式：

[
G_{\text{text}}=G_{\text{salient}}.
]

它把“几何上真实且不算特别微弱的局部变化”全部要求写进短文本，结果必然是：速度波动被拆成多个 event、一次主运动中的小回调被当成 reversal、长 dolly 中的局部 pan 被当成平级 event。更合理的分层应当是：

[
E_{\text{axis-present}}
\rightarrow
E_{\text{excursion}}
\rightarrow
P_{\text{camera-phase}}
\rightarrow
P_{\text{core}}
\rightarrow
P_{\text{text}}.
]

其中 `axis-present` 仍然是完整、不可删除的数值事实；`excursion` 消除同一轴上的碎片；`camera-phase` 表示一个自洽的摄影阶段；`core` 是短文本必须表达的核心意图；其余真实但次要的变化记录为 residual，而不是误判成 noise。Event-T2M 值得借鉴的也正是“event 是能映射到连续运动片段的最小、自洽语义单元”，而不是每个动词、每个轴或每次阈值越界都单独计数。它的论文没有为 Pulp 提供可继承的 event 数量上限；官方实现中的 `max_len=11` 只是固定 tensor 容量，代码也没有为超过 11 的输入实现截断或合并。([arXiv][1]) 

你现在应当在 H0/H1 axis interval 之后，加入一层 **cumulative-excursion consolidation，累计位移游程归并**。对每个轴，不再只看若干独立 rate intervals，而是从 step 增量构造累计位置或累计角度：

[
q_{a,t}
=======

\sum_{\tau <t}\Delta x_{a,\tau}.
]

一个轴级语义动作应当对应 (q_a(t)) 上的一次有意义的单调游程，而不是 rate 曲线每次跌破 (T_{\rm exit}) 后都重新计数。它能系统处理三种当前最常见的碎片。

第一种是同方向多段运动：

```text
pan right → 短暂停顿 → pan right
```

只要累计曲线仍然保持总体向右，没有显著向左回撤，就合成一个 `pan_right` excursion，并记录：

```text
temporal_pattern = intermittent
support_intervals = [[0, 8], [12, 19]]
```

这样没有篡改暂停事实，但文本事件只算一次，可以描述为 “the camera intermittently pans right” 或更简单的 “the camera pans right”。

第二种是主运动中的微小反向修正：

```text
pan right → 很短的 pan left → pan right
```

当前规则容易把它变成三个 salient events和两个 reversal。建议为中间反向 excursion 定义“回撤比例”：

[
r_{\mathrm{corr}}
=================

\frac{A_{\mathrm{opposite}}}
{\min(A_{\mathrm{before}},A_{\mathrm{after}})+\epsilon},
]

其中 (A) 使用累计净角度或净位移。只有反向运动同时满足绝对幅度和相对幅度门槛，才保留为真正 reversal；否则标记为：

```text
role = micro_correction
```

并将两侧同方向 excursion 合并。这样能删除“高速度但持续极短”的小回调，它们可能因为 median rate 很高而通过当前 salience，却并不构成摄影意图变化。

第三种是真正方向反转：

```text
pan right → pan left
```

若两个方向的累计幅度都超过 train-only amplitude scale，并且反向游程具有足够 prominence，则必须保留两个 excursion和 `reverses`。这里不能只使用 rate salience，因为一个很短的高速抖动和真正的反向运镜可能有相似峰值；累计幅度与回撤 prominence 才是区分二者的核心。

这层可以称为：

```text
axis interval
→ signed cumulative excursion
→ core excursion / micro correction
```

它比继续扩大 S2/S3 更系统。S2/S3 只能合并固定 2/3 step gap，而 cumulative excursion 可以合并被停顿或小修正隔开的同一整体动作，同时保留真正的大反转。

跨轴层面，当前 `complete-link + start/end 均接近` 也过于苛刻。它能合并边界几乎一致的 truck + pan，却无法处理大量“长主运动 + 短修饰运动”。例如：

```text
dolly in: 0–60
pan right: 10–20
pan left: 35–45
```

当前会得到三个 geometry events。更合理的是使用 **spine-based phase grouping，主干式摄影阶段归并**：

```text
phase g0
  primary: dolly in [0, 60]
  modifiers:
    pan right [10, 20]
    pan left [35, 45]
```

具体做法是先选择 normalized motion mass 最大的 excursion作为 phase spine，再将大部分时间位于 spine 内部的较短 excursion直接挂到该 phase 下。归并采用“每个 modifier 与 spine 直接满足关系”的 star-link，而不是 complete-link；因此两个 pan彼此不重叠，也不会妨碍它们同时属于持续 dolly 阶段。若两个轴开始和结束都近似一致，且贡献相当，则标记为 `co-primary compound`；若一个明显更长，另一个嵌套其中，则后者是 `modifier`；只有互不包含、代表新的主要运动阶段时，才产生新的 phase。

可使用：

[
\operatorname{IoS}(e_i,e_j)
===========================

\frac{|I_i\cap I_j|}
{\min(|I_i|,|I_j|)}
]

判断较短 excursion 是否基本位于 spine 中，但阈值应在 calibration 中选取。这里不建议继续只用“start/end 均相差不超过 B steps”，因为嵌套事件的 start/end 天然不会同时接近。

归并后还需要一层 **核心解释集选择**。当前 `salient` 是绝对意义上的“不是微弱运动”，但它不等于“必须写进短文本”。建议把它拆成：

```text
nontrivial_geometry
core_camera_intent
residual_adjustment
```

对每个 excursion 定义无量纲 motion mass，例如：

[
m_e
===

\max\left(
\frac{|A_e^{\mathrm{net}}|}{S_{a}^{\mathrm{amp}}},
\frac{\operatorname{median_rate}_e}{S_a^{\mathrm{rate}}}
\right),
]

phase 的质量为其 primary、co-primary 与 modifier 的质量之和。然后选择能够解释整条轨迹绝大部分 motion mass 的最小 phase/component集合：

[
C^\star
=======

\arg\min_C |C|,
\qquad
\frac{\sum_{e\in C}m_e}
{\sum_{e\in E_{\mathrm{nontrivial}}}m_e}
\ge \eta.
]

建议将

[
\eta\in{0.95,0.97}
]

作为两个 calibration 候选，而不是现在直接冻结。任何真正的大方向反转、主要 primitive切换以及与 primary 相当的复合轴，都强制进入 (C^\star)，不能被 motion-mass排序删除。被省略的 event 仍保存在完整 graph 中，并记录：

```text
role = residual_adjustment
caption_omission_reason = bounded_residual
```

正式 accepted 样本至少要满足：

[
\operatorname{ExplainedMass}\ge\eta,
]

[
\max_{e\notin C^\star}m_e
\le \tau_{\mathrm{residual}},
]

[
\operatorname{MajorReversalRecall}=1.
]

因此新的关系应当是：

[
G_{\text{text}}=G_{\text{core}},
\qquad
G_{\text{core}}\subseteq G_{\text{nontrivial}},
]

而不再是所有 salient event 都必须写入文本。这并不是制造错误标签。Camera caption描述的是核心摄影意图，而不是逐步转录每次稳定器修正；剩余 residual仍由完整 Camera target承担随机性和风格变化。关键是 residual必须被量化并受限，不能不经检查地静默遗漏。

在 event budget 上，也不应只控制一个 `K_geom`。建议同时冻结两个数量：

[
K_{\mathrm{phase}}
==================

\text{核心摄影阶段数},
]

[
K_{\mathrm{fact}}
=================

\text{这些阶段中需要表达的primitive-direction事实数}.
]

例如上面的 dolly + 两段 pan：

```text
K_phase = 1
K_fact = 3
```

这比把它计成三个完全平级 event合理，也避免把“一个含六轴动作的 phase”虚假算成复杂度 1。可以预注册：

```text
max_core_phases ∈ {3, 4}
max_core_facts  ∈ {4, 5, 6}
```

最终仍由 full-train分布和人工可读性共同决定。Event-T2M 的 4 和 11 都不应成为这里的取值依据；前者只是它的复杂度分组门槛，后者是未解释的实现容量。([arXiv][1])

对应的确定性 planner会变得更简单。例如：

```json
{
  "phase_id": "p0",
  "primary": {
    "primitive": "dolly",
    "direction": "in",
    "pattern": "continuous"
  },
  "modifiers": [
    {
      "primitive": "pan",
      "direction": "right",
      "relation": "during"
    },
    {
      "primitive": "pan",
      "direction": "left",
      "relation": "later_during"
    }
  ]
}
```

可以直接确定性生成：

> The camera dollies in throughout the shot, panning right and later left during the movement.

Qwen只进行同义改写。这样 Qwen既不需要读取 62 step，也不需要决定哪些小修正应被删除。

因此建议把当前主链调整为：

[
\boxed{
\begin{aligned}
&\text{C1REL six-axis step signals}\
\rightarrow;&\text{H0/H1 axis-present intervals}\
\rightarrow;&\text{cumulative signed excursions}\
\rightarrow;&\text{micro-correction pruning and same-direction consolidation}\
\rightarrow;&\text{spine-based camera phases}\
\rightarrow;&\text{minimal core explanatory set}\
\rightarrow;&\text{phase/fact budget}\
\rightarrow;&\text{deterministic clauses}\
\rightarrow;&\text{Qwen three-short realization}.
\end{aligned}}
]

其中 step仍然完整保留，但只服务于 interval、累计幅度、暂停、回撤和边界计算，不进入语言层。

当前 Calibration-512 也需要重新分配。原来的 192 条 threshold/duration boundary 对 H0/H1 有用，但现在全量统计已经显示 H0/H1差异不大，而真正不确定的是“哪些碎片应归为一个核心 event”。建议在不增加总数的情况下改为：

| stratum                        | 建议数量 | 主要判断                         |
| ------------------------------ | ---: | ---------------------------- |
| uniform random                 |  160 | 全局无偏正确率                      |
| threshold / weak / static      |   80 | H0/H1 与 salience             |
| same-direction multi-burst     |   80 | 是否应合成 intermittent excursion |
| micro-reversal / true reversal |   64 | correction 与真实 reversal      |
| long-spine + nested modifiers  |   64 | phase spine与modifier         |
| genuine multi-phase / long K>5 |   64 | 是否发生过度压缩                     |

raw-text conflict不需要占据第一轮 geometry calibration配额，可以放到 P4 language review。人工标注项应增加：

```text
same_core_event
separate_core_event
micro_correction
modifier
co_primary
independent_phase
uncertain
```

建议分阶段选择参数，避免重新产生大网格。先单独选 H0/H1；然后在冻结 H 上比较四套 semantic consolidation候选，由两个全局轴组成：

[
\tau_{\mathrm{correction}}
\in
{0.5,1.0}\times S_a^{\mathrm{amp}},
]

[
\theta_{\mathrm{attach}}
\in
{\text{strict},\text{relaxed}},
]

其中 strict/relaxed 的具体 IoS值在展示人工结果前预注册。选择依据不是谁的 event count最低，而是：

[
\text{false core merge},
\quad
\text{false core split},
\quad
\text{major reversal recall},
\quad
\text{explained motion mass},
\quad
K_{\mathrm{phase}}/K_{\mathrm{fact}}.
]

最后才在胜出的 semantic rule上比较 (\eta=0.95/0.97) 和文本预算。这样不会让 H0/H1、fragment pruning、phase grouping和 budget同时互相补偿。

VLM 不建议继续以 `K_geom>5` 为触发器直接决定 keep/noise/merge。它看到的是带 Human content 的视频，容易把人物运动和 Camera motion混淆，而且会成为隐藏的几何标注器。更合理的触发条件是：

```text
semantic_consolidation_ambiguous = true
```

例如两个候选方案的 explained mass几乎相同、某个反向 event正好位于 correction门槛附近，或者 core phase数量仍超预算。VLM最多做冻结候选 A/B 的偏好与 `uncertain`，不能自由创建或删除 primitive；主 canonical path仍应是确定性的。这也保持了 Paper A 只处理 Camera-local extrinsics语义、而不把 Human-relative判断提前侵入 DIRECT 的边界。

schema建议改为：

```text
camera_motion_axis_events_full
camera_motion_excursions
camera_motion_phases
camera_motion_core_phases
camera_motion_residual_events

axis_event_count
excursion_count
phase_count
core_phase_count
core_fact_count

caption_explained_motion_mass
max_residual_prominence
major_reversal_recall
semantic_consolidation_status
caption_budget_status
```

原有 `geometry_events` 可以保留为兼容字段，但正式 v2 应把 `camera_motion_phases` 作为语言规划单位。

必须对预期保持克制。当前 S0-B1 的 captionable `K≤6` 只有约 88%，说明即使新的机制有效，也还需要削减约 8–9 个百分点的复杂尾部，才能接近 95% 以上的覆盖；这不一定全部是碎片，其中一部分可能是真实的复杂 Camera trajectory。新的机制如果只能把 K≤6提高到 90% 左右，就不应继续提高 correction阈值或强行合并。此时正确结论是：约 10% 的 Pulp镜头不适合用三条 short完整表达，应进入 `complex_caption` 或 `overflow_abstain`，而不是把真实多阶段运镜洗成简单动作。

所以当前最合理的裁决是：**保留 H0/H1 和完整 axis graph，暂停继续扩大 S/B 合并；新增“累计游程归并—主干摄影阶段—核心解释集”三层机制。** 真正要削减的不是数值事实，而是把速度碎片、微小修正和嵌套 modifier错误计为平级 Camera event 的语义粒度。
