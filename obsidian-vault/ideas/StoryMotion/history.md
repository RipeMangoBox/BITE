## 2. 相似目的的版本片段

### Retrain tokenizer family

`v7.5 → v7.6–v7.8 → v7.12 → v7.13 → v7.14` 都在问“是否需要重新训练 tokenizer”，但不是同一个实验：

- v7.5 问 clean data hygiene；
- v7.6–v7.8 问 local objective、causal/non-causal、VAE 与 quantizer family；
- v7.12 问 separate branch representation；
- v7.13 问 joint branch representation；
- v7.14 才第一次同时闭合 feature、camera14、non-causal、owning decoder 和 official callback contract。

因此这些版本不能用一张旧的 FDTMR 表直接排序。当前唯一可用于 Stage2 promotion 的 local Stage1 evidence 是 v7.14 corrected contract；v7.6 的“看起来更好”属于旧 contract 下的视觉/工程历史，不能作为 official tokenizer 或 `ae_train_split` 的单变量对照。

### Stage2 coupling / reliability family

`v5.1 → v6.1–v6.4 → v7.2–v7.4` 大多固定 official Pulp tokenizer，主要改变 observed branch、task routing、noise/replay、relation 和 asymmetric sampling。它们回答的是 Stage2 condition dependency，不回答 local tokenizer 是否适合 diffusion。v6 pure official unified 是历史 reference；v7.17 local failure 是另一条 representation/objective 诊断线，不能混为同一 ranking。
