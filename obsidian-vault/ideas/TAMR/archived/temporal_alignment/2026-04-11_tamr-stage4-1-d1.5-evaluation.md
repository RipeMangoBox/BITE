# TAMR Stage4.1 D1.5 Evaluation

## Scope

- Goal: run the D1.5 control where the only intended model change vs D1 is `attention pooling -> uniform temporal pooling` for event representation.
- Run dir: `RUN_DIR/stage4_1_d1_5`
- Date: `2026-04-11`

## Training Config

- Model: `tmr_d1_5`
- Dataset: `humanml3d_e`
- Warm-start: `models/tmr_humanml3d_guoh3dfeats/last_weights`
- Frozen modules: motion backbone, text encoder, motion decoder
- Event loss: same masked InfoNCE definition as D1
  - cross-sample negatives kept
  - same-sample non-self events are masked out as negatives
- Event pooling: uniform temporal pooling under motion mask
- Optimizer: `AdamW`
- Learning rate: `1e-4`
- Batch size: `32`
- Max epochs: `100`
- Device: `1 GPU`

### Commands

```bash
conda run -n TMR python train.py \
  model=tmr_d1_5 \
  data=humanml3d_e \
  run_dir=RUN_DIR/stage4_1_d1_5 \
  dataloader.batch_size=32 \
  dataloader.num_workers=0 \
  trainer.accelerator=gpu \
  trainer.devices=1 \
  trainer.max_epochs=100 \
  trainer.log_every_n_steps=20
```


## Conclusion

- `val_evt_align_acc` gap is much larger than 5%.
- Best-gap: `22.82` percentage points.
- Last-gap: `22.82` percentage points.
- Conclusion: **attention has substantive gain**.

The retrieval metrics stay unchanged because this control does not modify the frozen global text/motion encoders used by `retrieval.py`; it only changes the event-time pooling inside the D1 event head.

## Recommendation

- **Go D2.**
- D1.5 answers the intended control question clearly: attention pooling is not a cosmetic choice and materially improves event alignment.
- If D2 later shows instability or weak event-level gains, the next thing to try is event-head regularization or temperature tuning, but D1.5 does not justify pausing before D2.
