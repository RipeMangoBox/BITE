## 概要

现有文本驱动的图像编辑方法通常依赖编辑掩码，难以实现大幅度的视觉变化，且难以在编辑区域保持原图的特定细节。**UniTune** 的核心思路是将图像生成模型通过单张图像微调转化为图像编辑器：在单张（图像，提示）对上微调大型扩散模型并不会导致灾难性遗忘，模型仍保留其视觉与语义知识。在此基础上，结合从噪声图像初始化的采样过程与基于像素邻域相似度的插值后处理，可在不牺牲保真度的前提下实现广泛的文本驱动编辑。

人类评估结果显示，在包含93对（基础图像，编辑提示）的数据集上，UniTune 的整体偏好以 72% vs 28% 显著优于 SDEdit；在需要大幅像素变化的非对齐编辑上优势更为突出（83% vs 17%）。在质量、保真度和文本对齐三项评分上，UniTune 亦全面领先。该方法无需编辑掩码即可进行局部与全局编辑，为基于扩散模型的通用图像编辑提供了新的范式。

## 核心方法与创新机理

UniTune 的核心洞察在于：**在单张图像上微调一个大规模文本到图像扩散模型，并不会导致灾难性遗忘**。微调后的模型虽然被偏置向该基础图像，却仍保留了其预训练阶段习得的丰富视觉先验与语义理解能力。这一发现将原本作为生成器的扩散模型，转化为一个仅需文本指令即可编辑任意图像的编辑器。

### 核心瓶颈与解决思路

现有文本驱动的图像编辑方法面临两个根本性难题：其一，依赖用户提供的编辑掩码来限定修改区域，这既增加了交互负担，又难以处理需要全局像素变化的大幅度编辑；其二，在追求编辑表达力的同时，如何保持对原始图像的高保真度——尤其是在非编辑区域，或当编辑指令要求显著改变像素分布时。

UniTune 通过一个两阶段框架突破上述瓶颈：
1. **微调阶段**：在基础图像上微调扩散模型，使其输出分布向该图像靠拢；
2. **修改采样阶段**：利用微调后的模型，结合噪声初始化、高权重无分类器引导（CFG）和像素后处理，在保真度与表达力之间取得平衡。

### 方法框架与模块顺序

UniTune 的完整管线由以下模块串联构成：

**基础模型栈**（预训练，不参与微调的核心部分）：
- T5-XXL 文本编码器：将文本提示嵌入为条件向量；
- 64×64 基础文本到图像扩散模型：生成低分辨率图像；
- 256×256 和 1024×1024 级联超分辨率模型：逐步上采样至最终分辨率。

**微调阶段**（仅作用于 64×64 和 256×256 模型）：
- 在单张基础图像 $\mathbf{x}^{(b)}$ 上，使用去噪损失进行参数更新；
- 条件文本 $c^{(b)}$ 由 3 个稀有 token 拼接构成，形成一个在原始训练数据中几乎不存在的“稀有词”，从而避免与模型已有语义产生冲突。

**修改采样阶段**：
- 从基础图像的噪声版本初始化潜变量；
- 拼接稀有 token 条件与编辑提示，施以高权重 CFG 引导反向去噪；
- 基于像素邻域相似度的线性插值，融合生成图像与基础图像的细节。

### 关键公式与变量含义

**微调损失函数**（Eq. 1）：

$$\mathbb{E}_{\epsilon,t}\big[w_t \| f_{\theta}(\alpha_t \mathbf{x}^{(b)} + \sigma_t \epsilon, c^{(b)}) - \epsilon \|_2^2 \big]$$

其中 $f_{\theta}$ 为预训练扩散模型，$\mathbf{x}^{(b)}$ 为基础图像，$\alpha_t$ 和 $\sigma_t$ 为扩散过程的噪声调度参数，$\epsilon \sim \mathcal{N}(0, \mathbf{I})$ 为标准高斯噪声，$c^{(b)}$ 为稀有 token 条件，$w_t$ 为时间步权重。该损失驱动模型学习在条件 $c^{(b)}$ 下精确复现基础图像。实验表明，约 64 步迭代后模型即可忠实再现原始图像（Fig. 3）。

![[assets/figures/papers/paper_list_l8_https_arxiv_org_abs_2210_09477/figures/003_Figure_3.jpg]]
*Figure 3: The images generated by the model conditioned on the tokens it was trained on after different number of fine tuning iterations. It takes around 64 iterations for the model to be able to faithfully reproduce the original image. Input source: Unsplash*

**采样初始化公式**（Eq. 2）：

$$z_t = \alpha_t \mathbf{x}^{(b)} + \sigma_t \boldsymbol{\epsilon}$$

该式利用扩散模型的正向过程，将基础图像与噪声在时间步 $t$ 混合，生成中间噪声潜变量 $z_t$，作为反向采样过程的起点。$t$ 的取值范围为 $0.8 \leq t \leq 0.98$，即从扩散过程的中间阶段开始去噪，而非从纯随机噪声（$t=1$）开始。这一设计使得采样起点已携带基础图像的大量结构信息，从而在后续去噪中自然保持视觉保真度。

### 三个关键 Changed Slots 及其因果机制

**Changed Slot 1：模型权重——从通用生成器到图像专用编辑器**

基线方法使用冻结的预训练扩散模型（如 Imagen），通过调整采样策略（如 SDEdit）或依赖掩码（如 Glide、Blended Latent Diffusion）来实现编辑。UniTune 的核心改变在于**修改模型权重本身**：在单张基础图像上微调 $f_{\theta} \rightarrow f_{\theta^{*}}$，使模型的输出分布被偏置向该图像。

因果链条：微调使模型“记住”了基础图像在稀有 token 条件下的外观，但并未丧失其对其他语义概念的生成能力。当采样时使用编辑提示（如“一只戴着墨镜的猫”）替代微调时的稀有 token 条件，模型会尝试在“复现基础图像”与“响应编辑提示”之间取得平衡——这正是编辑行为产生的根源。微调迭代次数成为控制这一平衡的关键参数：过少则模型无法忠实再现基础图像，过多则模型过度记忆而难以响应编辑指令。

**Changed Slot 2：采样初始化——从纯噪声到噪声基础图像**

基线扩散模型采样通常从 $t=1$ 的纯高斯噪声开始。UniTune 改为从中间时间步 $t$（$0.8 \leq t \leq 0.98$）开始，且初始潜变量 $z_t$ 由基础图像经正向扩散加噪得到（Eq. 2），而非随机采样。

因果链条：从噪声基础图像开始的采样，其初始潜变量已编码了基础图像的低频结构（如布局、主体轮廓）。后续去噪过程中，模型只需在保留这些结构的基础上，根据编辑提示修改局部或全局特征。这与 SDEdit 的核心理念相似，但 UnitiTune 的关键差异在于：微调后的模型 $f_{\theta^{*}}$ 对基础图像的“记忆”使得即使在较高的 $t$ 值（更接近纯噪声）下开始采样，仍能恢复出高保真度的基础图像内容。消融网格（Fig. 14）清晰展示了微调迭代次数与初始采样步 $t$ 的协同作用：两者共同决定了编辑结果在“忠实于原图”与“响应编辑指令”之间的位置。

**Changed Slot 3：条件机制与 CFG 权重——从单条件到双条件对抗引导**

基线方法仅使用编辑提示作为条件。UniTune 在采样时使用拼接条件：将微调时的稀有 token 条件 $c^{(b)}$ 与编辑提示串联，并施加无分类器引导（CFG）。

因果链条：CFG 机制在每一步去噪时，计算有条件预测与无条件预测的差值，并沿该方向外推。当条件为拼接的“稀有 token + 编辑提示”时，高 CFG 权重（文中选取 32）会放大编辑提示的影响，使生成结果偏离微调记忆而向编辑指令靠拢。Fig. 4 展示了 CFG 权重的调节效果：权重过低时，模型倾向于复现基础图像；权重过高时，模型完全响应编辑提示但丧失保真度；权重 32 在实验中取得了最佳平衡。

### 像素后处理模块的补充作用

在采样生成编辑图像后，UniTune 引入一个轻量级的像素后处理步骤：计算生成图像与基础图像在每个像素邻域的相似度，并据此进行线性插值。相似度高的区域（即编辑未涉及的背景或细节）更多地采用基础图像的原始像素，从而修复生成过程中可能丢失的精细纹理（如文字、面部细节）。Fig. 5 展示了该插值步骤对视觉质量的提升效果。这一模块并非编辑能力的核心来源，而是作为保真度的“安全网”，弥补扩散模型在细节复现上的不足。

### 训练与推理路径总结

**训练路径**：取预训练扩散模型 $f_{\theta}$，在单张基础图像 $\mathbf{x}^{(b)}$ 和固定稀有 token 条件 $c^{(b)}$ 上，使用 Eq. 1 的去噪损失进行微调（约 64-128 步），得到 $f_{\theta^{*}}$。仅微调 64×64 和 256×256 模型，1024×1024 超分辨率模型和文本编码器保持冻结。

**推理路径**：
1. 将基础图像 $\mathbf{x}^{(b)}$ 按 Eq. 2 加噪至时间步 $t$，得到 $z_t$；
2. 以拼接条件（稀有 token + 编辑提示）和 CFG 权重 32，从 $z_t$ 开始反向去噪至 $t=0$；
3. 对生成图像进行像素邻域相似度加权的线性插值，融合基础图像细节；
4. 经超分辨率级联上采样至 1024×1024。

整个方法链的因果核心可概括为：**微调赋予模型对基础图像的“记忆”，噪声初始化和 CFG 共同调节“记忆”与“编辑指令”的对抗平衡，像素插值作为保真度的兜底机制**。这三个模块的协同作用，使得 UniTune 无需任何掩码即可实现从局部对象添加（Fig. 6）到全局风格转换（Fig. 2）的广泛编辑。

## 实验与关键发现

UniTune 的实验评估围绕一个核心主张展开：通过在单张图像上微调扩散模型，可以在不依赖编辑掩码的情况下，实现比基线方法更优的保真度-表达力平衡。评估体系以人类主观评判为主，辅以消融实验揭示各控制参数的作用机制。

### 主实验结果：与 SDEdit 的全面对比

实验在自定义的 93 对（基础图像，编辑提示）数据集上进行，涵盖动物、人物、物体、食物、风景五个领域。其中一半编辑提示要求显著的像素级变化（非对齐编辑），另一半仅需较小的局部修改（对齐编辑）。主要基线为 SDEdit（Meng et al., 2021），这是当时无需掩码的任意图像编辑方法的代表。

**多数投票偏好**（Table 1）显示，UniTune 以 72% vs 28% 的整体偏好显著优于 SDEdit。这一优势在非对齐编辑场景下更为突出——当编辑需要大幅度像素变化时，UniTune 的偏好率达到 83% vs 17%，领先 66 个百分点。在对齐编辑场景下，UniTune 仍保持 60% vs 40% 的优势。这一差异模式表明，UniTune 的核心优势恰在于处理那些传统方法难以应对的大幅度视觉变化。

**分维度评分**（Table 2）进一步量化了质量差距。在 1-5 分评分体系下，UniTune 在三个维度均领先：
- 整体质量：4.14 ± 0.75 vs 3.90 ± 0.84（Δ0.24）
- 图像保真度：3.87 ± 0.75 vs 3.54 ± 0.79（Δ0.33）
- 文本对齐：4.21 ± 0.78 vs 3.89 ± 0.93（Δ0.32）

保真度维度的最大提升（Δ0.33）验证了微调策略在保持原始图像视觉细节方面的有效性，而文本对齐的提升（Δ0.32）则表明微调并未损害模型对编辑指令的响应能力。

**按语义差距分桶分析**（Table 4）将数据集按初始 CLIP 分数（编辑提示与基础图像的语义距离）分为三档。结果显示，UniTune 在不同语义差距下均保持偏好优势，但在中等语义差距区间优势最为明显——这恰好对应了那些既需要显著变化又不能完全脱离原图的编辑需求，也是实际应用中最常见的场景。

### 关键消融实验

UniTune 的设计包含三个可调控的核心参数：微调迭代次数、初始采样时间步 t₀、以及分类器自由引导（CFG）权重。消融实验揭示了这些参数之间的协同与权衡关系。

**微调迭代次数与初始采样步的网格消融**（Fig. 14）是理解方法行为的关键证据。该实验在固定编辑提示下，系统扫描了微调步数（x 轴）和初始采样步 t₀（y 轴）的组合。结果显示：
- 微调步数过低时，模型无法充分记忆基础图像，生成结果缺乏保真度；
- 微调步数过高时，模型过度偏向基础图像，难以响应编辑提示；
- 初始采样步 t₀ 控制从噪声基础图像开始反向采样的起点：t₀ 越接近 1（噪声更多），生成结果越偏离原图；t₀ 越接近 0（噪声更少），越接近原图。

两个参数形成二维控制平面：微调步数决定了模型对基础图像的“记忆强度”，t₀ 决定了采样过程从多大程度的噪声中恢复。两者协同调节保真度-表达力平衡。实验表明，约 64 步微调配合 0.8 ≤ t₀ ≤ 0.98 的初始采样步通常能取得最佳效果。

**分类器自由引导权重的独立作用**（Fig. 4）展示了 CFG 权重从低到高变化时生成结果的渐变。低 CFG 权重下，模型倾向于生成微调时记忆的内容（即基础图像）；随着 CFG 权重增大，编辑提示的影响力增强，生成结果逐渐偏离原图。实验确定 CFG 权重为 32 时取得最佳平衡——这一数值远高于常规文本到图像生成中的典型设置（通常为 7-15），说明需要更强的引导力才能克服微调带来的记忆偏向。

**像素邻域插值的附加价值**（Fig. 5）验证了后处理步骤的必要性。在生成图像中，某些基础细节（如文字、面部特征）可能因采样过程的随机性而丢失。基于像素邻域相似度的线性插值能够从基础图像中恢复这些细节，而不会引入明显的拼接痕迹。消融显示，该步骤对提升最终视觉质量有显著贡献，尤其是在需要保持非编辑区域精确细节的场景中。

**噪声初始化与微调的协同性**（Fig. 14 的跨条件对比）表明，仅使用微调或仅使用噪声初始化都不足以达到最佳效果。从随机噪声开始采样（即不使用噪声初始化）即使配合微调模型，生成结果也缺乏对原图的保真度；而仅使用噪声初始化但不微调（即 SDEdit 的思路），则无法实现大幅度的语义编辑。两者的结合是 UniTune 性能提升的关键机制。

### 与专用方法的定性比较

除了与 SDEdit 的定量对比，UniTune 还与两类专用编辑方法进行了定性比较。

**与 Text2LIVE 的比较**（Fig. 10）：Text2LIVE（Bar-Tal et al., 2022）是专为局部纹理/外观编辑设计的方法。在 Text2LIVE 支持的编辑类型上，UniTune 展示了相当的结果质量。这意味着 UniTune 作为一个通用方法，在专用方法的优势领域内也能达到相近水平，同时还能处理 Text2LIVE 无法处理的全局编辑和大幅度结构变化。

**与基于掩码的 In-painting 方法比较**（Fig. 11）：与 Glide（Nichol et al., 2021）和 Blended Latent Diffusion（Avrahami et al., 2022）的对比显示，当提供掩码时，UniTune 的 in-painting 变体（在附录 C 中描述，每步采样时用适当噪声化的基础图像替换非编辑区域）能够达到与专用 in-painting 方法相当的效果。但 UniTune 的核心优势在于无需掩码即可执行局部编辑（Fig. 6），这大幅降低了用户交互负担。

### 失败模式与适用边界

实验揭示了 UniTune 的几个实用边界条件：

1. **随机种子敏感性**：生成结果依赖于随机种子选择。实验流程中通常从 8 个种子中选取最佳结果，单次生成的成功率并非 100%。这在交互式编辑场景中可能影响用户体验。

2. **超参数手动调节负担**：微调步数、t₀、CFG 权重三个参数需要针对每次编辑手动调整。Table 3 列出了 Fig. 9 中每张图像的具体参数设置，可见不同编辑的参数差异显著。目前尚无自动化调参机制。

3. **生成速度限制**：整个流程包含微调（数十步梯度更新）和采样（扩散模型的多步反向过程），难以满足实时交互需求。

4. **极端编辑的保真度退化**：当编辑提示与基础图像语义差距极大时（Table 4 中高 CLIP 分数区间），UniTune 的偏好优势有所收窄，表明在极端语义偏离下保真度-表达力平衡仍面临挑战。

5. **超分辨率模型的独立性**：Table 3 的注释指出，Fig. 9 的图像生成中未对超分辨率模型进行微调。这意味着高分辨率细节的保真度可能受限于超分辨率模型自身的泛化能力，而非微调策略的直接控制。

## 定位与知识库关联

UniTune 的核心定位是将一个预训练的文本到图像扩散模型，通过在**单张图像**上进行微调，转换为该图像的专用编辑器。这与当时主流图像编辑范式存在本质差异，其改变的 slot 清晰且集中。

### 改变的 Slot：从“通用生成器”到“图像专用编辑器”

UniTune 相对于已有方法，改变的核心 slot 是**模型权重**。基线方法通常保持预训练扩散模型权重完全冻结，仅通过修改输入条件（如掩码、文本提示）或采样过程来实现编辑。而 UniTune 直接对模型权重执行微调，将其输出分布偏向目标图像。这一改变的因果机制在于：微调后的模型 $f_{\theta^*}$ 在给定稀有 token 条件 $c^{(b)}$ 时能够忠实地复现基础图像 $x^{(b)}$，但在给定新的编辑提示时，由于大型扩散模型未发生灾难性遗忘，模型仍能利用其原有的视觉与语义知识生成符合提示的内容。这种“记忆基础图像 + 保留生成多样性”的双重能力，是将生成模型转化为编辑器的基础。

### 与基线方法的本质差异

**与 SDEdit（Meng et al., 2021）相比**：SDEdit 是当时无掩码任意图像编辑的主要基线，其核心机制是仅通过从噪声图像初始化采样来平衡保真度与编辑强度，模型权重完全不变。UniTune 在 SDEdit 的噪声初始化基础上叠加了微调，从而在需要大幅像素变化的“非对齐编辑”上获得了决定性优势——人类偏好从 17% 提升至 83%（Table 1）。这说明微调为模型注入了对基础图像结构的高保真先验，而 SDEdit 仅靠调整噪声水平无法在强编辑下维持这种保真度。SDEdit 的保真度-表达力平衡仅由初始噪声步 $t_0$ 单一维度控制，而 UniTune 增加了微调迭代次数和 CFG 权重，形成了更细粒度的三维控制空间。

**与基于掩码的 in-painting 方法（Glide, Nichol et al., 2021；Blended Latent Diffusion, Avrahami et al., 2022）相比**：这些方法需要用户提供编辑掩码来指定修改区域，本质上是“填充”操作。UniTune 完全不需要掩码，模型通过微调隐式地“知道”哪些区域应保持不变、哪些区域应响应编辑提示。这种无掩码能力源于微调过程中模型对整个图像分布的拟合，而非对特定区域的显式约束。

**与 Text2LIVE（Bar-Tal et al., 2022）相比**：Text2LIVE 专注于局部纹理和外观的编辑，通过优化神经纹理层实现。UniTune 在支持的编辑类型上与之相当（Fig. 10），但编辑范围更广，可同时处理局部添加物体和全局风格转换（Fig. 7），且不需要针对特定编辑类型设计专门的优化目标。

### 知识库挂载点

UniTune 在知识库中的挂载点可以定位为**扩散模型微调与可控生成**这一交叉节点。其上游连接两个关键知识线：

1. **扩散模型去噪损失框架**：UniTune 的微调损失直接复用标准扩散去噪目标 $\mathbb{E}_{\epsilon,t}[w_t \| f_{\theta}(\alpha_t \mathbf{x}^{(b)} + \sigma_t \epsilon, c^{(b)}) - \epsilon \|_2^2]$，未引入任何额外损失项。这使其可以无缝挂载到任何基于该损失训练的扩散模型上（如 Imagen、Stable Diffusion）。

2. **分类器自由引导（Classifier-Free Guidance, Ho & Salimans, 2022）**：UniTune 将 CFG 作为调节微调偏好与提示响应的核心机制。高 CFG 权重（文中取 32）迫使模型偏离微调记忆而响应编辑提示，这一发现为后续工作提供了将 CFG 用于编辑控制的直接经验。

### 适用边界与限制

UniTune 的适用边界受以下因素约束：

- **随机种子依赖性**：编辑结果高度依赖随机种子，通常需要从 8 个种子中人工挑选最佳结果，单次生成成功率有限。
- **超参数手动调节**：微调迭代次数、初始噪声步 $t_0$（0.8–0.98）、CFG 权重需要针对每次编辑手动调整，缺乏自动化机制。Fig. 14 的消融网格清晰展示了不同参数组合对结果的显著影响，说明不存在一组通用最优参数。
- **生成速度**：受限于扩散模型的多步采样过程，无法实现实时交互式编辑。
- **编辑类型边界**：虽然覆盖面广，但在需要精确几何变换或大幅度结构重组的编辑上，方法的能力边界尚不明确。

### 后续启发与延伸价值

UniTune 的核心洞察——“在单样本上微调大型扩散模型不会导致灾难性遗忘，反而创造了可控的编辑能力”——对后续工作产生了深远影响。这一发现直接启发了 DreamBooth（Ruiz et al., CVPR 2023）等工作，后者同样通过微调将特定对象“植入”扩散模型，但使用了更精细的稀有 token 策略和先验保持损失。UniTune 的噪声初始化采样和像素插值后处理也被后续编辑方法广泛借鉴。

从更宏观的视角，UniTune 揭示了大型生成模型的一个重要性质：**模型权重空间中的局部偏移可以编码对特定图像的忠实记忆，同时不破坏模型的语义理解能力**。这一性质不仅适用于图像编辑，也为个性化生成、模型定制、少样本适应等方向提供了方法论基础。
