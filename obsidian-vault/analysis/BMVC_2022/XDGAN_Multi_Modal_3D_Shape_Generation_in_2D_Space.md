# XDGAN: Multi-Modal 3D Shape Generation in 2D Space

> [!tip] 核心洞察
> 通过固定的球面参数化和对称切割，把3D物体表面压缩为单通道距离图像，即可将强大的2D StyleGAN 直接用于3D几何生成，并利用对齐的2D属性图赋予网格纹理与法向，实现实时、可编辑的3D内容创建。

## 概要

**问题瓶颈**：现有3D生成模型长期受困于3D卷积的高内存需求、输出表示与下游3D工具不兼容，以及生成速度缓慢，使得2D图像生成领域的巨大进步难以直接迁移到3D形状生成中。

**核心洞察**：XDGAN 提出将3D形状参数化为紧凑的**单通道几何图像（Rad图像）**——通过固定的球面参数化和对称切割，把物体表面压缩为一个2D距离数组——从而彻底解除对定制3D网络组件的依赖。这使得标准2D StyleGAN3能够直接用于3D几何生成，再利用对齐的2D属性图赋予网格纹理与法向，实现实时、可编辑的3D内容创建。

**方法定位**：XDGAN 在2D空间中完成3D生成，其流水线由四个模块串联：几何图像转换器（3D网格→Rad图+对齐属性图）、StyleGAN3几何生成器（在Rad图上训练的标准GAN）、SPADE属性翻译器（Rad图→纹理/法向图），以及网格重建步骤（Rad图→固定拓扑三角网格）。该方法与基于体素、点云、隐式场或传统网格的生成范式形成根本性差异。

**主要结果**：
- 在ShapeNet汽车类别重建上，XDGAN的Chamfer Distance（0.977）优于所有基线方法，比最佳基线IM-Net（1.472）低33.6%；推理速度（0.020秒）比IM-Net快500倍以上，比DPC快3倍。
- 生成结果包含纹理和法向信息，可直接实时渲染为高保真3D网格，而DPC仅输出点云，IM-Net输出隐式表示需数秒才能可视化。
- 在飞机等复杂类别上，重建质量不及IM-Net，表明单通道Rad图在表达细长、对称性低的物体时存在不足。

**局限性**：该方法只能生成固定拓扑的网格，无法改变物体拓扑结构（如生成带洞或不连通部件）；参数化过程假设物体近似对称且亏格为零，限制了形状多样性。

三维内容生成是计算机视觉与图形学的核心挑战之一，其在游戏、影视、虚拟现实和工业设计等领域具有广泛需求。近年来，二维图像生成领域取得了革命性进展，以StyleGAN系列和扩散模型为代表的方法已经能够稳定生成高分辨率、高保真度的逼真图像。然而，这些进步并未能直接迁移到三维形状生成任务中。

**核心瓶颈在于表示方式的不兼容。** 现有三维生成模型普遍依赖专门设计的三维表示和对应的定制网络架构：基于体素网格的方法（如3D-GAN）受限于三维卷积带来的高昂内存开销，难以生成高分辨率形状；基于点云的方法（如DPC, Luo and Hu, CVPR 2021）虽然较为轻量，但输出缺乏完整的表面信息和拓扑结构，无法直接用于渲染和下游处理；基于隐式场的方法（如IM-Net, Chen and Zhang, CVPR 2019）能够产生高质量表面，但推理过程需要耗时的等值面提取（如Marching Cubes），单次生成动辄需要数秒乃至十几秒，远未达到实时交互的要求。

更深层的矛盾在于，**三维深度学习的工具链与二维图像领域存在巨大鸿沟**。二维生成模型受益于高度优化的卷积算子、成熟的训练技巧和丰富的预训练权重，而三维领域缺乏同等成熟的生态。这导致研究者要么在三维空间中“重复造轮子”，要么被迫接受生成质量、输出格式与推理速度之间的三重妥协。

XDGAN的核心洞察正是针对这一困境：**如果能够将三维形状无损地“压缩”为二维图像，那么整个成熟的二维生成体系就可以被直接复用。** 具体而言，该方法通过固定的球面参数化和对称切割，将物体表面映射为单通道的距离图像（Rad图像），使得标准的二维StyleGAN3无需任何架构修改即可用于三维几何生成。同时，利用对齐的二维属性图，图像翻译网络可以同步生成法向和纹理等表面属性，最终通过平凡的网格缝合步骤重建出可直接渲染的高保真三维网格。

这种“在二维空间中进行三维生成”的范式转换，不仅解除了对定制三维网络组件的依赖，更带来了推理速度的量级飞跃——相较于IM-Net快500倍以上，使实时三维内容创建成为可能。

## 核心方法与创新机理

XDGAN 的核心创新在于将 3D 形状生成问题**从 3D 空间迁移到 2D 空间**，从而绕开了 3D 卷积网络的高内存需求、定制化架构和慢速推理等瓶颈。这一迁移通过三个紧密耦合的“changed slots”实现：

### 1. 形状表示：从体素/点云/隐式场到 1 通道几何图像

现有 3D 生成方法依赖体素网格、点云或隐式场（如 SDF），这些表示要么内存效率低，要么需要专用解码器，且与下游 3D 工具兼容性差。XDGAN 提出将 3D 网格通过**球面参数化与固定切割**映射为紧凑的**单通道 Rad 几何图像**——每个像素仅存储一个沿投影射线的有向距离值（Rad），从而将 3D 表面压缩为标准的 2D 数组（§3.1）。这一转换同时生成对齐的法向图和纹理图，使几何与表面属性在像素空间天然对齐。

### 2. 生成器架构：从定制 3D 网络到标准 2D StyleGAN3

由于 Rad 图像是标准的 2D 单通道图像，XDGAN 可以直接使用**无需修改的 StyleGAN3** 进行几何生成，无需设计任何 3D 卷积或点云解码器。论文明确指出：“在单通道 Rad 图像上训练与标准图像 GAN 训练在稳定性上几乎没有差异”（§3.2）。这从根本上解除了对定制 3D 网络组件的依赖，使 3D 生成能够直接受益于 2D GAN 领域的全部进展。

### 3. 表面属性生成：从缺失/独立模型到条件图像翻译

传统 3D 生成方法通常不生成纹理，或需要独立的复杂模型。XDGAN 以生成的 Rad 几何图像为条件，使用 **SPADE 图像翻译网络**直接生成对齐的法向、纹理等属性图像（§3.2）。由于几何图与属性图在 2D 空间逐像素对齐，这一翻译任务高度结构化，训练高效。

### 4. 推理速度：从秒级到实时

上述设计使推理过程简化为“前馈生成 Rad 图 + 平凡网格缝合”两步。Rad 图中的每个像素对应固定拓扑网格的一个顶点，像素值乘以预定义的球面法向即得 3D 坐标，按像素索引连接即得三角网格。整个过程仅需 **0.02 秒**，比最快的基线 DPC（0.061 秒）快 3 倍，比隐式方法 IM-Net（11.055 秒）快 **500 倍以上**（Table 2），首次实现了 3D 形状的实时生成与可视化。

### 关键洞察

核心洞察可以概括为：**通过固定的球面参数化和对称切割，将 3D 物体表面压缩为单通道距离图像，即可将强大的 2D StyleGAN 直接用于 3D 几何生成，并利用对齐的 2D 属性图赋予网格纹理与法向**。这一设计使 3D 生成模型从“为 3D 定制一切”转变为“让 2D 模型处理 3D”，在保持生成质量的同时获得了数量级的效率提升。

XDGAN 的整体设计遵循一个核心原则：**将三维生成问题完全迁移到二维空间**，从而直接继承 2D 图像生成领域在架构、训练稳定性和速度上的巨大优势。其 pipeline 由四个紧密衔接的模块构成，形成一条“3D → 2D → 生成 → 3D”的闭环。

### 1. 几何图像转换器（3D → 2D 参数化）

这是整个框架的基石。给定一个带纹理的 3D 网格，该模块执行以下操作：

- **球面参数化**：将网格表面映射到单位球面上，采用特定的球面参数化族和固定的切割结构（seam structure），确保所有训练样本共享一致的拓扑映射。
- **Rad 图像生成**：对于球面上的每条投影射线，计算物体表面点到原点的有向距离，称为“Rad”值。该值被记录为单通道 2D 图像的像素值。由此，一个 3D 形状被压缩为一张紧凑的 **1 通道几何图像**，其中每个像素对应网格的一个顶点，像素间的邻接关系定义了网格的固定拓扑。
- **属性图对齐生成**：利用同一参数化方案，同步生成与几何图像像素级对齐的法向图、纹理图或其他表面属性图。

> **Figure 3** 展示了从 3D 数据生成几何图像的具体步骤（详见 §3.1）。

### 2. StyleGAN3 几何生成器（2D 生成）

在获得几何图像数据集后，XDGAN 直接采用**未经修改的标准 2D StyleGAN3** 进行训练。该模块的角色是学习几何图像的数据分布，并从随机潜在向量生成合理的新几何图像。

关键发现是：在单通道 Rad 图像上的训练稳定性与标准 RGB 图像 GAN 训练几乎无异。这验证了核心洞察——将 3D 几何编码为 2D 图像后，强大的 2D GAN 可以无缝应用于 3D 形状生成，无需任何定制的 3D 网络组件。

### 3. SPADE 属性翻译器（几何 → 表面属性）

几何图像仅定义了物体的宏观形状，缺乏表面细节。为赋予网格纹理和法向信息，XDGAN 训练一个**图像翻译网络**（以 SPADE 为实验架构），以几何图像为条件输入，生成对应的多通道属性图像。

- 输入：1 通道 Rad 几何图像
- 输出：对齐的法向图、纹理图等表面属性

该模块与几何生成器**分开训练**，这既是工程上的简化，也带来了灵活性——同一几何图像可以搭配不同的纹理生成结果。

### 4. 网格重建步骤（2D → 3D 解码）

测试时，将生成的几何图像和属性图像恢复为 3D 网格的过程是**平凡且实时的**：

- 每个像素的 Rad 值乘以对应球面射线的单位方向向量，得到 3D 顶点坐标。
- 按像素索引的固定邻接关系连接顶点，形成三角网格。
- 将法向图和纹理图直接映射到网格表面。

这一“前馈评估 + 简单缝合”的流程，使得从潜在向量到带纹理 3D 网格的端到端生成可在 **0.02 秒**内完成。

### 训练与推理流程总览

**Figure 2** 清晰展示了 XDGAN 的训练和推理双阶段流程：

- **训练阶段（Figure 2a）**：首先将带纹理的 3D 网格数据集转换为几何图像及对齐的属性图；随后，在几何图像上训练 GAN 以生成形状，在几何-属性图像对上训练图像翻译网络以生成表面属性。
- **推理阶段（Figure 2b）**：从前馈评估两个网络到最终的网格缝合，全过程实时产出带纹理的 3D 网格。

### 模块间的因果联结

整个 pipeline 的因果链条可概括为：

> **固定球面参数化** → 3D 形状被压缩为单通道 Rad 图像 → 标准 2D GAN 可生成几何 → 对齐的属性图使图像翻译网络能赋予表面细节 → 平凡解码步骤恢复 3D 网格。

这一设计彻底解除了对定制 3D 卷积、点云解码器或隐式场网络的依赖，实现了 3D 内容创建的速度飞跃。但同时，**固定拓扑的像素连接方式**也构成了框架的根本约束：生成的网格拓扑始终由几何图像的分辨率和切割结构决定，无法产生带洞或不连通部件等拓扑变化的形状。

XDGAN的核心设计围绕一个关键洞察展开：通过固定的球面参数化和对称切割，将3D物体表面压缩为单通道距离图像（Rad图像），从而将强大的2D生成模型直接应用于3D几何生成。整个流水线由四个紧密协作的模块构成。

### 几何图像转换器

该模块负责将3D网格数据转换为2D表示，是整个方法的基础。其工作流程为：首先对输入网格进行球面参数化，将3D表面映射到单位球面上；随后沿固定切割线将球面展开为2D平面，形成与3D顶点一一对应的像素网格。每个像素存储的不是RGB值，而是一个标量——沿投影射线从球心到表面点的有向距离，称为**Rad值**。这一设计将3D形状压缩为紧凑的1通道几何图像，同时保留了完整的表面几何信息。

对于表面属性（法向、纹理等），该模块使用相同的参数化坐标，将平滑法向和环境光照渲染的纹理分别烘焙为对齐的2D属性图。这意味着几何图像的每个像素与法向图、纹理图的对应像素精确匹配，为后续的属性生成提供了像素级的对齐基础。

### StyleGAN3几何生成器

这是XDGAN的几何生成核心。该模块直接在单通道Rad图像数据集上训练标准的2D StyleGAN3，无需任何架构修改。训练过程与常规图像GAN训练在稳定性上几乎没有差异——这一发现是该方法可行性的关键验证。生成器从随机潜在向量出发，输出$512\times512$的Rad几何图像，训练采用StyleGAN3-r变体、批大小8、$\gamma=1$、共500个epoch。

### SPADE属性翻译器

该模块以生成的Rad几何图像为条件输入，通过图像翻译网络生成对应的表面属性图。具体采用SPADE架构，在已对齐的几何-属性图像对上训练，使网络学习从几何形状到表面细节的映射。训练设置为300个epoch、批大小32。在推理时，该模块可与几何生成器串联，前馈生成法向图和纹理图，从而赋予网格完整的表面外观。

### 网格重建步骤

这是一个确定性的解码过程：将生成的Rad几何图像中每个像素值乘以对应球面方向上的单位法向量，恢复出3D顶点坐标；随后按像素邻接关系连接顶点，形成固定拓扑的三角网格。由于拓扑结构由几何图像的像素连接方式预先确定，该步骤是平凡的，仅需极少量计算即可完成从2D图像到3D网格的转换。

### 潜在空间编辑公式

XDGAN继承了StyleGAN的潜在空间可编辑性。对于学到的语义属性（如车型、车顶高度等），可通过SVM在潜在空间中求解分离超平面，其法向量$\mathbf{n}^T$即为编辑方向。给定潜在向量$p$，编辑操作定义为：

$$p' = p + (\alpha \times t \times \mathbf{n}^T)$$

其中$\alpha$为步长，$t$为移动步数。沿$\mathbf{n}^T$正方向移动可增强目标属性，反向移动则抑制该属性。这一机制使得用户可以在保持其他特征不变的前提下，连续调整特定语义维度。

**证据强度说明**：以上模块描述均有明确锚点支撑——几何图像转换器对应§3.1的完整参数化流程，StyleGAN3生成器对应§3.2的训练描述，SPADE翻译器对应§3.2的图像翻译网络部分，网格重建步骤对应摘要和§3.2的“trivial meshing step”表述，编辑公式对应§3.3的显式公式。所有模块的置信度均不低于0.9，但关于SPADE的具体训练超参数（300 epochs、批大小32）来自part_004的实验设置证据，置信度约0.9，建议在正式引用时核对原文§4.1的具体数值。

## 实验与关键发现

### 核心实验设置

XDGAN 的实验围绕两个核心任务展开：**3D 重建**（将真实形状投影到潜在空间并重建）和**单视图重建**（从单张 RGB 图像恢复 3D 形状）。所有实验均在 ShapeNetV2 数据集上进行，重点评估汽车（Cars）和飞机（Airplanes）两个类别。

**训练配置**：几何图像生成器采用 StyleGAN3-r 变体，输入为 $512 \times 512$ 的单通道 Rad 图像，batch size 为 8，$\gamma = 1$，训练 500 个 epoch。表面属性翻译网络采用 SPADE 架构，在已对齐的几何-纹理/法向图像对上训练 300 个 epoch，batch size 为 32。

**重建流程**：对于重建任务，从随机采样的潜在向量出发，通过 500 次迭代优化，最小化生成几何图像与真值几何图像之间的损失，反向传播至潜在空间。对于单视图重建任务，使用基于 ResNet 的编码器，以 ShapeNet 模型在随机视角下的渲染 RGB 图像为输入，直接预测潜在向量，再生成对应的几何图像。

**评估指标**：采用 Chamfer Distance（CD，$\times 10^3$）、Earth Mover's Distance（EMD，$\times 10^2$）、Light Field Distance（LFD）以及推理时间（秒）作为定量指标。所有方法均在生成网格（或点云）与真值之间采样 5000 个点计算 CD 和 EMD，保证可比性。

### 主要定量结果

**Table 2** 展示了 ShapeNet 重建任务的完整定量对比。XDGAN 在汽车类别上取得了全面的最优结果：CD 为 0.977，EMD 为 1.34，均显著优于所有基线方法。相比之下，最强基线 IM-Net 的 CD 为 1.472，EMD 为 1.80——XDGAN 的 CD 降低了 33.6%。在飞机类别上，IM-Net 仍保持优势（CD 1.647 vs XDGAN 2.721），XDGAN 排名第二，优于 AtlasNet（2.398）和 DPC（4.185）。

**推理速度是 XDGAN 最突出的优势**。XDGAN 的推理时间仅为 0.020 秒，比最快的基线 DPC（0.061 秒）快约 3 倍，比 IM-Net（11.055 秒）快超过 500 倍。这一速度优势源于其前馈生成机制：几何图像生成后，只需一次平凡的网格缝合步骤即可得到可渲染的 3D 网格，无需耗时的等值面提取或点云后处理。

**Table 3** 展示了单视图重建结果。在汽车类别上，XDGAN 的 CD 为 1.325，仅次于 IM-Net（0.935），优于 AtlasNet（4.001）和 DPC（2.878）。虽然 IM-Net 在数值上领先，但 XDGAN 生成的网格包含纹理和法向信息，可直接实时渲染，而 IM-Net 仅输出隐式表示，需要额外数秒的可视化步骤。

**Table 1** 从定性维度系统比较了不同 3D 表示方法的能力。XDGAN 在“实时生成”“高质量渲染”“表面质量”“纹理生成”四个维度上均达到最优（✓），而基于体素的 3D-GAN 无法实时生成，基于点云的 DPC 不支持纹理和高质量渲染，基于隐式场的 IM-Net 虽能生成高质量表面但推理缓慢且无纹理。

### 定性分析与可视化

**Table 4** 展示了重建结果的定性比较。XDGAN 生成的网格具有最高的保真度，尤其在表面法向细节上表现出色——这得益于 SPADE 网络从几何图像中翻译出的高质量法向图。相比之下，AtlasNet 虽然生成网格，但缺乏纹理和法向信息；DPC 仅输出点云，无法呈现连续的表面；IM-Net 生成的隐式表面虽然平滑，但缺少纹理细节。

**Figure 4** 进一步展示了 XDGAN 潜在空间的可探索性。上半部分演示了语义编辑能力：通过沿 SVM 分离超平面的法向量 $\mathbf{n}^T$ 移动潜在向量 $p$，即 $p' = p + (\alpha \times t \times \mathbf{n}^T)$，可以连续操控形状的语义属性（如车顶高度、车身长度）。下半部分展示了两个输入模型之间的平滑插值，表明潜在空间具有良好的连续性和可解释性。

### 方法优势与失败模式

**核心优势**：XDGAN 成功将 3D 生成问题降维为 2D 图像生成问题，从而充分利用了 StyleGAN3 等成熟 2D GAN 的强大生成能力。其生成的 3D 网格不仅质量高，而且包含纹理和法向信息，可直接用于实时渲染和下游应用。推理速度的压倒性优势使其成为交互式 3D 内容创建的有力候选。

**已知局限与失败模式**：
- **固定拓扑约束**：几何图像的像素连接方式决定了网格拓扑是固定的（球面拓扑，亏格为零），无法生成带洞或不连通部件的形状。这意味着 XDGAN 无法处理具有复杂拓扑结构的物体类别。
- **对称性与参数化假设**：球面参数化过程假设物体近似对称，对于细长、不对称的物体（如飞机），单通道 Rad 图的表达能力可能不足，这解释了飞机类别上质量不及 IM-Net 的结果。
- **几何与属性的解耦训练**：几何生成器（StyleGAN3）和属性翻译器（SPADE）是分开训练的，可能无法完美捕获几何与表面属性的联合分布，导致纹理与几何之间偶尔出现不一致。
- **类别泛化性未充分验证**：实验仅覆盖 ShapeNet 的汽车和飞机两个类别，方法在更多样化、更复杂形状类别上的表现尚待验证。

### 公平性说明

在解读结果时需注意以下公平性考量：DPC 仅输出点云，无法计算 LFD 距离，因此在 Table 2 中缺失该指标。所有方法的 CD 和 EMD 均在统一采样 5000 个点的条件下计算，保证了数值可比性。IM-Net 虽然在某些类别中质量占优，但其推理时间过长，不适合交互应用场景——XDGAN 强调的正是速度与质量的实用权衡。AtlasNet 虽然生成网格，但不产生纹理和法向信息，而 XDGAN 同时输出这三者，在功能完整性上存在维度差异。

## 定位与知识库关联

### 一、核心设计逻辑：从3D困境到2D降维

XDGAN的方法学突破源于对3D生成领域一个根本性瓶颈的因果诊断：**3D卷积的高内存需求、输出表示与下游工具的不兼容性、以及生成速度的低下，使得2D图像生成领域积累的丰富经验无法直接迁移到3D形状生成中**。论文提出的解决方案是一个简洁的因果旋钮——将3D形状参数化为紧凑的1通道几何图像（Rad图像），从而解除对定制3D网络组件的依赖。

这一设计的核心洞察在于：通过固定的球面参数化和对称切割，把3D物体表面压缩为单通道距离图像，即可将强大的2D StyleGAN直接用于3D几何生成，并利用对齐的2D属性图赋予网格纹理与法向，实现实时、可编辑的3D内容创建。

### 二、关键组件替换：与基线方法的结构性差异

XDGAN通过四个关键组件的替换，与现有3D生成方法形成了结构性差异：

**1. 形状表示（从体素/点云/隐式场到Rad几何图像）**

传统3D生成方法依赖体素网格（内存需求随分辨率立方增长）、点云（缺乏拓扑结构）或隐式场如SDF（需要昂贵的等值面提取）。XDGAN提出将3D网格通过球面参数化和固定切割映射为1通道Rad几何图像，每个像素存储一个顶点的有向距离值。这一表示是2D数组结构，天然兼容标准图像生成网络，且重建网格只需一次前馈计算加平凡缝合步骤。

**2. 生成器架构（从定制3D网络到标准2D StyleGAN3）**

现有方法通常需要定制的3D卷积网络（如3D-GAN）或点云/隐式解码器。XDGAN直接采用无修改的2D StyleGAN3进行几何生成。论文明确指出：“We found training over single-channel Rad images to differ little in its stability from standard image-based GAN training”，这意味着2D GAN训练的稳定性优势得以完全保留。

**3. 表面属性生成（从无纹理到对齐的属性图像翻译）**

多数3D生成基线（如**AtlasNet** (Groueix et al., CVPR 2018)、**DPC** (Luo and Hu, CVPR 2021)）不生成纹理或需要独立的复杂模型。XDGAN以Rad图为条件，使用SPADE图像翻译网络同时生成法向、纹理等对齐的属性图像，使输出网格具备可直接渲染的高保真表面细节。

**4. 推理速度（从秒级到实时）**

**IM-Net** (Chen and Zhang, CVPR 2019)的推理时间约11秒，DPC约0.06秒，而XDGAN仅需0.02秒——比最快基线快3倍，比IM-Net快500倍以上。这一速度优势源于几何生成完全在2D空间完成，网格重建仅需平凡计算。

### 三、在3D生成谱系中的定位

从3D生成方法的表示维度看，XDGAN处于一个独特的位置：

- **相对于体素方法**：避免了立方级内存增长，生成质量不受分辨率限制。
- **相对于点云方法（如DPC）**：输出带拓扑结构的网格，可直接渲染和编辑，而DPC仅产生点云，无法计算LFD距离（Table 2脚注）。
- **相对于隐式方法（如IM-Net）**：牺牲了部分拓扑灵活性，换取了500倍以上的推理加速和实时渲染能力。在ShapeNet汽车类别上，XDGAN的CD（0.977）和EMD（1.34）均优于IM-Net（CD 1.472, EMD 1.67），但在飞机类别上IM-Net仍占优（CD 1.647 vs 2.721），表明单通道Rad图在表达细长、对称性低的物体时存在不足。
- **相对于网格方法（如AtlasNet）**：AtlasNet虽生成网格，但不产生纹理和法向信息，而XDGAN可同时输出纹理和法向，生成质量更高。

### 四、适用边界与局限

XDGAN的设计隐含了若干强假设，这些假设划定了其适用边界：

1. **固定拓扑约束**：网格的拓扑结构由几何图像像素连接方式决定，无法生成带洞或不连通部件的物体。这是从2D GAN继承的结构性限制。
2. **对称性与亏格假设**：球面参数化过程假设物体近似对称且亏格为零，限制了形状多样性。对于高度不对称或复杂拓扑的物体，参数化质量会下降。
3. **几何与属性分离训练**：几何生成（StyleGAN3）与纹理/法向生成（SPADE）分开训练，可能无法捕获几何与属性的联合分布，导致纹理与几何在细节层面不完全一致。
4. **类别特异性**：在飞机等细长、对称性低的类别上，重建质量不及IM-Net，表明单通道Rad图的表达能力在这些场景下存在瓶颈。

### 五、开放问题与可能的演进方向

基于XDGAN的当前设计，以下几个方向值得关注：

1. **可变拓扑扩展**：如何将固定拓扑的几何图像思想扩展到可变拓扑或多部件物体生成？可能的路径包括分部件生成后组装，或引入自适应拓扑的2D表示。
2. **端到端联合生成**：能否设计统一的生成框架，同时预测几何和表面属性，以提升几何-纹理一致性？这需要解决不同模态间的条件依赖建模问题。
3. **参数化方法改进**：通过自动切割、自适应球面映射等技术，扩展至更广泛的不对称、任意亏格形状，是提升方法通用性的关键。
4. **架构演进空间**：在保持实时性的前提下，是否可以用其他2D GAN架构（如基于Transformer的生成器）进一步提高生成质量？这取决于2D生成领域的持续进展能否继续通过Rad图像这一桥梁迁移到3D领域。

总体而言，XDGAN的核心贡献在于证明了“将3D生成降维为2D图像生成”这一策略的可行性，其方法学价值在于打破了3D生成必须依赖定制3D网络的思维定式，为后续工作开辟了一条轻量、高效的技术路径。
