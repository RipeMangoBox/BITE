## 概述

多模态情感识别长期受困于**固定标签空间的封闭集假设**和**多数投票机制的标签模糊性**——传统方法仅从6类基本情感中强制选择，导致大量正确但非主流或非候选的微妙情绪被系统性遗漏。本文提出的**EMER（Explainable Multimodal Emotion Recognition，可解释多模态情感识别）**从根本上重构了这一任务范式：通过生成融合视觉、声学和词汇线索的多模态解释性描述，将情感识别从封闭集分类转化为**开放词汇标签提取**，从而解除标签空间限制，并为每个预测提供可追溯的推理依据。

该方法的核心机制在于利用大语言模型的推理能力实现**跨模态线索消歧**：先通过GPT-4V从视频帧和音频文本中提取视觉与声学线索，再以GPT-3.5整合两类线索对字幕进行消歧，最终生成完整的EMER描述。从该描述中提取的开放词汇标签集包含**301个候选类别**，平均每样本3个标签，远超MER2023的6类固定标签空间。

实验结果表明，EMER(Multi)在情感识别Avg指标上达到**80.05（英文）和85.20（中文）**，显著优于最强通用大模型GPT-4V的56.69/57.34，提升幅度超过23个百分点。消融实验进一步证实，融合所有线索的多模态描述远优于任何单模态变体，验证了跨模态消歧的必要性。此外，从EMER描述中抽取的离散情感识别Top-1准确率达93.48%，效价估计与MER2023的PCC为0.88，表明解释性描述在提供预测依据的同时，完好保留了关键的识别信息。

## 背景与动机

多模态情感识别（Multimodal Emotion Recognition, MER）旨在整合文本、语音、视觉等多源信息来推断人类情感状态。传统方法将该任务建模为封闭集分类问题：给定预定义的离散情感类别（如MER2023基准中的6类基本情感），模型直接输出类别标签。然而，这一范式存在根本性瓶颈——**标签模糊与多数投票机制的局限**。

在真实场景中，情感表达往往是微妙、混合且高度依赖语境的。固定标签空间强制模型在有限候选中做出选择，导致两个后果：（1）正确但非主流的情感被系统性地忽略；（2）模型输出缺乏可验证的推理依据，用户无法判断预测是否可信。现有工作主要依赖多数投票或注意力权重可视化来缓解可解释性不足的问题，但这些方法并未触及核心矛盾——**封闭集分类本质上无法捕捉情感的开放性与多义性**。

近年来，多模态大语言模型（MLLM）的兴起为情感识别带来了新可能。GPT-4V、VideoChat2等模型能够处理视频、音频和文本输入，并生成自然语言描述。然而，直接将这些模型应用于情感识别面临两个挑战：其一，现有开源MLLM在复杂多模态推理任务上表现有限，难以一步到位地生成准确的情感判断；其二，即使生成描述，如何从自由文本中可靠地提取情感标签仍是一个开放问题。

本文的核心动机在于**将多模态情感识别从封闭集分类转化为开放词汇标签提取任务**。具体而言，EMER（Explainable Multimodal Emotion Recognition）提出了一种新的范式：首先生成包含视觉、声学和词汇线索的多模态解释性描述，然后从描述中以开放词汇方式提取情感标签。这一设计的因果杠杆在于——通过大语言模型的推理能力整合多模态线索并生成解释，既能解除标签空间的限制，又能为每个预测提供明确的证据基础，从而同时提升识别的覆盖度与可信度。

## 核心创新

### 从封闭集分类到开放词汇解释生成

传统多模态情感识别（MER）的核心范式是：给定一段视频，模型从固定的6个基本情感标签（如“高兴”、“悲伤”、“愤怒”）中选择一个或多个作为预测结果。这一范式隐含两个关键假设——标签空间是完备且互斥的，以及“多数投票”选出的标签即为正确答案。然而，现实中的情感表达远比6个标签丰富和微妙：同一段视频可能同时包含“欣慰”、“怀念”、“苦涩”等多重情感，而固定标签空间既无法覆盖这些非候选情感，也无法为预测提供任何依据。

EMER的核心创新在于**将任务从“封闭集分类”重构为“多模态解释生成+开放词汇标签提取”**。模型不再直接输出情感标签，而是首先生成一段多模态解释描述（EMER description），该描述整合了视觉线索、声学线索和词汇线索，并明确陈述“为什么这个人物表现出某种情感”。随后，从解释描述中以开放词汇的方式提取情感标签，不再受限于预设的类别集合。这一重构带来三个根本性改变：

1. **标签空间从固定6类扩展到301个候选标签**，平均每个样本可提取3个情感标签，远超过MER2023的6类限制。
2. **每个预测标签都有对应的解释依据**，解决了传统黑盒预测缺乏可追溯性的问题。
3. **离散情感识别和维度情感估计被统一在同一框架下**，因为解释描述中自然包含了情感的类别信息和强度线索。

### 多模态消歧：从线索冲突到证据整合

在多模态情感识别中，不同模态传递的情感信号常常相互矛盾——例如，一个人可能嘴上说着“我很好”，但声音颤抖、表情僵硬。传统方法通常对各模态进行独立编码后简单融合，缺乏显式的冲突消解机制。

EMER引入了一个**基于大语言模型的消歧模块**来解决这一问题。其关键设计是“两步字幕整合策略”（S2）：首先从视频帧和音频中分别提取视觉线索和声学线索（不依赖字幕），然后以这些线索为上下文，让GPT-3.5对字幕文本进行消歧，生成最终的词汇线索。这一策略的动机在于：字幕（语音转写文本）往往只传达字面信息，而真实情感往往隐藏在语气、表情和肢体语言中——先用非语言线索建立情感上下文，再据此重新解读语言内容，能够有效区分“反讽”、“强颜欢笑”等复杂情感表达。

消融实验证实了这一设计的有效性：融合所有线索的EMER(Multi)在Avg指标上达到80.05（英文），远超仅使用单一模态的EMER(Audio)（65.42）、EMER(Video)（60.67）和EMER(Text)（47.13）。纯文本变体表现最弱，说明字幕文本本身承载的情感信息极为有限，必须借助非语言线索进行消歧。

### 与大模型范式的差异化定位

值得注意的是，EMER并非简单地“调用GPT-4V做情感识别”。实验表明，即使是最强的通用多模态大模型GPT-4V，在直接预测情感标签时仅能达到56.69 Avg（英文），而EMER(Multi)的80.05高出23.36个点。这一差距的根源在于：通用大模型缺乏专门的情感线索提取和消歧流程，其生成的描述往往笼统且缺乏针对性。

EMER的真正贡献在于定义了一套**可复现的提示工程流水线**：通过预标注（GPT-4V提取视觉/声学线索）→ 人工校对 → 消歧（GPT-3.5整合线索解读字幕）→ 描述生成 → 开放词汇标签提取的标准化流程，将大语言模型的推理能力聚焦于情感识别的关键瓶颈。这一流水线不依赖于特定模型，原则上可以适配任何具备多模态理解能力的LLM。

### 评估体系的重构

与任务重构相配套，EMER重新定义了评估指标。传统准确率要求预测标签与标注标签完全一致，这在开放词汇场景下过于严苛——例如，“开心”和“快乐”在语义上等价，但字符串匹配会将其判为错误。EMER采用**集合级评估**：先用GPT-3.5对预测标签和标注标签进行同义词分组，再计算分组后的集合准确率和召回率，最终以两者的算术平均（Avg）作为排序指标。这一设计使得评估更贴近语义层面的正确性，而非表面的字符串匹配。

## 整体框架

EMER 将多模态情感识别从传统的封闭集分类重新定义为**可解释的开放词汇情感提取**任务。其核心 pipeline 围绕一个关键洞察展开：利用大语言模型（LLM）的推理能力整合多模态线索并生成解释性描述，从而解除标签空间限制，同时为每个预测提供可追溯的证据基础。

### 数据标注与描述生成流程

整个框架的数据生产端分为四个串行模块，最终产出多模态解释描述 EMER(Multi)：

1. **视觉线索预标注**：对采样视频帧，由 GPT-4V 生成初始视觉线索（平均每样本 4.95 条）。
2. **声学线索预标注**：从字幕文本出发，由 GPT-4V 推断声学线索（音频到文本）。
3. **两轮人工校验**：对 GPT-4V 产生的幻觉和遗漏线索进行修正，确保线索质量。
4. **消歧模块**：将校验后的视觉与声学线索输入 GPT-3.5，对字幕进行消歧，生成词汇线索（lexical clues）。最终融合所有线索，形成 EMER(Multi) 描述。

这一流程体现了两个关键设计选择：**多模态消歧**（单模态线索不足以确定情感，必须交叉验证）与**分步整合**（直接一步式提示对开源多模态大模型过于复杂，两步策略 S2 普遍优于 S1）。

### 开放词汇标签提取与评估

从 EMER 描述中提取情感标签时，框架不再受限于 MER2023 的 6 个固定类别，而是通过 GPT-3.5 以开放词汇方式抽取，共识别出 301 个候选标签，每样本平均 3 个标签。评估前，先由 GPT-3.5 对标签进行同义词分组，再计算集合级指标：

- **集合级准确率**：$\mathrm{Accuracy}_{\mathrm{S}} = \frac{|\mathcal{V} \cap \hat{\mathcal{V}}|}{|\hat{\mathcal{V}}|}$（预测标签组中正确标签组的比例）
- **集合级召回率**：$\mathrm{Recall}_{\mathrm{S}} = \frac{|\mathcal{V} \cap \hat{\mathcal{V}}|}{|\mathcal{V}|}$（标注标签组中被成功覆盖的比例）
- **综合指标 Avg**：$\mathrm{Avg} = \frac{\mathrm{Accuracy}_{\mathrm{S}} + \mathrm{Recall}_{\mathrm{S}}}{2}$，作为最终排名依据。

### 输入输出流与模块关系

框架的推理侧（评估基线模型时）复用相同的描述生成提示模板，将各类多模态大模型（MLLM）生成的描述与 EMER(Multi) 标注进行对比。输入为视频帧、音频（以文本形式）和字幕文本，输出为开放词汇情感标签集及其对应的解释性描述。单模态变体 EMER(Audio)、EMER(Video)、EMER(Text) 作为消融基线，用于量化各模态的贡献——实验证实，融合所有线索的 EMER(Multi) 性能远超任何单模态描述，验证了多模态消歧的必要性。

## 核心模块与公式推导

### 多模态解释生成流水线

EMER 的核心在于将传统封闭集分类转化为**开放词汇标签提取**，其关键机制是通过生成多模态解释（EMER 描述）来提供预测依据，从而解除固定标签空间的限制。整个流水线由以下模块构成：

1. **视觉线索预标注**：GPT-4V 从采样的视频帧中生成初始视觉线索（如面部表情、肢体动作等），对应 Table 1 中的 Prompt #1。
2. **声学线索预标注**：GPT-4V 基于字幕文本（音频转写）生成初始声学线索（如语调、语速等），对应 Table 1 中的 Prompt #2。
3. **两轮人工校验**：人工校对 GPT-4V 产生的幻觉和遗漏线索，确保预标注质量。
4. **消歧模块**：GPT-3.5 整合校验后的视觉和声学线索，对字幕进行消歧，提取词汇线索（lexical clues），对应 Table 1 中的 Prompt #3。消歧是流水线的关键瓶颈——字幕本身可能语义模糊，需借助多模态上下文才能正确解读情感。
5. **多模态描述生成器**：将所有线索组合，形成最终的 EMER(Multi) 描述（Figure 2）。
6. **开放词汇标签提取器**：GPT-3.5 从 EMER 描述中提取情感标签，不限制标签空间，对应 Table 2 中的 Prompt #4。从 EMER 描述中实际提取到 301 个候选标签，平均每样本 3 个标签，远超 MER2023 的 6 个固定类别。
7. **同义词分组与指标计算器**：GPT-3.5 对同义标签进行分组，随后计算集合级准确率与召回率。

**字幕整合策略**是影响流水线性能的关键设计选择。论文对比了三种策略：
- **S0**：忽略字幕，仅用视觉和声学线索。
- **S1**：单步提示，直接将字幕纳入多模态大模型的输入。
- **S2**（两步消歧）：先用 S0 提取线索，再以这些线索作为上下文，让 GPT-3.5 对字幕进行消歧。

实验表明 S2 在所有多模态大模型上普遍优于 S1（Figure 5），说明现有开源多模态大模型难以处理复杂的一步式提示，分步消歧有效降低了任务复杂度。

### 关键公式与变量含义

EMER 采用集合级评估指标，以处理开放词汇下预测标签组与标注标签组之间的匹配问题。设 $\mathcal{V}$ 为标注标签组（经同义词分组后的组 ID 集合），$\hat{\mathcal{V}}$ 为预测标签组。

**集合级准确率**衡量预测的精确性——预测的标签组中有多大比例是正确的：

$$\mathrm{Accuracy}_{\mathrm{S}} = \frac{|\mathcal{V} \cap \hat{\mathcal{V}}|}{|\hat{\mathcal{V}}|}$$

**集合级召回率**衡量预测的覆盖度——标注的标签组中有多大比例被成功预测：

$$\mathrm{Recall}_{\mathrm{S}} = \frac{|\mathcal{V} \cap \hat{\mathcal{V}}|}{|\mathcal{V}|}$$

**Avg 指标**为准确率与召回率的算术平均，用作最终排名依据：

$$\mathrm{Avg} = \frac{\mathrm{Accuracy}_{\mathrm{S}} + \mathrm{Recall}_{\mathrm{S}}}{2}$$

**集合级重叠率**用于衡量两个标签集（如中英文提取结果）的相似度，在同义词分组后计算交并比：

$$\operatorname{Overlap}_{\mathrm{S}} = \frac{|\mathcal{P}^1 \cap \mathcal{P}^2|}{|\mathcal{P}^1 \cup \mathcal{P}^2|}$$

其中 $\mathcal{P}^1$ 和 $\mathcal{P}^2$ 分别为两个标签集经同义词分组后的组 ID 集合。该指标用于分析语言差异对标签提取的影响——实验发现相同描述的中英文标签重叠率最高仅约 0.82，且翻译会进一步降低重叠率至约 0.15，表明情感定义存在语言依赖性。

**同义词分组**是上述公式的前置步骤：所有标签先由 GPT-3.5 进行同义词聚类，再以组 ID 代替原始标签参与集合运算。这一设计旨在减少同义词对重叠率计算的干扰，但也引入了对 GPT-3.5 分组的依赖，其跨语言一致性尚未充分验证。

## 实验与分析

### 主实验结果

EMER在开放词汇情感识别任务上全面超越现有闭源与开源多模态大模型（MLLM）。Table 3展示了中英文双语的完整对比：**EMER(Multi)** 在英文描述上取得 **80.05** 的Avg得分，中文描述上达到 **85.20**，分别领先最强通用模型 **GPT-4V** 达 **+23.36** 和 **+27.86** 个百分点。这一巨大差距源于EMER的多模态解释机制——它并非直接预测标签，而是先生成包含视觉、声学和词汇线索的EMER描述，再从中提取开放词汇标签，从而打破了传统6类固定标签空间的限制。

细粒度指标进一步揭示了EMER的优势结构。在英文设置下，EMER(Multi)的集合级准确率（Accuracys）为80.03，远超最佳MLLM基线 **VideoChat2**（Li et al., CVPR 2024）的54.72（+25.31）；集合级召回率（Recalls）为80.07，同样高于GPT-4V的64.86（+15.21）。这表明EMER不仅预测更精确，覆盖面也更广——它能够识别出固定标签体系中被忽略的正确但非主流情感。

值得注意的是，所有MLLM基线（包括GPT-4V、VideoChat2、PandaGPT等）均使用原始7B权重运行，且部分模型不支持音频模态（见Table 5模型卡），这构成了基线对比的公平性边界。尽管如此，EMER的相对优势幅度（>20个Avg点）已远超合理的不公平性解释范围。

### 消融实验

#### 模态贡献分析

Table 3同时报告了EMER的单模态消融变体：**EMER(Text)**、**EMER(Video)** 和 **EMER(Audio)**。在英文设置下，EMER(Text)的Avg仅为47.13，EMER(Video)为60.67，EMER(Audio)为65.42，而融合所有线索的EMER(Multi)达到80.05。纯文本变体最弱，验证了情感表达的多模态本质——仅从字幕文字中难以捕捉完整的情感信息。视觉线索和声学线索各自提供了互补的消歧信号，三者融合后产生了显著的协同增益。Figure 4展示了从单模态描述到多模态描述的生成管线，直观说明了线索整合的路径。

#### 字幕整合策略对比

Figure 5和Table 7系统对比了三种字幕处理策略在多个MLLM上的表现：
- **S0**：完全忽略字幕，仅依赖视觉和声学线索。
- **S1**：将字幕直接拼入单步提示，要求模型一次性完成线索提取和消歧。
- **S2**：两步策略——先用S0提取线索，再用GPT-3.5以提取的线索消歧字幕。

核心发现是 **S2在所有MLLM上普遍优于S0，并在绝大多数情况下优于S1**。以EMER(Multi)的英文Avg为例，S2达到80.05，而S1仅为约72.5（从Figure 5估算）。这揭示了一个关键瓶颈：现有开源MLLM难以处理将字幕消歧与线索提取耦合在一起的复杂单步提示。分步消歧通过将任务分解为“线索提取”和“基于线索的字幕解读”两个子任务，显著降低了模型的认知负荷。这一发现具有工程指导意义：在构建多模态推理系统时，显式的推理步骤分解可能比端到端的单次生成更可靠。

#### 固定标签 vs. 开放词汇标签

Table 4报告了传统one-hot标签在开放词汇评估下的表现：英文准确率高达92.17，但召回率仅为50.67；中文准确率93.07，召回率51.67。高准确率表明one-hot标签本身是可靠的，但低召回率暴露了其根本缺陷——固定标签空间遗漏了约一半的正确情感类别。这直接支持了EMER的核心动机：从封闭集分类转向开放词汇提取，能够捕获更丰富、更微妙的情感表达。

### 跨语言影响分析

Figure 3和Table 3的语言对比揭示了两个层次的语言效应。首先，**性能排序在语言间高度一致**——在英文上表现好的模型在中文上也表现好，说明模型的相对能力具有跨语言稳定性。其次，**标签提取存在语言依赖性**：对同一段EMER描述分别用中英文提取标签，其集合级重叠率（OverlapS，公式见Formula部分）最高仅约0.82；若将英文标签翻译为中文后再计算重叠率，则进一步降至约0.15。这表明情感概念本身在不同语言中的边界并不完全重合，翻译过程会引入额外的语义偏移。这一发现对多语言情感系统的设计具有警示意义：不能简单假设情感标签的跨语言等价性。

### 匹配性指标的局限性

Table 8报告了各模型在BLEU-1/4、METEOR、ROUGE-L等传统文本匹配指标上的表现。Figure 6和Figure 8的指标相关性分析显示，这些匹配性指标与情感识别指标（Avg）之间的相关性较弱。这意味着“描述越接近EMER(Multi)的文本”并不等同于“情感识别效果越好”。匹配性指标无法低成本地替代情感评估，未来需要设计专门针对EMER任务的高效自动评估方法。

### 失败模式与局限性

1. **数据集规模瓶颈**：EMER数据集仅包含332个样本，从MER2023中选取。虽然标注质量经过了双重人工校验，但样本量限制了统计结论的稳健性和对长尾情感场景的覆盖。

2. **LLM依赖链的偏差累积**：标注过程依赖GPT-4V生成视觉/声学线索、GPT-3.5进行消歧和标签提取、以及GPT-3.5进行同义词分组。这一链条中的每个环节都可能引入幻觉和偏差，且尚未进行端到端的人工验证闭环。EMER的优越性部分可能源于其评估器（GPT-3.5）与生成器之间的同源偏好。

3. **解释可靠性未验证**：论文明确将“解释是否真正合理”的可靠性分析留待未来工作。当前评估仅关注标签层面的准确性，未考察EMER描述中的推理链条是否忠实于实际的多模态信号。

4. **跨语言公平性存疑**：同义词分组和标签提取均依赖GPT-3.5，其在中文上的分组一致性可能弱于英文，且跨语言标签对齐方法（翻译+重叠率计算）引入了不可控的语义损失。

5. **基线能力边界**：所有开源MLLM均以7B权重运行，未进行针对情感任务的微调或提示工程优化，部分模型（如VideoChat、Otter）不支持音频输入，这使比较的公平性受到模态覆盖度的限制。

## 方法谱系与知识库定位

### 任务范式的根本转变：从封闭集分类到开放词汇解释生成

传统多模态情感识别（MER）的核心瓶颈在于其封闭集分类范式：模型被训练将输入映射到一个固定的、预先定义的标签空间（如MER2023的6类基本情感）。这种范式隐含两个致命假设——标签空间完备且互斥，以及多数投票机制能消除标注歧义——而这两个假设在真实情感表达中均不成立。微妙情感（如“无奈的笑”、“压抑的愤怒”）往往跨越类别边界，或根本不在候选集中。

EMER通过**因果旋钮式重构**打破了这一范式。其核心操作是将任务目标从“预测标签”转换为“生成多模态解释”：模型首先输出一段自然语言描述（EMER description），详细阐述视觉、声学和词汇线索如何共同支撑某种情感判断，然后从该描述中以开放词汇方式提取情感标签。这一转换的关键效应是**解除了标签空间对模型表达能力的约束**：从EMER描述中实际提取出301个候选标签，平均每样本3个标签，远超MER2023的6类限制。同时，解释本身提供了预测的“依据链”，使标签可靠性获得可追溯的推理支撑。

### 与现有多模态大模型方法的对比定位

EMER并非孤立的方法创新，而是对2023年前后涌现的多模态大模型（MLLM）浪潮的**任务级重新定义**。表3的主实验结果清晰揭示了这一谱系关系：

- **直接预测基线**（如**VideoChat2** (Li et al., CVPR 2024)、**GPT-4V**、**PandaGPT** (Su et al., 2023)等）：这些模型被要求直接输出情感标签，但受限于封闭集思维或缺乏结构化推理，其Avg指标最高仅56.69（GPT-4V英文），远低于EMER(Multi)的80.05。
- **单模态解释变体**（EMER(Audio)、EMER(Video)、EMER(Text)）：作为消融对照，它们验证了多模态消歧的必要性——纯文本EMER(Text)最弱（Avg 47.13），说明仅靠字幕文本无法捕捉情感全貌；融合所有线索的EMER(Multi)比任何单模态变体高出至少14.6个百分点。
- **两步字幕整合策略S2 vs. 单步S1**：在所有MLLM上，先提取线索再消歧的S2策略普遍优于将字幕直接塞入提示的S1。这一发现揭示了一个深层问题：现有开源MLLM（7B规模）难以有效处理复杂的单步多模态推理提示，分步分解是当前模型能力边界下的务实选择。

值得注意的是，EMER的标签生成和评估流程深度依赖GPT-3.5和GPT-4V，这使其在方法谱系中处于“LLM增强标注与评估”与“端到端可解释情感识别”之间的过渡地带。其贡献不在于提出新的模型架构，而在于**定义了一个新的任务框架和评估体系**，为后续研究设立了基准。

### 适用边界与关键约束

EMER框架的适用性受以下边界条件限制：

1. **数据规模与多样性**：数据集仅332个样本且从MER2023选取，可能存在场景覆盖偏差。对于极端情感表达、长视频、或非对话场景的泛化性未经验证。
2. **LLM依赖链**：整个流程从线索预标注、消歧、描述生成到标签提取和同义词分组，均依赖GPT系列模型。这意味着：
   - 成本较高，难以大规模扩展；
   - 继承了LLM的幻觉和偏差，尤其在跨语言场景下（中英文标签重叠率最高仅约0.82，翻译后降至约0.15）；
   - 对特定LLM版本存在偏好，换用其他LLM的性能变化未充分探索。
3. **可靠性评估缺失**：当前仅评估标签准确性，未验证解释本身是否真正合理。论文明确指出“可靠性分析留待未来工作”。
4. **跨语言公平性**：同义词分组和标签提取均依赖GPT-3.5，在跨语言设置下可能出现基于语言而非语义的分组偏差，且情感定义本身存在语言依赖性。

### 开放问题与研究前景

EMER框架打开了若干值得深入的方向：

- **规模化与成本优化**：能否设计端到端的多模态LLM，直接生成EMER格式描述而无需分步调用GPT？这需要在保持解释质量的同时降低推理成本。
- **解释可靠性量化**：如何定义并自动评估“解释的可靠性”？这需要超越简单的标签匹配，建立解释忠实度、因果合理性的度量标准。
- **跨语言情感对齐**：当前标签提取和评估在跨语言场景下存在显著偏差，需要设计语言无关或语言公平的情感表示方法。
- **评估指标革新**：匹配性指标（BLEU、METEOR、ROUGE）与情感指标的相关性较弱（Figure 6、Figure 8），无法低成本替代人工评估。针对EMER任务设计高效自动评估指标是一个实际需求。
- **从解释到因果干预**：当前EMER解释是描述性的。未来工作可探索将解释转化为可操作的因果干预——例如，修改特定模态线索后预测情感变化，从而验证解释的因果效力。
