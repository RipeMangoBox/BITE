## 概要

真实物体与其屏幕图像之间常存在显著的光泽感知差异，根源在于显示设备有限的动态范围、峰值亮度和对比度无法忠实再现高光反射，导致观察者感知的 gloss 与实物不匹配。为此，本文提出一种基于粗糙度校正的光泽管理方法：通过大规模心理物理实验（42 名被试、480 种条件）量化跨媒介光泽感知偏移，建立多分类逻辑回归模型（Nagelkerke pseudo R² = 0.87），进而导出一个解析校正公式 $\alpha' = w_0(\mathbf{B}) + w_1(\mathbf{B})\alpha + w_3(\mathbf{B})\alpha^2$，以显示亮度 $\mathbf{B}$ 和光照条件为参数，对渲染中的 Cook-Torrance 粗糙度 $\alpha$ 进行补偿。两项应用的用户研究表明，经校正的渲染在数字产品设计和文物数字化场景中均显著提升了光泽匹配度（二项检验显著）。该方法将校正归结为对材料粗糙度参数的单一调整，且实验证明几何形状对校正的影响有限，为跨媒介一致 gloss 再现提供了低维、可操作的解决方案。

## 核心方法与创新机理

### 问题瓶颈：显示设备对光泽感知的扭曲

该工作的核心瓶颈在于：**标准2D显示器有限的动态范围、峰值亮度和对比度无法忠实再现真实物体光泽反射的高动态范围特性**。如Figure 5所示，除漫反射照明外，显示器在镜面高光区域普遍存在过饱和现象，而在暗部区域则无法准确再现低亮度细节。这种物理呈现能力的差异导致观察者在屏幕上感知到的光泽度与真实物体之间存在系统性偏差——低显示亮度下光泽被低估，高亮度下选择更接近真实但仍存在偏移。这一瓶颈从根本上限制了数字产品设计、文物数字化等需要跨媒介光泽一致再现的应用场景。

### 核心创新机理：基于粗糙度参数的分析型补偿模型

本文的核心创新在于提出了一种**分析型光泽校正模型**，通过调整渲染管线中Cook-Torrance BRDF的粗糙度参数α来补偿显示引起的感知光泽差异。其关键洞察是：**真实物体与屏幕图像之间的感知光泽度差异可通过心理物理实验量化，并可用一个依赖光照条件和显示亮度的低维参数模型有效补偿，且该补偿与物体几何形状弱相关**。

这一机理的本质是“感知驱动的前馈补偿”——不试图提升显示器的物理能力，而是通过修改渲染输入参数，使显示图像在感知上逼近真实物体的光泽体验。校正模型的形式为：

$$\alpha^{\prime} = w_0(\mathbf{B}) + w_1(\mathbf{B})\alpha + w_3(\mathbf{B})\alpha^2$$

其中α为原始Cook-Torrance粗糙度参数，α′为校正后的粗糙度，权重系数w₀、w₁、w₃依赖于显示亮度B和光照条件。该二次多项式形式简洁而有效：二次项捕捉了光泽感知的非线性特征，而系数对亮度B的依赖则反映了显示设备在不同亮度水平下对光泽再现能力的差异。

### 方法框架与模块顺序

整个光泽管理系统由四个核心模块顺序构成，形成从物理样本制作到最终校正应用的完整管线：

**模块一：物理光泽样本的制作与捕获（Fabrication and capture）**  
研究者通过3D打印制造了四种不同几何形状的物体（龙、幽灵、水滴、兔子），以覆盖不同的表面曲率分布。随后使用水性清漆混合物手工涂覆，通过调整光泽清漆与哑光清漆的比例（10%至100%，步长10%）获得10个离散光泽等级。这一步骤建立了可控的物理光泽基准，并通过预混清漆保证了表面光泽的均匀性。

**模块二：心理物理匹配实验（Psychophysical matching experiment）**  
实验采用跨媒介匹配范式：42名被试在真实物体与显示器上呈现的对应虚拟物体之间进行光泽度匹配。实验变量覆盖4种光照条件（漫反射、单聚光灯、三聚光灯、五聚光灯）、4种几何形状、3种显示亮度（暗、中、亮），共计480种实验条件。被试通过调整屏幕上虚拟物体的光泽等级，使其感知光泽度与真实物体一致。该实验产生的匹配数据直接量化了显示引起的感知偏差。

**模块三：多分类逻辑回归分析（Multinomial logistic regression analysis）**  
对匹配数据进行多分类逻辑回归建模，将光照条件、几何形状、显示亮度及其交互作用作为预测因子。完整模型达到Nagelkerke pseudo R² = 0.87（无交互项模型为R² = 0.85），所有因子及交互作用均显著（p < 0.001）。该分析揭示了各因素对光泽感知偏差的影响规律，并生成了针对每种光照-亮度组合的校正查找表。

**模块四：参数化校正模型（Parametric correction model）**  
将清漆混合比例V通过可逆映射α = M(V)转换为Cook-Torrance粗糙度参数α，然后应用二次校正函数得到α′。校正系数w(B)从回归分析结果中提取，针对每种光照条件分别确定。最终校正模型以公式形式给出，可直接集成到标准渲染管线中。

### 关键公式与变量含义

**粗糙度-清漆映射函数**：
$$\alpha = \mathcal{M}(V)$$
该函数将物理清漆混合比例V（光泽清漆百分比）映射为Cook-Torrance模型的粗糙度参数α。映射通过拟合实测BRDF数据获得，且为可逆函数，使得校正后的粗糙度α′可反向映射回清漆比例，从而指导物理制造。

**光泽校正模型**：
$$\alpha^{\prime} = w_0(\mathbf{B}) + w_1(\mathbf{B})\alpha + w_3(\mathbf{B})\alpha^2$$
其中：
- α：原始粗糙度（从清漆比例映射得到）
- α′：校正后的粗糙度（用于渲染）
- B：显示亮度条件（暗/中/亮）
- w₀(B)：常数偏移项，补偿显示亮度引起的整体光泽偏移
- w₁(B)：线性缩放系数，调整光泽变化的灵敏度
- w₃(B)：二次项系数，捕捉光泽感知的非线性饱和效应

值得注意的是，模型中没有w₂项（即α的一次项系数直接由w₁承担），这种参数化选择可能源于回归分析中特定多项式基的选择。

### 模块间的因果关系

四个模块之间存在清晰的因果链：**模块一**提供物理基准和参数化空间；**模块二**在可控条件下测量感知偏差，其匹配数据直接驱动**模块三**的统计建模；**模块三**识别显著影响因素并量化效应大小，为**模块四**的校正公式提供系数估计。最终校正模型在渲染时修改粗糙度参数，形成从物理测量到感知补偿的闭环。

### Changed Slot：渲染粗糙度参数的替换

该方法的**唯一changed slot**是渲染管线中材料的粗糙度参数。基线方法直接使用从清漆比例映射得到的测量粗糙度α进行渲染；而本文方法将其替换为校正粗糙度α′ = w₀(B) + w₁(B)α + w₃(B)α²。这一替换发生在渲染前的材质参数设置阶段，对渲染管线其余部分透明，因此可无缝集成到任何支持Cook-Torrance BRDF的渲染系统中。

### 几何无关性的实验支撑

校正模型的一个关键简化假设是**几何形状对校正的影响有限**。实验数据显示，龙模型与其他三种几何形状存在统计上的显著差异，但效应强度有限（“the strength is limited”）。基于此，研究者选择对几何形状取平均，构建与几何无关的校正模型。这一简化虽牺牲了部分精度（尤其是对具有复杂镶嵌结构的龙模型），但极大降低了模型的参数维度和应用复杂度。对于大多数平滑几何体（幽灵、水滴、兔子），该简化是合理的。

### 表面明度的边界条件

额外的控制实验揭示了表面明度对校正的影响规律：灰色表面与黑色表面的校正趋势非常相似，但白色兔子模型需要更大的校正量，且其校正规律更为复杂。这表明校正模型在暗色和中等明度表面上的泛化性较好，但在高反射率白色表面上需要进一步的研究和调整。该发现为模型的应用边界提供了明确的约束条件。

## 实验与关键发现

### 核心实验设计：跨媒介光泽感知的心理物理测量

实验的核心目标是量化真实物体与其屏幕再现之间的感知光泽度差异，并识别影响该差异的关键因素。研究团队构建了一个包含4种几何形状（龙、鬼、水滴、兔）、4种光照条件（漫反射、单聚光灯、三聚光灯、五聚光灯）、3档显示亮度（暗、中、亮）以及10个光泽等级的刺激集，共计480种实验条件。42名被试在真实物体与屏幕图像之间进行光泽度匹配判断。Figure 5揭示了差异的物理根源：漫反射光照下可实现精确的峰值亮度匹配，但在聚光灯光照下，屏幕无法再现真实高光区域的亮度动态范围，且暗部区域的再现精度在所有光照条件下均不足。

### 主结果：多分类逻辑回归模型的拟合与因素效应

采用多分类逻辑回归对匹配数据进行建模，完整模型（包含光照、几何、显示亮度及其交互项）的Nagelkerke伪R²达到**0.87**，所有主效应及交互效应均显著（p < 0.001）。去除交互项的简化模型R²降至0.85，表明因素间的耦合不可忽略。

Figure 6汇总了各因素的边际效应，关键发现如下：

- **显示亮度效应**：低亮度条件下被试系统性低估光泽度（选择的屏幕光泽等级低于真实物体对应等级）；高亮度下选择更接近真实值。这一趋势说明显示设备的亮度上限直接限制了光泽感知的保真度。
- **光照条件效应**：单聚光灯条件下中等光泽样本的匹配最为接近；复杂光照（三/五聚光灯）下偏差增大，与高光区域过饱和的物理限制一致。
- **几何形状效应**：鬼、水滴、兔三个模型的校正趋势高度相似，仅龙模型表现出系统性差异，但其效应强度有限。这一发现支持了后续校正模型对几何形状取平均的合理性。
- **表面明度效应**：灰色表面的校正趋势与黑色表面非常接近，但白色兔模型需要更大的校正量，且校正曲线呈现更复杂的非线性变化。

### 应用验证：两项用户研究

为验证校正模型的实际效果，研究者在两个应用场景中进行了二选一迫选用户研究：

1. **数字产品设计场景**（制造真实物体以匹配屏幕设计稿）：在漫反射和单聚光灯两种光照下，被试一致选择经校正的制造版本（即按校正模型调整清漆比例的真实物体）比未校正版本更接近屏幕图像的光泽度，二项检验显著（Figure 8左）。

2. **文物数字化场景**（屏幕再现需匹配真实物体）：在漫反射光照下，被试一致选择经校正的显示版本比未校正渲染更接近真实物体的光泽度，二项检验显著（Figure 8右）。

### 关键消融与边界条件

- **几何形状可平均化**：仅龙模型与其他几何存在有限差异，因此校正模型可对几何维度取平均而不显著损失精度。这简化了实际应用，但龙模型的异常提示复杂微几何（如鳞片状表面结构）可能与清漆产生未知的交互作用。
- **表面明度的边界**：黑色和灰色样本可共享相近的校正参数，但白色样本需要独立处理。白色表面的校正规律更为复杂，论文明确指出这需要进一步研究。
- **材料与光照的泛化限制**：所有实验均基于塑料3D打印件和水基清漆，未验证金属、木材等其他材料。实验在可控办公室光照下进行，更明亮的户外场景或更高动态范围的显示器可能需要重新标定校正参数。
- **显示设备的固有限制**：实验使用标准2D显示器，缺乏运动视差和双目立体等深度线索，这些线索在真实物体观察中天然存在，可能对光泽感知产生额外影响。

### 校正模型的量化形式

最终校正模型将感知匹配关系压缩为粗糙度参数的二次函数：

$$\alpha^{\prime} = w_0(\mathbf{B}) + w_1(\mathbf{B})\alpha + w_3(\mathbf{B})\alpha^2$$

其中$\alpha$为通过可逆映射$\alpha = \mathcal{M}(V)$从清漆混合比例$V$拟合得到的Cook-Torrance粗糙度，$\alpha^{\prime}$为校正后的粗糙度，权重$w_i(\mathbf{B})$依赖于显示亮度$\mathbf{B}$和具体光照条件。该模型将复杂的跨媒介感知差异封装为逐光照、逐亮度的低维查找表，可直接嵌入现有渲染管线。

### 实验效度说明

需注意以下效度限制：42名被试中包含2名作者（非盲），其余为本地学生，年龄和职业背景较单一，可能引入抽样偏差。性别比例均衡（20女/22男），但样本的代表性有限。所有结论基于塑料材质和特定清漆体系，向其他材料类别的推广需独立验证。

## 定位与知识库关联

### 问题定位：显示设备作为光泽感知的瓶颈

本文针对的核心问题是**跨媒介光泽再现的不一致性**：真实物体与其在标准2D显示器上的虚拟对应物之间存在系统性的感知光泽度差异。这一瓶颈的根源在于显示设备有限的动态范围、峰值亮度和对比度——尤其是高光区域因亮度饱和而无法忠实再现光泽反射的高动态范围（见Figure 5的亮度分布分析），导致观察者对显示图像的光泽度产生系统性偏差。传统渲染管线直接使用物理测量的材质参数（如Cook-Torrance粗糙度α）进行显示，并未对此差异进行补偿，因此构成了“未校正渲染”这一baseline。

### 改变的slot：渲染材质粗糙度参数

相对baseline，本文改变的核心slot是**渲染管线中的材质粗糙度参数**。Baseline直接使用从清漆混合比例V经由可逆映射$\alpha = \mathcal{M}(V)$获得的物理粗糙度α；本文提出的方法则将该粗糙度替换为校正值：

$$\alpha^{\prime} = w_0(\mathbf{B}) + w_1(\mathbf{B})\alpha + w_3(\mathbf{B})\alpha^2$$

其中权重系数$w(\mathbf{B})$依赖于显示亮度B和光照条件，通过心理物理实验数据的多分类逻辑回归拟合得到。这一改变的因果逻辑是：显示设备对光泽感知的扭曲效应可以通过调整渲染输入（粗糙度）来“预补偿”，使得显示图像在感知上与真实物体匹配。该slot改变不涉及显示硬件、观察条件或渲染算法的修改，仅作用于材质参数层面，因此具有高度的实用性和可集成性。

### 知识库挂载点

本工作可挂载到知识库的以下节点：

1. **感知驱动的图形学（Perception-driven Graphics）**：本文属于利用人类感知实验指导渲染参数调整的研究范式。与通用色调映射或感知均匀色彩空间不同，本文聚焦于光泽这一特定材质维度的跨媒介感知校准，提供了从心理物理数据到分析型校正模型的完整管线。

2. **外观再现（Appearance Reproduction）**：本文解决的是“真实-虚拟”外观匹配问题，与颜色管理、HDR显示、材质扫描与再现等子领域直接相关。其独特贡献在于将光泽感知差异量化为粗糙度参数空间的低维校正函数。

3. **心理物理实验方法**：本文使用的二选一强制选择（2AFC）匹配实验、多分类逻辑回归分析（Nagelkerke pseudo R² = 0.87，所有因子及交互作用p < 0.001），为外观感知研究提供了可复用的实验范式和统计框架。

### 与相关工作的本质差异

虽然论文未明确引用特定baseline方法进行直接对比，但从方法论角度可识别以下本质差异：

- **与直接使用测量参数的渲染（Uncorrected rendering）**：这是本文用户研究中使用的对照条件。差异在于是否对显示引起的感知偏差进行补偿。两个应用场景的用户研究均表明，校正后的版本在二项检验下被显著更频繁地选择（Figure 8），证实了补偿的必要性和有效性。

- **与通用色调映射/亮度重映射方法**：传统方法通常在图像空间调整亮度或对比度。本文选择在材质参数空间（粗糙度α）进行校正，其优势在于校正与渲染光照解耦，且对不同几何形状具有较好的泛化性（实验显示仅龙模型与其他几何有显著差异，且差异强度有限，因此作者选择对几何取平均）。

- **与基于物理的材质编辑**：本文的校正模型不修改底层BRDF模型结构，仅调整其输入参数，因此可以无缝嵌入现有的Cook-Torrance渲染管线。

### 适用边界与局限性

本文方法的适用边界明确，需在以下条件下理解其有效性：

1. **材质限制**：实验仅使用塑料3D打印基底和水基清漆（glossy varnish与matte varnish混合），未验证对金属、木材、织物等其他材质类别的泛化性。不同材质的表面散射特性（如金属的复折射率、次表面散射）可能改变显示引起的感知偏差模式。

2. **光照条件限制**：实验在可控的办公室环境光照下进行，覆盖了漫射、单聚光、三聚光和五聚光四种照明。更明亮的户外场景或极端高动态范围光照可能需要不同的校正参数。

3. **显示设备限制**：使用标准2D显示器，不具备运动视差、双目立体等深度线索。这些线索可能影响对表面光泽的感知判断，尤其是在镜面反射方向附近。

4. **几何复杂性**：虽然整体上几何影响有限，但龙模型（具有复杂的镶嵌曲面）表现出与其他几何不同的校正趋势。微几何与清漆的相互作用机制尚不清楚，这构成一个已知的失效模式。

5. **表面明度**：灰色与黑色表面的校正趋势相似，但白色物体（white bunny）需要更大且规律更复杂的校正，作者明确指出这需要进一步研究。

### 后续工作启发

本文为以下研究方向提供了直接起点：

1. **材质类别扩展**：将校正模型推广到金属、木材、织物等不同材质类别，探索是否可以通过引入额外的材质相关参数来统一描述。

2. **显示技术泛化**：在HDR显示器、近眼显示（VR/AR）等不同显示模态下验证和调整校正模型，特别是具有更高峰值亮度和动态范围的设备可能缩小感知差异。

3. **替代粗糙度调制技术**：作者提出将校正方法应用于抛光、微结构图案化等其他表面粗糙度修改技术，这为数字化制造和产品设计提供了新的应用场景。

4. **微几何交互的深入理解**：龙模型的异常行为提示微几何与光泽感知之间存在未被建模的交互效应，这需要更系统的几何参数化研究和感知实验。

5. **白色物体的特殊校正规律**：白色表面的非线性校正需求暗示了漫反射分量与镜面反射分量之间的感知交互可能比预期更复杂，值得独立研究。
