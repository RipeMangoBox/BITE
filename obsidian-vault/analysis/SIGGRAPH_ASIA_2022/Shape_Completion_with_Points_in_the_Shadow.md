> [!tip] 核心洞察

## 概要

单视角点云补全的核心瓶颈在于：由于遮挡和稀疏采样，未观测区域的几何形状高度欠约束，传统方法依赖全局特征到完整形状的映射，容易产生模糊结果或与输入不一致的伪影。本文提出“Points in the Shadow”方法，借鉴计算机图形学中的阴影体技术——将相机视为点光源，则物体不可见部分必然位于观测点遮挡形成的阴影体内。基于此，将补全过程建模为沿光线的有向点位移优化问题：首先将观测点沿相机光线复制并移动以生成初步补全点，再通过基于偏移量的自适应局部约束（offset-constrained refinement）控制精细化移动范围，从而大幅收缩解空间并保留观测细节。

在MVP数据集上，该方法在所有指标上均优于7种基线方法，包括此前最强的SnowflakeNet：CD从2.696降至2.419，F-Score从0.796升至0.800，专门衡量未观测区域补全质量的SCD₂从4.683降至3.896。消融实验证实，偏移约束和偏移调整两个模块对观测保真度与补全质量分别起决定性作用。该方法属于“几何约束驱动补全”范式，与依赖全局特征解码或对称性启发式的现有方法形成根本区别。

## 核心方法与创新机理

### 问题瓶颈与核心洞察

单视角点云补全的根本困难在于：从单一视点观察到的部分扫描中，未观测区域的几何形状高度欠约束，解空间巨大。传统方法（如PCN、MSN、SnowflakeNet等）几乎完全依赖网络从全局特征中“猜测”缺失几何，缺乏显式的几何先验约束，导致生成结果常与输入不一致、细节模糊或产生错误的对称化。

本文的核心洞察借鉴了计算机图形学中的**阴影体（shadow volume）**概念：将相机视为点光源，则物体不可见部分必然位于观测点遮挡形成的阴影体内。因此，补全的候选几何被严格限制在阴影体内部，而相机到每个观测点的光线则构成补全的天然基底——缺失点应当沿这些光线分布。这一几何约束将补全问题从“任意生成完整形状”转化为“沿光线有向移动点并局部精炼”，大幅收缩了解空间。

### 方法总览与模块顺序

方法将补全过程建模为**点位移优化问题**：点初始化为部分扫描的观测点，通过两类运动到达目标位置——沿光线的有向运动（directional movement）和受约束的局部运动（constrained local movement）。网络由两大核心模块串联构成：

1. **光线构造（Ray Construction）**：从相机位置向每个观测点投射光线，构成补全基。
2. **偏移预测模块（Offset Prediction Module）**：包含初始偏移预测（O-Predictor）和偏移调整（O-Adjustment），沿光线生成初步补全点。
3. **偏移约束精炼模块（Offset Constrained Refinement Module, OCRU）**：通过两层OCRU对初步补全点进行局部移动，移动范围受偏移量自适应约束。

### 关键 Changed Slots

#### Slot 1：补全解空间约束

- **基线值**：无显式几何约束，依赖全局特征解码或镜像对称等启发式策略。
- **提出值**：利用相机位姿建立阴影体和光线集合，将补全限制在受遮挡体内部并沿光线进行。这从根本上改变了问题的几何正则化方式——补全不再是“凭空生成”，而是在物理上合理的受限空间内搜索。

#### Slot 2：点云生成策略

- **基线值**：直接预测完整点云坐标、点代理（如FoldingNet式折叠），或通过合并输入与生成结果后再子采样（如MSN）。
- **提出值**：在每条光线上预测偏移量，将观测点复制并沿光线移动生成初步补全点，再通过偏移调整网络修正。生成过程天然保持与观测部分的几何连续性。

#### Slot 3：局部精炼约束

- **基线值**：使用折叠操作或点解卷积（SPD）进行无约束的局部调整。
- **提出值**：基于每个点的光线偏移量计算自适应约束值，限制SPD输出的移动向量幅度——靠近观测部分的点几乎不被移动（保留细节），远处点有更大自由度（填充缺失区域）。

### 模块详解与因果链路

#### 3.1 光线构造与问题形式化

给定部分扫描点云 $P = \{p^i\}_{i=1}^{N}$ 和相机位置 $Cam$，对每个观测点定义光线 $\vec{r}_i = p^i - Cam$。光线集合 $R = \{r_i\}$ 构成补全的一维基底：缺失几何应当位于这些光线上、观测点之后（相对于相机）。这一形式化将三维补全问题降维为一维偏移量预测问题。

#### 3.2 偏移预测模块

偏移预测模块（Fig. 4）分两步沿光线生成初步补全点：

![[assets/figures/papers/paper_list_l87_https_arxiv_org_abs_2209_08345/figures/004_Figure_4.jpg]]
*Figure 4: The structure of the offset prediction module. It contains the initial offset prediction (O-Predictor) and the offset adjustment (O-Adjustment)*

**第一步：初始偏移预测（O-Predictor）**。对每个观测点 $p^i$，在每条光线上复制生成 $L$ 个点，预测每个复制点沿光线的偏移量：

$$p_o^{i,l} = p^i + \mathcal{F}_d^l(p^i) \cdot \vec{r}_i$$

其中 $\mathcal{F}_d^l$ 为第 $l$ 个复制点预测的标量偏移，$p_o^{i,l}$ 为初步补全点。这一步生成 $N \times L$ 个点，构成对缺失几何的粗糙估计。

**第二步：偏移调整（O-Adjustment）**。初始偏移可能存在系统偏差，偏移调整网络对每个初步补全点的偏移量进行修正（Fig. 3(c)中绿色点表示正向调整，红色点表示负向调整），输出调整后的点集作为后续精炼的输入。

**因果链路**：O-Predictor 提供沿光线的粗糙几何估计 → O-Adjustment 修正偏移偏差 → 输出具有合理全局结构的初步补全点云。

#### 3.3 偏移约束精炼模块（OCRU）

初步补全点云虽然具有合理的全局结构，但局部细节仍需精炼。传统SPD（Snowflake Point Deconvolution）允许点自由移动，容易破坏观测部分的几何保真度。OCRU的核心创新在于：**利用偏移量信息自适应约束精炼移动范围**。

对第 $j$ 个初步补全点，计算其总偏移量 $O_j$（沿光线的总移动距离），在第 $u$ 层OCRU中的约束值为：

$$C_u^j = f_c(O_j, u) = (O_j / 2 + 0.03) / \alpha^{u-1}$$

其中 $\alpha = 1.5$。该公式的因果含义：

- **$O_j$ 小** → 该点靠近观测表面 → $C_u^j$ 小 → 精炼移动被严格限制 → **观测细节得以保留**。
- **$O_j$ 大** → 该点远离观测表面（位于缺失区域深处） → $C_u^j$ 大 → 精炼移动自由度大 → **缺失区域可灵活调整**。
- **层间衰减**：$u$ 增大时 $C_u^j$ 减小（除以 $\alpha^{u-1}$），使得精炼逐层收敛，避免过度变形。

OCRU内部流程（Fig. 5）：SPD预测无约束移动向量 $\vec{v}$ → 通过 $f_c$ 计算约束值 $C$ → 将 $\vec{v}$ 裁剪到 $[-C, C]$ 范围内得到约束移动 $\vec{v}_c$ → 更新点位置：

![[assets/figures/papers/paper_list_l87_https_arxiv_org_abs_2209_08345/figures/005_Figure_5.jpg]]
*Figure 5: The structure of offset constrained refinement unit (OCRU). We use function*

$$p_*^{m,k} = p_o^m + \mathcal{F}_{\vec{v}}^k(p_o^m)$$

其中 $\mathcal{F}_{\vec{v}}^k$ 为第 $k$ 个精炼步骤的约束移动函数。方法使用两层OCRU串联，逐步提升局部几何质量。

**因果链路**：偏移预测模块输出初步补全点 + 偏移量信息 → OCRU层1：基于偏移量约束进行粗精炼 → OCRU层2：进一步细精炼（约束更紧） → 最终补全点云。

### 训练策略与损失函数

网络端到端训练，使用对称Chamfer距离（CD）作为主损失：

$$\mathcal{L}_{CD}(P_1,P_2) = \sum_{p\in P_1} \min_{q\in P_2} ||p-q||_2^2 + \sum_{q\in P_2} \min_{p\in P_1} ||q-p||_2^2$$

训练时，损失直接作用于最终补全结果与真值之间。由于光线构造和偏移约束已提供强几何正则化，无需额外的中间监督或对抗训练。

### 推理路径

推理时：输入部分扫描 + 相机位姿 → 构造光线 → O-Predictor预测初始偏移 → O-Adjustment修正偏移 → 得到初步补全点云 → 两层OCRU精炼 → 输出最终补全结果。整个过程确定性强，无随机采样步骤，保证输出稳定。

### 方法边界条件

方法有效性依赖两个前提：(1) 已知相机视点（消融实验表明使用预测视点时性能仍优于基线，但略有下降）；(2) 部分扫描质量足够覆盖物体主要结构（极端遮挡或扫描质量极低时恢复困难）。当前方法生成单一补全结果，未建模多模态几何分布。

## 实验与关键发现

### 评估设置

实验在 **MVP（Multi-View Partial）** 数据集上进行。该数据集包含 16 个 ShapeNet 类别共 4000 个 CAD 模型，每个模型从 26 个相机位姿渲染部分扫描。训练/测试按模型划分（无重叠），训练集使用 62,400 对、测试集使用 41,600 对，所有对比方法在相同数据划分上评估。

除传统指标 Chamfer Distance（CD）、F-Score 和 Density-aware Chamfer Distance（DCD）外，本文引入 **Split CD（SCD）** 指标，将真值点云和补全结果按是否位于观测点邻域切分为两部分，分别评估：**SCD₁** 衡量观测部分的保真度（值越低表示输入细节保留越好），**SCD₂** 衡量未观测部分的补全质量（值越低表示生成几何越合理）。这一细粒度指标能区分“保留输入”与“生成缺失区域”两个子任务的表现。

### 主实验结果

在 MVP 数据集上与 7 种基线方法全面对比，结果见 **Table 1**。本文方法在所有指标上均取得最优：

![[assets/figures/papers/paper_list_l87_https_arxiv_org_abs_2209_08345/figures/008_Table_1.jpg]]
*Table 1: Evaluation for each method. ???? and ?????? are multiplied by*

| 指标 | 本文方法 | SnowflakeNet（最优基线） | 提升幅度 |
|------|----------|-------------------------|---------|
| CD (×10⁴) | **2.419** | 2.696 | −0.277 |
| F-Score | **0.800** | 0.796 | +0.004 |
| DCD (×10⁴) | **0.513** | 0.524 | −0.011 |
| SCD₁ (×10⁴) | **0.646** | 0.951 | −0.305 |
| SCD₂ (×10⁴) | **3.896** | 4.683 | −0.787 |

关键发现：

1. **观测部分保真度大幅领先**：SCD₁ 从 SnowflakeNet 的 0.951 降至 0.646，降幅达 32%。这表明基于偏移约束的精炼机制有效锁定了输入观测点附近的几何，避免被过度修改。相比之下，其他方法在补全过程中往往模糊甚至破坏输入部分的边界、孔洞和凹陷等关键细节。

2. **未观测部分补全更合理**：SCD₂ 从 4.683 降至 3.896，降幅约 17%。将补全限制在阴影体内并沿光线生成点的策略，有效收缩了解空间，使缺失区域的几何推断更加准确，减少了不合理的凸起或空洞。

3. **整体形状质量最优**：CD 和 F-Score 的领先幅度虽不如 SCD 显著，但仍一致优于所有基线。这验证了方法的整体有效性——不仅局部保真度好，全局形状也正确。

定性对比（**Fig. 7**）进一步支撑上述结论：本文方法能清晰保留输入扫描中的边界轮廓、孔洞和凹陷等拓扑/几何特征，而 **ME-PCN**、**PoinTr** 和 **SnowflakeNet** 等方法常模糊这些细节，甚至错误地进行对称化补全。

### 消融实验

**Table 2** 报告了关键模块的消融结果：

#### 偏移约束的作用（No offset constraint）

移除 OCRU 中的偏移约束后：
- **SCD₁ 从 0.646 升至 0.827**（恶化 28%），观测部分保真度显著下降；
- CD 从 2.419 升至 2.628，F-Score 从 0.800 降至 0.791，DCD 从 0.513 升至 0.568。

这表明无约束的局部精炼（类似 SnowflakeNet 的 SPD 操作）会不加区分地移动所有点，导致观测区域的几何被“修平”或扭曲。偏移约束的核心作用在于：靠近观测位置的点（偏移量小）几乎不被移动，而远离观测位置的点（偏移量大）拥有更大调整自由度，从而在精炼过程中保护输入细节。**Fig. 9** 的定性对比直观展示了无约束版本对孔洞和边界的破坏。

#### 偏移调整的作用（No adjustment）

移除偏移调整步骤后：
- **SCD₂ 从 3.896 升至 4.090**，未观测区域补全质量下降；
- CD 从 2.419 升至 2.528，F-Score 从 0.800 降至 0.790。

偏移调整网络（O-Adjustment）在初始偏移预测基础上进行逐点修正，使沿光线的点分布更贴合真实几何。缺少该步骤时，初步补全结果在未观测区域出现空洞或不完整部分（**Fig. 8**），说明初始偏移预测的精度不足以独立完成高质量补全。

#### 每条光线生成点数的影响

**Table 3** 探索了沿每条光线生成不同数量点的效果：

| 每条光线点数 | CD (×10⁴) | F-Score | SCD₂ (×10⁴) |
|-------------|-----------|---------|-------------|
| 2 | 2.571 | 0.790 | 4.097 |
| 3 | 2.446 | 0.798 | 3.952 |
| **4** | **2.419** | **0.800** | **3.896** |
| 5 | 2.425 | 0.799 | 3.899 |

4 个点取得最佳整体性能。点数过少（2-3 个）导致光线上的表示能力不足，无法充分覆盖阴影体内的几何变化；点数过多（5 个）性能不再提升甚至略降，可能原因是在物体内部产生冗余填充，干扰了后续精炼模块的优化。

### 对不精确视点的鲁棒性

### 适用边界与失败模式

1. **扫描质量依赖**：方法的核心机制依赖于观测点定义的阴影体和光线基底。当部分扫描质量极低、关键结构大面积缺失时（如仅扫描到物体的一小片平坦区域），阴影体无法提供有效的几何约束，恢复正确的局部细节存在困难。

2. **单一输出限制**：当前方法生成确定的单一点云结果，未考虑高度不确定性场景下的多模态补全。对于遮挡严重的区域，可能存在多种合理几何，方法无法输出分布或提供备选方案。

3. **合成数据评估局限**：所有实验在 MVP 合成数据集上进行，缺少真实扫描（如 RGB-D 相机或 LiDAR 采集的部分点云）上的评估。真实数据中的噪声、稀疏性和不规则采样可能对光线构建和偏移预测带来额外挑战，泛化能力有待验证。

4. **网格重建未探索**：方法输出为点云，未尝试沿光线预测隐式函数以直接重建网格。这限制了在需要高质量表面表示的下游任务中的应用潜力。

## 定位与知识库关联

本文的核心贡献在于为单视角点云补全引入了一个**显式的几何约束槽位**（补全解空间约束），这是与现有方法最本质的差异。现有主流方法——从早期基于全局特征的 **PCN** (Yuan et al., 2019)、基于合并采样的 **MSN** (Liu et al., 2019)，到较新的基于点移动的 **PMP-Net++** (Wen et al., 2022)、基于Transformer的 **PoinTr** (Yu et al., 2021) 和基于点解卷积的 **SnowflakeNet** (Xiang et al., 2021)——在生成未观测几何时，几乎完全依赖网络从全局特征中隐式学习完整形状的先验分布，解空间巨大且缺乏对生成位置的硬约束。这导致两个典型失效模式：一是观测部分的边界、孔洞等细节在补全过程中被模糊或错误修正；二是未观测区域产生与输入不一致的几何（如错误对称化）。

本文改变的**关键槽位**是：将“无显式几何约束的全局特征解码”替换为“基于相机视点的阴影体约束与光线引导的点位移优化”。具体而言，方法借鉴计算机图形学中的阴影体（shadow volume）概念——将相机视为点光源，则物体未观测部分必然位于观测点遮挡形成的阴影体 $V_c$ 内，而 $V_c$ 以外的 $V_f$ 为禁止区域。这一几何约束将补全的解空间从整个三维空间大幅收缩至阴影体内部，从根本上降低了问题的欠约束程度。在知识库中，该槽位的挂载点可定位于**基于物理/几何先验的3D重建与补全**分支，与以下工作形成互补或对比关系：

- **基于视觉外壳（visual hull）的方法**：阴影体本质上是一种从单视角构造的保守视觉外壳近似。传统多视角视觉外壳需要多视角轮廓，而本文仅用单视角深度/点云和相机位姿即可构造约束体，这是对视觉外壳思想在单视角补全场景的适配与简化。
- **PMP-Net++** (Wen et al., 2022)：同样采用“点移动”范式，但其移动方向和范围由网络隐式预测，缺乏沿光线的方向性约束和基于偏移量的自适应局部约束。本文的位移优化可视为在PMP-Net++范式上叠加了显式几何引导。
- **SnowflakeNet** (Xiang et al., 2021)：其SPD（Snowflake Point Deconvolution）模块在局部精炼时无移动范围约束，本文的OCRU模块通过公式 $C_u^j = (O_j/2 + 0.03) / \alpha^{u-1}$ 将SPD输出约束在自适应范围内，这是对点解卷积精炼策略的关键改进。

**适用边界**方面，方法存在以下限制：

1. **扫描质量依赖**：当部分扫描质量低、关键结构严重缺失时，阴影体本身的信息量不足，恢复正确局部细节仍存在困难。这提示该方法更适合扫描覆盖率不低于一定阈值（如单视角可见面占比>30%）的场景。
2. **单一解输出**：当前方法仅生成一个确定性补全结果，未建模几何分布。对于高度遮挡或对称性模糊的物体（如仅看到椅子腿的一半），多种合理补全可能存在，但方法无法输出多样性结果。
3. **视点依赖**：主实验假设已知真实相机视点。消融研究表明使用预测视点时性能略有下降但仍优于基线，说明框架对不精确视点有一定鲁棒性，但极端错误的视点估计可能导致阴影体构造失败。
4. **合成数据验证**：仅在MVP（Multi-View Partial）合成数据集上评估，缺乏真实扫描（如RGB-D相机、LiDAR）的泛化验证。真实数据中的噪声、缺失区域不规则性可能挑战阴影体构造的可靠性。

**后续研究启发**：

1. **生成式扩展**：将补全过程从确定性点位移扩展为概率性生成，在阴影体约束下学习几何分布，以支持多样化补全。这需要设计条件生成网络（如条件扩散模型），以阴影体为条件生成多种可能几何。
2. **隐式场重建**：当前方法沿光线生成离散点，可探索沿光线预测隐式占用场或SDF，直接重建网格，可能获得更高质量的光滑表面。这需要设计沿光线的连续场预测网络和相应的训练策略。
3. **多视角扩展**：将单视角阴影体扩展至多视角阴影体交集，可进一步收缩解空间。这需要设计视角间信息融合机制，可能适用于多帧扫描补全场景。
4. **与视觉基础模型结合**：利用单目深度估计或视觉语言模型预测物体语义类别和典型形状先验，与阴影体几何约束互补，在极度稀疏观测下提供额外引导。
5. **真实场景适配**：针对真实扫描中的噪声和缺失，需要研究阴影体的鲁棒构造方法（如基于概率占有率的软阴影体），以及域适应训练策略。

总体而言，本文的核心知识贡献在于**将图形学中的阴影体概念系统性地引入学习式补全框架**，通过显式几何约束缩小解空间，从而在观测保真度和补全合理性两个维度同时超越纯学习式方法。这一“几何约束+学习优化”的混合范式为其他欠约束3D重建任务（如单视角深度估计、新视角合成）提供了可迁移的设计思路。
