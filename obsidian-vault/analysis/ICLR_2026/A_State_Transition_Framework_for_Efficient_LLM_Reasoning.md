## 概述

本文针对长链思维（Long CoT）推理中Transformer注意力机制计算复杂度随上下文长度二次增长、KV缓存内存开销线性增长的核心瓶颈，提出了一种状态转移推理框架。核心思路是将推理过程建模为状态转移过程：利用线性注意力机制将历史推理信息压缩为状态矩阵，使当前推理步的每个token可直接从状态矩阵检索历史信息，从而在不缩短或简化CoT序列的前提下，将注意力计算复杂度从O(C²)降为O(C)、KV缓存内存开销从O(C)降为O(1)。

该方法的核心洞察在于：推理步中的语言信息主要用于保证流畅性，而推理信息（如结论）才是支持后续推理的关键。基于此，论文设计了混合注意力模块（MAM）替换原始注意力模块，包含两个子模块：Softmax注意力子模块（仅关注当前推理步内token和查询提示，保持局部上下文建模）和线性注意力子模块（通过状态矩阵检索历史推理信息）。此外，还提出了基于状态的推理策略，利用动量法累积全局推理方向来校正当前推理步方向，缓解噪声步导致的过度思考问题。训练目标结合了自回归损失和知识蒸馏损失（KL散度），使线性注意力子模块学习全局推理信息。

在数学推理基准（AIME24、MATH500等）上的主实验结果显示，所提框架在1.5B和7B模型上均取得了平均准确率优于所有基线（包括Qwen2.5基模型、TAMM、SBT-D、L1-Max、AR等对比方法）的结果：1.5B模型平均准确率56.2%，7B模型68.3%。在AIME24上，推理速度相比基模型提升16-18%（相对速度440.13和434.8）。当CoT长度达到32K时，推理速度比基模型快40%以上。消融实验证实，移除模型推理状态（替换为64大小的滑动窗口）导致性能下降最大（平均准确率从56.2降至46.8），移除蒸馏损失和基于状态的推理策略也导致显著性能下降。该方法在科学推理（GPQA Diamond）和代码生成（HumanEval）基准上也优于所有基线，表明其泛化能力。

## 背景与动机

大语言模型（LLM）的长链思维（Long Chain-of-Thought, Long CoT）推理在提升复杂任务准确率的同时，暴露了严重的效率瓶颈。其根本原因在于Transformer注意力机制的计算复杂度随上下文长度呈二次增长，而KV缓存的内存开销呈线性增长。当推理链长度达到数万token时，这种复杂度增长导致推理延迟显著增加，成为实际部署中的关键障碍。

现有缓解方法主要聚焦于缩短或压缩CoT序列本身，例如通过提示压缩（TAMM）、监督微调缩短（SBT-D）、强化学习缩短（L1-Max）或直接去除不重要token（AR）。然而，这些方法本质上是在“简化”推理过程，可能牺牲模型的推理深度和可解释性。它们并未解决注意力机制本身的复杂度问题，而是试图绕过它。

该论文的核心洞察在于：**推理步中的语言信息主要用于保证流畅性，而推理信息（如中间结论）才是支持后续推理的关键**。基于此，作者提出将推理过程建模为状态转移过程，用线性注意力机制将历史推理信息压缩为状态矩阵，使当前推理步的每个token可直接从状态矩阵检索信息，无需显式关注之前推理步的每个token。这一设计将注意力计算复杂度从二次降为线性，同时将KV缓存内存开销从线性降为常数，且无需缩短或简化CoT序列。

该动机在实验证据中得到支撑：在AIME24上，所提模型推理速度相比基模型提升16-18%（相对速度440.13和434.8）；当CoT长度达到32K时，推理速度比基模型快40%以上。这些数据表明，状态转移框架在保持完整推理链的前提下，实现了显著的效率提升。

## 核心创新

该工作的核心瓶颈在于长链推理（Long CoT）中 Transformer 注意力机制的二次复杂度与线性 KV 缓存内存开销。其因果旋钮在于将推理过程重新建模为状态转移过程，用线性注意力机制将历史推理信息压缩为状态矩阵，使得当前推理步的每个 token 可直接从该矩阵检索信息，无需显式关注先前推理步中的所有 token。核心洞察在于：推理步中的语言信息主要用于保证流畅性，而推理信息（如中间结论）才是支持后续推理的关键；通过线性注意力将推理信息压缩为状态矩阵，可在不缩短或简化 CoT 序列的前提下，将注意力计算复杂度从二次降为线性，同时保持推理能力和可解释性。

该框架对基线模型（Qwen2.5-1.5B-Instruct / Qwen2.5-7B-Instruct）的关键变更集中在四个槽位：

1. **注意力模块**：原始 Softmax 注意力（每个 token 可关注所有历史 token）被替换为混合注意力模块（MAM），包含两个子模块：Softmax-Attention (SA) 子模块仅关注当前推理步内的 token 和查询提示，将计算复杂度从二次降为线性；Linear-Attention (LA) 子模块通过状态矩阵检索历史推理信息。SA 和 LA 的输出经门控机制合并后得到 MAM 最终输出（公式 $\widetilde{h}_{t,i-1}^{(l)} = W_o(\check{h}_{t,i-1}^{(l)} + \hat{h}_{t,i-1}^{(l)})$）。

2. **KV 缓存管理**：基线保留所有历史 token 的 KV 向量（内存开销 $O(C)$），而所提方法仅保留当前推理步和查询提示的 KV 向量，完成推理步后清除，将内存开销降为 $O(1)$。这直接源于 LA 子模块中状态矩阵 $S_t = \sum_{i=1}^t k_i^\top v_i$ 的累积更新机制——历史信息被压缩进 $d \times d$ 的矩阵，而非逐 token 存储。

3. **推理策略**：基线无全局方向引导，每个推理步独立更新状态。所提方法引入基于状态的推理策略，用动量法累积所有先前推理步的推理方向得到全局方向 $\bar{\nabla}_{t-1}^l = \frac{1}{t-1} \sum_{i=1}^{t-1} \nabla_i^l$，并据此校正当前推理步方向 $\hat{\nabla}_t^l = (1 - \alpha) \nabla_t^l + \alpha \bar{\nabla}_{t-1}^l$，其中 $\alpha$ 随步数线性增加至 $\alpha_{\text{max}}$。该策略旨在缓解噪声推理步导致的过度思考问题。

4. **训练目标**：基线仅使用自回归损失 $\mathcal{L}_{\text{AR}}$，而所提方法联合优化两项损失：$\mathcal{L} = \mathcal{L}_{\text{AR}} + \beta \mathcal{L}_{\text{KD}}$，其中 $\mathcal{L}_{\text{KD}} = \text{KL}(\hat{P}(A,T|Q) \parallel P(A,T|Q))$ 是基模型与所提模型输出分布之间的 KL 散度。蒸馏损失 $\mathcal{L}_{\text{KD}}$ 专门用于训练 LA 子模块捕捉全局推理信息——消融实验表明，移除该损失导致所有基准上性能下降 3.6–6.6 个百分点（平均准确率从 56.2 降至 50.8）。

该框架还包含两个辅助模块：门控机制根据 token 在推理步中的位置动态控制对历史推理信息的依赖程度（早期 token 依赖高，后期依赖低），以及 CoT 分割与类型标注模块（使用 K-means 聚类将推理步标注为 128 种思考类型）。此外，线性注意力的状态更新可被解释为测试时训练（TTT）过程：$\mathcal{L}(S) = -\langle S k_t, v_t \rangle; \quad S_t = S_{t-1} - \beta \nabla \mathcal{L}_t(S_{t-1}) = S_{t-1} + \beta v_t k_i^\top$。

决定性证据来自主实验（Table 1）和消融实验（Table 2）：所提框架在数学推理基准上平均准确率优于所有基线（1.5B 模型 56.2%，7B 模型 68.3%），在 AIME24 上推理速度相比基模型提升 16–18%（相对速度 440.13 和 434.8）；当 CoT 长度达到 32K 时，推理速度比基模型快 40% 以上。消融实验中，移除模型推理状态（替换为 64 大小的滑动窗口）导致性能下降最大（平均准确率从 56.2 降至 46.8），而移除基于状态的推理策略导致平均准确率下降 3.54 个百分点（56.2→52.6），证实了状态压缩和全局方向校正两个创新点的有效性。

需注意，实验仅在 Qwen2.5 系列（1.5B 和 7B）上验证，未在更大规模模型或不同架构上测试；训练数据来自特定长 CoT 数据集，可能引入领域偏差；推理速度比较基于相对速度（ReL），未报告绝对时间或硬件配置细节。

## 整体框架

![[assets/figures/papers/iclr26_0004_Zz8ikW4uWG_A_State-Transition_Framework_for_Efficient_LLM_R/figures/002_Figure_2.jpg]]
*Figure 2: In our framework, the original softmax attention module in LLMs is replaced with our mixed attention module (MAM), thus improving reasoning efficiency and reducing memory cost*

该工作将LLM的长链推理过程重新建模为**状态转移过程**，其核心动机在于：传统基于token的注意力机制中，计算复杂度随上下文长度呈二次增长（O(C²)），KV缓存内存开销呈线性增长（O(C)），这严重制约了长CoT推理的效率。框架的关键洞察是——推理步中的语言信息主要用于保证流畅性，而推理信息（结论）才是支持后续推理的核心；通过将推理信息压缩为状态矩阵，可在不缩短CoT序列的前提下将注意力复杂度降为线性。

**Pipeline与模块关系**：框架由三个核心模块构成，它们协同替换了原始LLM中的标准注意力模块，并引入新的推理与训练策略。

1.  **混合注意力模块 (Mixed Attention Module, MAM)**：这是替换原始注意力模块的核心组件（Figure 2）。MAM包含两个并行子模块：
    - **Softmax注意力子模块 (SA)**：沿用原始softmax注意力，但其注意力范围被限制——每个token只能关注查询提示（Query Prompt）和**当前推理步内**已生成的token。这直接切断了跨推理步的显式注意力，将计算复杂度从全局二次降低为步内局部。
    - **线性注意力子模块 (LA)**：通过简化线性注意力（恒等核，无归一化，公式 $O_t = q_t S_t; S_t = \sum_{i=1}^t k_i^\top v_i$）维护一个**推理状态矩阵 $S_t$**。该矩阵以在线学习（测试时训练）的方式逐token更新（$S_t = S_{t-1} + \beta v_t k_i^\top$），压缩并累积了所有已完成推理步的历史推理信息。当前推理步的token通过门控机制 $\check{h}_{t,i-1}^{(l)} = \sigma(\check{W}_g h_{t,i-1}^{(l-1)}) * o_{i-1}^{(l)}$ 从该状态矩阵中检索所需信息，而非关注原始token。
    - **门控机制**：根据token在推理步中的位置动态控制其对历史推理信息的依赖程度。实验表明，推理步早期的token依赖更高，后期的token依赖更低（Figure 5(b)）。

2.  **基于状态的推理策略 (State-based Reasoning Strategy)**：为缓解噪声推理步导致的“过度思考”问题，该策略引入动量法。它维护一个全局推理方向 $\bar{\nabla}_{t-1}^l = \frac{1}{t-1} \sum_{i=1}^{t-1} \nabla_i^l$，并用它来校正当前推理步的方向：$\hat{\nabla}_t^l = (1 - \alpha) \nabla_t^l + \alpha \bar{\nabla}_{t-1}^l$。超参数 $\alpha$ 随推理步数线性增加至 $\alpha_{max}$（最优值为0.4），使得后期推理步更依赖全局方向，从而减轻噪声步的干扰。

3.  **CoT分割与类型标注模块**：为支持上述框架，需要将原始的长CoT序列分割为有意义的推理步。该方法使用高熵token检测进行初步分割，再通过K-means聚类（128类）为每个推理步标注“思考类型”，并引入特殊token（`<type i>`和`</type i>`）来控制推理过程。

**输入输出流**：
- **输入**：查询提示 $Q$ 和完整的CoT序列（包含答案 $A$ 和思考序列 $T$）。
- **处理流程**：在训练阶段，CoT序列被分割并标注类型。在推理阶段，模型以状态转移的方式逐推理步生成：给定查询 $Q$ 和前一步的状态 $S_{t-1}$，生成当前推理步 $think_t$，然后更新状态至 $S_t$。SA子模块处理步内token交互，LA子模块通过状态矩阵提供跨步的历史信息，门控机制融合两者输出，最终由状态校正模块引导推理方向。
- **输出**：最终答案 $A$。

**训练目标**：采用联合损失函数 $\mathcal{L} = \mathcal{L}_{AR} + \beta \mathcal{L}_{KD}$ 进行训练。
- **自回归损失 $\mathcal{L}_{AR}$**：标准的下一个token预测损失，确保模型能生成流畅的CoT和答案。
- **知识蒸馏损失 $\mathcal{L}_{KD}$**：计算基模型（Qwen2.5）与所提模型输出分布之间的KL散度。该损失的关键作用是训练LA子模块，使其能有效捕获全局推理信息。消融实验（Table 2）证实，移除 $\mathcal{L}_{KD}$ 会导致所有基准上性能下降3.6-6.6个百分点，证明仅靠自回归损失无法有效训练线性注意力子模块学习跨步的推理依赖。

**效率与性能的权衡**：通过将注意力复杂度从 $O(C^2)$ 降至 $O(C)$，KV缓存从 $O(C)$ 降至 $O(1)$，框架实现了显著的效率提升。当CoT长度达到32K时，推理速度比基模型快40%以上（Figure 4(a)）。同时，在AIME24基准上，1.5B和7B模型的相对推理速度分别达到440.13和434.8（基模型为100），提升约16-18%（Table 1）。在性能方面，该框架在数学推理（AIME24, MATH500）、科学（GPQA Diamond）和代码（HumanEval）基准上均优于所有基线方法，1.5B和7B模型的平均准确率分别达到56.2%和68.3%（Table 1）。消融实验（Table 2）进一步揭示，模型推理状态（状态矩阵）是最关键的组件，其移除（替换为滑动窗口）导致性能下降最大（平均准确率从56.2降至46.8）。

## 核心模块与公式推导

该框架的核心瓶颈在于长链思维（Long CoT）推理中，Transformer注意力机制的计算复杂度随上下文长度呈二次增长，KV缓存的内存开销呈线性增长。其因果杠杆在于将推理过程建模为状态转移过程，用线性注意力机制压缩历史推理信息为状态矩阵，使当前推理步的每个token可直接从状态矩阵检索历史信息，无需显式关注之前推理步的token。

### 混合注意力模块（MAM）

框架用混合注意力模块（MAM）替换LLM中的原始注意力模块。MAM由两个子模块组成：Softmax注意力（SA）子模块和线性注意力（LA）子模块。SA子模块仅处理当前推理步内的token交互和查询提示，从而将注意力计算复杂度从二次降为线性，KV缓存内存开销从线性降为常数。LA子模块通过线性注意力维护推理状态矩阵，记录历史推理信息。

**线性注意力基础：** 标准softmax注意力输出为：
$$o_t = \frac{\sum_{i=1}^t \exp(q_t k_i^\top / \sqrt{d}) v_i}{\sum_{i'=1}^t \exp(q_t k_{i'}^\top / \sqrt{d})}$$
使用核函数的线性注意力形式为：
$$o_t = \frac{\phi(q_t) \sum_{i=1}^t \phi(k_i)^\top v_i}{\phi(q_t) \sum_{i'=1}^t \phi(k_{i'})^\top}$$
采用恒等核且无归一化的简化版本为：
$$O_t = q_t \sum_{i=1}^t k_i^\top v_i = q_t S_t; \quad S_t = \sum_{i=1}^t k_i^\top v_i$$
其中 $S_t$ 为状态矩阵，通过累加键值向量的外积来压缩历史信息。该更新过程可视为测试时训练（TTT）：在线学习目标 $\mathcal{L}(S) = -\langle S k_t, v_t \rangle$ 的梯度下降更新 $S_t = S_{t-1} + \beta v_t k_i^\top$ 等价于上述累加形式。

**LA子模块中的状态更新与门控：** 当前推理步内逐token更新模型状态：
$$S_{t,i-1}^{(l)} = S_{t,0}^{(l)} + \sum_{j=1}^{i-1} \Sigma k_j^{(l)^\top} v_j^{(l)}$$
通过门控机制从状态矩阵中提取历史推理信息：
$$\check{h}_{t,i-1}^{(l)} = \sigma(\check{W}_g h_{t,i-1}^{(l-1)}) * o_{i-1}^{(l)}$$
其中门控信号 $\sigma(\check{W}_g h_{t,i-1}^{(l-1)})$ 根据token在推理步中的位置动态控制对历史信息的依赖程度。MAM最终输出为SA和LA子模块输出的合并：
$$\widetilde{h}_{t,i-1}^{(l)} = W_o(\check{h}_{t,i-1}^{(l)} + \hat{h}_{t,i-1}^{(l)})$$

### 基于状态的推理策略

为缓解噪声推理步导致的过度思考问题，框架提出基于状态的推理策略，用动量法累积全局推理方向。全局推理方向为所有先前推理步方向的均值：
$$\bar{\nabla}_{t-1}^l = \frac{1}{t-1} \sum_{i=1}^{t-1} \nabla_i^l$$
校正后的当前推理步方向为：
$$\hat{\nabla}_t^l = (1 - \alpha) \nabla_t^l + \alpha \bar{\nabla}_{t-1}^l$$
其中 $\alpha$ 随推理步数线性增加至最大值 $\alpha_{\text{max}}$（实验表明 $\alpha_{\text{max}}=0.4$ 时性能最佳）。

### 训练目标

总训练损失包含两个部分：
$$\mathcal{L} = \mathcal{L}_{\mathrm{AR}} + \beta \mathcal{L}_{\mathrm{KD}}$$
其中自回归损失为：
$$\mathcal{L}_{\mathrm{AR}} = -\log \mathbf{\bar{P}}(A, \bar{T} | Q)$$
知识蒸馏损失为基模型与所提模型输出分布的KL散度：
$$\mathcal{L}_{\mathrm{KD}} = \mathrm{KL}(\hat{P}(A, T | Q) || P(A, T | Q))$$
蒸馏损失的权重 $\beta$ 在实验中设为0.2时性能最佳。该损失项使LA子模块能够学习全局推理信息——仅靠自回归损失难以训练LA子模块捕获长程相关性，因为线性注意力无法直接建模token间的精确相关性。

## 实验与分析

### 主实验结果

在数学推理基准（AIME24、MATH500、GSM8K等）上的主实验结果（Table 1）显示，所提框架在两个参数规模（1.5B和7B）上均显著优于所有基线方法。具体地，1.5B模型平均准确率达到56.2%，7B模型达到68.3%，分别超过基模型Qwen2.5-Instruct约4.7和4.0个百分点。在最具挑战性的AIME24基准上，1.5B模型准确率26.7%（基模型23.3%），7B模型43.3%（基模型36.7%）。在MATH500上，1.5B模型达到90.4%（基模型85.6%），7B模型94.0%（基模型92.4%）。值得注意的是，该框架的主要设计目标是提升推理效率而非准确率，因此性能提升属于“意外收获”。

![[assets/figures/papers/iclr26_0004_Zz8ikW4uWG_A_State-Transition_Framework_for_Efficient_LLM_R/figures/005_Table_1.jpg]]
*Table 1: The results of our model and baselines on mathematical reasoning benchmarks*

推理速度方面，在AIME24上，所提模型的相对速度（ReL）达到440.13（1.5B）和434.8（7B），相比基模型（设为100）提升约340%。当CoT长度达到32K时，推理速度比基模型快40%以上。这一加速源于注意力计算复杂度从二次降为线性，以及KV缓存内存从线性降为常数。

在GPQA Diamond和HumanEval基准上（Figure 5(a)），所提模型同样一致优于所有基线，表明框架在科学和代码领域的泛化能力。

### 消融实验

消融实验（Table 2）揭示了各组件的关键贡献：

![[assets/figures/papers/iclr26_0004_Zz8ikW4uWG_A_State-Transition_Framework_for_Efficient_LLM_R/figures/006_Table_2.jpg]]
*Table 2: Ablation results of our model on mathematical reasoning benchmarks*

- **移除模型推理状态**（替换为64大小的滑动窗口）导致性能下降最大：1.5B模型平均准确率从56.2降至46.8，降幅9.4个百分点。这直接验证了推理状态矩阵是框架的核心——它压缩并存储了历史推理信息，使得当前推理步无需显式关注之前所有token。

- **移除蒸馏损失L_KD**导致所有基准上性能下降3.6–6.6个百分点（56.2→50.8）。这表明仅靠自回归损失L_AR不足以训练LA子模块有效捕获全局推理信息，蒸馏损失是LA子模块学习的关键训练信号。

- **移除基于状态的推理策略**（即动量校正机制）导致平均准确率下降3.54个百分点（56.2→52.6），验证了全局推理方向校正对缓解噪声步导致的过度思考问题的有效性。

- **移除门控机制**导致轻微性能下降，说明门控对历史信息依赖度的动态控制有一定贡献但非决定性。

### 效率分析与超参数敏感性

Figure 4(a)显示，在CoT长度从1K增长到32K的过程中，基模型的计算时间和内存使用呈线性增长，而所提模型保持近乎常数的内存使用和显著更低的计算时间。当CoT长度达到32K时，所提模型的计算时间仅为基模型的约30%，内存使用仅为基模型的约15%。

超参数敏感性分析（Figure 4(b)–(c)）表明：蒸馏损失权重β=0.2时性能最佳，α_max=0.4时性能最佳。这些值在1.5B模型上通过网格搜索确定。

### 组合基线分析

Table 3显示，所提框架可与现有缩短CoT的方法（TAMM、SBT-D、L1-Max、AR）结合，进一步提升推理效率。例如，与TAMM结合后，在AIME24上准确率提升至28.3%（1.5B），同时token相对速度提升至522.18。

Table 4对比了不同解码策略下的性能。所提模型在所有解码策略下均优于基模型，且重复生成率（RC rate）显著更低。例如，在贪婪解码下，基模型的重复生成率为16.7%，所提模型仅为5.6%。这表明状态校正机制有效减少了模型在推理过程中陷入重复循环的问题。

### 推理步移除分析

Figure 7(a)–(b)揭示了有趣的发现：移除少于20%的推理步可提升模型性能，同时降低推理延迟。这暗示原始训练数据中存在冗余或噪声推理步，框架的状态压缩能力使其能够容忍甚至受益于适度的步骤精简。当移除比例超过20%时，性能开始下降，表明关键推理信息开始丢失。

### 门控机制分析

Figure 5(b)展示了推理步内不同位置token的平均门控分数。结果表明，推理步早期的token门控分数更高，即需要更多历史推理信息；而后期token门控分数降低，表明其对历史信息的依赖减弱。这与直觉一致：推理步开头需要理解上下文，而结尾更多是完成当前步的内部推导。

### 失败模式与局限性

尽管性能提升显著，实验存在以下局限：（1）仅在Qwen2.5系列（1.5B和7B）上验证，未在更大规模模型（如70B）或不同架构（如Llama）上测试；（2）训练数据来自特定长CoT数据集，可能引入领域偏差；（3）推理速度比较基于相对速度（ReL），未报告绝对时间或硬件配置细节，可重复性受限；（4）CoT分割依赖高熵token检测和K-means聚类（128类），该方法的鲁棒性和最优性未充分探讨；（5）超参数α_max和最大推理步数|T|（默认40）的设定可能不适用于所有任务。

## 方法谱系与知识库定位

### 与基线的对比定位

本文所提框架的核心目标是提升LLM长链推理的效率，而非单纯追求性能提升（作者在附录F中明确指出性能增益是"意外之喜"）。框架在Qwen2.5-1.5B-Instruct和Qwen2.5-7B-Instruct基模型上构建，通过混合注意力模块（MAM）替换原始注意力模块，将注意力计算复杂度从二次O(C²)降至线性O(C)，KV缓存内存从线性O(C)降至常数O(1)。与四类基线方法的对比揭示了不同的效率-性能权衡路径：

- **TAMM、SBT-D、L1-Max、AR**：这些方法通过缩短或压缩CoT序列来提升效率（提示压缩、SFT缩短、RL缩短、token移除），本质上是**缩减推理深度**。本文框架则在不缩短CoT序列的前提下，通过**改变注意力计算结构**实现效率提升，因此可与这些方法叠加使用（Table 3显示叠加后效率进一步提升）。

- **基模型（Qwen2.5系列）**：原始Softmax注意力下，每个token可关注所有历史token，导致长序列下计算和内存开销急剧增长。本文框架通过线性注意力将历史推理信息压缩为状态矩阵，使当前推理步的token只需关注查询提示和当前步内token，从根本上改变了信息检索方式。

### 适用边界与条件

框架的有效性依赖于几个关键前提：

1. **推理步的可分割性**：框架依赖将长CoT序列分割为离散推理步，并通过K-means聚类（128类）标注思考类型。这要求推理过程具有可分解的结构化特征，对于高度非线性或跳跃性推理可能不适用。

2. **推理信息的可压缩性**：核心假设是推理步中的语言信息主要用于保证流畅性，而推理信息（如结论）才是支持后续推理的关键。这一假设在数学推理、科学问答和代码生成等结构化任务上成立，但在需要细粒度上下文理解的开放域任务上可能失效。

3. **状态矩阵的容量限制**：线性注意力使用恒等核和简化形式（无归一化），状态矩阵S_t ∈ ℝ^{d×d}的容量有限。当推理步数极多或推理信息维度极高时，状态矩阵可能成为信息瓶颈。消融实验（Table 2）中，移除模型状态并替换为64大小的滑动窗口导致性能下降最大（平均准确率从56.2降至46.8），证实了状态矩阵的关键作用，但也暗示其容量有限。

### 核心局限

1. **架构与规模泛化性不足**：实验仅在Qwen2.5系列（1.5B和7B）上验证，未在更大规模模型（如70B）或不同架构（如Llama、Mistral）上测试。线性注意力在大规模模型上的训练稳定性、与预训练权重的兼容性等问题尚未探讨。

2. **领域覆盖有限**：实验覆盖数学推理（AIME24、MATH500、GSM8K等）、科学（GPQA Diamond）和代码（HumanEval），未涉及常识推理、开放域问答、多语言任务等。训练数据来自特定长CoT数据集，可能引入领域偏差。

3. **CoT分割方法的鲁棒性**：依赖高熵token检测和K-means聚类（128类）进行推理步分割和思考类型标注，该方法的最优性和鲁棒性未充分探讨。聚类数128的设定可能不适用于所有任务类型，且高熵检测阈值的选择缺乏理论指导。

4. **超参数敏感性**：基于状态的推理策略中，动量校正系数α_max（默认0.4）和最大推理步数|T|（默认40）的设定可能不适用于所有任务。Figure 4显示α_max在0.4时性能最佳，但未探讨不同任务间的最优值差异。

5. **可重复性限制**：推理速度比较基于相对速度（ReL），未报告绝对时间或硬件配置细节。这限制了与其他方法的直接比较和可重复性。

### 开放问题

1. **状态矩阵的扩展应用**：模型状态能否用于无监督估计推理步的过程奖励，以支持强化学习训练？这需要进一步理解状态矩阵中编码的信息结构。

2. **跨领域迁移能力**：所提框架能否有效迁移到数学、科学和代码之外的领域？特别是需要细粒度上下文理解的常识推理和开放域问答任务。

3. **CoT分割的优化**：是否存在更优的推理步分割策略？聚类算法和聚类数的选择如何影响思考类型标注质量和最终性能？Figure 7显示移除少于20%的推理步反而提升性能，暗示当前分割策略可能过于细粒度。

4. **理论理解的深化**：线性注意力的测试时训练（TTT）视角能否进一步解释或提升模型的推理能力？门控机制和状态校正策略的理论分析尚不深入，其有效性主要依赖实验验证。

5. **效率-性能的帕累托前沿**：是否存在更优的推理步移除策略，以在保持性能的同时最大化效率提升？当前框架在效率提升（16-40%）和性能提升（平均准确率提升约4-7个百分点）之间取得了平衡，但帕累托前沿尚未系统探索。
