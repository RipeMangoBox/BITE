## 概要

现有对话助手的记忆评测主要依赖静态、离线策略数据，无法反映助手在真实互动中的记忆表现，导致优化方向偏差。AMemGym 提出交互式记忆基准，通过结构化状态演化驱动 LLM 模拟用户进行自由对话，使记忆能力在自身行为产生的上下文中接受检验，从而弥合离线评测与真实部署之间的差距。

核心思路是将结构化数据生成与自由形式交互相融合：从目标题目反向推导用户状态与演化轨迹，再由模拟用户按状态脉络自然揭示信息，实现可扩展、诊断性强的在线评测环境。框架支持全自动化数据生成与评测，并提供归一化记忆分数和写入/读取/利用失败率等诊断指标，为记忆优化提供细粒度反馈。

主要发现如下：
- **在线策略评测更可靠**：离线策略评测引入重用偏差，显著改变记忆实现的相对排名。例如 AWE-(2,4,30) 在线策略记忆分数为 0.291，离线策略降至 0.253；AWI 在线策略为 0.172，离线策略反升至 0.199（Table 2）。
- **代理写入策略显著优于基线**：Agentic Write (External) 系列在多种超参数下均保持最高记忆分数，相较 Native LLM（gpt-4.1-mini 的 0.117）提升 0.174（Figure 6）。
- **自动化数据质量可靠**：全自动生成的交互数据在状态暴露质量（99.1%）、对话状态一致性（99.2%）和真值判断可靠性（LLM-人类一致性 0.96/0.94）方面均达到极高水平（Section 3.4）。
- **自我进化可行**：利用环境反馈循环更新助手的记忆管理策略提示，完全反馈策略在记忆分数和事实召回率上均取得稳步提升（Figure 11，Table 3）。

AMemGym 为对话记忆研究提供了统一的交互式评测框架，其在线策略评测范式揭示了离线基准的固有偏差，并为记忆代理的自主优化开辟了新路径。

大型语言模型（LLM）驱动的对话助手正被部署于日益长程的交互场景，如个人助理、客户支持和教育辅导。在这些场景中，助手必须持续追踪用户偏好、历史决策和情境信息，才能提供连贯、个性化的服务。然而，**记忆能力**——即跨对话轮次持久化并有效利用过往信息的能力——仍是当前系统的核心瓶颈。

### 现有记忆评测的困境

当前主流的记忆基准测试普遍采用**离线策略（off‑policy）评测**范式：研究者预先收集一批静态对话数据，然后让待测助手在这些固定轨迹上回答问题。这种范式存在两个根本性缺陷。

**第一，重用偏差（reuse bias）扭曲评测结论。** 离线策略数据通常由独立的对话系统产生，而非待测助手自身的行为轨迹。当助手的记忆写入或读取策略与其行为分布不一致时，评测结果将系统性地偏离真实交互中的表现。AMemGym 的实验证实了这一偏差的严重性：同一记忆实现在在线策略与离线策略下的记忆分数排名发生显著变化（Table 2），例如 AWE‑(2,4,30) 的在线策略分数为 0.291，离线策略则为 0.253；AWI 的在线策略分数为 0.172，离线策略反而升至 0.199。这意味着**基于离线策略数据的优化方向可能将记忆系统引向错误的设计选择**。

**第二，静态数据无法提供诊断性反馈。** 现有基准通常仅报告单一的问答准确率或检索召回率，难以定位记忆失败的具体环节——是信息未被写入、写入后无法检索，还是检索到的信息未被有效利用？缺乏细粒度的诊断信号，开发者只能盲目调参，无法进行有针对性的改进。

### 从离线策略到在线策略的范式转换

上述困境的根源在于**评测与真实交互的脱节**。在真实部署中，助手的记忆策略（π）决定了哪些信息被写入记忆（$m_{t+1}$），进而影响未来轮次中的观测（$o_t$）和动作（$a_t$），形成闭环反馈：

$$o_t, m_t \stackrel{\pi}{\rightarrow} a_t, m_{t+1}$$

交互历史 $\tau_t = [o_0, a_0, o_1, a_1, \ldots, o_t]$ 的分布因此与策略 π 紧密耦合。离线策略评测切断了这一耦合，如同用他人的驾驶轨迹评估一辆车的操控性能——结论必然失真。

AMemGym 的核心动机正是**建立在线策略（on‑policy）的交互式评测环境**，使记忆能力在自身行为产生的上下文中接受检验。这一范式转换同时解决了两个痛点：评测结果真实反映助手在实际交互中的记忆表现，且交互过程本身可被细粒度诊断，为记忆系统的定向优化提供反馈信号。

## 核心方法与创新机理

AMemGym 的核心创新在于将对话记忆评测从**离线策略（off‑policy）范式系统性转向在线策略（on‑policy）范式**，并通过三个相互耦合的 changed slots 实现这一转变。

### 从离线策略到在线策略的评测模式转变

现有记忆基准（如 LoCoMo、LongMemEval 等）普遍采用静态、预收集的对话数据进行评测。在这种离线策略设定下，助手的记忆行为不会影响评测数据的生成——对话内容与助手的实际交互历史完全解耦。这一设计引入了一个被低估的系统性偏差：**重用偏差（reuse bias）**。由于离线数据中的信息暴露模式与助手自身行为产生的上下文分布不一致，评测结果会系统性偏离真实交互中的记忆表现。

AMemGym 以在线策略评测取代这一范式：由 LLM 模拟的用户在与助手实时对话中，按照预定义的状态演化轨迹自然揭示个人信息，助手的每一次响应都会影响后续对话走向，从而使其记忆能力在**自身行为产生的上下文**中接受检验。这一转变的因果效应在核心实验中得到了量化验证——Table 2 显示，AWE‑(2,4,30) 在在线策略下记忆分数为 0.291，而离线策略下仅为 0.253；更关键的是，AWI 的排名发生了逆转（在线策略 0.172 vs. 离线策略 0.199），直接证明了离线评测会扭曲记忆实现的相对优劣排序。

### 结构化状态演化与自由形式交互的融合

实现在线策略评测需要解决一个核心矛盾：自由对话的不可控性与评测所需的可诊断性之间的张力。AMemGym 的解法是将二者融合——**以结构化状态演化作为骨架，以自由形式交互作为血肉**。

具体而言，框架采用反向工程策略：从目标评测问题出发，推导出关键用户状态变量，再模拟这些状态在多个周期内的演化轨迹，并为每个状态变体生成个性化真值答案。随后，LLM 模拟的用户按此状态脉络进行角色扮演，在自然对话中逐步暴露信息。这一设计使得每次交互既保持了对话的自然性，又确保了评测信号的可追溯性。

元评测（Section 3.4）为这一融合的有效性提供了强证据：状态暴露质量达 99.1%（Gwet's AC1 96.8%），对话状态一致性达 99.2%（Gwet's AC1 98.2%），LLM 生成的答案与人工标注的一致性分别为 0.96 和 0.94。这些指标表明，全自动生成的交互数据在关键维度上已接近人工水平。

### 从单一准确率到多维度诊断性指标

传统记忆评测主要依赖问答准确率或检索召回率，这些聚合指标无法揭示记忆失败的根本原因。AMemGym 引入了**诊断性指标**体系，将记忆过程分解为三个可独立归因的操作阶段：

- **写入失败（Write Failure）**：信息未被正确存入记忆存储；
- **读取失败（Read Failure）**：信息虽已存储但未被检索到；
- **利用失败（Utilization Failure）**：信息已被检索但未在回答中被正确使用。

这一分解使得评测从“是否记住”升级为“在哪个环节出错”，为记忆系统的定向优化提供了直接反馈。同时，框架引入**归一化记忆分数** $S_{memory} = \frac{S_{overall} - S_{random}}{S_{UB} - S_{random}}$，将整体准确率相对于随机基线和完美记忆上限进行归一化，有效隔离了基础语言能力对记忆评测的干扰。

### 全自动化与可配置难度

AMemGym 将评测流程从手动或半自动化推进至**全自动化**：结构化数据生成、用户模拟、周期性评测均无需人工干预。数据合成成本约为每实例 $0.40（使用 gpt‑4.1），用户模拟成本约 $0.17，相对于被评测 LLM 的推理成本（如 gpt‑4.1 自身约 $13.0）可忽略不计。框架同时支持通过调节周期数 $N_p$、每周期会话数 $N_s$、每会话交互数 $N_i$ 等参数实现难度配置，base (10,2,4) 和 extra (20,3,10) 两种预设分别对应 128K+ 和 512K+ 的上下文窗口需求。

### 闭环自我进化能力

基于在线策略评测的反馈信号，AMemGym 进一步支持助手的**自我进化**：通过生成函数 $P_{k+1} = G(P_k, F_k)$，环境反馈 $F_k$ 被用于迭代优化助手的记忆管理策略提示 $P_k$。实验表明，完全反馈（Complete Feedback，包含诊断信息）比仅问题反馈（Question Only）更能稳步提升记忆分数和事实召回率（Table 3, Figure 11），验证了诊断性指标对策略优化的实际价值。

AMemGym 的核心洞察在于将**结构化状态演化**与**自由形式交互**相融合，从而构建一个可扩展、诊断性强的评测与优化环境。与传统记忆基准依赖静态、离线策略数据进行评测不同，AMemGym 采用**在线策略交互式评测**：由预定义的用户状态演化轨迹驱动 LLM 模拟用户进行自由对话，使助手的记忆能力在其自身行为产生的上下文中接受检验。这一设计直接回应了现有基准的瓶颈——离线策略评测引入重用偏差，显著改变记忆实现的排名（Table 2 显示 AWE-(2,4,30) 在线策略记忆分数 0.291，离线策略仅 0.253；AWI 在线策略 0.172，离线策略反升至 0.199），导致优化方向偏差。

框架由三个核心模块串联为闭环，并可选配第四个自我进化模块：

### 1. 结构化数据生成
从目标评测题目反向推导用户状态变量，生成状态演化轨迹及个性化真值答案。具体而言，系统从 Nemotron-Personas 的 10 万个人设中采样用户画像，然后模拟用户在 $N_p$ 个周期内的状态演进，每次状态转移由叙事性生活事件驱动。这一反向工程策略确保了评测问题与用户状态的严格对应，同时使数据生成完全自动化。

### 2. 在线交互仿真
LLM 模拟用户根据当前状态和对话历史进行角色扮演，生成自然对话。模拟用户需遵循状态演化脉络，在对话中自然揭示信息，而非直接确认状态。全自动生成的交互数据在状态暴露质量、对话状态一致性和真值判断可靠性方面均达到极高的人机一致水平：状态暴露质量 99.1%（Gwet's AC1 96.8%），对话一致性 99.2%（Gwet's AC1 98.2%），LLM 与人类标注者的一致性分别为 0.96 和 0.94。

### 3. 多维度评测
在每个对话周期，系统计算归一化记忆分数和诊断性失败率。归一化记忆分数定义为：

$$S_{memory} = \frac{S_{overall} - S_{random}}{S_{UB} - S_{random}}$$

该指标将整体准确率相对于随机基线和完美记忆上限进行归一化，从而隔离记忆能力本身。诊断指标则将失败归因至三个操作阶段：**写入失败**（信息未进入记忆）、**读取失败**（记忆未被检索到）和**利用失败**（检索到的信息未被正确使用），为优化提供精准反馈。

### 4. 自我进化（可选）
利用环境反馈循环更新助手的记忆管理策略提示，实现自主优化。生成函数 $G$ 根据当前策略提示 $P_k$ 和反馈 $F_k$ 生成改进后的提示 $P_{k+1}$：

$$P_{k+1} = G(P_k, F_k)$$

实验表明，完全反馈（Complete Feedback）比仅问题反馈（Question Only）更能稳步提升记忆分数和事实召回率。

整个框架将助手的交互过程形式化为：观测 $o_t$ 和内部记忆 $m_t$ 通过策略 $\pi$ 产生动作 $a_t$ 和更新后的记忆 $m_{t+1}$，即 $o_t, m_t \stackrel{\pi}{\rightarrow} a_t, m_{t+1}$，交互历史累积为 $\tau_t = [o_0, a_0, o_1, a_1, \ldots, o_t]$。这一形式化使框架能统一评测 Native LLM、Standard RAG、Agentic Write (External/AWE) 和 Agentic Write (In-Context/AWI) 等多种记忆实现方式。

### 3.1 结构化数据生成

AMemGym 的核心设计在于将自由形式的对话锚定在结构化的状态数据之上。该模块采用反向工程策略：从目标评测问题出发，追溯识别关键的用户状态变量，并预定义其演化轨迹。

具体流程如下：
- **用户画像采样**：从 Nemotron-Personas 的 10 万个人设池中采样用户画像，为对话赋予基础人格。
- **状态变量定义**：基于评测问题反向推导出需要追踪的用户状态（如偏好、目标、经历等），形成结构化状态模式。
- **状态演化模拟**：在 $N_p$ 个对话周期内模拟用户状态的渐进式变化，每次状态转移由叙事性生活事件驱动，确保变化的合理性与连贯性。
- **个性化真值生成**：为每个状态变体生成对应的个性化答案，并通过精炼步骤确保答案在不同状态间具有可区分性。

### 3.2 在线交互仿真

仿真模块将结构化状态数据转化为自然的对话流。LLM 模拟的用户根据当前状态和对话历史进行角色扮演，在遵循状态演化脉络的前提下，以自由形式向助手透露信息。

关键约束包括：
- 查询需隐式揭示用户状态，避免直接确认状态值。
- 状态更新需保持渐进性和真实性，强依赖的状态变量应同步更新。

### 3.3 多维度评测

评测模块在每个对话周期结束时触发，计算归一化记忆分数和诊断性失败率。

**归一化记忆分数**定义为：

$$S_{memory} = \frac{S_{overall} - S_{random}}{S_{UB} - S_{random}}$$

其中：
- $S_{overall}$ 为助手在当前周期评测问题上的整体准确率；
- $S_{random}$ 为随机猜测基线的准确率；
- $S_{UB}$ 为完美记忆上限（即助手可访问所有历史状态时）的准确率。

该公式将原始任务表现中由记忆能力贡献的部分隔离出来，消除了 LLM 本身推理能力的混杂影响。

**诊断性指标**将失败归因至三个操作阶段：
- **写入失败**：用户状态信息未被正确记录至记忆系统；
- **读取失败**：记忆系统未能检索到已存储的相关信息；
- **利用失败**：检索到的信息未被助手正确用于回答。

### 3.4 助手策略形式化

助手与用户的交互可形式化为策略 $\pi$ 的迭代过程：

$$o_t, m_t \stackrel{\pi}{\rightarrow} a_t, m_{t+1}$$

其中 $o_t$ 为时刻 $t$ 的观测（用户消息），$m_t$ 为助手内部记忆状态，$a_t$ 为助手输出的动作（回复），$m_{t+1}$ 为更新后的记忆。截至时刻 $t$ 的交互历史为：

$$\tau_t = [o_0, a_0, o_1, a_1, \ldots, o_t]$$

### 3.5 自我进化循环（可选）

框架支持利用环境反馈进行记忆策略的自主优化。在第 $k$ 个进化周期中，策略提示 $P_k$ 经生成函数 $G$ 根据反馈 $F_k$ 更新：

$$P_{k+1} = G(P_k, F_k)$$

其中 $G$ 由 LLM 在自我进化提示的引导下实现，$F_k$ 包含诊断性失败率和记忆分数等反馈信息。该循环使助手的记忆管理策略能够在交互环境中持续改进。

## 实验与关键发现

### 核心定量结果：在线策略与离线策略的排名反转

AMemGym 的核心实验揭示了一个关键发现：**离线策略评测会引入重用偏差，显著改变记忆实现的排名**。在 Table 2 中，Agentic Write (External) (AWE) 配置 (2,4,30) 的在线策略记忆分数为 0.291，而离线策略仅为 0.253；更关键的是，Agentic Write (In-Context) (AWI) 的在线策略分数为 0.172，离线策略却达到 0.199，**排名发生反转**。这表明，传统基于静态数据的评测不仅低估了 AWE 的真实能力，还高估了 AWI 的表现，导致优化方向偏差。

![[assets/figures/papers/iclr26_0012_sfrVLzsmlf_AMemGym_Interactive_Memory_Benchmarking_for_Assi/figures/006_Table_2.jpg]]
*Table 2: The on-policy v.s. off-policy comparison on memory scores of various assistants. Results on different native LLMs are listed in a separate table below. Memory agents use the same LLM (gpt-4.1-mini) for generation*

在基准配置 (10,2,4) 下，AWE-(2,4,30) 的记忆分数 (0.291) 相较 Native LLM (gpt-4.1-mini, 0.117) 提升 +0.174，验证了代理式写入策略的有效性。不同 LLM 的原生记忆能力差异显著：gemini-2.5-flash 的归一化记忆分数达到 0.324，而 gpt-4o-mini 仅为 0.150（Table 8, Figure 5）。所有受测 LLM 的上界分数 S_UB 均超过 0.8，但随着交互历史增长，性能急剧下降，说明**上下文窗口容量并非唯一瓶颈，记忆管理策略才是关键**。

### 消融分析：写入策略与超参数的影响

Figure 7 的诊断热力图揭示了不同记忆实现的失败模式：

![[assets/figures/papers/iclr26_0012_sfrVLzsmlf_AMemGym_Interactive_Memory_Benchmarking_for_Assi/figures/013_Figure_7.jpg]]
*Figure 7: Diagnosis on various memory implementations*

- **写入失败**：AWI 和 AWE 的写入失败率显著低于直接写入的 RAG，验证了代理决策在筛选有价值信息方面的有效性。但 AWI 受限于上下文空间，写入失败率在长对话中上升更快。
- **读取失败**：Native LLM 的读取失败率随对话增长单调上升，RAG 的检索误差在 topk 较小时尤为突出。
- **利用失败**：即使信息已被正确存储和检索，LLM 在推理中有效利用这些信息仍存在瓶颈，这是当前记忆系统共同的薄弱环节。

超参数消融（Figure 7）表明：
- 增加记忆更新频率 (freq) 可降低写入失败，但高频更新导致性能饱和，存在边际收益递减。
- 保留少量近期消息（短上下文长度 ns）有助于维持对话连贯性，但对长程记忆的提升有限。
- 检索记忆数量 (topk) 的增加能在一定程度上弥补检索误差，但过大的 topk 会引入噪声，反而降低利用效率。

### 自我进化：环境反馈驱动的策略优化

Table 3 和 Figure 11 展示了 AMemGym 的自我进化能力。以 AWI 为基线（记忆分数 0.172），引入环境反馈后：
- 仅问题反馈 (Question Only) 将记忆分数提升至 0.197，事实召回率也有改善。
- 完全反馈 (Complete Feedback) 同样达到 0.197，但在事实召回率上表现更稳定，说明**完整的诊断反馈比仅提供问题更能帮助策略稳步改进**。

Table 5 的定性示例显示，策略提示在进化过程中逐步细化：从 P1 的通用指令，到 P10 中针对特定状态变量（如 `team_size`、`experience`）的精确写入规则，体现了从“记住重要信息”到“识别并存储与用户状态变化相关的关键事实”的演进。

### 开源记忆框架与模型对比

在开源记忆框架的比较中（Table 6），Mem0（含图版本）取得最高记忆分数（约 0.30），A-Mem 最低（0.220），各框架间的差距主要源于写入和读取策略的差异。开源模型中（Table 7），gemini-2.5-flash 以 0.327 的记忆分数领先，glm-4.6 (0.257) 和 kimi-k2-instruct (0.234) 次之，说明**模型的基础能力仍是记忆表现的重要决定因素**。

Table 8 显示五次独立运行的记忆分数标准差在 0.003–0.008 之间，证明 AMemGym 的评测结果具有高度可复现性。成本方面（Section C.2），单实例数据合成成本约 $0.40，用户模拟器成本约 $0.17，在线评测的额外开销相对于被评测 LLM 的推理成本（如 gpt-4.1 约 $13.0）可忽略不计。

## 定位与知识库关联

### 与现有记忆基准的定位关系

AMemGym 在评测模式、优化反馈和自动化水平三个维度上与现有基准形成根本性区隔。Table 1 的系统对比表明，此前所有记忆基准均采用**静态、离线策略数据**进行评测——即预先录制对话轨迹，再让被测助手在固定上下文上作答。这种离线范式无法反映助手在真实互动中的记忆表现，因为助手的回答、记忆写入决策和检索行为会改变后续对话的分布，离线评测无法捕捉这种闭环效应。AMemGym 是首个支持**交互式在线策略评测**的基准，由 LLM 模拟用户在结构化状态引导下与被测助手进行自由对话，使记忆能力在自身行为产生的上下文中接受检验。

在优化反馈方面，现有基准仅提供单一的问答准确率或检索召回率，缺乏对记忆失败根源的诊断能力。AMemGym 引入了**写入失败率、读取失败率和利用失败率**三级诊断指标（Figure 3），将整体记忆分数的下降归因至具体操作阶段，为记忆策略的定向优化提供了可操作的反馈信号。这一诊断框架在自我进化实验中得到验证：使用完整反馈（Complete Feedback）的代理在记忆分数和事实召回率上均优于仅使用问题反馈（Question Only）的基线（Table 3）。

### 与记忆实现方法的关系

AMemGym 通过**存储位置**（上下文内 vs. 外部）和**写入策略**（代理决策 vs. 直接写入）两个维度对记忆实现进行抽象（Figure 4），覆盖了当前主流的记忆范式：

- **Native LLM**：仅依赖上下文窗口，作为长上下文基线。实验表明，即使是最强的商业 LLM（如 gemini-2.5-flash），其归一化记忆分数也仅为 0.324，且随对话周期增长持续下降（Figure 5）。
- **Standard RAG**：基于检索增强生成，将对话历史向量化后检索。其记忆分数高于 Native LLM，但受限于检索误差和缺乏主动写入机制。
- **Agentic Write (External)（AWE）**：LLM 自主决策是否将信息写入外部长期记忆存储。在所有配置中，AWE 系列均取得最高记忆分数（Figure 6），验证了代理式写入策略的有效性。
- **Agentic Write (In-Context)（AWI）**：LLM 决策写入但记忆保留在上下文内，避免了外部存储的检索误差，但在长对话中受上下文窗口限制。

开源记忆框架（Mem0、A-Mem、Nemori）在 AMemGym 上的表现验证了基准的区分度：统一使用相同嵌入模型和向量数据库后，各框架的记忆分数呈现显著差异，反映了其底层记忆策略的有效性差异。

### 适用边界

AMemGym 当前的设计存在以下适用边界：

1. **语言与模态限制**：框架目前主要面向英文文本对话，未涵盖多模态（图像、音频）或具身交互场景。用户模拟器仅使用单一 LLM，尚未探索不同语言风格和认知水平的多样性。
2. **领域范围**：基准中的用户状态和问题主要围绕个人信息管理场景设计，其在代码辅助、知识工作等专业领域的适用性有待验证。
3. **自我进化的分布限制**：自我进化实验仅在相同分布内进行少量迭代（10 个周期），未见其在分布外任务或跨任务迁移上的表现。策略更新的安全性和可解释性也尚未得到系统性评估。
4. **成本约束**：生成结构化数据的每一步仍依赖商业 LLM（单实例约 $0.40），虽然在线评测的增量成本（约 $0.17）相对于被测 LLM 的推理成本（如评测 gpt-4.1 自身约 $13.0）可忽略不计，但在大规模部署中仍需探索更经济的合成方法。

### 开放问题

AMemGym 框架的提出引出了若干值得进一步探索的方向：

1. **多模态与多代理扩展**：如何将在线评测框架推广至多模态、多轮协同的复杂助理任务？在多代理场景中，记忆的共享、冲突解决和隐私边界将引入新的评测维度。
2. **安全与可控进化**：在自我进化过程中，如何保证策略更新的安全性，避免退化或特权泄露？当代理通过环境反馈不断调整记忆策略时，需要建立可解释的更新轨迹和回滚机制。
3. **真实用户反馈闭环**：能否将框架与真正的在线用户反馈相结合，实现真实世界中的持续记忆优化？当前模拟用户虽然达到了极高的人机一致性（状态暴露质量 99.1%，对话一致性 99.2%），但与真实用户的交互分布仍存在差距。
4. **离线策略偏差的量化与校正**：Table 2 揭示了离线策略评测引入的**重用偏差**（AWE 在线 0.291 vs. 离线 0.253；AWI 在线 0.172 vs. 离线 0.199），这种偏差如何随对话长度、记忆策略和任务类型变化，以及是否存在校正方法，是评测方法论层面的开放问题。
