# FedDAG: Clustered Federated Learning via Global Data and Gradient Integration for Heterogeneous Environments

> [!tip] 核心洞察
> 融合来自数据和梯度的多模态信息能够更稳健地发现客户端间的内在聚类结构，而通过需求-供给对齐的选择性跨集群特征迁移既能保留集群特异性又能弥补类别表示的不足，从而显著提升联邦学习在多种异构场景下的准确性。

## 概述

联邦学习在数据分布于多个客户端时面临严重的非独立同分布（non‑IID）挑战，尤其是标签偏斜、特征偏斜、概念转移与数量转移交织的复杂异构环境。现有聚类联邦学习方法通常仅依赖单一的数据相似度或梯度相似度进行客户端分组，且知识共享被限制在集群内部，导致分组鲁棒性不足且无法充分利用跨集群的互补信息，性能受限。

针对上述瓶颈，FedDAG 提出了一套以“多模态相似度融合 + 自适应聚类 + 跨集群表示共享”为核心的框架。该方法首次将**加权类级别数据相似度**与**稀疏梯度相似度**结合，通过可学习的客户端专属权重构建全面的相似度矩阵；在此之上，采用联邦感知的联合损失自动确定最优聚类数目，无需人工预设簇数；同时，通过**需求–供给对齐的互补图**和**双编码器架构**，在保护集群特异性前提下实现选择性跨集群特征迁移，使每个集群模型能够从其他集群获得缺失的类别表示增益。

实验结果表明，FedDAG 在多种异构设置下均显著优于现有最先进的聚类联邦学习方法。在 CIFAR‑10 和 FMNIST 的标签偏斜（20%）与数量转移（Dirichlet α′=1）组合条件下，准确率分别达到 $94.53\%$ 和 $96.82\%$，较最强基线 PACFL 分别提升 **+4.08** 和 **+2.41** 个百分点。在更极端的数量转移（α′=0.25）或 LDA 偏斜等严苛场景中，领先优势进一步扩大，CIFAR‑10 上相较 FedAvg 的优势可达 **+11.36** 个百分点。在真实大规模数据集 Google Landmarks 上，FedDAG 的准确率（$58.23\%$）超过 FedAvg **+21.70** 个百分点，验证了方法在现实异构环境中的强泛化能力。消融实验证实，融合数据与梯度的相似度度量、跨集群表示共享以及自适应聚类机制是性能提升的关键驱动力，且双编码器的训练调度和梯度稀疏化均展现出良好的效率与稳定性。

## 背景与动机

联邦学习允许多个客户端在不共享原始数据的前提下协同训练模型，然而真实部署中客户端的数据分布往往高度异构，存在标签偏斜（label skew）、特征偏斜（feature skew）、概念迁移（concept shift）以及样本数量偏斜（quantity shift）等多种非独立同分布情形。这些异构性使单一全局模型难以拟合所有客户端，导致收敛缓慢且准确率大幅下降。为应对这一挑战，聚类联邦学习（Clustered Federated Learning, CFL）通过发掘客户端的潜在分布结构，为语义相似的客户端群组维护独立的模型，已被视为一项有效策略。

现有聚类联邦学习方法在分组依据与知识共享机制上存在三个关键缺口：

1. **客户端相似度计算依赖单一信息源**：例如 PACFL 仅利用数据子空间的主角度（忽略了类别信息），而 CFL 等则完全依赖梯度相似度。在标签偏斜与样本数量偏斜共存的复杂场景下，单一模态难以全面捕捉客户端间的内在关联，导致聚类错误或无法识别细粒度差异。  
2. **知识共享局限于簇内**：多数方法（如 IFCA、CFL）强制每个簇独立训练，禁止跨簇信息交流。当某个簇缺乏某些类别的样本时，其模型无法获得其他簇拥有的互补表示，造成该类别的表征能力严重不足；而尝试全局混合的方法（如 FedSoft）又可能引入无关客户端的噪声，削弱簇特异性。  
3. **聚类数目需要人工预设**：如 IFCA 要求提前固定簇数 $K$，CFL 仅支持分裂而不支持合并。在真实环境中簇的个数未知且可能随时间演化，这种刚性限制了方法的自适应性与实用性。

上述缺口直接导致了现有方法在高度异构环境下的性能瓶颈：例如，在仅 20% 标签偏斜结合中等数量偏斜（Dirichlet $\alpha'=1$）的 CIFAR‑10 任务上，最强的基线 PACFL 仅取得 90.45% 的准确率；当进一步引入特征偏斜或极端数量偏斜时，性能下降更为明显。这说明单纯依靠数据或梯度的相似度以及封闭的簇内聚合，无法充分挖掘客户端群体间的互补结构。

本文的动机正是突破这些限制，提出 **FedDAG**——一种融合全局数据与梯度信息的聚类联邦学习框架。其核心思路是：（1）构建加权类别级数据主角度与稀疏梯度角度的多模态客户端相似度矩阵，并通过可学习的权重融合二者，以更稳健地揭示真实聚类结构；（2）设计双编码器架构，使簇特异性编码器专注本簇数据的同时，通过需求–供给对齐的选择性跨簇特征迁移，补齐缺失类别的表示能力；（3）通过带过分割惩罚的联邦感知聚类损失实现自适应的簇数选择，摆脱对人工 $K$ 的依赖。通过上述设计，FedDAG 致力于在多种异构数据分布下同时提升聚类准确性与全局模型精度。

## 核心创新

FedDAG 针对现有聚类联邦学习方法在复杂异构环境（标签偏斜、特征偏斜、概念转移、数量转移）下依赖单一信息源、知识共享严格局限于集群内部等瓶颈，从客户端相似度计算、聚类配置确定和跨集群表示共享三个维度进行了系统性创新。

### 1. 多模态客户端相似度：数据与梯度的加权融合
**基线局限**：PACFL 仅比较客户端完整数据子空间的最小主角度，忽略类别标签和数量偏斜对分布相似性的影响；CFL 等仅利用梯度收敛差异进行聚类；两类信息从未被联合使用，导致在混合异构场景中聚类结构不稳定。

**FedDAG 创新**：构建了一种“类级别加权数据相似度 + 稀疏梯度相似度”的双通道融合机制。
- **数据通道**：对每个客户端按类别截断 SVD 得到类主向量，计算类别间最小主角度 $\mathcal{V}'_{i,j,c}$（Eq.4），并引入基于类别样本量对数比的数量偏移权重 $\mathcal{W}_{i,j,c}$（Eq.5），加权聚合得到数据相似度 $\mathcal{V}_{i,j}$（Eq.6），显式捕捉标签偏斜和数量转移。
- **梯度通道**：利用稀疏化（Top‑k）的局部更新计算角度相似度 $\mathcal{G}_{i,j}$（Eq.3），有效反映客户端优化方向的共性，且计算与通信开销极低。
- **自适应融合**：通过小型 MLP 学习每个客户端专属的融合权重，将两条通道的相似度矩阵融合为一个综合邻近矩阵，并最小化熵损失以锐化矩阵，使聚类结构更加清晰（Eq.7‑8）。

该设计使聚类不再依赖单一的相似度来源，在不同异构设置下明显优于仅用数据或仅用梯度的方法（Table 14, Table 15），为后续的高精度聚类和知识共享奠定了基础。

### 2. 自适应聚类：无需预设 K 的层次聚类与联邦感知指标
**基线局限**：IFCA 等要求人工预先指定聚类数 K，对真实分布一无所知的场景极不实用；CFL 虽然可以动态分裂，但无法合并过度划分的簇，难以发现合适的聚类粒度。

**FedDAG 创新**：采用单链接层次聚类与联邦感知的聚类质量指标相结合的自适应机制。
- 在 (0, 1] 区间内候选一系列聚类阈值 $\alpha$，每个 $\alpha$ 决定合并截止距离，产生不同粒度的聚类划分（Algorithm 3）。
- 设计了一种联合 **簇内紧密度损失** 与 **过分割惩罚** 的聚类损失 $\mathcal{L}_{\{\mathbb{C}_1,\dots,\mathbb{C}_Z\}}$（Eq.9‑10），该指标完全依赖客户端上传的梯度/数据信息，无需额外全局数据。
- 选择使聚类损失最低且簇数不过多的 $\alpha$ 作为最优配置，实现 **自动识别正确的聚类数**。

实验证明，该机制在 11 个真实聚类分布的场景中能准确恢复簇数，且损失曲线在最优划分处存在明显的稳定平原（Table 19, Figure 5），表明算法对阈值选择具有鲁棒性。

### 3. 跨集群表示共享：需求‑供给对齐的双编码器架构
**基线局限**：IFCA 等只在集群内部聚合，集群之间完全隔离，导致每个集群无法获得其他集群擅长的类别表示，在标签极度偏斜时性能严重受限；FedSoft 虽允许软共享，但将全部集群的信息混合，引入大量无关噪声，无法实现精确的表示互补。

**FedDAG 创新**：提出 **全局表示共享（Global Representation Sharing, GRS）** 框架，通过需求‑供给互补图（CC‑Graph）和双编码器实现 **选择性** 的跨集群知识迁移。
- **CC‑Graph 构建**：基于每个集群的类别需求（缺失或少的类）和供给（丰富且高质量表示的类），结合类级别主角度对齐度（Eq.11‑15），为每个集群找出前 k 个最互补的源集群，形成有向互补图。
- **双编码器训练**：
  - **主要编码器** $\phi^{(1)}$ 只在本集群数据上优化，保留集群专属特征表达能力；
  - **辅助编码器** $\phi^{(2)}$ 从互补源集群的客户端梯度中进行加权聚合和更新，将源集群擅长的类别表示迁移到学习集群；
  - 最终分类器拼接两个编码器的输出，同时利用本集群一致特征和补足的特征进行分类（Eq.16‑21）。
- **训练战略**：主要/辅助阶段交错执行，主编码器初始值来自局部预热后的特征提取器，辅助编码器采用 5:1 的稀疏更新调度，在保持精度基本不变的前提下大幅降低额外通信与计算（Table 18）。

GRS 在标签偏斜、概念转移等多种设置下均带来一致的准确率增益，其收益源于有效的特征互补，而非单纯增加模型容量（Table 3, Table 16）。结合数据与梯度融合聚类，FedDAG 在 CIFAR‑10（20% 标签偏斜）上达到 94.53% 准确率，超越最佳聚类基线 PACFL 达 4.08 个百分点（Table 1），并在真实大规模数据集 Google Landmarks 上超过 FedAvg 达 21.70 个百分点（Table 12）。

三项创新协同作用，使 FedDAG 能够稳健发现内在聚类结构，并通过选择性跨集群知识共享突破集群间数据隔阂，在多种异构联邦学习场景下取得显著优于现有方法的性能。

## 整体框架

![[assets/figures/papers/iclr26_0013_eIMXY9qkKz_FedDAG_Clustered_Federated_Learning_via_Global_D/figures/002_Figure_1.jpg]]
*Figure 1: Overview of FEDDAG. Clients compute principal vectors and gradients to build an adjacency matrix and a graph indicating which clusters can supply features for cross-cluster sharing. Training proceeds in two phases: (1) the primary encoder and classifier are trained on each cluster’s local data; (2) the secondary encoder of a requesting cluster is trained on source cluster’s data*

FedDAG 的整体 pipeline 围绕两个核心目标展开：在多源异构客户端中自动发现内在的组结构，以及通过组间有选择的知识共享提升全局模型质量。流程可分为 **聚类阶段** 与 **双编码器训练阶段**，二者通过自适应聚类结果与集群互补图（CC‑Graph）紧密衔接。

**1. 局部预热与信息上传**  
客户端首先在本地数据上进行少量独立训练（默认 2 轮），生成稀疏梯度更新 $\tilde{\Delta}^i$ 和各类别的主向量 $U_c^i$ 并上传至服务器（Algorithm 1）。梯度经 Top‑k 稀疏化，仅保留幅度最大的分量以降低通信开销；主向量则通过截断 SVD 从各类别原始数据中提取，作为数据分布的结构化摘要。

**2. 双模态相似度计算**  
服务器利用稀疏梯度按 Eq. (3) 计算客户端间的梯度角度相似度矩阵 $\mathcal{G}_{i,j}$；同时，对每个类别独立计算主向量间的最小主角度 $\mathcal{V}'_{i,j,c}$（Eq. 4），并引入基于类别样本数量比的对数权重 $\mathcal{W}_{i,j,c}$ 刻画数量偏斜（Eq. 5–6），加权得到数据相似度矩阵 $\mathcal{V}_{i,j}$（Algorithm 2）。这一环节使得标签偏斜、特征偏斜与数量偏斜等异质性均被显式编码。

**3. 邻近矩阵融合与锐化**  
服务器将 $\mathcal{G}_{i,j}$ 与 $\mathcal{V}_{i,j}$ 拼接后，通过一个轻量级 MLP 为每个客户端生成专属权重向量，经加权求和形成初步邻近矩阵（Eq. 7）。为进一步突出聚类结构，引入熵损失最小化邻近矩阵的熵，使相似度分布锐化（Eq. 8）。

**4. 自适应最优聚类**  
在候选阈值 $\alpha$ 集合上执行凝聚层次聚类（以邻近矩阵的距离为合并依据），对每个候选配置计算联邦感知的联合损失 $\mathcal{L}$（Eq. 9–10），该损失同时惩罚簇内松散和过度分割。选择使 $\mathcal{L}$ 最小的 $\alpha^*$ 对应聚类作为最终分组，无需人工指定聚类数目 K（Algorithm 3）。

**5. 集群互补图构建**  
聚类完成后，根据每个集群各类别的需求度 $d_{p,c}$、供给度 $s_{q,c}$ 以及集群间各类别主角度对齐分数 $\bar{\Gamma}_{p,q,c}$，计算互补性得分 $H_{p,q}$（Eq. 11–14）；为每个集群 $p$ 选取前 k 个互补得分最高的源集群，形成有向 CC‑Graph，用于后续指导跨集群特征迁移。

**6. 双编码器训练与跨集群表示共享**  
每个集群 $z$ 的模型采用双编码器架构 $F_z(\cdot) = \psi\big(\phi^{(1)}(\cdot;\Theta_z^{1f}), \phi^{(2)}(\cdot;\Theta_z^{2f}); \Theta_z^{c}\big)$（Eq. 2）。训练分两部分交替进行：
- **主要编码器训练**：仅使用本集群客户端数据优化 $\Theta_z^{1f}$ 和 $\Theta_z^{c}$，此时辅助编码器冻结，保护集群特异性；
- **辅助编码器训练（GRS）**：对于集群 $p$ 的每个源集群 $q$，将 $p$ 的辅助编码器 $\Theta_p^{2f}$ 发送至 $q$ 中客户端训练并产生梯度，服务器聚合梯度后更新 $\Theta_p^{2f}$。这一机制实现基于需求‑供给对齐的选择性特征迁移，在保留各集群独有表示的同时弥补其类别覆盖的不足。

**7. 新客户端泛化**  
当新客户端加入时，服务器扩展邻近矩阵并学习其专属权重，随后基于已固定的阈值 $\alpha^*$ 将其分配至最相似的现有集群，无需重新执行全局聚类（Algorithm 4）。

综上，FedDAG 通过融合梯度与数据的多模态相似度实现精准自适应聚类，并借助双编码器与 CC‑Graph 驱动的选择性跨集群共享，有效解决了异构联邦学习中单一信息源分组脆弱、知识隔离导致性能受限的瓶颈。

## 核心模块与公式推导

FedDAG 的核心由三个紧密耦合的模块构成：**多模态客户端相似度计算与自适应聚类**、**双编码器跨集群表示共享** 以及 **联邦感知的聚类数自选择**。以下围绕关键公式推导各模块的机制与变量含义。

### 1. 整体模型结构
每个客户端群组（cluster）维持一个双编码器预测模型：
$$F_{z}(\cdot) = \psi\big( \phi^{(1)}(\cdot; \Theta_{z}^{1f}) , \phi^{(2)}(\cdot; \Theta_{z}^{2f}) ; \Theta_{z}^{c} \big) \quad\text{(Eq. 2)}$$
其中 $\phi^{(1)}$ 为专研本群组数据的主要编码器，$\phi^{(2)}$ 为从其他群组选择性迁移特征的辅助编码器，$\psi$ 为分类头。该双路结构是在传统单编码器模型（Eq. 1）上的关键扩展，使群体既能保留特异性又能获得互补表示。

### 2. 客户端相似度矩阵的构建与自适应聚类
为在复杂异构环境下准确发现客户端的内在聚类结构，FedDAG 融合梯度相似度与类级别加权数据相似度，并通过可学习的权重网络生成最终的邻近矩阵。

**梯度相似度**  
每客户端在局部预热（两轮独立训练）后计算稀疏梯度更新 $\tilde{\Delta}^{i}$（保留 0.5%~2% 的坐标），服务器据此构造梯度角度矩阵：
$$\mathcal{G}_{i,j} = \cos^{-1}\!\left( \frac{\langle \tilde{\Delta}^{i}, \tilde{\Delta}^{j} \rangle}{\| \tilde{\Delta}^{i} \| \| \tilde{\Delta}^{j} \|} \right) \times \frac{180}{\pi} \quad\text{(Eq. 3)}$$
$\mathcal{G}_{i,j}$ 直接反映模型优化方向的差异（单位：度），具有轻量通信开销（稀疏化后 ≈ 1% 的模型参数）。

**类级别加权数据相似度**  
对于类别 $c$，客户端 $i$ 上传类别数据的主向量子空间 $U_c^i$（由截断 SVD 获得的一组基）。服务器计算任意两名客户端在该类上的最小主角度：
$${\mathcal{V}'}_{i,j,c} = \min_{\mathbf{v} \in U_c^i, \mathbf{x} \in U_c^j} \cos^{-1}\!\left( \frac{| \mathbf{v}^{\top} \mathbf{x} |}{\| \mathbf{v} \| \cdot \| \mathbf{x} \|} \right) \quad\text{(Eq. 4)}$$
为避免数量偏斜误导相似度，引入对数尺度权重：
$$\mathcal{W}_{i,j,c} = \frac{ \max\big(\ln(|D_{i,c}|+\epsilon), \ln(|D_{j,c}|+\epsilon)\big) }{ \min\big(\ln(|D_{i,c}|+\epsilon), \ln(|D_{j,c}|+\epsilon)\big) } \quad\text{(Eq. 5)}$$
其中 $|D_{i,c}|$ 为客户端 $i$ 上类别 $c$ 的样本数。加权类级别相似度汇总为：
$$\mathcal{V}_{i,j} = \frac{1}{|C|} \sum_{c=1}^{C} \mathcal{V}'_{i,j,c} \cdot \mathcal{W}_{i,j,c} \quad\text{(Eq. 6)}$$
该设计既捕获了不同类别下的分布差异，又对非平衡数据更具鲁棒性。

**邻近矩阵融合与权重学习**  
数据相似度矩阵 $\mathcal{V}$ 与梯度相似度矩阵 $\mathcal{G}$ 通过一个轻量 MLP 为每对客户端学习融合权重 $\mathbf{w}_{i,j} \in \mathbb{R}^2$，并利用熵损失强制产生的邻近矩阵 $\mathbf{A}$ 趋向锐利（即相近客户端间值接近 1 或 0）：
$$\mathcal{L}_{\text{ent}} = -\sum_{i,j} \mathbf{A}_{i,j} \log \mathbf{A}_{i,j} \quad\text{(Eq. 7‑8, Section 3.3)}$$
（原文 Eq. (7)‑(8) 的具体矩阵函数形式需参照原文，此处仅给出熵损失思想。）

**自适应最优聚类**  
区别于需要预先指定聚类数 $K$ 的方法，FedDAG 在众多候选距离阈值 $\alpha$ 上运行层次聚类，并通过一个联邦感知的损失函数 $\mathcal{L}_{\{\mathbb{C}_1,\ldots,\mathbb{C}_Z\}}$（Eq. 9‑10）同时评估聚类紧密度和过分割惩罚，自动选择使损失最小且簇数适宜的聚类配置（Algorithm 3）。实验表明，该机制能在真实包含 11 个分布的场景中成功恢复正确聚类数（Table 19, Figure 5）。

### 3. 跨集群全局表示共享（Global Representation Sharing, GRS）
完成聚类后，FedDAG 通过有向的**集群互补图（CC‑Graph）** 实现选择性跨集群特征迁移，弥补单集群的类别表示不足。

**CC‑Graph 构建**  
定义集群 $p$ 对类别 $c$ 的需求量 $d_{p,c}$ 和集群 $q$ 的供应量 $s_{q,c}$：
$$d_{p,c} = \sum_{i \in \mathbb{C}_p} (m_i - r_{i,c}), \qquad s_{q,c} = \frac{1}{|\mathbb{C}_q|} \sum_{i \in \mathbb{C}_q} (r_{i,c} + 1) \quad\text{(Eq. 11)}$$
其中 $r_{i,c}$ 为客户端 $i$ 在类别 $c$ 上的经验风险，$m_i$ 为最大容忍风险。初始数量互补得分 $H_{p,q}' = \sum_c d_{p,c} s_{q,c}$（自环设为 $-\infty$）进一步与数据对齐度结合：
$$\Gamma_{i,j,c} = 1 - \frac{\mathcal{V}'_{i,j,c}}{90^\circ},\quad \bar{\Gamma}_{p,q,c} = \frac{1}{|\mathbb{C}_p||\mathbb{C}_q|} \sum_{i \in \mathbb{C}_p} \sum_{j \in \mathbb{C}_q} \Gamma_{i,j,c} \quad\text{(Eq. 13‑14)}$$
最终互补得分 $H_{p,q} = H_{p,q}' \cdot \bar{\Gamma}_{p,q}$，并保留 top‑$k$ 得分边，构成 CC‑Graph，标识各集群的 $k$ 个最佳特征供给集群。

**双阶段训练**  
- **主要编码器初始化与训练**：聚类形成后，主要编码器 $\Theta_z^{1f}$ 由各客户端已收敛的局部特征提取器加权平均初始化（Section 4，Eq. 初始化公式），随后使用本集群数据优化交叉熵损失（Eq. 16‑18），冻结辅助编码器。  
- **辅助编码器跨集群更新**：集群 $j$ 的辅助编码器 $\Theta_j^{2f}$ 被派发到 CC‑Graph 中指向它的源集群 $\mathbb{C}_z$ 内的客户端，在源数据上计算局部梯度并加权聚合：
$$\Theta_{j}^{2f} \gets \Theta_{j}^{2f} + \sum_{i \in \mathbb{C}_z} \frac{|D_i|}{\sum_{k \in \mathbb{C}_z} |D_k|} \big( \theta_i^{2f'} - \Theta_{j}^{2f} \big) \quad\text{(Eq. 20 简化)}$$
该机制使辅助编码器吸收源集群的类别特征，返回后与主编码器输出拼接，由分类头联合利用（Eq. 2）。消融实验证实，跨集群共享带来的精度增益远超单纯增加模型容量（Table 3, Table 16）。

### 4. 新客户端泛化
对于新加入的客户端，FedDAG 扩展邻近矩阵并学习其融合权重，使用已固定的最优阈值 $\alpha^*$ 分配至对应群组（Algorithm 4）。该流程无需重新聚类，保证了动态部署的可行性（详见 Appendix A.8）。

以上各模块的协同实现了从多模态相似度感知聚类到选择性跨集群知识迁移的完整学习范式，其关键公式直接对应非 IID 异构性下的核心瓶颈。

## 实验与分析

### 主实验结果

FEDDAG 在标签偏斜、数量转移、概念迁移和组合异构等场景下全面领先现有聚类联邦学习方法，其性能增益源于两方面因果设计：（1）加权类级别数据相似度与梯度相似度的自适应融合，使客户端聚类能同时捕捉数据分布和优化地形差异，避免单模态信息导致的错误分组；（2）双编码器跨集群表示共享，通过需求-供给互补图选择性迁移缺失类别的特征，弥补集群孤立训练的表示贫化。以下关键结果验证了这两点。

在非 IID 标签偏斜（20%）与数量转移（Dirichlet α′=1）的标准设定下，FEDDAG 在 CIFAR‑10 上达到 **94.53±0.12%** 准确率，较最强基线 PACFL（90.45±0.30%）提升 **4.08 个百分点**；在 FMNIST 上为 **96.82±0.18%**，领先 PACFL 2.41 个百分点（Table 1）。当数量偏斜加剧（α′=0.25，20% 标签偏斜），FEDDAG 在 CIFAR‑10 上仍取得 **90.76±0.12%**，显著优于移除跨集群共享的消融变体 FEDDAG†（88.67±0.18%），说明在高异构下跨集群补充贡献突出（Table 3 / Table 4）。在纯 LDA 标签偏斜（α′=0.25）下，FEDDAG 在 CIFAR‑10 上达到 **77.84±0.23%**，比 FedAvg 高 11.36 个百分点，较次优聚类方法 PACFL 高 3.93 个百分点（Table 5）。对组合特征与标签偏斜（CIFAR‑10‑C，多种腐蚀类型）的复杂场景，FEDDAG 准确率为 **65.62%**（标准差待确认，置信度 0.85），显著超出 PACFL 的近 10 个百分点（Table 11）。在大规模真实数据集 Google Landmarks 上，FEDDAG 取得 **58.23±0.15%**，对比 FedAvg 的 36.53% 提升 21.70 个百分点，证明方法在真实应用中有效（Table 12）。

### 失败模式与局限性

论文未专门报告失败案例，但从消融结果可推断若干退化条件：若客户端间异构程度极低，自适应聚类可能将所有客户端归为同一簇，此时不存在跨集群互补关系，GRS 退化为无共享模式，性能上限等同于单编码器基线；该情形在实验中未被测试，需手动验证所得结论。此外，梯度稀疏化虽能提升通信效率，但稀疏度低于 0.5% 后性能开始下降（Table 9），意味着在极低带宽环境中需权衡压缩率与聚类质量。最后，当数据或梯度的分布漂移过于剧烈，类级别主角度与梯度相似度均可能失效，论文未提供相关鲁棒性分析，该风险需结合后期监控机制进一步评估。

## 方法谱系与知识库定位

FedDAG 的提出针对现有聚类联邦学习（Clustered FL）中两个关键瓶颈：**客户端相似度计算依赖单一信息源**（如 PACFL 仅用数据主角、CFL 仅用梯度）导致在复杂异构场景下聚类不准，以及**知识共享严格局限于集群内部**（如 IFCA 集群间无交互），难以弥补客户端表示能力的不足。论文通过引入**加权类级别数据相似度与稀疏梯度相似度的融合**、**自适应层次聚类**以及**双编码器跨集群表示共享**，在标签偏斜、数量转移、特征偏斜和概念转移等多种非 IID 设定下取得了显著优于各基线的表现。

### 与已有方法的关系

**相对于标准联邦学习（FedAvg）**，FedDAG 通过显式的客户端聚类打破了“单一全局模型”的假设，本质上属于个性化联邦学习的范畴。但与 PerFedAvg 等仅凭本地微调实现个性化的方法不同，FedDAG 利用聚类结构让每个集群维护独立的模型，从而在面对跨集群的分布冲突时避免梯度冲突。在极端 LDA 标签偏斜（$\alpha'=0.25$）下，FedDAG 在 CIFAR-10 上相对 FedAvg 提升超过 11 个百分点（Table 5），表明直接聚类比单一平均更能应对强异质性。

**与主流聚类联邦学习方法对比**，FedDAG 从三个维度改进了现有方案：

1. **多模态客户端相似度**：PACFL 仅通过类别主角度（最小主角）计算数据相似度，未考虑标签数量和梯度信息；CFL 及其变体仅利用梯度收敛状态分裂客户端。FedDAG 则将 **类级别加权的数据主角与稀疏梯度角度融合**，并通过 MLP 学习客户端专属的融合权重，同时最小化熵损失以锐化邻近矩阵（Section 3.2‑3.3）。消融实验（Table 14, 15）证实，同时使用数据与梯度信息在数量和概念转移场景下均优于仅使用单一模态。

2. **跨集群知识共享**：IFCA、FedRC 等方法仅在集群内聚合，FedSoft 的软分配虽允许跨集群共享但会引入噪声。FedDAG 采用 **双编码器架构**（主要编码器专研本集群特征，辅助编码器从互补集群选择性迁入特征），并通过需求‑供给对齐的 CC-Graph 精准选择源集群（Section 4）。在标签偏斜和概念转移设置下，具有跨集群表示共享（GRS）的双编码器模型始终优于无 GRS 的双编码器或单编码器，且增益并非单纯来自模型容量增加（Table 3, 16）。

3. **自适应聚类数目发现**：IFCA 需要预定义簇数 $K$，CFL 仅支持分裂无法合并。FedDAG 设计了一种 **联邦感知的联合损失函数**，在层次聚类树的不同阈值 $\alpha$ 上搜索，平衡簇内相似度与过分割惩罚，自动确定最优聚类配置（Section 3.4）。在人为构造的 11 个真实分布的场景中，FedDAG 成功恢复正确聚类数，且损失曲线上出现明显稳定平原（Table 19, Figure 5）。

**与其他改进路线的区别**：FedDAG 聚焦于通过结构化的聚类与特征共享来对抗异质性，而非像 FedProx 那样通过正则项限制本地更新，或像 FedMix 那样利用数据增强补偿分布转移。因此，FedDAG 可与这些方法互补（例如在客户端本地使用 FedProx 更新的变体作为基础）。

### 适用边界与局限

FedDAG 的设计假定客户端能够被划分到若干**内部相对同质、集群间异质的簇**中。当客户端分布呈连续平滑变化而无清晰聚类结构时，自适应层次聚类可能退化为单一集群，此时 FedDAG 退化为近似 FedAvg 的性能，但引入的额外通信开销（上传类别主向量和稀疏梯度）依然存在。此外，方法要求客户端至少拥有部分类别的样本以计算类别主向量，极端数据稀疏（每个客户端仅有 1‑2 个类）下主向量的估计可能不稳健。

在通信开销方面，尽管梯度稀疏化至 $0.5\%$ 仍可保持全部准确率（Table 9），但上传每类主向量（约 $1\%$ 的数据量）仍增加额外负载。对于大规模模型或高维数据，这一开销可能成为瓶颈。同时，双编码器训练涉及辅助编码器在源集群上的额外更新，虽然通过 5:1 调度可大幅降低开销（Table 18），但在通信受限场景下仍需考量。

另一个局限在于 **隐私与安全**。FedDAG 要求上传类别级主向量和稀疏梯度，这可能泄露比传统联邦平均更多的本地分布信息，尽管论文未专门讨论差分隐私或安全聚合，实际部署时需引入额外保护机制。类似地，跨集群表示共享依赖于 CC-Graph 中的需求‑供给信息，若集群间存在数据隔离要求（如机构间数据不能混合），此机制可能不适用。

### 开放问题

论文留下了若干未充分解决的问题，值得后续工作探索：

1. **动态客户与分布漂移**：FedDAG 在附录中给出了新客户加入的泛化扩展（Algorithm 4），但缺乏对客户端随时间改变数据分布（概念漂移）或集群结构动态演变的理论和实验分析。自适应聚类的稳定平原假设（Figure 5）是否在流式数据下仍然存在需要验证。

2. **理论收敛性保障**：论文未给出对双编码器架构和跨集群梯度共享的收敛性分析。在非凸设定下，选择性特征迁移与本地集群训练的交互可能引入额外的稳定性挑战，理论收敛速率相对于 FedAvg 或 FedProx 的退化程度是重要开放问题。

3. **超参数敏感性**：聚类融合权重学习中的 MLP 结构、熵损失系数、稀疏化比例、CC-Graph 的 $k$ 值等均需根据数据集调整。虽然附录给出了部分敏感性实验（Table 6‑8），但对于全新应用场景，调参成本可能较高，自动化调参或更鲁棒的默认值是实际落地的需求。

4. **隐私‑效用权衡**：将差分隐私噪声注入主向量和梯度，或采用安全聚合，会对聚类质量和表示共享产生多大影响，论文未涉及。开发隐私保护的加权相似度计算和跨集群迁移机制是一个有价值的方向。

5. **更广泛异构类型的覆盖**：除标签、数量、特征和概念偏斜外，现实联邦学习中还存在**任务异质性**（不同客户端解决不同但相关的任务）和**模态异质性**（文本、图像混合）。FedDAG 的聚类与共享机制是否可直接泛化到这些场景，或需额外设计，仍需考察。

综上，FedDAG 在聚类联邦学习的方法谱系中处于 **多模态信息融合与跨集群协作** 的新节点，显著提升了面对多种非 IID 扭曲的泛化能力，但其应用边界的固有限制与开放性理论问题为后续研究提供了明确切入点。
