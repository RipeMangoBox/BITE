# Routing, Cascades, and User Choice for LLMs

> [!tip] 核心洞察
> 在大多数参数区域，提供者的最优路由策略是静态的、无级联的，且取决于模型对用户的净价值而非仅仅是一次成功的成本；当用户对模型效用的排序与提供商的成本排序不一致时，会出现提供者最优路由与用户偏好的路由之间的错位，极端情况下提供者可能通过人为增加延迟（节流）来压缩成本，进一步损害用户效用。

## 概要

LLM提供商面临一个根本性的两难：如何在控制推理成本的同时，保证用户不因任务失败而弃用服务。现有路由方法通常将用户行为视为外生固定，仅优化单次推理成本，忽略了用户会根据服务体验动态调整重试与弃用决策这一事实。本文将该问题形式化为一个Stackelberg博弈——提供者先承诺路由与级联策略$(i, s)$，用户随后根据期望效用决定弃用概率$q$。

**核心瓶颈**在于，当标准模型与推理模型对用户的净价值$\xi_i = V p_i - t_i$符号不同（一个价值占优、一个延迟占优），或用户弃用惩罚$P$较低时，提供者的成本最小化目标与用户效用最大化目标之间会产生系统性错位。级联概率$s$正是调节这一博弈均衡的核心杠杆：它同时影响用户的弃用行为$q^*$和提供者的期望成本$J_i(s, q)$。

**关键发现**包括：

- **用户行为完全由净价值决定**（Theorem 2）：当$\xi_1 < 0 < \xi_2$时，存在阈值$s_0 = -\xi_1 / (\xi_2/p_2 - \xi_1)$，用户仅在级联概率$s \ge s_0$时接受路由；当$\xi_1 > 0 > \xi_2$时，用户行为在特定区域内呈现随机弃用。
- **最优路由几乎总是静态无级联**（Theorems 3–5）：当两个模型同属价值占优或延迟占优时，最优策略由每次成功成本$c_i/p_i$决定；即使在混合价值场景下，级联仅在弃用惩罚极低或成本差异显著时才有价值。
- **用户错位与节流风险**（Propositions 1–2）：当提供者成本排序与用户效用排序不一致时，存在用户效用缺口$\Delta_U > 0$；在低弃用惩罚下，提供者甚至可能通过人为增加延迟（节流）来压缩成本，进一步损害用户效用。

本文的分析完全基于理论推导，假设参数已知且恒定，尚未在真实LLM数据集上进行实证验证。



大语言模型（LLM）的规模化部署面临一个核心矛盾：推理模型（reasoning models）在复杂任务上表现出更高的成功率，但其推理延迟和计算成本远超标准模型。提供商必须在服务质量与推理成本之间做出权衡，而这一权衡并非孤立存在——用户会根据服务质量动态调整自身行为，包括对失败任务进行重新提示（re-prompting）或完全放弃使用该服务。

现有路由方法（如 Ding et al., 2024 等单轮成本最优路由）将用户行为视为外生固定变量，仅优化单次推理成本。这种简化忽略了一个关键的反馈回路：提供者的路由决策影响用户的成功体验和等待延迟，进而改变用户的坚持意愿和弃用概率，而用户的弃用行为又反过来影响提供者的期望成本结构。当两个模型对用户的净价值符号不同，或用户弃用惩罚较低时，这一反馈回路会产生系统性的错位——提供者为最小化自身成本所采取的路由策略，可能严重偏离用户效用最大化的路径。

本文的核心动机在于：将用户行为内生化，建模为一个斯塔克尔伯格博弈（Stackelberg game），其中LLM提供者作为领导者选择路由与级联策略，用户作为追随者根据观测到的服务质量决定是否继续使用或放弃任务。通过完整刻画这一博弈的均衡结构，本文旨在回答以下问题：在用户可重试和弃用的条件下，提供者的最优路由策略具有何种结构？级联（cascading，即标准模型失败后升级到推理模型）在何时是必要的？提供者与用户的目标在何种条件下会发生错位？

Figure 1 概括了本文的核心发现框架：用户行为取决于两个模型各自处于“价值占优”（净价值为正）还是“延迟占优”（净价值为负）的状态，而提供者的最优策略在不同区域遵循不同的阈值规则。这一框架揭示了路由博弈中的关键权衡维度——模型的每次成功成本（cost-per-pass）、弃用惩罚强度，以及模型对用户净价值的符号组合——共同决定了均衡策略的形态。



## 核心方法与创新机理

### 1. 用户行为从外生固定到内生博弈响应

现有LLM路由方法（如Ding et al., 2024）将用户行为视为外生固定——用户仅提交一次任务，不进行重试或弃用，提供者只需最小化单次推理成本。本工作将用户建模为博弈的**内生参与者**：用户观察到提供者公开的路由与级联策略后，会理性地在每次失败后决定是重新提示（re-prompt）还是永久弃用（abandon）任务。

这一改变的关键在于引入了**多轮交互下的用户最佳响应**。用户根据两个模型的**净价值** $\xi_i = V p_i - t_i$（成功价值减等待延迟）做出静态弃用决策 $q^* \in [0,1]$。当 $\xi_1 < 0 < \xi_2$（标准模型延迟占优、推理模型价值占优）时，存在一个精确的级联概率阈值 $s_0 = -\xi_1 / (\xi_2/p_2 - \xi_1)$，用户仅在级联概率 $s \geq s_0$ 时接受路由到M1，否则直接弃用。当 $\xi_1 > 0 > \xi_2$ 时，用户行为更为复杂，在特定参数区域出现**随机弃用**（$q^* \in (0,1)$），由隐式函数 $F(s,q)=0$ 刻画（Theorem 2, Figure 3）。

这种内生建模使得提供者的路由决策必须预判用户的弃用行为，而非简单假设用户会无限重试。

### 2. 提供者优化目标从单次成本到期望总成本

基准方法仅最小化单次成功或单次调用的服务成本。本工作将提供者目标重新定义为在用户最佳响应约束下的**期望总成本最小化**：

$$J_i(s,q) = C_i(s,q) + P(1 - S_i(s,q))$$

其中 $C_i(s,q)$ 为期望服务成本，$P$ 为每次弃用带来的惩罚（如声誉损失、收入损失），$S_i(s,q)$ 为任务最终成功率。这一目标函数将用户弃用行为直接内化为提供者的成本项，使得提供者必须在服务成本和弃用惩罚之间权衡。

### 3. 级联概率 $s$ 作为核心调节杠杆

在基准方法中，路由决策通常是二元的（选M1或M2）。本工作引入**级联概率** $s \in [0,1]$ 作为连续调节变量：当任务首先路由到标准模型M1且失败时，以概率 $s$ 升级到推理模型M2。$s$ 同时影响用户的弃用概率 $q^*$（通过改变用户期望效用）和提供者的期望成本 $J_i$，成为调节双方博弈均衡的**核心杠杆**。

提供者的优化问题因此被归约为一个单变量优化：
$$\min\left\{ \min_s J_1(s, q^*(1,s)), \; J_2(\mathbb{1}\{\xi_2 < 0\}) \right\}$$

### 4. 关键理论发现：最优路由几乎总是静态无级联

尽管级联概率 $s$ 提供了连续调节空间，但理论分析揭示了一个反直觉的结果：**在绝大多数参数区域，提供者的最优策略是静态的、无级联的**（$s^* \in \{0,1\}$），直接路由到M1或M2（Theorem 3, 4, 5; Figure 4）。级联仅在 $\xi_1 > 0 > \xi_2$ 且弃用惩罚 $P$ 较低或两模型成本差异显著时才可能出现 $s^* \in (0,1)$。

更重要的是，当两个模型同为价值占优（$\xi_1, \xi_2 > 0$）时，最优路由由**每次成功成本**（cost-per-pass）决定：若 $c_1/p_1 \leq c_2/p_2$ 则选M1，否则选M2——这与仅优化单次成本的传统直觉一致。但当模型净价值符号不同时，提供者的最优路由取决于用户净价值 $\xi_i$ 和弃用惩罚 $P$ 的联合阈值，而非单纯的每次成功成本比较。

### 5. 识别并提供者-用户错位与节流风险

当提供者的成本排序与用户的效用排序不一致时，出现系统性的**用户效用错位缺口** $\Delta_U > 0$（Proposition 1, 2; Figure 5）。极端情况下，提供者可能通过**人为增加延迟**（节流，throttling）来压缩成本——例如将 $t_1$ 提升到 $\hat{t}_1 > t_1$，使得 $\xi_1$ 从正值变为负值，从而改变用户行为、降低提供者期望成本。这种节流在弃用惩罚 $P$ 低于 $\min\{c_1/p_1, c_2/p_2\}$ 时尤为显著（Figure 5 Right），揭示了无监管下提供者损害用户效用的潜在风险。

> **注意**：以上发现均基于理论推导，缺乏在真实LLM数据集或用户实验上的实证验证，需在实际部署中进一步检验。

本文构建了一个**单提供者–单用户的两模型Stackelberg路由博弈**，将LLM推理服务中的路由决策、级联机制与用户重试/弃用行为统一为闭环系统。整体框架由三个核心模块串联而成。

### 模块一：马尔可夫交互模型

提供者拥有两个模型：标准模型 $M_1$（成功率 $p_1$，延迟 $t_1$，单次推理成本 $c_1$）和推理模型 $M_2$（成功率 $p_2$，延迟 $t_2$，成本 $c_2$）。提供者首先承诺一个路由与级联策略 $(i, s)$：初始路由到模型 $i \in \{1, 2\}$，若 $i=1$ 且 $M_1$ 失败，则以概率 $s \in [0,1]$ 将任务级联到 $M_2$。用户观测到该策略后，确定一个静态弃用概率 $q \in [0,1]$，即每次模型调用失败后以概率 $q$ 放弃任务、离开系统。交互的状态转移由 Figure 2 的马尔可夫链描述，核心循环为"调用→失败→重试或弃用"，直至任务成功或用户退出。

**输入**：模型参数 $(p_i, t_i, c_i)_{i=1,2}$、用户任务成功价值 $V$、提供者弃用惩罚 $P$。
**输出**：提供者策略 $(i, s)$ 与用户弃用概率 $q$ 的均衡对。

### 模块二：用户最佳响应表征

给定提供者策略 $(i, s)$，用户通过最大化期望效用 $U_i(s,q) = V S_i(s,q) - L_i(s,q)$ 来选择 $q$，其中 $S_i$ 为任务最终成功概率，$L_i$ 为累计期望延迟。分析的关键在于引入**每模型净价值** $\xi_i = V p_i - t_i$：$\xi_i > 0$ 表示该模型为"价值占优"（成功带来的价值超过等待延迟），$\xi_i < 0$ 则为"延迟占优"。

用户最佳响应 $q^*$ 的完整表征由 Theorem 1 和 Theorem 2 给出，呈现三种行为区域（Figure 3）：
- **静态弃用**（$q^* = 1$）：用户立即放弃，发生在两模型均为延迟占优、或级联概率低于阈值 $s_0$ 时。
- **完全坚持**（$q^* = 0$）：用户永不放弃，发生在两模型均为价值占优、或级联概率足够高时。
- **随机弃用**（$q^* \in (0,1)$）：仅出现在 $\xi_1 > 0 > \xi_2$ 的混合价值区域，用户弃用概率由隐式函数 $F(s,q)=0$ 决定，随 $s$ 连续变化。

### 模块三：提供者最优策略优化

提供者在用户最佳响应约束下最小化期望总成本 $J_i(s,q) = C_i(s,q) + P(1 - S_i(s,q))$，其中 $C_i$ 为期望服务成本，$P(1-S_i)$ 为弃用惩罚。问题归约为单变量优化：

$$\min\left\{ \min_s J_1(s, q^*(1,s)),\; J_2(\mathbb{1}\{\xi_2 < 0\}) \right\}$$

核心发现（Theorem 3–5，Figure 4）：
- **同符号区域**：当两模型同为价值占优或延迟占优时，最优策略总是**静态无级联**（$s^* \in \{0,1\}$），路由选择由每次成功成本 $c_i/p_i$ 决定。
- **混合价值区域**（$\xi_1 < 0 < \xi_2$）：最优策略几乎总是直接路由到 $M_1$，级联仅在弃用惩罚 $P$ 极低或成本差异显著时有用。
- **反向混合区域**（$\xi_1 > 0 > \xi_2$）：存在少量参数区域需采用随机级联 $s \in (0,1)$。

**输入**：模型参数、$V$、$P$，以及模块二导出的 $q^*(i,s)$ 函数形式。
**输出**：提供者最优策略 $(i^*, s^*)$ 与对应的用户效用 $U_{i^*}(s^*, q^*)$。

### 模块间数据流

模块一提供博弈结构与效用/成本定义 → 模块二解析推导 $q^*(i,s)$ 的分段闭式解 → 模块三将 $q^*$ 代入 $J_i$，通过单变量优化与阈值比较输出全局最优策略。最终通过**错位缺口** $\Delta_U = \max_{i,s} U_i - U_{i^*}$ 度量用户最优效用与提供者最优策略下用户实际效用之间的差距（Figure 5），揭示双方目标在弃用惩罚较低时的系统性偏离。

> **注意**：本框架完全基于理论推导，未在真实LLM数据集或用户实验上进行实证验证。所有成功率假设为独立同分布的伯努利试验，且参数 $V, p_i, P$ 均假设已知恒定。



### 模块一：用户最佳响应表征

该模块在给定提供商路由与级联策略 $(i, s)$ 的前提下，解析推导用户的稳态弃用概率 $q^*$。核心逻辑是：用户根据每个模型的**净价值** $\xi_i = V p_i - t_i$ 决定行为——$\xi_i > 0$ 表示模型为“价值占优”（成功价值超过等待延迟），$\xi_i < 0$ 表示“延迟占优”。

**当提供商直接路由到推理模型 M2（$i = 2$）时**，用户行为退化为简单的阈值规则（Theorem 1）：
- 若 $\xi_2 \geq 0$，用户坚持使用（$q^* = 0$）；
- 若 $\xi_2 < 0$，用户直接弃用（$q^* = 1$）。

**当提供商从标准模型 M1 开始路由（$i = 1$）时**，用户行为取决于 $\xi_1$ 与 $\xi_2$ 的符号组合（Theorem 2）：
- **$\xi_1 \geq 0, \xi_2 \geq 0$（双价值占优）**：用户始终坚持（$q^* = 0$）。
- **$\xi_1 < 0, \xi_2 < 0$（双延迟占优）**：用户始终弃用（$q^* = 1$）。
- **$\xi_1 < 0 < \xi_2$（M1 延迟占优，M2 价值占优）**：存在阈值 $s_0$，级联概率 $s \geq s_0$ 时用户坚持，否则弃用。阈值定义：
  $$s_0 := -\frac{\xi_1}{\xi_2 / p_2 - \xi_1}$$
- **$\xi_1 > 0 > \xi_2$（M1 价值占优，M2 延迟占优）**：用户行为随 $s$ 连续变化，存在随机弃用区域。最优 $q^*$ 由隐函数 $F(s, q) = 0$ 确定，其中：
  $$F(s,q) = \xi_1 (1-s)(p_2+(1-p_2)q)^2 + \xi_2 s \left(1-(1-p_1)(1-p_2)(1-s)(1-q)^2\right)$$
  当 $s \leq s_H$ 时用户完全坚持（$q^* = 0$），当 $s \geq 1$ 时用户弃用（$q^* = 1$），中间区域 $q^* \in (0,1)$。上阈值 $s_H := \xi_1 / (\xi_1 - \xi_2)$。

Figure 3 以热图展示了 $i=1, s=0.25$ 时 $q^*$ 随 $\xi_1, \xi_2$ 的变化，验证了上述分区：右上角（双价值占优）和左下角（双延迟占优）为静态区域，左上角和右下角（混合价值）出现阈值行为，且仅 $\xi_1 > 0 > \xi_2$ 时存在 $q^* \in (0,1)$ 的内点解。

### 模块二：提供商最优策略优化

在用户最佳响应 $q^*(i, s)$ 约束下，提供商最小化总成本：
$$J_i(s, q) = C_i(s, q) + P(1 - S_i(s, q))$$
其中 $C_i$ 为期望服务成本，$P$ 为弃用惩罚，$S_i$ 为任务成功概率。当从 M1 路由时，$S_1$ 和 $C_1$ 的显式表达式为：
$$S_1(s,q) = \frac{p_1 + \alpha\beta p_2 s}{1 - \alpha(1-s)}, \quad C_1(s,q) = \frac{c_1 + \alpha\beta c_2 s}{1 - \alpha(1-s)}$$
其中 $\alpha = (1-p_1)(1-q)$ 表示任务未成功且用户未弃用的概率，$\beta = p_2 + (1-p_2)q$ 表示进入 M2 后任务最终成功的概率。

提供商问题可归约为单变量优化：
$$\min\left\{ \min_s J_1(s, q^*(1,s)), \; J_2(\mathbb{1}\{\xi_2 < 0\}) \right\}$$

**关键结论**（Theorem 3）：当两个模型同属价值占优或延迟占优时，最优策略总是**静态无级联**的——直接路由到每次成功成本（cost-per-pass）更低的模型。价值占优时比较 $c_1/p_1$ 与 $c_2/p_2$；延迟占优时用户必然弃用，提供商选择成本更低的模型。

**混合价值场景**（Theorem 4, 5）：当 $\xi_1 < 0 < \xi_2$ 时，最优策略由弃用惩罚 $P$ 与两个阈值 $P_1, P_2$ 的关系决定。当 $\xi_1 > 0 > \xi_2$ 时，大部分参数区域仍为静态路由，仅弃用惩罚极低或成本差异显著时才出现概率性级联 $s \in (0,1)$。Figure 4 的热图验证了这一点：最优策略在绝大多数区域为直接路由到 M1 或 M2，无级联。

| 符号 | 含义 |

| $\xi_i = V p_i - t_i$ | 模型 $i$ 的单次使用净价值 |

## 实验与关键发现

### 理论实验设计

本文采用完全理论分析的方法，通过数值热图系统性地探索参数空间，而非在真实LLM数据集上进行实证验证。实验的核心设计思路是：固定标准模型M1的推理成本 $c_1=1$，在由两个关键维度构成的参数网格上扫描提供者最优策略和用户行为——横轴为“每次成功成本差异” $c_1/p_1 - c_2/p_2$（衡量两个模型成本效率的相对差距），纵轴为弃用惩罚 $P$（衡量用户流失对提供者的代价）。

这一设计使得作者能够覆盖从“推理模型极为昂贵且弃用惩罚极低”到“推理模型极为高效且弃用惩罚极高”的完整参数区域，从而揭示路由策略的相变边界。

### 用户行为热图分析

Figure 3 展示了当提供者初始路由到M1且级联概率固定为 $s=0.25$ 时，用户最优弃用概率 $q^*$ 随两个模型净价值 $\xi_1, \xi_2$ 的变化。热图明确划分出三个行为区域：


![[assets/figures/papers/iclr26_0010_VqAhhF6av8_Routing_Cascades_and_User_Choice_for_LLMs/figures/003_Figure_3.jpg]]
*Figure 3: Heatmap of the user response when i = 1 and s = 0 . 2 5 . When both models are valuedominated (top right) or latency-dominated (bottom left), the user best response is static. When the models differ in their regime (top left and bottom right), the user response depends on $\xi _ { 1 } , \xi _ { 2 }$ . Note that $q ^ { * } \in$ ( 0 , 1 ) is in the interior only in certain regimes for $\xi _ { 1 }$ > 0 > $\xi _ { 2 }$

1. **静态弃用区域**（$q^*=1$，用户立即离开）：当两个模型均为延迟占优（$\xi_1<0, \xi_2<0$，左下角）时，用户无论级联概率如何都会放弃任务。此时等待延迟超过了任务成功的预期价值，用户的最优策略是立即退出。

2. **完全坚持区域**（$q^*=0$，用户永不放弃）：当两个模型均为价值占优（$\xi_1>0, \xi_2>0$，右上角）时，用户会持续重试直到任务成功。每个模型的单次使用净价值均为正，用户没有动机主动退出。

3. **随机弃用区域**（$q^* \in (0,1)$）：仅出现在 $\xi_1>0>\xi_2$ 的特定参数子集（右下角），即标准模型为价值占优而推理模型为延迟占优时。在此区域内，用户以严格介于0和1之间的概率随机弃用，且该概率随级联概率 $s$ 连续变化。在 $\xi_1<0<\xi_2$ 区域（左上角），用户行为呈现阈值特性——当级联概率 $s$ 超过阈值 $s_0$ 时完全坚持，否则立即弃用，不存在随机化区域。

这一结果证实了用户行为的内生性：用户的最优响应并非简单的外生参数，而是由模型净价值的符号组合和提供者的级联策略共同决定的。

### 提供者最优策略热图分析

Figure 4 分别展示了两种混合价值场景下提供者最优策略的热图：


![[assets/figures/papers/iclr26_0010_VqAhhF6av8_Routing_Cascades_and_User_Choice_for_LLMs/figures/005_Figure_4.jpg]]
*Figure 4: L e f t . Heatmap of the provider-optimal policy for $\xi _ { 1 }$ < 0 < $\xi _ { 2 }$ R i g h t $\cdot$ Heatmap of the provider-optimal policy for $\xi _ { 1 }$ > 0 > $\xi _ { 2 }$ . For both plots, we hold $c _ { 1 }$ = 1 constant and sweep the difference in cost-of-pass $c _ { 1 } / p _ { 1 } - c _ { 2 } / p _ { 2 }$ as well as $\bar { P . }$ . For most regimes, the optimal policy is either to route immediately to $M _ { 1 }$ or to $M _ { 2 }$ without any cascading. There exist only some regimes for $\xi _ { 1 }$ > 0 > $\xi _ { 2 }$ where the optimal policy involves probabilistic s $\in$ ( 0 , 1 )

**场景一：$\xi_1<0<\xi_2$（标准模型延迟占优，推理模型价值占优）**

提供者最优策略几乎总是静态无级联的。具体而言：
- 当弃用惩罚 $P$ 较高时，提供者直接路由到M1（标准模型），因为用户弃用的代价过高，提供者倾向于让用户留在系统中；
- 当弃用惩罚 $P$ 较低且推理模型的每次成功成本显著低于标准模型时，提供者直接路由到M2（推理模型）；
- 级联策略（$s \in (0,1)$）仅在极窄的参数区域内出现，位于两个静态策略的边界附近。

**场景二：$\xi_1>0>\xi_2$（标准模型价值占优，推理模型延迟占优）**

此时出现更丰富的策略结构：
- 大部分区域仍为静态无级联策略——要么直接路由到M1，要么直接路由到M2；
- 存在一个显著的概率级联区域（$s \in (0,1)$），且该区域出现在弃用惩罚 $P$ 较低且推理模型成本效率较高的参数组合中。这意味着当用户流失代价小且推理模型虽慢但便宜时，提供者有动机通过级联来平衡成本与成功率。

**核心发现**：在绝大多数参数区域，提供者的最优策略是静态的、无级联的。级联作为一种策略工具，仅在弃用惩罚较低或两个模型的成本差异显著时才有实际价值。这一结论具有直接的工程指导意义——在典型的商业部署场景中，复杂的动态级联机制可能并不必要。

热图揭示：
- 错位缺口在弃用惩罚 $P$ 较低的区域最为显著。当提供者不太担心用户流失时，其成本最小化策略与用户效用最大化策略之间的分歧最大；
- 在 $\xi_1<0<\xi_2$ 场景下，错位缺口随推理模型成本效率的提高而扩大——推理模型越便宜，提供者越倾向于使用它，但这可能与用户对延迟的敏感度相冲突；
- 在 $\xi_1>0>\xi_2$ 场景下，错位缺口在中间弃用惩罚区域达到峰值，呈现出非单调特征。

### 节流效应分析

Figure 5 的右图展示了提供者通过人为增加延迟（节流）来降低成本的动机。热图比较了节流前后的提供者最优成本差异，虚线标注了 $P = \min\{c_1/p_1, c_2/p_2\}$ 的边界。

关键发现：
- 当弃用惩罚 $P$ 低于虚线阈值时，提供者有明确的动机通过节流增加延迟来降低成本。这是因为低弃用惩罚意味着用户流失的代价小，提供者可以通过降低服务质量（增加等待时间）来压缩推理成本，而无需担心用户大规模流失；
- 节流的收益在推理模型成本效率较高时尤为显著——提供者可以通过延迟迫使更多用户接受成本更低的模型路由；
- 当弃用惩罚 $P$ 高于阈值时，节流反而增加提供者总成本，因为用户弃用带来的惩罚超过了延迟所节省的服务成本。

这一分析揭示了一个潜在的系统性风险：在缺乏有效弃用惩罚机制（如用户黏性低、替代服务多、或监管缺失）的环境中，提供者可能主动降低服务质量以优化自身成本，进一步加剧用户与提供者之间的目标错位。

### 实验局限性

需要明确指出，本文的所有“实验”均为理论数值分析，缺乏在真实LLM部署环境中的实证验证。以下方面需要后续工作补充：

1. **参数校准缺失**：模型成功率 $p_1, p_2$、用户价值 $V$、弃用惩罚 $P$ 等关键参数在热图中以归一化形式扫描，未基于任何真实LLM基准测试或用户行为数据进行校准。热图的绝对数值意义有限，其价值主要在于揭示定性规律和相变边界。

2. **用户行为假设未验证**：用户最优响应 $q^*$ 的推导基于完全理性和完全信息的假设——用户知晓提供者的完整路由策略和模型成功率。实际用户可能仅基于有限交互经验形成信念，其弃用行为可能呈现惯性、过度反应或学习动态，这些均未被实验检验。

3. **任务异质性未考虑**：模型成功率被假设为固定的伯努利参数，忽略了不同任务难度对成功概率的影响。在真实场景中，标准模型和推理模型在不同任务类型上的相对优势可能截然不同，这可能导致最优路由策略的任务依赖性，而本文的统一阈值规则可能过于简化。

4. **延迟建模简化**：延迟 $t_i$ 被建模为固定常数，未考虑排队效应、负载波动或推理模型的自适应计算量分配。在实际API服务中，延迟往往是负载依赖的，这可能改变用户对“延迟占优”与“价值占优”的感知边界。

综上，本文的理论结果提供了理解LLM路由博弈的清晰框架和定性指导，但在将其直接应用于生产系统之前，需要基于真实数据和用户实验进行参数校准和行为假设验证。



## 定位与知识库关联

### 与基准方法的本质差异

本研究提出的 Stackelberg LLM 路由博弈框架与现有路由方法存在两个根本性差异，分别体现在**用户行为建模**和**提供者优化目标**的设定上。

**用户行为建模**：现有路由方法（如 Ding et al., 2024 等单轮成本最优路由）将用户行为视为外生固定——用户被动接受路由结果，不会根据服务质量调整自身行为。本研究将用户行为内生化，建模为用户在观察到提供者路由与级联策略后，以稳态最佳响应（stationary best response）决定是重试还是弃用任务。这一转变使得用户弃用概率 $q^*$ 成为博弈均衡的一部分，而非预设常数。

**提供者优化目标**：基准方法的目标是最小化单次推理成本（single-pass cost），而本框架的目标是最小化用户最佳响应约束下的提供者期望总成本 $J_i(s,q) = C_i(s,q) + P(1 - S_i(s,q))$，其中服务成本 $C_i$ 与弃用惩罚 $P$ 被联合优化。这一目标函数的结构性差异导致：当弃用惩罚较低时，提供者可能选择看似低效的路由策略以压缩服务成本，而这在单轮成本优化范式下无法被解释或预测。

此外，朴素策略“直接将所有任务路由到推理模型（M2）”在本框架中作为提供者优化问题的退化解之一出现，其最优性仅在特定参数区域成立（如 Theorem 3 中两个模型均为延迟占优且 M2 的每次成功成本更低时）。

### 适用边界与核心假设的约束力

本框架的结论严格依赖于以下建模假设，偏离这些假设时结论需要重新审视：

1.  **双模型限定**：分析仅覆盖一个标准模型（M1）和一个推理模型（M2）的场景。当模型数量超过两个时，级联路径的组合爆炸和用户对多级级联的响应模式将显著复杂化，Theorem 3–5 中的简洁阈值规则（如每次成功成本比较 $\frac{c_1}{p_1} \leq \frac{c_2}{p_2}$）能否推广尚属开放问题。

2.  **完全信息与静态弃用**：假设用户知晓完整的路由策略 $(i, s)$ 和模型成功率 $p_i$，并据此采取静态弃用策略。实际场景中用户仅能观测路由决策而无法直接获知级联概率 $s$，此时用户需要形成信念并动态调整行为，引入探索-利用权衡。这一信息不对称可能改变博弈均衡的结构，尤其是当提供者可以利用信息优势进行策略性误导时。

3.  **独立同分布的成功假设**：每次调用的成功概率被建模为独立同分布的伯努利试验，不考虑任务间的依赖关系或通过用户反馈改进成功率的可能。若成功概率随重试次数提升（例如用户修改 prompt），则用户弃用阈值将下移，级联的价值可能被重新评估。

4.  **参数已知且恒定**：用户价值 $V$、模型成功率 $p_i$、弃用惩罚 $P$ 均假设为已知常数。现实中这些参数随任务类型、用户群体和时间动态变化，且无法直接观测。这限制了定理的直接操作性，需要在线估计机制的配合。

5.  **无显式货币价格**：框架仅通过延迟 $t_i$ 和弃用惩罚 $P$ 间接反映成本，未纳入订阅费用或按查询定价等显式货币维度。这使得经济解释的完备性受限——例如，当提供者可以通过提高订阅费来补偿弃用损失时，节流延迟的动机可能减弱。

### 局限性与开放问题

**已识别的局限性**：

-   缺乏在真实 LLM 数据集或用户实验上的实证验证，所有结论均基于理论推导，定理中的阈值条件（如 $P_1$、$P_2$、$s_0$）的实际量级和敏感性未知。
-   单提供者假设排除了竞争效应，现实中用户可在多个 LLM 服务间切换，提供者间的路由博弈可能改变弃用惩罚的有效性和均衡策略。
-   用户价值 $V$ 被假设为任务成功与否的二元价值，未建模部分成功或质量梯度对用户效用的影响。

**值得关注的开放问题**：

1.  **多模型扩展**：如何将阈值规则推广到 $N$ 个模型的级联链或更一般的路由图？是否存在类似于每次成功成本排序的简洁最优性条件？

2.  **不完全信息下的学习动态**：当用户仅观测路由决策而无法直接观测 $s$ 和 $p_i$ 时，用户如何形成信念？提供者是否有动机策略性地模糊级联概率以操纵用户行为？这会引入怎样的 regret 和收敛性质？

3.  **定价与路由的联合优化**：将每查询货币定价纳入订阅框架后，定价策略与路由、级联的联合优化问题具有三层决策结构（定价→路由→用户响应），其 Stackelberg 均衡的结构可能比当前双层层级更丰富。

4.  **非 i.i.d. 成功概率**：若每次交互的成功概率通过用户反馈得到改进（例如模型从失败中学习或用户改进 prompt），博弈均衡如何变化？这可能使得级联的价值随时间衰减，最优策略从静态转为动态。

5.  **在线参数估计与自适应路由**：如何通过在线学习机制同时估计 $V$ 和 $P$，并自适应地调整路由策略？Theorem 4–5 中的阈值条件需要这些参数的点估计，估计误差的传播效应需要量化。

6.  **多提供者竞争**：当多个提供者竞争同一用户群体时，弃用惩罚 $P$ 内化为用户流失到竞争对手的期望损失，路由博弈将变为提供者间的非合作博弈，均衡行为可能与单提供者场景有质的不同。
