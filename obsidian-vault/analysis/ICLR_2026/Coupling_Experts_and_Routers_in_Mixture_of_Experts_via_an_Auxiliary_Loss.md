# Coupling Experts and Routers in Mixture-of-Experts via an Auxiliary Loss

> [!tip] 核心洞察
> 将路由器参数视作 token 聚类的中心，利用有界扰动后的路由器嵌入作为 token 簇的代理点，通过比较这些代理点在所有专家上的中间激活范数，并以辅助损失强制代理点与其对应专家的激活最高，从而以极低的固定成本实现专家与路由器的紧密耦合，无需全量激活。

## 概要

混合专家（Mixture-of-Experts, MoE）架构通过稀疏激活机制，在显著扩展模型容量的同时控制计算成本，已成为大规模语言模型的核心范式。然而，传统 MoE 存在一个根本性瓶颈：**路由器（Router）在做出 token 分发决策时，缺乏对专家处理能力的显式感知**。路由器参数与专家参数各自独立优化，导致 token 可能被路由到并非最适合处理它的专家，梯度信号也因此干扰了专家的专业化进程，最终限制模型性能。

针对这一问题，本文提出 **专家-路由器耦合损失（Expert-Router Coupling Loss, ERC Loss）**——一种轻量级辅助损失函数。其核心洞察在于：将路由器的嵌入向量视作 token 聚类的中心，通过施加有界随机扰动生成“代理 token”，并比较这些代理点在所有专家上的中间激活范数，以辅助损失强制每个专家对自身代理点的响应最强，同时每个代理点在其对应专家处获得最高激活。这一设计以极低的固定计算成本实现了专家与路由器的紧密耦合，且**无需像 Autonomy-of-Experts（AoE）等方法那样进行全量专家激活**。

ERC 损失的关键优势体现在三个层面：

1. **有效性**：在 3B 至 15B 参数规模的 MoE 预训练中，ERC 损失稳定提升下游任务性能。在 15B 参数、256 专家的高稀疏配置下，MMLU、C-Eval、MMLU-Pro、AGI-Eval 等 8 个挑战性基准均取得全面提升，其中 AGI-Eval 提升达 +2.2 个百分点，TriviaQA 提升 +1.9 个百分点。更重要的是，ERC 损失显著缩小了与计算昂贵的 AoE 方法之间的性能差距。

2. **高效性**：ERC 损失引入的训练额外开销仅为 **0.2%–0.8%**，推理阶段**零额外开销**。相比之下，AoE 需要 1.6 倍的训练时间和 1.3 倍的内存占用。

3. **机制可解释性**：消融实验揭示了 ERC 损失成功的关键机制——代理点生成中的随机噪声 δ 至关重要，移除噪声会导致性能大幅下降，因为耦合会过拟合到路由器嵌入而无法泛化到簇内真实 token。超参数 α 直接调节专家-路由器耦合的严格程度，α 越小耦合越强、专家越专一化，但追求极端专业化反而损害性能，揭示了专业化与协作之间的内在权衡。

在方法谱系中，ERC 损失定位于**辅助损失驱动的稀疏 MoE 优化**路径，与负载均衡损失（Fedus et al., 2022）等现有辅助损失形成互补。不同于 AoE（Lv et al., 2025）通过稠密激活范数选择路由的激进方案，ERC 损失保留了标准稀疏 MoE 的路由效率，仅通过训练阶段的轻量约束重塑专家-路由器的对齐关系，在性能与效率之间取得了优异的平衡。

### 混合专家模型的路由困境

混合专家（Mixture-of-Experts, MoE）架构通过稀疏激活机制，使每个 token 仅由少量专家处理，从而在扩大模型容量的同时控制计算成本。在标准 MoE 中，路由器根据输入 token $x$ 计算专家权重向量 $\pmb{w} = \mathrm{softmax}(\pmb{x} \pmb{R}^{\top})$，并选择 Top-K 个专家进行激活，最终输出为加权和 $\sum_k^K \pmb{w}[k] E_k(\pmb{x})$。每个专家 $E_i$ 通常采用 SwiGLU 结构：

$$E_i(\pmb{x}) = \left( \mathrm{SiLU}(\pmb{x} \pmb{W}_g^i) \odot (\pmb{x} \pmb{W}_p^i) \right) \pmb{W}_o^i$$

然而，这一架构存在一个根本性缺陷：**路由器缺乏对专家能力的显式感知**。路由决策与专家的真实处理能力相互独立优化，导致两个严重后果：其一，token 可能被错误路由到不擅长的专家，浪费模型容量；其二，梯度信号可能干扰专家专业化，使专家之间趋于同质化，丧失 MoE 架构的核心优势。

### 现有方案的代价

针对这一问题，**Autonomy-of-Experts**（AoE, Lv et al., 2025）提出了一种激进的解决方案：完全移除路由器，转而基于所有专家的激活范数直接选择专家。这种方法虽然建立了专家选择与专家能力之间的直接联系，但代价极为高昂——训练时间增加至 **1.6 倍**，内存占用增加至 **1.3 倍**，且推理时需计算所有专家的激活，丧失了稀疏激活的效率优势。这种“用稠密换耦合”的策略在规模化预训练中难以承受。

### 核心动机与设计原则

本文的核心洞察是：**路由器的决策与专家能力之间的耦合才是瓶颈，而非路由器的存在本身**。基于这一认识，作者提出了三条设计原则：

1. **保留路由器**：维持稀疏激活的推理效率，路由器不可移除。
2. **引入辅助损失**：通过一个轻量级的辅助损失，使专家与路由器在训练中产生交互，建立有意义的耦合关系。
3. **固定开销**：辅助损失的计算复杂度必须与输入 token 数量无关，且不增加激活密度，确保训练开销可忽略。

这一设计思路直指 MoE 架构的根本矛盾：如何在保持稀疏激活效率的同时，让路由器“了解”每个专家的真实能力，从而做出更优的路由决策。

## 核心方法与创新机理

本工作提出 **专家-路由器耦合损失（ERC Loss）**，通过一个轻量级辅助损失函数，首次在稀疏激活的混合专家模型中以极低开销实现专家能力与路由器决策的显式耦合。其核心创新围绕以下四个关键维度展开。

### 1. 聚类视角下的代理点机制

传统 MoE 中，路由器参数 $R$ 仅用于计算路由 logits，与专家的实际处理能力之间缺乏直接交互。ERC 损失将路由过程重新诠释为 token 聚类：路由器嵌入的每一行 $R[i]$ 被视为分配给专家 $i$ 的 token 簇的聚类中心。在此基础上，为每个聚类中心生成一个**扰动代理 token** $\tilde{R}[i] = R[i] \odot \delta_i$，其中 $\delta_i$ 是有界乘性随机噪声。这些代理点作为对应 token 簇的代表，被送入所有专家的中间激活计算，从而以固定成本（与批量大小无关）建立专家-路由器之间的信息通道。值得强调的是，扰动仅用于损失计算，实际路由仍使用纯净的路由器嵌入 $R$，保证了推理阶段零额外开销。

### 2. 双向耦合约束的 hinge 损失

ERC 损失的核心是对代理点激活矩阵 $M$ 施加两个对称约束：

$$M[i,j] = \| \tilde{R}[i] \cdot W_g^j \|$$

- **约束 (1)**：每个专家对自己的代理点的激活必须高于对其他专家代理点的激活，即 $M[i,j] < \alpha M[i,i]$（$\forall j \neq i$）。
- **约束 (2)**：每个代理点在其对应专家处的激活必须高于在其他专家处的激活，即 $M[j,i] < \alpha M[i,i]$（$\forall j \neq i$）。

最终 ERC 损失函数为：

$$\mathcal{L}_{\mathrm{ERC}} = \frac{1}{n^2} \sum_{i=1}^{n} \sum_{j \neq i}^{n} \left( \max(M[i,j] - \alpha M[i,i], 0) + \max(M[j,i] - \alpha M[i,i], 0) \right)$$

其中超参数 $\alpha \in (0,1]$ 控制耦合的严格程度。这一双向设计同时约束了“专家选择代理点”和“代理点选择专家”两个方向，形成对称的耦合结构，这是 ERC 损失区别于简单对比学习或正交化损失的关键所在。

### 3. 有界噪声实现簇内泛化

代理点生成中的随机噪声 $\delta_i$ 并非随意添加，其幅度受聚类边界约束：

$$\epsilon_i \leq \frac{\|R[i] - R[j]\|}{2\|R[i]\|}$$

该上界确保扰动后的代理点仍位于原聚类中心所属的 token 簇内。消融实验提供了决定性证据：**移除随机噪声 $\delta$ 会导致性能大幅下降**，因为此时专家-路由器耦合会过拟合到路由器嵌入本身，无法泛化到簇内的真实 token。这一设计使得 ERC 损失能够在不访问实际 token 的条件下，以极低的固定成本实现有效的簇内泛化。

### 4. 固定计算复杂度的轻量设计

ERC 损失的计算复杂度为 $O(n^2 D d)$，仅依赖于专家数量 $n$ 和隐藏维度，与输入 token 的批量大小 $T$ 完全无关。在 3B 至 15B 参数规模的预训练实验中，该损失引入的训练额外开销仅为 **0.2–0.8%**，远低于 Autonomy-of-Experts（AoE）方法的 1.6× 训练时间和 1.3× 内存开销。同时，由于 ERC 损失仅在训练阶段使用，推理阶段**零额外开销**。

### 与 baseline 的核心差异总结

| 维度 | Vanilla MoE | ERC Loss 增强的 MoE |
|------|-------------|---------------------|
| 专家-路由器对齐 | 无显式约束，各自独立优化 | 通过双向 hinge 损失强制耦合 |
| 路由器嵌入的角色 | 仅用于计算路由 logits | 同时作为 token 聚类中心，生成代理点参与专家能力评估 |
| 训练开销来源 | 仅标准稀疏前向计算 | 额外引入固定 $n^2$ 量级的激活范数计算，与批量大小无关 |
| 泛化机制 | 不适用 | 通过有界乘性噪声使耦合损失泛化到簇内真实 token |

消融实验进一步证实，即使 baseline 模型的路由器嵌入已接近正交（平均绝对余弦相似度仅 0.15），单独施加正交化损失带来的增益极为有限，而 ERC 损失仍能带来显著提升——这直接证明 **路由器-专家耦合才是核心瓶颈，而非路由器的正交性**。

ERC 损失的设计遵循一条清晰的三步流水线，在不改变标准稀疏 MoE 推理路径的前提下，以极低的固定成本实现专家与路由器之间的紧密耦合。该流水线的核心思想源自对 MoE 路由机制的聚类视角：路由器参数 $R \in \mathbb{R}^{n \times d}$ 的每一行可视为一个聚类中心，负责将语义相近的 token 分配给对应的专家。ERC 损失正是利用这些聚类中心作为代理点，通过评估专家对代理点的响应强度来强制建立耦合关系。

整个框架由四个模块串联构成，其中前三个模块专用于 ERC 损失的计算，第四个模块则保持标准 MoE 的前向传播不变。

**模块一：扰动路由器代理点生成（Perturbed Router Proxy Generation）**

对于第 $i$ 个专家的路由器嵌入 $R[i]$，该模块生成一个扰动后的代理 token $\tilde{R}[i] = R[i] \odot \delta_i$，其中 $\delta_i \in \mathbb{R}^d$ 是有界乘性随机噪声。噪声的上界由聚类几何约束确定：

$$\epsilon_i \leq \frac{\|R[i] - R[j]\|}{2\|R[i]\|}$$

这一约束确保扰动后的代理点不会跨越到邻近聚类中心所属的区域，从而保证每个代理点仍能代表分配给对应专家的 token 分布。引入随机噪声是该方法的关键设计选择——消融实验表明，移除噪声 $\delta$ 会导致性能大幅下降，因为耦合会过拟合到纯净的路由器嵌入 $R$，无法泛化到簇内真实 token 的多样性。

**模块二：激活矩阵计算（Activation Matrix Computation）**

将 $n$ 个代理点分别送入所有 $n$ 个专家的门控投影矩阵 $W_g^j$，计算 L2 范数，得到一个 $n \times n$ 的激活矩阵 $M$：

$$M[i, j] = \| \tilde{R}[i] \cdot W_g^j \|$$

其中 $M[i, j]$ 表示代理点 $\tilde{R}[i]$（代表专家 $i$ 的 token 簇）在专家 $j$ 的门控中间激活上的响应强度。对角线元素 $M[i, i]$ 反映了专家 $i$ 对“自己”代理点的激活程度，而非对角线元素则度量了专家间的交叉响应。值得注意的是，该计算仅涉及 $n^2$ 次矩阵乘法，与批量大小 $T$ 无关，这是 ERC 损失保持低开销的根本原因。

**模块三：ERC 损失计算（ERC Loss Calculation）**

基于激活矩阵 $M$，对每一对 $(i, j)$ 施加两个对称的 hinge 约束：

$$\mathcal{L}_{\mathrm{ERC}} = \frac{1}{n^2} \sum_{i=1}^{n} \sum_{j \neq i}^{n} \left( \max(M[i, j] - \alpha M[i, i], 0) + \max(M[j, i] - \alpha M[i, i], 0) \right)$$

约束 (1) $\max(M[i, j] - \alpha M[i, i], 0)$ 要求每个专家对自己的代理点反应最强，惩罚专家 $i$ 对他人代理点的激活超过 $\alpha$ 倍自身对角线激活的部分。约束 (2) $\max(M[j, i] - \alpha M[i, i], 0)$ 要求每个代理点在对应专家处获得最高激活，惩罚代理点 $i$ 在专家 $j$ 处的激活超过阈值的情况。超参数 $\alpha \in (0, 1]$ 直接控制耦合的严格程度：$\alpha$ 越小，约束越紧，专家越专一化。

**模块四：标准 MoE 前向传播（Standard MoE Forward Pass）**

在训练和推理的每一步，模型仍然执行标准稀疏 MoE 的前向计算：使用纯净的路由器嵌入 $R$ 计算路由 logits，通过 Top-K 选择激活的专家，并由选中的专家处理输入 token。扰动后的代理点 $\tilde{R}$ 仅用于损失计算，不参与实际的路由决策或 token 处理。这一设计保证了推理阶段零额外开销，训练阶段的额外 FLOPs 仅为 $2n^2 D d$（其中 $D$ 为中间激活维度），在实验中仅引入 0.2–0.8% 的训练时间开销。

**与 AoE 的架构对比**

Figure 2 展示了标准 MoE 与 Autonomy-of-Experts (AoE)（Lv et al., 2025）的架构差异。AoE 通过计算所有专家的激活范数来选择路由，虽然能天然实现专家-路由器耦合，但需要每个 token 激活全部 $n$ 个专家，导致训练时间增加 1.6 倍、内存占用增加 1.3 倍。ERC 损失在保持标准稀疏激活的前提下，以辅助损失的形式达到了接近 AoE 的耦合效果，在 15B 参数规模下显著缩小了与 AoE 的性能差距，同时保持了与 vanilla MoE 几乎相同的吞吐量和内存开销。

### 3.1 动机与设计约束

ERC 损失的设计源于对 MoE 路由机制的聚类视角：路由器参数 $R$ 可视为 token 聚类的中心，每个行向量 $R[i]$ 代表了分配给专家 $i$ 的 token 簇的质心。基于此视角，论文提出三条设计原则：

1. **保留路由器**：路由器必须保留在 MoE 架构中以维持路由效率。
2. **专家-路由器交互**：需要一个辅助损失来促成专家与路由器之间的交互，强化其耦合。
3. **固定开销**：损失的复杂度必须与输入 token 数量无关，且不能引入超出普通 MoE 的激活密度。

### 3.2 核心模块：三步计算流程

ERC 损失的计算包含三个关键模块，对应 Figure 1 所示流程：

**模块一：扰动代理点生成（Perturbed Router Proxy Generation）**

对于每个聚类中心 $R[i]$，生成一个带扰动的代理 token：

$$\tilde{R}[i] = R[i] \odot \delta_i$$

其中 $\delta_i \in \mathbb{R}^d$ 是有界乘性随机噪声。噪声的上界由聚类几何结构决定：

$$\epsilon_i \leq \frac{\lVert R[i] - R[j] \rVert}{2 \lVert R[i] \rVert}$$

该约束确保扰动后的代理点仍位于原聚类中心所属的簇内。需要注意的是，扰动代理点 $\tilde{R}$ 仅用于损失计算，实际路由决策仍使用纯净的路由器嵌入 $R$ 计算路由 logits。

**模块二：激活矩阵计算（Activation Matrix Computation）**

将 $n$ 个代理点分别送入所有 $n$ 个专家的门控权重矩阵 $W_g^j$，计算中间激活的 L2 范数，得到 $n \times n$ 的激活矩阵 $M$：

$$M[i, j] = \lVert \tilde{R}[i] \cdot W_g^j \rVert$$

其中 $M[i, j]$ 表示专家 $j$ 对代理点 $\tilde{R}[i]$ 的响应强度。选择 $W_g$ 的中间激活范数作为度量，是因为消融实验（Figure 6a）表明其在所有候选方案（$W_p$、SiLU 激活、SwiGLU 激活、最终输出范数）中效果最佳且计算开销最低。

**模块三：ERC 损失计算（ERC Loss Calculation）**

基于激活矩阵 $M$，施加两个对称约束：

- **约束 (1)**：每个专家对自己的代理点的激活，必须高于对其他代理点的激活，即 $M[i, j] < \alpha M[i, i]$
- **约束 (2)**：每个代理点在自己对应专家处的激活，必须高于在其他专家处的激活，即 $M[j, i] < \alpha M[i, i]$

将两个约束转化为 hinge 损失形式，得到 ERC 损失：

$$\mathcal{L}_{\mathrm{ERC}} = \frac{1}{n^2} \sum_{i=1}^{n} \sum_{j \neq i}^{n} \left( \max(M[i, j] - \alpha M[i, i], 0) + \max(M[j, i] - \alpha M[i, i], 0) \right)$$

其中 $\alpha \in (0, 1]$ 是控制耦合严格程度的核心超参数。$\alpha$ 越小，约束越严格，专家越专一化；$\alpha$ 越大，耦合越松弛。当 $\alpha > 1$ 时，约束过松，模型逐渐退化至普通 MoE 的性能（Figure 7）。

### 3.3 计算开销分析

ERC 损失引入的额外计算量仅为 $2 n^2 D d$ FLOPs（其中 $n$ 为专家数，$D$ 为中间维度，$d$ 为路由器嵌入维度），这是一个与批量大小 $T$ 无关的固定开销。在实际的 3B 至 15B 参数规模预训练中，该开销仅占训练总开销的 0.2–0.8%，且推理阶段无任何额外开销，远低于 AoE 方法所需的 1.6× 训练时间和 1.3× 内存开销。

### 3.4 噪声的必要性

消融实验（Figure 6b）表明，移除代理点生成中的随机噪声 $\delta$ 会导致性能大幅下降。原因在于：若无噪声扰动，耦合损失会过拟合到路由器嵌入 $R$ 本身，无法泛化到簇内真实 token 的多样性。有界随机噪声使得代理点 $\tilde{R}[i]$ 能够更好地捕捉分配给专家 $i$ 的 token 集合 $\mathcal{X}_i$ 的分布特征。

### 3.5 与路由器正交化的区别

消融实验（Figure 6c）还对比了单独施加路由器正交化损失 $\hat{R}\hat{R}^{\top} = I$ 的效果。结果表明，正交化损失的增益非常有限，因为基准 MoE 的路由器嵌入已经接近正交（平均绝对余弦相似度仅 0.15）。这证明路由器-专家耦合才是核心瓶颈，而非路由器的正交性。ERC 损失不能被简单地归约为对路由器或专家单独施加的对比技术。

## 实验与关键发现

### 核心性能增益：从 3B 到 15B 的稳定提升

ERC 损失在 3B 至 15B 参数规模的 MoE 预训练中均带来了稳定且显著的下游任务性能提升。在 15B 参数、256 个专家的高稀疏配置下，该方法在 8 个挑战性基准上全面超越 vanilla MoE 基线（Table 1）：MMLU 从 63.2 提升至 64.6（+1.4），C-Eval 从 67.5 提升至 69.0（+1.5），AGI-Eval 从 42.0 提升至 44.2（+2.2），TriviaQA 从 47.2 提升至 49.1（+1.9），MMLU-Pro、BBH、MATH、GSM8K 也分别录得 +0.4 至 +1.3 的增益。这些结果验证了 ERC 损失在大规模模型上的鲁棒性。

![[assets/figures/papers/paper_list_l30_https_openreview_net_forum_id_MpeyjgWbKt/figures/006_Table_1.jpg]]
*Table 1: Scaling to 15B parameters: ERC loss improves performance on challenging benchmarks*

更关键的是，ERC 损失显著缩小了与计算昂贵的 Autonomy-of-Experts（AoE）方法之间的性能差距。AoE 需要基于所有专家的激活范数进行稠密路由，训练时间增加 1.6 倍，内存占用增加 1.3 倍；而 ERC 损失在训练中仅引入 0.2–0.8% 的额外开销，推理阶段零开销——因为它仅作为辅助损失参与训练，不改变前向路由逻辑。

### 专业化与协作的平衡：α 作为核心旋钮

超参数 α 是控制专家-路由器耦合强度的核心旋钮。α 越小，ERC 约束越严格，专家越专一化；α 越大，约束越松弛，专家间协作空间越大。实验表明，所有测试的 α 值均优于 vanilla MoE 基线，但性能并非单调递增。

Figure 5(b) 展示了不同 α 值下的下游准确率曲线：α=0.5 和 α=1.0 在训练后期（300–500 步）达到约 56.5% 的最高准确率，而 α=0.01（极端专业化）和 α=0.1 的表现明显逊色，甚至在某些阶段接近基线水平。这揭示了一个核心权衡：**追求极端专业化反而损害性能**，适度的专业化与协作平衡才是最优解。

![[assets/figures/papers/paper_list_l30_https_openreview_net_forum_id_MpeyjgWbKt/figures/009_Figure_5.jpg]]
*Figure 5: (a) Since routers are deeply coupled with experts, the distance between neighboring cluster centers ( $\mathrm { i . e . }$ the maximum noise level ϵ) quantitatively reflects changes in expert specialization during training, which is controlled by α. (b) Downstream performance across different values of α*

Figure 5(a) 进一步量化了这一关系。由于路由器与专家深度耦合，相邻聚类中心的最大噪声水平 ϵ 可以作为专家专业化的定量代理指标。随着 α 增大，ϵ 单调下降，反映了专业化程度的降低。这种从 α 到 ϵ 再到下游性能的传导链条，使 α 成为调节 MoE 模型行为的高效单旋钮。

### 消融实验：设计选择的决定性证据

#### 激活范数的选择

计算激活矩阵 M 时，使用代理点经过专家门控矩阵 $W_g$ 后的中间激活范数（即 $\tilde{R} W_g$）在所有候选方案中效果最佳（Figure 6a）。替代方案包括使用 $W_p$ 矩阵、SiLU 或 SwiGLU 激活后的输出、以及最终输出范数。虽然使用最终输出范数也能取得相近性能，但其计算成本更高，因此默认选择中间激活 $W_g$。

![[assets/figures/papers/paper_list_l30_https_openreview_net_forum_id_MpeyjgWbKt/figures/010_Figure_6.jpg]]
*Figure 6: Results of ablation studies. For detailed task-specific results, please refer to Figure 9*

#### 随机噪声 δ 的必要性

去除代理点生成中的随机噪声 δ 会导致性能大幅下降（Figure 6b）。这一消融结果具有决定性意义：没有噪声扰动时，ERC 损失会使路由器-专家耦合过拟合到纯净的路由器嵌入 $R$ 上，无法泛化到簇内真实 token 的多样性。有界乘性噪声使代理点 $\tilde{R}[i]$ 能够更好地代表分配给专家 $i$ 的整个 token 分布 $\mathcal{X}_i$，这是 ERC 损失有效性的关键机制。

#### 路由器正交化的对比

单独对路由器施加正交化损失（$\hat{R}\hat{R}^\top = I$）仅带来有限增益（Figure 6c）。原因在于，基线 MoE 模型的路由器嵌入本身已接近正交——平均绝对余弦相似度仅为 0.15。这一发现直接证明了：**路由器-专家耦合才是核心瓶颈，而非路由器的正交性**。即使路由器嵌入已经良好分离，若专家能力与路由决策不匹配，模型性能仍会受限。

#### α > 1 时的退化

当 α > 1 时，ERC 约束过松，模型逐渐退化至 vanilla MoE 的性能水平（Figure 7）。α=2 时提升已非常微弱，α=3 时几乎无增益。这与 Table 2 的静态评估一致：对 vanilla MoE 进行事后 ERC 损失评估，当 α ≥ 4 时大多数层的损失降为零，说明基线模型本身已满足极端松弛的约束。

*Table 2: Post-hoc ERC loss evaluation of the vanilla MoE across α values. For clarity, loss values are computed using the original R rather than $\tilde { R }$ , making the results deterministic*

### 损失降低的机制验证

一个自然的质疑是：模型是否通过简单地扩大或缩小参数范数来“欺骗”ERC 损失？Table 3 排除了这种可能性。对比有无 ERC 损失的模型，$R[i]$ 和 $W_g^i$ 的参数范数变化极小（例如 $||W_g^i||$ 仅从约 25–32 降至约 24–31.5），而各层的 ERC 损失却精确降至零。这表明模型确实学习了有意义的专家-路由器耦合，而非通过范数操纵来最小化损失。


### 负载均衡的保持

所有实验统一使用负载均衡损失（Fedus et al., 2022）且权重固定为 0.01。加入 ERC 损失后，负载均衡损失的变化在 $10^{-5}$ 量级（Figure 3），基本不影响 token 在各专家间的均衡分配。这意味着 ERC 损失可以在不破坏现有负载均衡机制的前提下独立施加耦合约束。

### 当前局限与待验证方向

尽管实验证据充分，以下问题仍需手动验证或进一步探索：

- **最优 α 的自动化选择**：目前 α 的最优值依赖经验调参，缺乏自动化机制和可靠的量化度量。
- **更大规模的验证**：实验仅覆盖最多 15B 参数、256 个专家的配置，对千亿参数以上或数百位专家的适用性未经验证。
- **训练阶段的局限性**：ERC 损失仅应用于预训练阶段，微调、指令调优或强化学习阶段是否仍需该损失尚不明确。
- **噪声分布的设计空间**：代理点噪声目前仅采用有界均匀分布，更复杂的噪声分布能否进一步提升泛化性有待探索。
- **跨架构移植**：该方法基于 SwiGLU 结构及 $W_g$ 的中间激活范数设计，移植到其他 MoE 变体时需要调整。

## 定位与知识库关联

### 1. 与基线方法的关系

#### 1.1 标准稀疏 MoE（Vanilla MoE）

本文的核心基线是标准稀疏激活的混合专家模型（Vanilla MoE）。在此架构中，路由器仅负责计算每个 token 对 n 个专家的 Top-K 选择权重，专家参数与路由器参数各自独立优化，不存在任何显式的专家-路由器耦合约束。论文的实验揭示了一个关键瓶颈：即使基准 MoE 的路由器嵌入已接近正交（平均绝对余弦相似度仅 0.15），模型性能仍然受限。这直接证明**路由器正交性并非核心瓶颈，真正的瓶颈在于路由器决策与专家实际处理能力之间的脱节**。

ERC 损失正是在这一诊断基础上提出的：它不改变路由器的 Top-K 选择机制，也不增加推理时的激活密度，而是在训练阶段通过辅助损失强制建立耦合关系。实验表明，ERC 损失在所有测试的 α 值下均优于 vanilla MoE，且当 α > 1 时约束过松，模型逐渐退化至 vanilla MoE 的性能水平（α=2 时提升微弱，α=3 时几乎无提升），这反向验证了耦合约束的必要性。

#### 1.2 Autonomy-of-Experts（AoE）

**AoE**（Lv et al., 2025）是本文最直接的竞争方法。AoE 采用了一种激进的设计：完全摒弃路由器，直接基于所有专家的激活范数来选择专家，从而天然实现了专家与路由的紧密耦合。然而，这种设计以巨大的计算开销为代价——AoE 需要计算所有专家的激活，导致训练时间增加至 1.6 倍，内存占用增加至 1.3 倍，且在 15B 参数规模下因资源限制无法成功训练。

ERC 损失的设计目标明确指向 AoE 的性能上界与计算成本之间的矛盾：它通过仅使用固定数量的代理点（n 个）来计算激活矩阵，将额外计算量控制在 n² 量级，与批量大小 T 无关，从而将训练开销压缩至 0.2–0.8%，推理开销为零。在 3B 参数规模的对比中，ERC 损失显著缩小了与 AoE 的性能差距，同时保持了与 vanilla MoE 几乎相同的吞吐量和内存成本。

### 2. 与负载均衡损失的关系

ERC 损失与经典的负载均衡损失（Fedus et al., 2022）在功能上互补而非竞争。所有实验均统一使用负载均衡损失且权重固定为 0.01，加入 ERC 损失后负载均衡损失的变化仅在 10⁻⁵ 量级，表明两种损失可以协同工作而互不干扰。负载均衡损失关注的是 token 在专家间的分布均匀性，而 ERC 损失关注的是路由器决策与专家能力的匹配质量，两者作用于 MoE 训练的不同维度。

### 3. 与路由器正交化损失的关系

消融实验直接对比了 ERC 损失与单独对路由器施加正交化损失（约束 $\hat{R}\hat{R}^{\top}=I$）的效果。结果表明，正交化损失的增益非常有限，因为基准 MoE 的路由器嵌入已经接近正交。这进一步强化了论文的核心论点：**ERC 损失不能被还原为单独应用于路由器或专家的对比技术**，其关键在于建立跨模块的耦合关系，而非优化单一模块的内部结构。

### 4. 适用边界

ERC 损失的设计基于以下前提条件，超出这些边界时需谨慎评估：

- **专家结构依赖**：损失计算依赖于 SwiGLU 专家的中间激活 $W_g$ 矩阵的 L2 范数。若移植到使用标准 ReLU 或其他激活函数的专家变体，需要重新验证激活范数的有效性。消融实验已测试了多种替代激活（$W_p$、SiLU、SwiGLU 激活、最终输出范数），其中 $W_g$ 范数在性能与成本之间取得了最优平衡。

- **专家数量规模**：实验验证覆盖了最多 256 个专家的 MoE 模型（15B 参数）。由于 ERC 损失的计算复杂度为 $O(n^2 d)$，当专家数量 n 增长至数百甚至数千时，固定开销仍可能保持可控，但在极端情况（如百万级细粒度专家）下的适用性未经验证。

- **训练阶段限制**：ERC 损失仅在预训练阶段应用。在微调、指令调优或强化学习阶段是否仍需该损失，以及是否会产生不同的效果，尚不明确。

### 5. 局限性与开放问题

#### 5.1 已知局限

1. **α 的经验依赖性**：最优的专业化程度（α 值）目前完全依赖人工经验选择。实验表明，α 过小会导致过度专业化而损害性能，α 过大则退化为 vanilla MoE，但缺乏自动确定最优 α 的机制和可靠的量化度量。

2. **噪声分布单一**：代理点生成中的随机噪声 δ 目前仅采用有界均匀分布。消融实验证明去除噪声会导致性能大幅下降（耦合过拟合到路由器嵌入而无法泛化到真实 token），但更复杂的噪声分布能否进一步提升泛化性有待探索。

3. **规模验证上限**：实验仅覆盖至 15B 参数、256 个专家的配置，对千亿参数以上或更多专家的超大规模模型的适用性缺乏直接证据。

#### 5.2 开放问题

1. **自动化专业化控制**：如何为给定的模型结构（专家数量 n、Top-K 值、层数等）自动确定最优 α，以平衡专业化与泛化？论文提出 ϵ（类间距离）可作为专业化的定量指标，但尚未建立从 ϵ 到最优 α 的自动化映射。

2. **跨架构推广**：ERC 损失能否推广到其他类型的混合模型，如注意力头混合（MoA）或层混合（MoL）？其核心思想——将路由参数视为聚类中心并强制激活对齐——在理论上具有通用性，但需要针对不同模块的激活形式进行调整。

3. **与 token 级辅助损失的协同**：ERC 损失与负载均衡损失、z-loss 等基于 token 的辅助损失之间是否存在更优的联合训练策略（如动态权重调整），值得进一步探索。

4. **推理阶段的负载影响**：更强的专家专业化是否会在推理阶段加剧负载不均衡或增加冷启动专家的问题？论文在训练阶段验证了负载均衡基本不受影响，但推理时的分布偏移可能带来新的挑战。

5. **训练动态监控**：是否可以通过分析 ERC 损失的层间动态演化来自动检测训练中的专家坍塌或冗余？Table 2 的事后评估已展示了不同层对约束的满足程度存在差异，这暗示了层级诊断的可能性。
