## 概述

### 问题背景

传统具身智能体任务要求智能体遵循明确指令完成物体重排，例如“把杯子放到桌子上”。然而，现实中的个性化协助场景（Personalized Assistance）远比这复杂——用户往往使用模糊的、依赖个人语境的指令，如“把我的杯子放到老地方”。这类指令要求智能体不仅理解当前环境，还必须从过去的交互记忆中提取用户特定的知识，将其映射为可执行的目标。Figure 1 对比了这两类任务的本质差异：传统任务仅需遵循简单指令，而个性化协助要求智能体将指令锚定在历史交互中。

当前以LLM为高层策略规划器的具身智能体虽然在传统任务上表现优异，但在个性化场景中面临两个核心瓶颈：

1. **信息过载**：增加检索记忆的数量（top-k）反而引入噪声，导致成功率持续下降。
2. **协调失败**：智能体无法有效协调多条记忆，即使仅需组合两条对象语义记忆的简单联合任务，GPT-4o 的成功率也下降了 20.8%。

此外，智能体倾向于依赖参数化的常识知识，而非非参数化的个性化记忆，导致性能不一致。

### 核心方法

针对上述瓶颈，本文提出 **MEMENTO**——一个端到端的两阶段个性化具身智能体评估框架，以及一种基于层级知识图谱的用户画像记忆模块（Hierarchical Knowledge Graph-based User Profile Memory）。

MEMENTO 将个性化物体重排任务形式化为部分可观察马尔可夫决策过程（POMDP），其核心设计在于通过**记忆获取**（Memory Acquisition）和**记忆利用**（Memory Utilization）两个阶段来隔离评估智能体的记忆利用能力。两阶段共享相同的场景和任务目标，但指令不同：获取阶段提供包含充分个性化知识的指令，利用阶段则使用欠指定的指令，要求智能体从情景记忆中检索并推理用户特定信息。

个性化知识被分类为两个维度：
- **对象语义**（Object Semantics）：识别具有个人意义的目标物体（如“我的杯子”）。
- **用户模式**（User Patterns）：重建完整的任务目标序列（如“先放杯子，再放书”）。

用户画像记忆模块采用三层结构——用户层、知识类型层、具体元素层——将个性化知识从情景记忆轨迹中独立出来管理，通过混合检索管道（嵌入搜索结合LLM推理）提取信息，从而减轻协调负担并改善信息提取。

### 核心结论

实验揭示了三个关键发现：

1. **记忆利用是严重瓶颈**：所有模型在记忆利用阶段的成功率下降超过 20%，联合记忆任务下降更为严重——GPT-4o 从获取阶段的 95.0% 降至利用阶段的 63.9%（ΔSR -30.5%）（Table 1）。

2. **情景记忆提供双重好处**：情景记忆不仅提供个性化知识，还提供上下文学习（in-context learning）利益。摘要记忆移除了轨迹信息，导致较小模型（Llama-3.1-8b、Qwen-2.5-7b）性能下降，而完整情景记忆保持较高性能（Table 2）。

3. **独立记忆管理是关键**：用户画像记忆模块显著提升了单记忆和联合记忆任务的性能，尤其改善了此前受困的序列用户模式任务（Figure 8），验证了将个性化知识从情景记忆中分离管理的设计有效性。

## 背景与动机

具身智能体（Embodied Agents）在传统任务中主要遵循简单指令执行物体重排（object rearrangement），例如“把苹果放到桌子上”。这类任务仅要求智能体理解当前场景并执行标准化的动作序列，不涉及对用户特定知识的依赖。然而，现实世界中的个性化协助（personalized assistance）场景对智能体提出了更高要求：智能体必须能够识别具有个人意义的物品、回忆用户的日常习惯与偏好，并基于这些个性化知识做出决策。

当前以LLM为高层策略规划器的具身智能体系统，虽然在指令遵循方面表现出色，但在个性化任务中面临两个相互关联的瓶颈。首先，**信息过载（information overload）** 导致性能随检索记忆数量增加而持续下降：增加top-k值引入噪声，干扰智能体对关键信息的提取。其次，**记忆协调失败（coordination failure）** 使得智能体在需要组合多条记忆的任务中表现急剧恶化——即使仅需整合两条对象语义记忆的简单联合任务，GPT-4o的成功率也从获取阶段的95.0%骤降至63.9%，降幅达30.5个百分点。

这些瓶颈的根源在于现有记忆架构将个性化知识与完整的交互轨迹混合存储于情景记忆（episodic memory）中。智能体必须从包含大量无关细节的ReAct格式轨迹中自行提取个性化信息，这不仅增加了推理负担，还导致智能体倾向于依赖参数化的常识知识而非非参数化的个性化记忆，造成性能的不一致。

针对上述缺口，本文提出两个核心贡献。在评估层面，构建了**MEMENTO**——一个端到端的两阶段个性化具身智能体评估框架，通过将相同目标的不同指令分配至记忆获取（acquisition）与记忆利用（utilization）两个阶段，隔离并量化智能体的记忆利用能力。在方法层面，设计了**基于层级知识图谱的用户画像记忆模块**（Hierarchical Knowledge Graph-based User Profile Memory），将个性化知识从情景记忆中解耦并独立管理，以缓解信息过载并减轻多记忆协调的负担。

## 核心创新

针对LLM驱动具身智能体在个性化任务中暴露的**信息过载**与**记忆协调失败**两大瓶颈，本文的核心创新在于将个性化知识从情景记忆中解耦，引入独立的**层级知识图谱用户画像记忆模块**（Hierarchical Knowledge Graph-based User Profile Memory），改变了记忆的表示、管理与检索方式。

### 创新一：个性化知识独立管理——从“嵌入轨迹”到“结构化画像”

在基准配置中，个性化知识（如“用户最喜欢的杯子是蓝色的那个”）与导航轨迹、动作序列等细节混杂在完整的ReAct风格情景记忆中。这种设计导致两个后果：检索时噪声信息过载，以及联合任务中多条记忆难以协调。

本文提出的方法将个性化知识抽取为独立的三层知识图谱结构：顶层为用户节点，中间层为知识类型（对象语义与用户模式），底层为具体元素（物体、模式、位置）。该模块与情景记忆并行存在，使智能体在记忆利用阶段可以精准获取个性化知识，而不必从冗长的交互轨迹中自行提取。

**证据支撑**：消融实验表明，用户画像记忆模块在所有模型上均带来显著性能提升（Figure 8）。此前受困于信息过载的用户模式任务改善尤为明显。

### 创新二：混合检索与表示——从“相似度匹配”到“推理增强检索”

基准方法采用基于指令嵌入的相似度检索（all-mpnet-base-v2），直接返回原始情景记忆文本。该方法在信息过载场景下缺乏对检索结果的精炼能力。

本文提出的混合检索管线将嵌入搜索与LLM推理相结合：智能体首先解析当前指令，再从用户画像知识图谱中检索相关节点，最终由LLM将图结构内容重新表述为自然语言，作为策略生成的上下文输入。这一设计减轻了智能体从噪声记忆中自行提取有效信息的认知负担。

### 创新三：保留情景记忆的上下文学习利益

实验揭示了一个关键发现：简单的记忆摘要会移除轨迹信息，导致Llama-3.1-8b和Qwen-2.5-7b等较小模型的性能下降（Table 2）。这表明情景记忆中的完整交互轨迹为LLM提供了重要的上下文学习（in-context learning）信号。

因此，本文的方法并非用画像记忆替代情景记忆，而是保持两者的互补关系——情景记忆保留轨迹以支撑上下文学习，画像记忆独立管理个性化知识以降低信息提取难度。这一设计在消除信息过载的同时，避免了对较小模型上下文学习能力的损害。

## 整体框架

### 问题形式化

本研究将个性化物体重排任务建模为部分可观测马尔可夫决策过程（POMDP），定义为 $(S, A, T, R, \Omega, O, \gamma)$。在此框架下，智能体需根据指令 $I$ 和情景记忆 $M$，从观测-动作轨迹 $\tau_t = (w_1, a_1, w_2, a_2, \dots, w_{t-1}, a_{t-1}, w_t)$ 中推导出目标表示并生成动作：

$$\pi(I, M, \tau_t) \to a_t$$

其中目标推导函数 $\phi$ 将指令和记忆映射为由物体-位置对组成的目标 $g$：

$$\phi(I, M) \longrightarrow g = (o_i, l_i)_{i=1}^{k}$$

该形式化将个性化协助的核心挑战——即如何从历史交互中提取用户特定知识来完成当前任务——统一纳入策略生成框架。

### 两阶段评估框架：MEMENTO

MEMENTO 框架的核心设计思想是**通过保持场景和目标不变、仅改变指令的信息完整度，来隔离智能体的记忆利用能力**。具体而言，框架包含两个阶段：

- **记忆获取阶段（Memory Acquisition Stage）**：智能体接收包含充分个性化知识的指令 $I_{acq}$，执行常规物体重排任务。此阶段生成的情景记忆轨迹 $M$ 作为后续利用阶段的记忆库。该阶段的 episode 定义为 $\epsilon_{acq} = (S, I_{acq}, g)$。

- **记忆利用阶段（Memory Utilization Stage）**：智能体面对相同场景 $S$ 和相同目标 $g$，但指令 $I_{util}$ 被刻意设计为信息不足（underspecified），必须从先前获取的情景记忆中检索并利用个性化知识才能完成任务。该阶段的 episode 定义为 $\epsilon_{util} = (S, I_{util}, g)$。

两阶段之间的性能差距 $\Delta SR = SR_{util} - SR_{acq}$ 直接量化了智能体的记忆利用能力。该设计有效排除了导航、抓取等底层技能差异的干扰，将评估焦点精准锁定在“能否从记忆中提取并应用个性化知识”这一核心能力上。

### 个性化知识分类

框架将个性化知识沿两个关键维度进行分类，以细粒度诊断智能体的能力瓶颈：

- **物体语义（Object Semantics）**：评估智能体识别具有个人含义的目标物体的能力。例如，理解“我的杯子”指的是哪个特定杯子，而非依赖通用常识。

- **用户模式（User Patterns）**：评估智能体重构完整目标的能力。这涉及理解用户的序列化行为习惯或空间偏好，例如“像上次那样整理桌面”。

### 系统架构与模块组成

智能体系统由以下核心模块构成流水线：

1. **LLM 高层策略规划器（LLM High-Level Policy Planner）**：作为系统的决策中枢，采用 ReAct 提示格式，基于当前观测和检索到的记忆，从预定义的技能库中选择合适的技能执行。技能库包含导航、抓取、放置等原子操作。

2. **语义记忆（Semantic Memory）**：以场景图（Scene Graph）形式提供层级化的世界状态信息，采用三层有向图结构：房屋 → 房间 → 家具/物体/智能体。该模块为智能体提供结构化的环境理解。

3. **情景记忆（Episodic Memory）**：存储完整的交互轨迹，包括 `<Thought, Action, Observation>` 三元组。记忆检索采用基于嵌入的相似度搜索，使用 `all-mpnet-base-v2` 编码器，以当前指令为查询、以历史记忆的指令为键进行 top-k 检索。默认 $k=5$ 配置下，黄金记忆召回率达 96.5%。

4. **用户画像记忆（User Profile Memory，本文提出）**：独立于情景记忆的层级知识图谱模块，采用三层结构——顶层为用户，中间层为知识类型（物体语义和用户模式），底层为具体元素（物体、模式、位置）。该模块通过混合检索流水线（结合嵌入搜索与 LLM 推理）提取并重格式化个性化知识为自然语言，旨在减轻信息过载和协调失败两大瓶颈。

### 输入输出流

整体流水线的数据流如下：用户指令 $I$ 首先触发情景记忆检索，获取 top-k 相关历史轨迹；同时（若启用用户画像记忆模块），系统从知识图谱中提取相关个性化知识。LLM 策略规划器将当前观测 $w_t$、检索到的记忆内容、以及技能库描述拼接为提示，生成思考过程和动作 $a_t$。动作由底层技能执行器在 Habitat 3.0 模拟器中执行，产生新的观测 $w_{t+1}$，形成闭环交互。任务成功与否由目标 $g$ 中所有物体-位置对的完成情况判定。

## 核心模块与公式推导

### 任务形式化：个性化物体重排的POMDP建模

本文将个性化物体重排任务形式化为部分可观测马尔可夫决策过程（POMDP），定义为七元组 $(S, A, T, R, \Omega, O, \gamma)$。在此框架下，智能体需要根据指令 $I$ 和情景记忆 $M$ 推导出目标表示 $g$，该过程由grounding函数刻画：

$$\phi ( I , M ) \longrightarrow g = ( o _ { i } , l _ { i } ) _ { i = 1 } ^ { k }$$

其中 $g$ 由 $k$ 个物体-位置对组成，$o_i$ 为目标物体，$l_i$ 为对应的目标位置。这一推导过程是连接自然语言指令与可执行动作序列的核心桥梁——指令中隐含的个性化指代（如“我常用的杯子”）必须通过记忆中的过往交互记录才能正确解析为具体的物体标识。

在每一时间步 $t$，LLM策略根据指令、情景记忆以及观测-动作轨迹 $\tau_t$ 生成动作：

$$\pi ( I , M , \tau _ { t } ) \to a _ { t } , \quad \tau _ { t } = ( w _ { 1 } , a _ { 1 } , w _ { 2 } , a _ { 2 } , \dots , w _ { t - 1 } , a _ { t - 1 } , w _ { t } )$$

其中 $w_i$ 为第 $i$ 步的环境观测，$a_i$ 为对应的动作。轨迹 $\tau_t$ 完整保留了 ReAct 格式的 `<Thought, Action, Observation>` 三元组，这是情景记忆提供上下文学习利益的结构基础。

### MEMENTO评估框架：两阶段隔离设计

MEMENTO框架的核心设计思想是通过控制变量来隔离记忆利用能力。具体而言，记忆获取阶段和记忆利用阶段共享相同的场景 $S$ 和目标表示 $g$，仅改变指令 $I$：

- **记忆获取阶段**：$\epsilon_{acq} = (S, I_{acq}, g)$，指令包含充分的个性化知识（如“把Alice的红色马克杯放到厨房台面上”），智能体执行任务的同时将交互轨迹存入情景记忆。
- **记忆利用阶段**：$\epsilon_{util} = (S, I_{util}, g)$，指令被刻意模糊化（如“把我的杯子放回原位”），强制智能体必须从情景记忆中检索并利用过往交互信息才能完成任务。

两阶段的成功率差值 $\Delta SR = SR_{util} - SR_{acq}$ 直接量化了记忆利用能力的瓶颈程度。实验表明，所有模型在利用阶段的成功率下降均超过20%，GPT-4o在联合记忆任务上的降幅高达30.5%（Table 1）。

### 个性化知识分类体系

为精细分析记忆利用失败的具体原因，本文将个性化知识划分为两个关键维度：

- **物体语义（Object Semantics）**：评估智能体根据个人意义识别目标物体的能力。例如，指令“拿我的杯子”要求智能体从多个外观相似的杯子中，依据过往交互记录识别出属于特定用户的哪一个。
- **用户模式（User Patterns）**：评估智能体重构完整目标的能力，涉及用户特有的行为习惯和空间偏好。例如，用户习惯将钥匙放在门口鞋柜上，而非通用的收纳位置。

这一分类揭示了性能差异的结构性来源：物体语义任务在各模型上退化较小，而用户模式任务表现出显著的性能崩塌（Figure 4），表明当前智能体在推理用户行为规律方面存在系统性缺陷。

### 记忆检索与信息过载机制

记忆利用阶段的检索采用基于嵌入相似度的top-k机制，以当前指令为查询，使用 `all-mpnet-base-v2` 编码器计算与情景记忆中历史指令的余弦相似度。默认配置 $k=5$ 可实现96.5%的黄金记忆召回率，但这一看似合理的设置却引发了信息过载问题：随着 $k$ 增大，检索到的无关记忆引入噪声，导致所有模型的成功率持续下降（Figure 6）。

这一现象揭示了LLM驱动智能体的一个根本性脆弱点——在需要从多条记忆中筛选相关信息的场景下，模型倾向于被噪声干扰而非有效利用冗余信息进行交叉验证。该瓶颈在用户模式任务上尤为突出，因为这类任务要求智能体从多条记忆片段中归纳出用户的行为规律，而非简单地匹配单个物体指代。

### 层级知识图谱用户画像记忆模块

针对上述瓶颈，本文提出的核心改进是一个独立的用户画像记忆模块，采用三层级知识图谱结构：

- **顶层**：用户节点，区分不同用户的个性化知识空间。
- **中间层**：知识类型节点，分为物体语义和用户模式两类。
- **底层**：具体元素节点，包括物体、模式、位置等实体。

该模块与情景记忆并行运作，通过混合检索管线（结合嵌入搜索与LLM推理）将图谱内容重新表述为自然语言后注入策略上下文。其关键设计动机在于：将个性化知识从杂乱的情景轨迹中解耦，使智能体无需在包含大量无关动作细节的记忆文本中进行信息提取，从而缓解信息过载和协调失败的瓶颈。

消融实验证实，情景记忆的摘要化会移除轨迹信息，导致较小模型（Llama-3.1-8b、Qwen-2.5-7b）性能显著下降（Table 2），证明完整的 ReAct 轨迹提供了关键的上下文学习利益。因此，保留情景记忆的同时通过独立的用户画像模块管理个性化知识，是在利用上下文学习优势与降低信息提取负担之间取得平衡的关键设计选择。

## 实验与分析

### 4.1 记忆利用的双重瓶颈：信息过载与协调失败

MEMENTO框架通过两阶段评估范式（记忆获取阶段与记忆利用阶段）系统性地揭示了LLM驱动的具身智能体在个性化任务中面临的核心瓶颈。Table 1呈现了六种主流LLM在单记忆与联合记忆任务上的完整性能对比。

![[assets/figures/papers/paper_list_l8_https_openreview_net_forum_id_E5L43l5EIu/figures/004_Table_1.jpg]]
*Table 1: Model performance across memory acquisition and utilization stage in MEMENTO*

**单记忆利用的普遍退化。** 所有模型在记忆利用阶段的成功率均出现超过20%的显著下降。以GPT-4o为例，其记忆获取阶段成功率达95.0%，但在单记忆利用任务中降至85.1%（ΔSR = -9.9%）。更小规模的模型退化更为严重：Llama-3.1-8b从获取阶段的78.0%降至利用阶段的52.8%，降幅达25.2%。这一结果表明，即使检索系统已将黄金记忆（gold memory）纳入top-k结果（默认k=5，召回率96.5%），智能体仍无法有效从情景记忆中提取并应用个性化知识。

**联合记忆任务的协调崩溃。** 当任务需要同时利用两条情景记忆时，性能退化呈指数级加剧。GPT-4o的联合记忆利用成功率骤降至63.9%，与获取阶段平均成功率（95.0%）相比，ΔSR达到-30.5%。这一发现揭示了当前LLM智能体的关键弱点：即使每条记忆单独可被正确利用，同时协调多条记忆信息的能力存在根本性缺陷。

### 4.2 个性化知识类型的非对称影响

Figure 4按个性化知识类型对单记忆任务进行分解分析，揭示了两种知识维度的非对称影响模式。

**对象语义（Object Semantics）任务相对稳健。** 智能体在识别具有个人意义的物品（如"我的水杯"、"孩子最喜欢的玩具"）时性能退化较小。这表明LLM能够将检索到的对象-语义映射与当前指令进行有效对齐，该能力受益于模型在预训练中习得的丰富语义表征。

**用户模式（User Patterns）任务构成主要瓶颈。** 当任务要求智能体重建用户的序列行为模式或空间布局偏好时，性能出现大幅下降。Figure 5的定性案例分析进一步揭示了失败的根本原因：智能体倾向于依赖参数化的常识知识（parametric commonsense knowledge）而非非参数化的个性化记忆（non-parametric personalized memory）。例如，当用户将特定物品放置在非常规位置时，智能体频繁回退到"物品应放在典型位置"的常识判断，忽略了记忆中记录的用户实际行为模式。

### 4.3 信息过载：检索数量增加的反直觉效应

Figure 6展示了不同top-k值对记忆利用成功率的系统性影响。实验通过确保黄金记忆始终包含在检索结果中，隔离了检索质量对利用能力的干扰。

![[assets/figures/papers/paper_list_l8_https_openreview_net_forum_id_E5L43l5EIu/figures/007_Figure_6.jpg]]
*Figure 6: Success rate comparison across models as top-k value increases. Dashed lines represent memory acquisition stage baselines for each model*

**持续下降趋势。** 随着k值从1增加至7，所有模型的成功率呈现单调下降趋势。这一结果揭示了信息过载（information overload）机制：增加检索记忆数量虽然提高了黄金记忆的召回率，但同时引入了大量噪声记忆，干扰了LLM对关键信息的提取和利用。用户模式任务对该效应尤为敏感，因为此类任务需要精确提取特定的行为序列，噪声记忆中的无关轨迹信息会严重混淆LLM的推理过程。

**模型规模与鲁棒性的关系。** 更大规模的模型（如GPT-4o、Qwen-2.5-72b）对信息过载表现出更强的鲁棒性，但仍无法完全避免性能下降。这暗示信息过载并非仅靠增加模型容量即可解决的问题，而是需要从记忆架构层面进行根本性改进。

### 4.4 联合记忆协调的深层分析

Figure 7按个性化知识类型对联合记忆任务进行分解，进一步揭示了协调失败的具体模式。

![[assets/figures/papers/paper_list_l8_https_openreview_net_forum_id_E5L43l5EIu/figures/008_Figure_7.jpg]]
*Figure 7: Personalized knowledge type-based analysis on joint-memory tasks*

**同类型记忆组合的意外困难。** 即使是最简单的联合场景——组合两条对象语义记忆（Obj-Obj）——GPT-4o的成功率也下降了20.8%。这一发现挑战了"联合困难主要源于跨类型知识整合"的直觉假设。实验表明，LLM在同时处理两条语义上独立的记忆时，存在信息混淆和优先级分配失败的问题。

**用户模式组合的极端退化。** 涉及用户模式的联合任务（Pattern-Pattern、Obj-Pattern）表现出最严重的性能下降。这表明序列行为模式的协调需要更高层次的推理能力，而当前LLM在记忆利用的上下文中缺乏有效的行为模式合成机制。

### 4.5 情景记忆的双重价值与格式简化陷阱

Table 2比较了三种记忆格式下的模型性能：完整情景记忆（Full Episodic Memory）、摘要记忆（Summarized Memory）和仅指令（Instruction-only）。

![[assets/figures/papers/paper_list_l8_https_openreview_net_forum_id_E5L43l5EIu/figures/009_Table_2.jpg]]
*Table 2: Model performance with memory format simplification approaches. Full memory indicates the episodic memory*

**情景记忆提供上下文学习利益。** 实验揭示了情景记忆的双重功能：它不仅存储个性化知识，还为LLM提供关键的上下文学习（in-context learning）信号。当使用GPT-4o对情景记忆进行摘要化处理（移除轨迹细节，仅保留关键信息）时，较小模型出现明显的性能退化：Llama-3.1-8b的SR从52.8%降至44.4%，Qwen-2.5-7b从47.2%降至37.5%。相比之下，GPT-4o和Qwen-2.5-72b等大模型对摘要化表现出较强的鲁棒性。

**轨迹信息的关键作用。** 这一规模相关的敏感性差异表明，情景记忆中的完整交互轨迹（ReAct格式的<Thought, Action, Observation>三元组）为较小模型提供了重要的推理示范。摘要化移除了这些示范信号，迫使模型完全依赖自身推理能力，而较小模型在此方面存在不足。因此，简单的记忆压缩策略会不成比例地损害资源受限场景下的智能体性能。

### 4.6 用户画像记忆的架构改进

Figure 8展示了引入层级知识图谱用户画像记忆（Hierarchical Knowledge Graph-based User Profile Memory）后的性能变化。

![[assets/figures/papers/paper_list_l8_https_openreview_net_forum_id_E5L43l5EIu/figures/011_Figure_8.jpg]]
*Figure 8: Agent performance with user profile memory across single- and joint-memory tasks*

**单记忆与联合记忆的全面提升。** 在所有评估模型中，配备用户画像记忆的智能体在单记忆和联合记忆任务上均取得显著提升。该模块通过将个性化知识（对象语义和用户模式）从情景记忆中解耦，以独立的三层知识图谱结构进行管理（用户层-知识类型层-具体元素层），有效缓解了信息过载和协调失败两大瓶颈。

**用户模式任务的针对性改善。** 改进效果在之前表现最差的用户模式任务上尤为突出。这是因为知识图谱的结构化表征使智能体能够通过混合检索管道（结合嵌入相似度搜索与LLM推理）精确提取所需的行为模式信息，避免了在大量无关轨迹中搜索的噪声干扰。

**遗留问题。** 尽管用户画像记忆带来了显著改进，联合记忆任务的性能仍低于单记忆任务，表明多记忆协调的根本性挑战尚未完全解决。此外，该模块对节点引用噪声的鲁棒性有限（准确率约75%），存在不必要的节点重复问题，需要进一步优化。

### 4.7 记忆质量与鲁棒性

补充消融实验（Table 17）进一步验证了记忆质量对性能的影响。移除导航轨迹（w/o Nav）导致所有模型中最大的性能下降，证实了空间导航信息在个性化物品整理任务中的关键作用。随机噪声注入同样导致性能退化，进一步支持了信息过载假说。

### 4.8 主要实验结论

综合上述分析，实验揭示了三个层次的核心发现：

1. **瓶颈识别**：信息过载和协调失败是阻碍LLM智能体有效利用记忆的两大关键瓶颈，二者分别源于检索噪声和LLM的多信息合成能力缺陷。

2. **机制理解**：情景记忆同时提供个性化知识和上下文学习信号；简单的压缩策略会损害较小模型的性能；智能体存在"常识偏好"——倾向于依赖参数化知识而非检索到的个性化记忆。

3. **架构方向**：将个性化知识管理从情景记忆中解耦，采用独立的结构化记忆模块（如层级知识图谱），是缓解当前瓶颈的有效架构设计方向。

## 方法谱系与知识库定位

### 1. 问题定位：从通用具身任务到个性化协助

传统具身智能体研究聚焦于遵循明确指令完成物体重排等任务（图1）。这些任务中，指令本身包含完整的目标信息，智能体只需进行场景理解与动作规划。本研究将问题推进至**个性化协助**场景：用户指令是欠指定的（underspecified），依赖智能体从过往交互记忆中提取个性化知识来补全目标。这一转变暴露了LLM驱动具身智能体的关键短板——记忆利用能力不足，而非记忆获取或动作执行能力不足。

### 2. 基线方法：全量情景记忆范式

本工作的默认基线是**全量情景记忆**配置（Full Episodic Memory）。该范式将智能体的每次交互以ReAct格式的`<Thought, Action, Observation>`三元组完整存储，在后续任务中通过嵌入相似度检索（使用all-mpnet-base-v2编码器）将top-k相关记忆注入LLM策略的上下文窗口。策略生成遵循公式：

$$\pi ( I , M , \tau _ { t } ) \to a _ { t }$$

其中 $I$ 为指令，$M$ 为情景记忆，$\tau_t$ 为观测-动作轨迹。目标推导函数为：

$$\phi ( I , M ) \longrightarrow g = ( o _ { i } , l _ { i } ) _ { i = 1 } ^ { k }$$

该范式在记忆获取阶段表现优异（GPT-4o成功率达95.0%），但在记忆利用阶段暴露出系统性缺陷。

### 3. 方法改进：层级知识图谱用户画像记忆

本研究提出的**层级知识图谱用户画像记忆**（Hierarchical Knowledge Graph-based User Profile Memory）是对全量情景记忆范式的关键改进。其核心设计理念是**将个性化知识从情景轨迹中解耦，独立管理**。

**架构变更对比**：

| 维度 | 基线（全量情景记忆） | 本方法（用户画像记忆） |
|------|---------------------|----------------------|
| 个性化知识管理 | 嵌入完整情景轨迹中，与无关轨迹细节混杂 | 独立的三层知识图谱（用户→知识类型→具体元素），与情景记忆并行使用 |
| 记忆检索方式 | 纯嵌入相似度检索 | 混合检索：嵌入搜索 + LLM推理，将图谱内容重新表述为自然语言 |
| 知识组织粒度 | 扁平化记忆条目 | 层级化：对象语义与用户模式分类型存储 |

用户画像记忆的三层结构为：顶层为用户节点，中间层为知识类型（对象语义、用户模式），底层为具体元素（物体、模式、位置）。这种设计使智能体能够直接访问结构化个性化知识，避免了从含噪声的完整轨迹中提取信息的认知负担。

### 4. 适用边界与关键约束

**适用前提**：
- 智能体需具备稳定的感知和运动技能库（本研究在Habitat 3.0模拟器中使用预定义技能集）
- 需要至少一次完整的记忆获取交互来建立个性化知识基础
- 检索系统需确保黄金记忆在top-k结果中的高召回率（默认k=5时达96.5%）

**关键约束**：
- **信息过载敏感**：增加检索记忆数量（top-k）会引入噪声，持续降低所有模型的成功率（图6），证明当前LLM在区分相关与无关记忆方面存在根本性困难
- **协调能力瓶颈**：即使仅需组合两条对象语义记忆的简单联合任务，GPT-4o成功率也下降20.8%（图7），表明多记忆协调是独立于单记忆提取的额外挑战
- **模型规模依赖**：摘要记忆在较大模型（GPT-4o、Qwen-2.5-72b）上影响轻微，但在较小模型（Llama-3.1-8b、Qwen-2.5-7b）上导致性能退化（表2），说明情景记忆提供的上下文学习利益对能力较弱的模型更为关键

### 5. 已知局限

1. **评估框架边界**：MEMENTO聚焦于记忆利用，未纳入会话能力或多轮对话的整合，难以评估完整的个性化交互流程。

2. **模拟器与现实差距**：所有评估在Habitat 3.0模拟器中进行，未考虑真实部署中的传感器噪声、物体外观变化和动态环境等因素。

3. **用户画像记忆鲁棒性**：对节点引用噪声的鲁棒性有限（准确率仅75%），存在不必要的节点重复问题（需人工验证具体数据）。

4. **个性化知识来源**：实验仅使用GPT-4o生成个性化知识，缺乏真实用户交互数据的验证，可能高估或低估实际场景中的记忆利用难度。

5. **隐私与安全**：实际部署中的隐私保护措施尚未详细探讨。

### 6. 待解决的核心开放问题

**记忆架构层面**：
- 如何从根本上提升多记忆协调性能，而非仅仅依赖更强大的底层模型？当前联合记忆任务中所有模型均出现大幅性能下降（表1），表明需要架构级别的创新。
- 如何自动平衡情景记忆的上下文学习利益与信息过载风险，动态确定最佳检索数量和记忆表示粒度？

**交互与泛化层面**：
- 如何将记忆利用与会话能力有机结合，实现更自然的个性化协助？当前框架缺乏对话交互维度。
- 用户画像记忆能否扩展到跨领域、跨场景的泛化能力，而不仅仅局限于训练时见过的情境？

**实际部署层面**：
- 在真实用户交互中，如何处理模糊、隐式甚至自相矛盾的个性化引用？当前评估使用明确的知识类型标签，实际场景更为复杂。
