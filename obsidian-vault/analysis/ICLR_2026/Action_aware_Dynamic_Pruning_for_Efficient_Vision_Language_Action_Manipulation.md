> [!tip] 核心洞察

## 概述

视觉-语言-动作（Vision-Language-Action, VLA）模型在机器人操作中展现出强大的泛化能力，但其参数量庞大的大语言模型骨干网络在推理时面临显著的计算开销。**核心瓶颈**在于视觉 token 的冗余程度随操作阶段剧烈变化：粗粒度的移动阶段背景信息高度冗余，可大幅剪枝；而精细操作阶段（如抓取、对齐）则需要完整的视觉细节来保证动作精度。现有静态剪枝方法无法在二者之间有效平衡，要么牺牲成功率，要么节省的算力有限。

针对该问题，本文提出**动作感知的动态剪枝（Action-aware Dynamic Pruning, ADP）**框架。其核心洞察是：视觉 token 的重要性不仅取决于与文本指令的语义相关性，还受当前动作动态的调控。ADP 将两项机制协同集成：

1. **文本驱动的预见性剪枝（Text-driven Anticipatory Pruning）**：利用大语言模型内部的文本-视觉交叉注意力权重，计算每个视觉 token 与任务指令的语义相关性分数，并据此在视觉 token 进入骨干网络前进行 Top-K 筛选，仅保留与任务最相关的视觉信息。
2. **动作感知的动态门控（Action-aware Dynamic Gating）**：基于滑动窗口内的末端执行器运动幅度（欧几里得位移 $\delta_i$ 相对历史均值 $\bar{\delta}_i$ 的大小），动态决定是否启用剪枝。粗粒度大位移阶段激活剪枝以抑制冗余 token，精细操作阶段关闭剪枝以保留完整视觉上下文。

**主要结果**：在 LIBERO 模拟基准上，VLA-ADP 在保留 50% 视觉 token 的条件下达到 96.3% 的平均成功率（基线 OpenVLA-OFT 为 98.6%），同时将 FLOPs 从 7.91T 降至 7.03T，实现 1.13 倍加速；在保留 30% token 时加速比可达 1.35 倍，成功率仍维持 94.4%。在真实 Jaco2 机器人平台的拾取、放置和擦拭任务中，ADP 的平均成功率较基线提升 2.5%（88.3% vs. 85.8%），推理延迟从 76.9ms 降低至 51.8ms，加速 1.49 倍。

**消融实验证实**：去除动作感知动态策略（w/o D）导致 Object 任务成功率从 98.0% 骤降至 88.0%，且加入周期性剪枝替代（w/o D+PS）会进一步恶化至 87.0%，验证了自适应门控的必要性。逆序剪枝实验进一步表明，保留语义高相关性 token（直接 30%）的成功率（94.4%）远优于保留低相关性 token（逆序 70%，仅 68.1%），说明文本驱动的语义对齐是 token 选择的主导因素，而不仅仅是保留数量的问题。

## 背景与动机

视觉-语言-动作（VLA）模型在机器人操作任务中展现出强大的感知-规划-执行能力，但其推理成本严重制约了在资源受限平台上的实时部署。以 OpenVLA-OFT 为代表的先进 VLA 架构采用并行 Transformer 骨干处理多模态输入，其中视觉 token 通常占据输入序列的大部分——例如每帧场景图像被切割为数百个 patch，与较短的文本和本体感受 token 共同送入大语言模型。这种密集的视觉表征导致单次前向推理的计算量高达 7.91 TFLOPs，成为延迟瓶颈。

直观地看，操作任务的视觉需求并非一成不变。如图 1 所示，在一个完整的操作片段中，末端执行器的粗粒度移动阶段（如将机械臂从休止位置移动到目标上方）背景区域高度冗余，此时大幅剪枝视觉 token 对任务成功率的影响很小；而在细粒度操作阶段（如抓取对齐或放置物件）则需要完整的视觉细节来保证动作精度。然而，现有视觉 token 压缩或剪枝方法，如 EfficientVLA、FastV 等，普遍采用静态保留策略，即依据单层文本-视觉注意力评分或注意力地图对所有时刻固定剪枝比例，无法区分上述两种截然不同的视觉需求。这种无视操作阶段的方法导致要么在细粒度阶段丢失关键信息而失败，要么在粗粒度阶段保留过多冗余 token 而错失性能增益。

此外，仅依赖文本指令的相关性评分也暴露了不足：同一视觉 token 在不同动作阶段的"任务攸关性"可能截然不同。例如，"杯子"在移动阶段的背景分词可能与操作无关，但在抓取阶段必须完整保留。因此，我们需要一种将**动作动态信息**引入剪枝决策的机制，使剪枝策略能感知机器人当前处于何种操作阶段。

本文的核心动机正是填补这一缺口：提出**动作感知的动态剪枝（Action-aware Dynamic Pruning, ADP）**，将文本驱动的视觉 token 重要性评分与基于末端执行器运动轨迹的动态门控相结合。该门控信号通过滑动窗口内的轨迹位移 $\delta_i$（公式 15）和自适应阈值函数 $f(\cdot)$（公式 16）实现，在大幅度运动阶段激活剪枝以抑制背景冗余，在精细操作阶段恢复全视觉以保证精度。这样，ADP 既避免了静态剪枝粗粒度阶段的无效信息驻留，又防止了细粒度阶段的灾难性信息丢失，在 LIBERO 基准上将 FLOPs 从 7.91 T 降至 7.03 T（1.13× 加速），同时保持 96.3% 的平均成功率（保留 50% token）。消融实验进一步证实，去除动作感知的动态策略会使 Object 任务成功率从 98.0% 降至 88.0%，验证了自适应门控的必要性（表 3）。该思路不仅为 VLA 模型的实时化提供了一种训练自由的轻量方案，也为多阶段操作中视觉 token 的动态分配提供了新的理论视角。

## 核心创新

现有视觉-语言-动作（VLA）模型在推理时对所有视觉 token 统一处理，但视觉冗余性随操作阶段急剧变化：粗粒度移动阶段背景 patch 携带大量无关信息，而抓取、对齐等精细操作又要求完整的视觉上下文。静态剪枝或周期剪枝无法适应这种相变，要么牺牲精度，要么计算节省有限。本文的关键发现是：**视觉 token 的重要性不仅取决于它与文本指令的语义对齐，还受到当前动作动态的强力调制**。末端执行器的运动幅度本身就是一个免费的监督信号——粗移动阶段动作幅度大、允许大幅压缩；精细操控阶段位移微小，必须保留全量视觉信息。

基于这一洞察，ADP 框架在两个方面**系统性地改变了基线 VLA 的 token 处理流程**：

**1. 从均等保留改成文本驱动的可预见剪枝（Text-driven Anticipatory Pruning）**  
基线方法（如 OpenVLA）将所有视觉 patch 不加区分地送入骨干网络，或者仅根据单层注意力图随机丢弃。ADP 则从 LLM 第 0 层（最浅层）预训练权重中提取**文本-视觉交叉注意力**，通过缩放点积计算文本查询与视觉键的相似度（公式 8），再对多头、所有文本 token 平均得到每个视觉 patch 的全局重要性分数 $\Phi(v)$（公式 9）。该分数直接度量了"该 patch 与任务指令的语义匹配程度"。随后，按照全局保留率 $\rho$ 进行 Top-K 选择（公式 10），只保留最关键的前 $k$ 个视觉 token；对于多视角输入（场景相机+腕部相机），则是按视角权重 $\alpha_c$ 分配配额（公式 11）。这一改造使剪枝不再是盲目的均匀丢弃，而是**指令感知的预拣选**，去除冗余背景的同时集中保留任务相关物体区域。

**2. 从静态/周期剪枝改成动作感知的动态门控（Action-aware Dynamic Gating）**  
基线采用的固定保留率或周期性剪枝完全无视操作阶段的变化。ADP 将剪枝决策绑定到末端执行器的实时运动上：在长度为 $w$ 的动作窗口内，计算相邻末端执行器位姿（6-DoF 位移+gripper 状态）的欧几里得距离之和 $\delta_i$（公式 15），作为运动幅度的度量。门控函数 $f(\delta_i)$（均值阈值或邻接极值规则，公式 16）将 $\delta_i$ 与历史均值对比：当 $\delta_i$ 超过历史均值（粗移动阶段），触发剪枝状态 $s_{i+1}=1$；否则禁用剪枝，使用全视觉。为防止误差连续累积，设计上限制连续剪枝窗口数不得超过 3，至多每 4 个窗口恢复一次全视觉。这一动态调度使计算节省与感知保真度在粗/细操作阶段之间自主切换，无需人工预设阶段边界。

上述两个 changed slots 协同构成了**瓶颈驱动的因果机制**：动作幅度 $\delta_i$ 决定"何时剪枝"，文本相关性分数 $\Phi(v)$ 决定"剪谁"，二者共同实现对 VLA 推理负载的阶段自适应压缩。

**决定性证据**：
- 在 LIBERO 基准上，保留 50% 视觉 token 时，VLA-ADP 的平均成功率仍达 96.3%，同时将 LLM FLOPs 从 7.91T 降至 7.03T，实现 1.13× 加速（Table 1）。保留率 30% 时，加速比进一步提升至 1.35×，成功率 94.4%（Table 5）。
- 消融实验表明，**移除动态策略（w/o D）直接导致 Object 任务成功率从 98.0% 跌落至 88.0%**，而替换为周期性剪枝（w/o D+PS）性能进一步恶化（Table 3a），证实动作感知门控的不可或缺。
- 逆序剪枝实验显示，直接保留高相关性 token（30% 保留）平均成功率 94.4%，而逆序保留低相关性 token（70% 保留）仅 68.1%（Table 4），证实文本驱动的排序准确捕获了任务关键 patch，语义对齐才是剪枝有效性的主导因素。

综上，ADP 的创新本质是将 **"动作-视觉"双向耦合**引入 token 筛选流程，用末端执行器轨迹驱动动态门控，用文本注意力引导 token 选择，从而在粗/细粒度阶段之间自适应平衡效率与精度。

## 整体框架

![[assets/figures/papers/iclr26_0006_ea6j8k8Rnw_Action-aware_Dynamic_Pruning_for_Efficient_Visio/figures/002_Figure_2.jpg]]

![[assets/figures/papers/iclr26_0006_ea6j8k8Rnw_Action-aware_Dynamic_Pruning_for_Efficient_Visio/figures/001_Figure_1.jpg]]

Action-aware Dynamic Pruning (ADP) 是一种面向 Vision-Language-Action (VLA) 模型的多模态推理加速框架，其核心思想是将 **文本指令驱动的视觉 token 重要性评分** 与 **末端执行器轨迹驱动的动态门控** 统一成一个自适应剪枝流水线，使得模型在保持操作成功率的前提下显著降低计算开销。图 2 给出了 ADP 的总体架构，主要由两个功能模块和一个多模态序列组装步骤构成：**文本驱动的预见性剪枝**、**动作感知动态门控**，以及剪枝后的多模态序列拼装与动作预测。

**文本驱动预见性剪枝。** 该模块 (图 2b) 在所有 LLM 层之前工作，利用预训练 VLA 模型中某层的交叉注意力权重来量化每个视觉 patch 与文本指令的语义相关程度。具体而言，对于第 $l$ 层的文本查询 $\mathbf{Q}^{(l)}$ 和视觉键 $\mathbf{K}^{(l)}$，计算缩放点积注意力矩阵 $\mathbf{A}^{(l)}=\mathbf{Q}^{(l)}(\mathbf{K}^{(l)})^\top/\sqrt{d}$，再通过对多头和全部文本 token 进行平均得到全局重要性分数 $\Phi^{(l)}(v)$（公式 9）。随后按照预设保留率 $\rho$ 执行 Top-K 选择，仅保留分数最高的 $k=\lfloor\rho\cdot L^{\mathrm{vis}}\rfloor$ 个视觉 token（公式 10）。对于多视图输入，则额外交付视图配额 $\alpha_c$ 进行预算分配（公式 11）。这一过程使与任务相关的物体区域始终保持完整，而大量背景冗余 token 被提前剔除。

**动作感知动态门控。** 仅靠静态剪枝无法应对操作过程中的相位变化：在粗粒度的长距离移动阶段，视觉冗余度高，剪枝可大幅降低计算量；但在精细的抓取、对准阶段，完整视觉上下文对于成功至关重要。动作感知门控模块 (图 2a) 通过分析滑动窗口内的末端执行器轨迹来解决这一矛盾。对于第 $i$ 个窗口，计算窗口内末端执行器位姿序列 $\mathbf{p}_t$ 的欧氏位移总和 $\delta_i=\sum_{t=b_i}^{e_i-1}\|\mathbf{p}_{t+1}-\mathbf{p}_t\|_2$（公式 15），然后根据门控函数 $s_{i+1}=f(\delta_i)$ 决定下一窗口是否激活剪枝。函数 $f(\cdot)$ 可以是基于历史均值的阈值规则（公式 16），也可采用对局部运动更敏感的相邻极值变体。当运动幅度大时，门控将状态置为 1（启用剪枝）；当运动放缓、即将进入精细操作时，门控置 0（恢复全视觉）。此外，为防止误差累积，连续启用剪枝的窗口数上限为 3，超过后强制使用全视觉。这种自适应门控使得 ADP 能够在"粗移动-细操作"各阶段间平滑切换计算策略。

**输入输出流。** 一次推理的完整流程如下：
1. 视觉编码器将场景图像和腕部图像映射为视觉 token 序列 $\mathbf{X}^{\mathrm{vis}}$，文本编码器生成文本 token $\mathbf{X}^{\mathrm{txt}}$。
2. 动作感知动态门控从缓冲区读取最近的动作窗口轨迹，计算出当前窗口的剪枝状态 $s$。
3. 若 $s=1$，则对 $\mathbf{X}^{\mathrm{vis}}$ 执行文本驱动预见性剪枝：从指定层取出交叉注意力权重，计算重要性分数 $\Phi$，保留 Top-K 视觉 token，得到剪枝后的 $\widetilde{\mathbf{X}}^{\mathrm{vis}}$；若 $s=0$，则保留全部视觉 token。
4. 将剪枝后的视觉 token 与文本 token、任务相关的属性 token（如本体感知信息）以及并行动作解码所需的动作占位 token 拼接成缩减后的多模态序列 $\widetilde{\mathbf{X}}^{m}$。
5. 该序列送入 LLM 主干，通过并行动作解码头一次性预测 7 维动作 token（机械臂位移、旋转和夹爪开合），输出动作 $\hat{\mathbf{a}}$。

该流水线中，文本驱动剪枝保证了在任何阶段保留的视觉 token 始终与任务指令语义对齐；动作感知门控则在运行时刻根据机器人运动动态切换剪枝与否，使得粗暴的静态剪枝方案转变为可适应不同操作密度的智能压缩。两者协同，既在 LIBERO 仿真基准上仅牺牲约 2.3% 的成功率即可将 FLOPs 降低 11% 并取得 1.13 倍加速（保留 50% 视觉 token），也在真实机器人平台上实现了同时提成功率和降延迟的效果（成功率由 85.8% 升至 88.3%，延迟降低 32.6%，1.49 倍加速），验证了该框架在实际部署中的有效性。

## 核心模块与公式推导

ADP（Action-aware Dynamic Pruning）在 VLA 模型中引入两个互补的剪枝机制：文本驱使的预见性剪枝与动作感知动态门控。前者依据任务指令筛选出语义相关的视觉 token，抑制背景冗余；后者利用末端执行器轨迹自适应地开关剪枝，在粗粒度运动阶段削减计算，在精细操作阶段恢复全视觉以保证感知精度。被保留的视觉 token 经多模态序列组装后送入 LLM 进行动作预测。

### 文本驱使的预见性剪枝

该模块在 LLM 各层利用文本到视觉的交叉注意力计算每个视觉 patch 的重要性，通过 Top-K 选择仅保留与任务最相关的 token。具体步骤：

1. **文本-视觉注意力相似度**（公式 (8)）：
   $$ \mathbf{A}^{(l)} = \frac{\mathbf{Q}^{(l)}(\mathbf{K}^{(l)})^\top}{\sqrt{d}} $$
   其中 $\mathbf{Q}^{(l)}$ 为第 $l$ 层的文本查询向量，$\mathbf{K}^{(l)}$ 为视觉键向量，$d$ 为缩放因子，输出 $\mathbf{A}^{(l)}$ 表示文本 token 对每个视觉 patch 的原始关注分值。

2. **全局重要性分数**（公式 (9)）：
   $$ \Phi^{(l)}(v) = \frac{1}{N^h \cdot L_{\mathrm{txt}}} \sum_{h=1}^{N^h} \sum_{t=1}^{L_{\mathrm{txt}}} \mathbf{A}^{(l)}_{h,t,v} $$
   对 $N^h$ 个注意力头与所有 $L_{\mathrm{txt}}$ 个文本 token 的注意力值取平均，得到每个视觉 token $v$ 的任务相关性得分 $\Phi^{(l)}(v)$。

3. **Top-K 保留与保留率 $\rho$**（公式 (10)）：
   $$ \mathbf{X}_{\mathrm{keep}} = \mathrm{Top-K}(\Phi^{(l)}, k), \quad k = \lfloor \rho \cdot L^{\mathrm{vis}} \rfloor $$
   按 $\Phi^{(l)}$ 从高到低保留前 $k$ 个视觉 token，$k$ 由全局保留率 $\rho$ 与总视觉 token 数 $L^{\mathrm{vis}}$ 决定。

4. **多视图配额分配**（公式 (11)）：对于多相机视角（如场景相机与腕部相机），总保留预算 $k$ 按视图权重 $\alpha_c$ 分配：
   $$ \mathbf{X}_{(c)}^{\mathrm{vis}} = \mathrm{Top-K}(\boldsymbol{\Phi}_{(c)}^{(l)}, k_c), \quad k_c = \lfloor \alpha_c \cdot k \rfloor $$
   其中 $c$ 表示视角，$\alpha_c$ 满足 $\sum_c \alpha_c = 1$。

实际采用**第 0 层**的注意力权重计算重要性分数，在准确性与计算开销之间取得最优平衡（消融实验表明深层评分不仅增加 FLOPs，且性能略有下降）。

### 动作感知动态门控

该模块根据末端执行器的运动幅度自适应开关剪枝，避免静态策略在精细阶段丢失必要视觉信息。

1. **窗口化轨迹距离**（公式 (15)）：
   $$ \delta_i = \sum_{t=b_i}^{e_i-1} \lVert \mathbf{p}_{t+1} - \mathbf{p}_t \rVert_2 $$
   其中 $[b_i, e_i]$ 为第 $i$ 个动作窗口的起止时间步，$\mathbf{p}_t$ 为末端执行器位姿向量，$\delta_i$ 反映窗口内末端执行器的欧氏位移总和，度量运动幅度。

2. **动态决策函数（均值阈值）**（公式 (16)）：
   $$ s_{i+1} = f(\delta_i) = \begin{cases} 1, & \delta_i \geq \bar{\delta}_i \\ 0, & \text{otherwise} \end{cases}, \quad \bar{\delta}_i = \frac{1}{i} \sum_{j=1}^{i} \delta_j $$
   若当前窗口位移 $\delta_i$ 达到或超过历史平均位移 $\bar{\delta}_i$，则下一窗口进入剪枝状态 ($s=1$)；反之使用全视觉 ($s=0$)。该方法使剪枝在高运动阶段自动激活，在精细阶段保持全部视觉 token。

   额外采用**相邻极值变体**，通过对比相邻窗口的轨迹极值实现更快的状态切换，以适应局部运动突变（论文未给出显式闭合公式，需参阅原文）。

3. **误差累积抑制**：为防止连续剪枝导致信息丢失，若剪枝状态连续出现三次，则强制下一窗口使用全视觉（$s=0$）。

### 剪枝后多模态序列组装

经过上述两个模块，保留的视觉 token 与其他模态序列拼接，形成缩减后的多模态输入 $\mathbf{X}^{m}$，送入 LLM 进行并行动作解码。该过程遵循 OpenVLA-OFT 的序列结构，仅视觉部分被压缩，文本、占位符等保持不变。

## 实验与分析

### 主实验结果

ADP的核心优势在于，它在维持高任务成功率的同时实现了可观的推理加速。在LIBERO四类任务基准上（Table 1），当全局视觉保留率ρ=0.5且使用第0层评分时，VLA-ADP的平均成功率达到96.3%，相较OpenVLA-OFT的98.6%仅下降2.3个百分点，但浮点计算量（FLOPs）从7.91T降至7.03T，实现了1.13×的推理加速。当保留率进一步缩减至0.3时，加速比提升至1.35×，而成功率仍保持在94.4%，说明文本驱动的剪枝能够有选择地抛弃真正冗余的背景信息，而非泛化地牺牲全部视觉细节。这一结果与理论上"粗粒度阶段可大幅压缩而细粒度阶段需保留完整视觉"的瓶颈判断一致：门控机制仅在末端执行器运动幅度大的阶段启用剪枝，从而维持了精细操作的成功率。

![[assets/figures/papers/iclr26_0006_ea6j8k8Rnw_Action-aware_Dynamic_Pruning_for_Efficient_Visio/figures/004_Table_1.jpg]]

在真实机器人平台Jaco2上的实验（Table 2）更具说服力：VLA-ADP不仅将平均推理延迟从76.9 ms降至51.8 ms（1.49×加速），成功率甚至还反超基线2.5个百分点（85.8%→88.3%）。这一反转可能源于剪枝去除了无关背景对多模态响应的干扰，验证了"视觉冗余的减少有利于任务聚焦"这一核心洞察。

![[assets/figures/papers/iclr26_0006_ea6j8k8Rnw_Action-aware_Dynamic_Pruning_for_Efficient_Visio/figures/006_Table_2.jpg]]

### 消融分析

#### 动作感知动态策略的必要性

Table 3(a)的消融实验直接验证了动作感知门控的关键作用。去除动态策略（w/o D）后，Object任务成功率从98.0%骤降至88.0%，Spatial任务也出现类似下降；进一步引入周期性剪枝（w/o D+PS）则使性能进一步降至87.0%。这表明仅靠静态或周期性剪枝无法适应粗/细操作阶段的切换需求，在需要细粒度视觉反馈的抓取、对齐等环节，强制剪枝会导致关键视觉线索丢失，而自适应门控（公式16及其邻接极值变体）能够根据窗口内末端执行器位移δ_i（公式15）动态关闭剪枝，从根本上规避了此类失败模式。

![[assets/figures/papers/iclr26_0006_ea6j8k8Rnw_Action-aware_Dynamic_Pruning_for_Efficient_Visio/figures/008_Table_3.jpg]]

#### 评分层的选择

Table 3(b)对比了从不同transformer层提取文本-视觉注意力来评分的效果。第0层（嵌入后第一层）在各项任务上均取得最优平衡：更高层（第1、4层）虽然理论上可捕获更深层语义，却引入了额外的计算开销，且成功率未必提升。这与Figure 6、Figure 7的层间统计一致——浅层注意力已能产生高度集中的token重要性分布（参与比PR和熵H均随深度快速下降），表明任务相关信号早期就已浮现，无需深层重计算。

#### 逆序实验：文本驱动评分的有效性

Table 4的逆序实验以一种强因果方式证实了文本-视觉相关性评分的有效性。当按直接顺序保留相关性最高的30% token时，平均成功率为94.4%；如果反转排序，保留相关性最低的70% token，成功率暴跌至68.1%。这种"少即是多"的结果说明：决定任务成败的是token的内容相关性而非数量，ADP的预见性剪枝所依赖的语义信号是稳定且具有判别力的，而非随机或噪声驱动的注意力模式。

![[assets/figures/papers/iclr26_0006_ea6j8k8Rnw_Action-aware_Dynamic_Pruning_for_Efficient_Visio/figures/015_Table_4.jpg]]

### 关键失败模式与局限

ADP在长程组合指令任务中出现显著性能下降。以LIBERO Long套件中涉及精确空间关系的任务为例（Table 13），"将白杯子放在盘子上并将巧克力布丁放在盘子右边"这类需连续转换注意力目标的任务中，ADP成功率相较基线下降达18个百分点。根本原因在于当前VLA骨干缺乏子目标完成的显式感知：当保留率受限时，早期子任务（如"抓取杯子"）结束后，其相关视觉token仍占据配额，挤压了后续子任务的视觉覆盖，导致失败。这一瓶颈指向了方法的当前边界——仅依据静态指令和末端轨迹的门控无法处理视觉焦点需多次转移的多阶段场景。

### 重要图表结论

Figure 4的可视化结果直接呈现了ADP的剪枝行为：在移动阶段，蓝色遮罩覆盖了大量背景patch，而高亮保留的token集中在任务相关物体（如碗、抽屉）周围；进入抓取或放置等关键阶段时，系统自动恢复全视觉，与门控逻辑完全吻合。这从定性角度证实了文本驱动的剪枝能够识别出语义关键区域，且动态策略确实在精细阶段起到了保护作用。

Figure 9提供了一个"基线失败而ADP成功"的定性对比案例：在需要从柜子中取物的Spatial任务中，基线因背景干扰而失败，ADP通过剪除背景token使模型聚焦于操作区域，从而成功完成任务。这一案例与定量结果相互印证，揭示了冗余视觉输入可能对VLA形成"注意力分散"的不良影响，而针对性剪枝则转化为一种精度增益。

## 方法谱系与知识库定位

ADP 在高效 VLA 推理方法谱系中位于**训练自由的视觉 token 剪枝**路径，其核心创新在于将剪枝决策从单一的语义相关性扩展为"语义相关性 × 动作阶段"的联合控制。与现有工作相比，FastV 和 EfficientVLA 使用基于注意力地图的静态 token 压缩或剪枝，FlashVLA 和 VLA-Cache 通过键值缓存重用加速推理，DeeR-VLA 和 Mole-VLA 分别采用动态重参数化、结构剪枝和选择性层激活的训练感知方案，RoboMamba 则从轻量化架构设计入手。这些方法均未显式考虑操作任务中剪枝需求随动作阶段动态变化的特性——粗粒度移动阶段容忍大量背景 token 丢弃，而细粒度抓取/对齐阶段要求完整视觉上下文。ADP 首次将末端执行器轨迹的动态幅度作为剪枝的门控信号，使剪枝策略在粗/细阶段之间自适应切换，填补了这一空白。

从因果机制看，核心调节变量是滑动窗口内的末端执行器欧几里得位移总和 δ_i（公式 15）。当 δ_i ≥ 历史均值 ̄δ_i 时，门控函数 f(·) 激活剪枝状态（s=1），抑制冗余视觉输入；当 δ_i 低于阈值时，切换回全视觉状态（s=0），保留精细操作所需的完整感知。这一规则的因果有效性由 Table 3 的消融实验直接证实：去除动态策略（w/o D）后，Object 任务成功率从 98.0% 跌至 88.0%，而引入周期性剪枝（w/o D+PS）更降至 87.0%，说明自适应门控而非简单的稀疏采样是关键性能保证。此外，为遏制连续剪枝的误差累积，ADP 限制连续剪枝窗口数至多 3 个，超过则强制恢复全视觉。

在 token 选择层面，文本驱动的预见性剪枝通过交叉注意力计算文本到视觉 token 的重要性分数 Φ^(l)(v)（公式 8-9），并按保留率 ρ 进行 Top-K 筛选（公式 10）。逆序实验（Table 4）提供强因果证据：直接保留 30% 高相关性 token 的平均成功率达 94.4%，而逆序保留 70% 低相关性 token 降至 68.1%——差距逾 26 个百分点。这确认了文本-视觉语义对齐是剪枝后性能的主导因素，而非保留 token 的绝对数量。

**适用边界与局限性。** ADP 在 LIBERO 四类仿真任务（Spatial/Object/Goal/Long）和 Jaco2 真实平台的四类操作任务（拾取、放置、擦拭）上得到验证。仿真端保留 50% 视觉 token 时平均成功率 96.3%（vs. OpenVLA-OFT 的 98.6%），FLOPs 从 7.91T 降至 7.03T（Table 1）；真实端成功率 88.3% 甚至超出基线 2.5%，延迟降至 51.8 ms（1.49× 加速，Table 2）。这一"加速且精度反超"现象提示，去除冗余背景 token 在真实环境中可能产生正则化效果，减少无关干扰对动作预测的噪声。

然而，ADP 在**长程组合任务**中存在系统性的 token 误分配问题。由于 VLA 模型缺乏子目标完成的显式感知模块，当早期子任务完成后，其相关视觉 token 仍被文本驱动评分保持高位，在总 token 预算受限时挤压后续阶段的视觉覆盖。这在"将白杯子放在盘子上并将巧克力布丁放在盘子右边"一类任务中表现为成功率较基线下降 18%（Table 13）。当前仅基于静态指令和当前多模态上下文的 scoring 机制，未能追踪任务进展并重分配视觉注意力。

**开放问题。** 上述局限性指向若干待研究方向：(1) 如何为 VLA 嵌入显式的子目标估计模块或动态视觉注意力重分配机制，使 token 保留随任务进度自适应迁移？(2) 除末端执行器轨迹外，力/触觉反馈（如夹爪闭合力）是否能提供更细粒度的操作阶段判别信号，进一步精炼门控规则？(3) ADP 作为训练自由剪枝框架，能否与模型量化或 DeeR-VLA 式的结构剪枝形成互补，在保持成功率的前提下进一步降低内存占用和单步延迟？(4) 当前保留率 ρ 为固定超参数——在多阶段操作任务中，能否学习一个任务或阶段相关的自适应保留率，替代人工预设？这些问题构成了高效 VLA 推理从"感知冗余消除"走向"任务结构感知计算分配"的关键路径。
