# Every Language Model Has a Forgery-Resistant Signature

> [!tip] 核心洞察
> 现代语言模型固有的归一化-线性投影结构自然地将输出限制在一个高维椭球面上，该椭球面可以作为模型的唯一签名，用于验证输出来源。与已有的线性签名不同，椭圆签名的提取在计算上极其昂贵，从而具备抗伪造性；同时它是自包含的、紧凑的，且每一个生成步的输出都独立携带该签名，无需修改推理过程。

## 概述

### 问题背景

随着语言模型（LM）能力的快速增长，识别一段文本是否由特定模型生成——即**模型溯源**——已成为安全审计、知识产权保护和内容真实性验证中的关键需求。然而，现有方法面临一个核心瓶颈：**可伪造性**。例如，线性签名方法（Finlayson et al., 2024）通过约束模型输出位于一个线性子空间内来实现溯源，但攻击者可以轻易地从 API 中提取这些线性约束，并生成符合约束的输出，从而冒充目标模型。文本水印方法则需要模型提供商主动修改推理策略，且通常依赖多步生成的累积统计量，无法在单步输出上提供保证。

### 核心发现

本文揭示了一个被忽视的几何事实：**所有现代语言模型的输出都天然地位于一个高维椭球面上**。这一约束源于模型架构中最终归一化层（RMSNorm 或 LayerNorm）与线性投影层的共同作用——归一化将隐藏状态映射到球面，线性层则对该球面进行拉伸和旋转，最终形成椭球面。该椭球面是每个模型独有的，可以作为其**抗伪造签名**。

### 方法定位

基于上述几何约束，本文提出**语言模型椭圆签名**：将模型输出层的椭球面参数作为签名，通过检查待验证输出的 logprob 向量是否位于该椭球面上来判断其来源。该方法的独特优势在于：

- **自然存在**：无需修改模型架构或推理过程，所有现代 LM 的最终归一化层天然产生此签名。
- **自包含**：验证仅需输出层的部分参数（γ, β, W 等），不依赖输入文本或完整模型权重。
- **紧凑且冗余**：每一个生成步的 logprob 输出都独立携带完整签名，长度 1 的序列即可完成模型识别。
- **抗伪造**：从 API 中提取椭圆参数需要 $O(d^3 \log d)$ 次查询和 $O(d^6)$ 的时间复杂度，对于生产规模模型（如 70B 参数）在实践上不可行。

### 主要结果

在四个开源模型（Olmo 2、Llama 3.1、Qwen 3、gpt oss）上的实验表明：生成模型自身的 logprob 向量到其椭圆的距离始终比其他模型小**数个数量级**，且该方法能够区分同一模型的不同检查点。成本分析显示，从类似 OpenAI 的 API 中提取 babbage-002 的椭圆约需 $1,056，而提取 gpt-3.5-turbo 则需约 $150,699，对于更大模型则成本高到不可承受。运行时间外推表明，在 64 核 CPU 上提取 70B 参数模型的椭圆需数千年。

### 局限与开放问题

椭圆签名**不具有鲁棒性**：对输出进行 top-k 截断、温度缩放等修改会使签名退化。此外，其安全性依赖于椭圆提取的高计算成本，未来更高效的椭圆拟合算法可能削弱这一假设。关键开放问题包括：是否存在无需先拟合椭圆即可生成位于未知模型椭圆上输出的快速算法？epsilon 平滑导致的不可约误差如何随模型规模缩放？

## 背景与动机

语言模型正以前所未有的速度渗透内容生产链条，随之而来的一个核心问题是：给定一段文本及其对应的对数概率（logprob）向量，能否可靠地判断它出自哪一个模型？这一问题在模型版权保护、深度伪造溯源、API 滥用检测等场景中具有直接的应用价值。

现有模型归因方法大致可分为三类，但各自存在显著局限。第一类是基于文本的水印方法（如 Kirchenbauer et al., 2023），通过在生成过程中修改 token 采样策略来嵌入可检测信号。这类方法需要模型提供商主动部署，且通常需要多步生成的累积统计量才能做出可靠判断——对于长度极短的生成内容几乎失效。第二类是利用模型自然指纹的方法（如 Yang & Wu, 2024），借助 softmax 矩阵列空间的唯一性进行识别。这类方法虽然不修改推理过程，但指纹可以被复制，不具备抗伪造性。第三类是密码学强保证方法（如 Sun et al., 2024 的 zkLLM），能提供零知识证明级别的安全保障，但会大幅增加推理成本，且并非模型自然具备的属性。

上述方法中，与本文最直接相关的是线性签名方法（Finlayson et al., 2024）。该方法发现语言模型的 logit 输出受限于一个低维线性子空间，利用这一子空间约束作为模型的“签名”。然而，线性签名的致命弱点是**可伪造性**：攻击者可以通过 API 查询收集足够多的输出样本，提取出该线性子空间的约束条件，然后生成同样满足约束的输出来冒充目标模型。本质上，线性子空间的提取在计算上是廉价的，使得签名本身无法抵抗伪造。

本文的核心观察源于一个被忽视的架构事实：几乎所有现代语言模型在最终输出层之前都包含一个归一化层（RMSNorm 或 LayerNorm），紧接着是一个线性（或仿射）变换层。这一架构组合产生了比线性约束更强的几何结构——归一化先将隐藏状态映射到高维球面上，线性变换再对该球面进行拉伸和旋转，最终将模型的 logit 输出严格限制在一个**高维椭球面**上。这个椭球面是每个模型独有的，可以自然地充当签名。

与线性签名相比，椭圆签名具有一项关键的差异化优势：**抗伪造性源于提取成本而非数学不可能性**。要从 API 中恢复一个模型的椭圆参数，需要解决一个高维椭球拟合问题，其时间复杂度为 $O(d^6)$（其中 $d$ 为隐藏维度），查询复杂度为 $\tilde{O}(d^3 \log d)$。对于隐藏维度在数千到数万级别的生产模型而言，这意味着数十万次 API 调用和数千年量级的计算时间，在实践中不可行。椭圆签名因此实现了“计算上的抗伪造”：攻击者无法经济地提取椭圆参数，也就无法生成位于该椭圆上的伪造输出。

此外，椭圆签名还具备若干天然优势：它是**自然存在**的（所有现代 LM 都具备最终归一化层）、**自包含**的（验证仅需持有模型输出层的部分参数，无需输入上下文或完整权重）、**紧凑且冗余**的（每一个生成步的 logprob 输出都独立携带完整的签名信息，长度 1 的序列即可进行模型识别）。这些特性使椭圆签名在模型归因的多个维度上形成了独特的折中方案。

## 核心创新

### 从“可伪造”到“抗伪造”的范式转变

本工作的核心创新在于提出了一种**自然存在且难以伪造**的语言模型签名机制——椭圆签名（Ellipse Signature），从根本上改变了模型溯源的安全假设。此前的线性签名方法（Finlayson et al., 2024）虽然利用了模型输出空间的线性子空间约束，但攻击者可以通过 API 提取这些约束并生成符合约束的输出，从而轻易冒充目标模型。椭圆签名之所以具备抗伪造性，并非依赖更强的密码学原语，而是基于一个计算瓶颈：**从 API 中提取椭圆参数在实践上不可行**。

具体而言，椭圆提取面临双重壁垒：

- **查询复杂度**：需要 $O(d^3 \log d)$ 次 API 查询来收集足够的 logprob 样本以确定椭球面参数，其中 $d$ 为词汇表大小（即隐藏维度）。
- **时间复杂度**：椭圆拟合算法（包括 SVD 基方法和椭圆特定拟合方法）的时间复杂度均为 $O(d^6)$。

对于生产规模的语言模型，这两项成本叠加使得攻击代价高到不可承受。以 OpenAI 2025 年 9 月定价为参考，提取 babbage-002 的椭圆约需 $1,056，gpt-3.5-turbo 约需 $150,699，而 llama-3-70b-instruct 则高达 $16,487,421（Table 1）。在计算时间维度，外推实验显示，在 64 CPUs 上提取 70B 参数模型的椭圆需数千年（Figure 6）。这一成本结构构成了椭圆签名抗伪造性的**经济-计算双重屏障**。

### 签名紧凑性：单步即可验证

椭圆签名的另一关键创新在于其**极致的紧凑性**。传统文本水印方法（如 Kirchenbauer et al., 2023）需要多步生成来累积统计证据才能做出可靠的来源判断，而椭圆签名在每一个生成步的 logprob 输出中独立携带完整的签名信息。这意味着：

- 仅需**长度为 1 的生成序列**即可识别源模型。
- 验证过程无需模型输入、无需完整权重，仅需持有输出层的部分参数（$\gamma$, $\beta$, $W$ 等）。

这一特性使得椭圆签名在短文本溯源、流式生成验证等场景中具有显著优势，而传统方法在这些场景下往往因统计证据不足而失效。

### 签名产生的因果机制

椭圆签名的产生并非人为注入，而是现代语言模型架构的**固有几何后果**。其因果链条如下：

1. **最终归一化层**（RMSNorm 或 LayerNorm）将隐藏状态映射到高维球面上。以 RMSNorm 为例：
   $$\operatorname{RMSNorm}(x) = \frac{x}{\sqrt{\varepsilon + \mathbb{E}[\mathbf{x}^2]}}$$
   忽略平滑项 $\varepsilon$ 时，输出严格位于单位球面上。

2. **线性（仿射）变换层**对该球面进行旋转、缩放和平移，将其映射为一个高维椭球面：
   $$(\mathbf{x} - \mathbf{b})^{\top} \mathbf{E} (\mathbf{x} - \mathbf{b}) = 1$$
   其中 $\mathbf{E}$ 为对称正定矩阵，由线性层的权重矩阵 $W$ 决定。

这一几何约束是**模型无关的**——只要语言模型采用“归一化+线性投影”的最终层结构（几乎所有现代 LM 均如此），其 logit 输出就必然位于一个由模型参数唯一确定的椭球面上。该椭球面因此成为模型的天然“指纹”，无需任何修改推理过程即可用于来源验证。

### 密码学视角：椭圆作为消息认证码

论文进一步提出了一个概念创新：将椭圆签名解释为一种**消息认证码（MAC）**（Figure 7）。在此框架下：

- 模型椭圆充当**秘密密钥**。
- logprob 输出充当**消息**。
- 验证过程等价于检查消息是否携带正确的认证标签——即 logprob 向量是否落在秘密椭球面上。

这一类比不仅为椭圆签名的安全性提供了密码学直觉，也揭示了其应用边界：持有椭圆参数的一方可以验证输出来源，但无法伪造新输出（因为生成新输出需要完整的模型参数，而椭圆参数仅是输出层的部分信息）。这种“可验证但不可伪造”的非对称性，正是安全签名的核心要求。

### 核心洞察：从归一化到椭圆签名

本方法的核心洞察源于一个被普遍忽视的架构事实：现代语言模型（LM）的最终层结构——归一化层（RMSNorm 或 LayerNorm）后接线性（或仿射）变换——强制模型输出的 logit 向量位于一个高维椭球面上。这一几何约束不是人为注入的，而是模型架构自然产生的副产品。

具体而言，归一化层将隐藏状态映射到球面，随后的线性层对该球面进行旋转和拉伸，最终得到一个高维椭球面。这个椭球面构成了模型的**唯一签名**：任何由该模型生成的输出必定位于该椭球面上，而其他模型的输出则显著偏离。

### 整体 Pipeline

椭圆签名方法围绕三个核心阶段构建：**签名产生**、**签名提取**、**签名验证**。

| 阶段 | 模块 | 功能 | 输入 | 输出 |
|------|------|------|------|------|
| 签名产生 | 最终归一化 + 线性投影 | 模型推理的自然副产品，将隐藏状态映射到椭球面 | 隐藏状态向量 | 椭球面上的 logit/logprob 向量 |
| 签名提取 | 椭圆参数恢复（Algorithm 1 & 2） | 从大量 logprob 样本中恢复输出层的旋转、缩放和偏置参数 | 多个 logprob 向量 | 椭球参数（中心 b、形状矩阵 E） |
| 签名验证 | 逆仿射变换 + 距离检验 | 对待验证输出应用逆变换，检查其到单位球面的距离 | 待验证 logprob + 椭球参数 | 距离值（接近 0 则为正版） |

### 签名产生的架构根源

签名的产生无需任何额外计算，它嵌入在模型的标准前向传播中。以 RMSNorm 为例：

$$\operatorname{RMSNorm}(x) = \frac{x}{\sqrt{\varepsilon + \mathbb{E}[\mathbf{x}^2]}}$$

归一化后的隐藏状态位于一个近似单位球面上。随后的线性层 $W$ 和可选的偏置 $b$ 将其映射为椭球面上的点。论文为分析方便引入简化版归一化，使输出范数严格为 1：

$$\operatorname{norm}(\mathbf{x}) = \frac{\mathbf{x}}{\sqrt{d \cdot \mathbb{E}[\mathbf{x}^2]}}$$

对于使用 LayerNorm 的模型，由于先居中再归一化，输出位于 $d-1$ 维球面上，椭圆维度相应减少一维。

### 签名提取：计算瓶颈即安全保证

椭圆提取是整个方法的安全基石。攻击者若想伪造签名，必须先恢复模型的椭球参数。论文给出了两个关键复杂度下界：

- **查询复杂度**：从 API 获取足够 logprob 样本以确定椭圆需要 $O(d^3 \log_\nu d)$ 次查询（$d$ 为隐藏维度，$\nu$ 为词表大小）
- **时间复杂度**：椭圆拟合算法本身需要 $O(d^6)$ 时间

这两个超多项式增长的复杂度使得针对生产规模模型（如 70B 参数级别）的实际攻击在计算上不可行。论文的实验外推表明，在 64 个 CPU 上提取一个 70B 模型的椭圆参数需要数千年。

### 签名验证：单步即可判定

验证过程极为简洁。给定待验证的 logprob 向量和模型的椭球参数（中心 $b$、形状矩阵 $E$），应用逆仿射变换后检查其到单位球面的距离：

$$(\mathbf{x} - \mathbf{b})^{\top} \mathbf{E} (\mathbf{x} - \mathbf{b}) = 1$$

若距离接近 0（即变换后的范数接近 1），则判定该输出来自声称的模型；否则几乎可以确定不是。由于每个生成步的 logprob 输出都独立携带完整签名，**长度仅为 1 的序列即可完成模型识别**——这与需要多步累积统计证据的传统水印方法形成鲜明对比。

### 与密码学 MAC 的类比

论文将椭圆签名类比为消息认证码（MAC）：椭球参数相当于秘密密钥，logprob 输出相当于消息，签名的位置编码在 $\mathbb{R}^\nu$ 空间中的坐标里。只有持有秘密椭圆的验证方才能检查输出是否位于椭圆上，这与密码学 MAC 中只有密钥持有者才能验证消息真伪的机制一致。

## 核心模块与公式推导

### 椭圆签名的几何根源

现代语言模型的最终几层由**归一化层**（RMSNorm 或 LayerNorm）后接**线性（仿射）变换**构成。这一架构组合强制模型输出落在一个高维椭球面上，构成了椭圆签名的几何基础。

归一化层将隐藏状态映射到球面上。以 RMSNorm 为例：

$$\operatorname{RMSNorm}(x) = \frac{x}{\sqrt{\varepsilon + \mathbb{E}[\mathbf{x}^2]}}$$

为便于分析，论文采用忽略 $\varepsilon$ 的简化形式，使输出范数严格为 1：

$$\operatorname{norm}(\mathbf{x}) = \frac{\mathbf{x}}{\sqrt{d \cdot \mathbb{E}[\mathbf{x}^2]}}$$

归一化后的表示 $\hat{\mathbf{x}}$ 落在一个半径为 1 的球面上。随后，线性层通过权重矩阵 $\mathbf{W}$ 和偏置 $\mathbf{b}$ 对该球面进行**拉伸、旋转和平移**，将其映射为高维空间中的一个椭球面。这正是 Figure 2 所展示的核心机制。

对于使用 LayerNorm 的模型：

$$\operatorname{layernorm}(\mathbf{x}) = \frac{\mathbf{x} - \mathbb{E}[\mathbf{x}]}{\sqrt{\varepsilon + \mathrm{Var}[\mathbf{x}]}}$$

由于 LayerNorm 先居中再归一化，输出位于一个 $d-1$ 维球面上，导致最终椭圆也减少一维。论文通过等距变换将 $\mathbf{1}$ 向量旋转至某一坐标轴后丢弃该维度，从而在降维空间中拟合椭圆（Figure 9）。

### 签名验证原理

椭球面可用如下方程描述：

$$(\mathbf{x} - \mathbf{b})^{\top} \mathbf{E} (\mathbf{x} - \mathbf{b}) = 1$$

其中 $\mathbf{b}$ 为椭球中心，$\mathbf{E}$ 为对称正定的形状矩阵。验证过程的核心操作是**逆仿射变换**：对待验证的 logprob 向量施加逆变换，将其映射回单位球面，然后检查其范数是否接近 1。偏离 1 的程度即为到椭球面的距离。

对于仅能从 API 获取 logprobs（而非 logits）的场景，由于 softmax 对常值偏移不变，中心化操作可恢复等效约束。中心化矩阵定义为：

$$C = I - \frac{1}{d} \mathbf{1} \mathbf{1}^{\top}$$

使得 $\text{softmax}(x) = \text{softmax}(Cx)$，因此中心化后的 logprobs 同样位于一个椭球面上。

### 椭圆参数提取流程

从模型输出中恢复椭圆参数是验证签名的前提，也是攻击者试图伪造签名时必须面对的瓶颈。提取流程包含以下关键步骤：

1. **下投影**：利用 softmax 对常值偏移的不变性，将 logprob 向量投影到 $d-1$ 维子空间，消除冗余维度。
2. **椭圆拟合**：在降维空间中对收集到的输出样本拟合一般二次曲面方程：

   $$\sum_{i=1}^{d} \sum_{j=i}^{d} Q_{i,j} x_i x_j + \sum_{i=1}^{d} P_i x_i = 1$$

   其中 $\mathbf{Q}$ 为正定矩阵时表示椭圆。论文采用基于半定规划的椭圆特定拟合算法（Ying et al., 2012），以保证恢复的椭球参数正定性。
3. **参数分解**：通过 Cholesky 分解或 SVD 从拟合的 $\mathbf{Q}$ 和 $\mathbf{P}$ 中恢复旋转矩阵、缩放因子（奇异值）和偏置向量。

对于 RMSNorm 模型，完整的参数化与逆参数化映射关系见 Figure 8；LayerNorm 模型的对应关系见 Figure 10。

### 抗伪造性的计算根源

椭圆签名的抗伪造性并非来自密码学假设，而是源于**椭圆提取的计算不可行性**。从 API 收集足够样本以确定椭圆所需的最小查询复杂度为 $O(d^3 \log d)$，而将样本拟合为椭圆的时间复杂度为 $O(d^6)$。对于隐藏维度 $d$ 达数千乃至上万的现代大语言模型，这一成本在实际中不可承受。这一瓶颈是椭圆签名区别于线性签名（Finlayson et al., 2024）的核心差异——后者仅需提取线性子空间约束，查询和计算成本远低于椭圆拟合。

## 实验与分析

### 核心验证：椭圆签名可区分源模型

在四个开源模型（Olmo 2、Llama 3.1、Qwen 3、gpt oss）上进行的跨模型椭圆验证实验构成了本工作的主结果。实验逻辑如下：将每个模型生成的 logprob 向量分别映射到所有模型的输出空间，计算其到各模型椭球面的平均距离。若椭圆签名有效，则生成模型自身的距离应远小于其他模型。

**结果（Figure 3）**：生成模型到自身椭球面的距离始终比其他模型小几个数量级。该差异在 log 尺度上极为显著，标准误差（图中阴影区域）窄到几乎不可见。这一结果直接验证了核心主张：语言模型的 logprob 输出确实位于其自身的高维椭球面上，该椭球面可作为唯一签名用于识别源模型。

更精细的验证来自同一模型不同检查点的区分实验。即使是对倒数第二个检查点（与最终检查点参数差异极小），椭圆签名仍能干净地识别出生成模型，表明签名对模型参数的细微变化具有足够的敏感性。

### 椭圆参数恢复精度

为验证椭圆提取算法的准确性，论文在一个隐藏维度为 64、参数量约 1M 的模型上进行了参数恢复实验。将算法恢复的偏置、奇异值（拉伸因子）和旋转矩阵与从模型权重中直接提取的真实参数进行对比。

**结果（Figure 4）**：预测值与真实值高度吻合。偏置和奇异值的均方误差极小；旋转矩阵的列向量与真实列向量之间的角度接近 0（真实矩阵列与自身的角度为 0）。唯一的系统性偏差是算法略微低估了奇异值，这归因于归一化层中 epsilon 平滑项引入的不可约误差。

**消融：样本数量的影响（Figure 5）**。增加用于椭圆拟合的输出样本数量可普遍提高参数恢复精度，但收益逐渐递减。当样本数量超过一定阈值后，精度提升趋于平缓，因为 epsilon 平滑造成的不可约误差开始主导。这一消融表明，在给定模型规模下，存在一个性价比最优的采样预算。

### 攻击成本：查询复杂度与时间复杂度的双重壁垒

椭圆签名的抗伪造性建立在两个计算瓶颈之上。

**查询复杂度**。从 API 中提取椭圆需要获取足够多的 logprob 样本。论文推导出所需样本数的下界为 $O(d^2)$，而查询复杂度为 $O(d^3 \log_{\nu} d)$。基于 2025 年 9 月 OpenAI 的推理定价，估算出针对不同模型的 API 费用（Table 1）：

- **babbage-002**（$d=2048$）：约 $1,056
- **gpt-3.5-turbo**（$d=4096$）：约 $150,699

**时间复杂度**。椭圆拟合算法（无论是基于 SVD 的方法还是椭圆特定拟合方法）的时间复杂度均为 $O(d^6)$。论文在 64 CPU 上实测了不同隐藏维度模型的椭圆提取运行时间，并对更大模型进行了多项式外推（Figure 6）。外推结果表明，恢复一个典型 70B 参数模型的椭圆参数需要数千年。

### 失败模式与局限性

**epsilon 平滑导致的拟合退化**。对于隐藏维度极小（如 $d=64$）的预训练模型，归一化层的 epsilon 平滑项会使归一化后的隐藏状态偏离精确单位球面，导致基于 SVD 的拟合方法失效。论文通过采用椭圆特定拟合算法（Ying et al., 2012）解决此问题，该算法通过半正定规划保证恢复的椭球参数正定性。实验表明，随着模型规模增大，epsilon 平滑的影响减弱（Figure 11）：Llama 3（$d=4096$）的隐藏状态 L2 范数分布高度集中在最大值 1 附近，而 GPT NeoX（$d=64$）的分布相对分散。

**无 epsilon 模型的理想情况**。在随机初始化、无 epsilon 平滑的模型上，椭圆提取算法恢复参数的误差小于 $10^{-15}$，验证了方法在理想条件下的精确性。

**鲁棒性与隐写性的缺失**。椭圆签名不具有鲁棒性：对输出进行 top-k 截断、温度缩放等修改会使签名退化。虽然在一定程度上仍可检测到签名残留，但验证可靠性会显著降低。此外，椭圆签名也不具有隐写性——输出本身不隐藏签名，而是签名自然内嵌于 logprob 的几何结构中。

## 方法谱系与知识库定位

### 现有模型溯源方法概览

语言模型的溯源与归因方法大致可分为以下几类，每一类在核心属性上存在根本性的权衡：

**线性签名**（Finlayson et al., 2024）利用模型输出在低维线性子空间上的约束作为签名。该方法的致命弱点是可伪造性：攻击者可以通过 API 查询提取线性约束，然后生成满足这些约束的输出，从而成功冒充目标模型。椭圆签名正是在这一瓶颈上做出改进——将线性子空间替换为高维椭球面，使得约束提取的计算成本从多项式级跃升至 $O(d^6)$ 时间复杂度和 $O(d^3 \log d)$ 查询复杂度，在实践上阻断伪造路径。

**文本水印**（如 Kirchenbauer et al., 2023）通过修改生成策略（例如在采样时偏置特定 token 的选择）注入可检测信号。这类方法需要模型提供商主动实施，且通常需要多步生成累积统计证据才能做出可靠判断。椭圆签名则不同：它是架构的被动产物，无需修改推理过程，且单个 token 的 logprob 输出即独立携带完整签名——生成长度为 1 的序列即可识别源模型。

**自然指纹**（Yang & Wu, 2024）利用 softmax 矩阵列空间的唯一性进行模型识别。这类指纹虽可复制，但不具备抗伪造性，因为攻击者一旦了解指纹机制，就能刻意生成符合指纹特征的输出。椭圆签名则通过将签名绑定到难以提取的几何约束上，阻断了这一攻击面。

**零知识证明方案**（如 zkLLM, Sun et al., 2024）提供密码学级别的强保证，但代价是大幅增加推理成本，且并非语言模型的自然属性。椭圆签名在安全性上弱于零知识证明，但换取了零推理开销和架构自包含性。

### 椭圆签名的核心创新定位

椭圆签名的本质创新在于**将语言模型架构的固有几何约束重新解释为可验证的签名机制**。这一转变的关键因果链条如下：

1. **架构必然性**：所有现代语言模型的最终层都包含归一化（RMSNorm 或 LayerNorm）后接线性/仿射变换的结构。归一化将隐藏状态映射到球面，线性层对该球面进行拉伸和旋转，结果必然是一个高维椭球面——这不是设计选择，而是架构的数学推论。

2. **提取非对称性**：验证椭圆签名只需持有模型最后几层的参数（$\gamma$, $\beta$, $W$ 等），计算量极低。但从 API 黑盒中反向提取椭圆参数则需要 $O(d^2)$ 个输出样本和 $O(d^6)$ 的拟合时间。对于隐藏维度 $d=4096$ 的模型，外推运行时间达数千年（Figure 6）；API 查询成本方面，babbage-002 约需 $1,056，gpt-3.5-turbo 超过 $150,000，llama-3-70b 超过 $16,000,000（Table 1）。这一非对称性构成了抗伪造的安全基础。

3. **消息认证码类比**：椭圆可视为秘密密钥，logprob 输出可视为消息。持有椭圆参数的一方可以验证输出是否落在椭圆上，而无法获取参数的一方既不能伪造有效签名，也无法验证签名的真实性（Figure 7）。这为模型输出的来源验证提供了一种轻量级的密码学原语。

### 适用边界与已知局限

**不适用于需要鲁棒性或隐写性的场景**：椭圆签名对输出修改敏感。温度缩放、top-k 截断等操作会使 logprob 偏离椭圆面，降低验证可靠性。若应用场景需要对文本进行后处理或压缩后仍能溯源，椭圆签名不是合适的选择。

**验证方需持有部分模型参数**：与完全零知识证明方案相比，椭圆签名要求验证方持有输出层的归一化参数和线性变换矩阵。这在某些部署场景中可能被视为额外的秘密泄露，增加了信任假设。但这一代价换取了推理过程的完全零开销。

**攻击成本分析的时间敏感性**：当前的成本估算基于特定 API 定价（2025 年 9 月）和特定椭圆拟合算法实现。未来若出现更高效的椭圆提取算法或 API 降价，攻击难度可能降低。然而，论文明确指出目前尚无已知的快速椭圆生成算法——即无法在不先拟合椭圆的情况下生成位于未知模型椭圆上的新输出。

**大规模验证的外推局限**：实验中的椭圆拟合仅在隐藏维度 8–256 的小模型上实际运行。对 70B 级别模型的结论基于六次多项式外推（Figure 6），缺乏直接的大规模实验验证。这一外推假设算法复杂度严格遵循 $O(d^6)$ 增长，但实际中常数因子和硬件特性可能改变具体数值。

**重放攻击的脆弱性**：椭圆签名验证的是 logprob 向量是否位于模型椭圆上，而非序列的语义完整性。攻击者若收集足够多的已生成 logprob 并拼接构造新序列，椭圆签名本身无法直接检测此类攻击。论文提出了前缀重建作为缓解措施，但这增加了系统复杂度，且未在实验中充分验证。

**API 访问假设**：方法假设 API 可返回完整的 logprob 向量，或至少一组固定 token 的 logprob。若 API 限制更严格（如仅返回 top-k 且 $k$ 远小于隐藏维度），则椭圆提取几乎不可能，但验证能力也相应受限。

### 开放问题

1. **椭圆伪造的快速算法**：是否存在一种无需先拟合椭圆就能生成位于未知模型椭圆上的新输出的算法？这是椭圆签名安全性的核心假设，目前尚无已知攻击，但缺乏形式化的困难性证明。

2. **epsilon 平滑的缩放行为**：归一化层中的 epsilon 平滑项导致不可约误差，该误差如何随模型尺寸增加而缩放？是否存在一个明确的门槛，超过该门槛后基于 SVD 的拟合方法完全失效而必须使用椭圆特定拟合（如 Ying et al., 2012）？

3. **拟合效率的突破可能**：是否有方法可以在不降低安全性的前提下，通过近似或并行化大幅降低椭球拟合的时间复杂度？当前 $O(d^6)$ 的增长使得大模型提取在实践上不可行，但若出现亚六次方算法，安全假设将需要重新评估。

4. **量化和混合精度的影响**：量化/混合精度推理对输出层椭圆约束的影响在本工作中仅被简单讨论，缺少系统的实验验证。低精度下归一化和线性变换的数值误差可能使椭圆约束松弛，影响签名的可区分性。

5. **多模型融合场景**：当输出由多个模型协作生成（如模型集成、推测解码）时，椭圆签名的行为尚不明确。混合模型的 logprob 可能不严格位于任何单一模型的椭圆上，这既是挑战也可能成为检测模型协作的新途径。
