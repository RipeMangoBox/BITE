# Arbitrary-Shaped Image Generation via Spherical Neural Field Diffusion

> [!tip] 核心洞察
> 通过将图像生成从平面网格扩展到球面网格（L-细分二十面体），并利用接缝感知填充（Seam-Aware Padding）和接缝强制去噪（Seam Enforcement Denoising）保持跨视角的语义和空间一致性，再结合球面神经场实现坐标条件化的失真自由采样，从而在一个统一框架内实现视角、视场角和分辨率的精确控制，支持任意形状的图像生成。

## 概要

本文提出ASIG（Arbitrary-Shaped Image Generation）框架，旨在解决现有扩散模型局限于固定形状图像生成的问题。ASIG通过引入基于网格的球面潜空间扩散（mesh-based spherical latent diffusion）和球面神经场（spherical neural field），在一个统一框架内实现了对视角、视场角（FOV）和分辨率的精确控制，支持透视、全景和鱼眼等多种图像形状的高质量生成。实验结果表明，ASIG在Matterport3D数据集上的透视、全景和鱼眼图像生成任务中，FID、KID、CLIP-FID等指标均显著优于现有专门方法。



现有扩散模型（如Stable Diffusion、SDXL）在平面网格上操作，生成固定形状的图像，无法灵活控制视角、视场角和分辨率等空间属性。虽然已有工作尝试扩展扩散模型以支持任意分辨率（如INFD、Kim et al.）或全景图像生成（如PanFusion、SMGD），但这些方法缺乏统一框架来支持透视、全景和鱼眼等多种图像形状的高质量生成。核心瓶颈在于：平面网格表示无法自然编码球面几何，导致跨视角的语义和空间一致性难以保持，且无法实现失真自由的任意区域采样。



## 核心方法与创新机理

ASIG的核心创新包括：

1. **基于网格的球面潜空间扩散**：将图像生成从平面网格扩展到球面网格（L-细分二十面体），利用其层次化细分结构与扩散UNet的多尺度架构自然对齐，生成完整的球面场景潜表示。

2. **接缝感知填充（Seam-Aware Padding, SAP）和接缝强制去噪（Seam Enforcement Denoising）**：在扩散UNet和VAE解码器中，通过从网格相邻补丁重映射边界特征，保持跨补丁的语义和空间一致性，消除接缝伪影。

3. **球面神经场（Spherical Neural Field, SNF）**：从球面潜表示中采样任意区域，通过坐标条件化实现失真自由的解码，支持任意视角、视场角和分辨率的灵活控制。



![[assets/figures/papers/iclr26_vision_multimodal_applications__image_and_video_generation__b001_UNeL5NdLzc_Arbitrary-Sha/figures/001_Figure_1.jpg]]
*Figure 1: ASIG Overview. Our framework generates a complete spherical scene representation via a mesh-based spherical latent diffusion and enables distortion-free sampling through a spherical neural field. The proposed framework provides flexible control over FOV, viewpoint, and resolution, supporting high-quality generation across diverse image shapes, such as perspective, panoramic, and fisheye views. Generation at arbitrary aspect ratios naturally emerges from the joint control of FOV and resolution. As extended cases, irregular images can also be generated by jointly controlling FOV and resolution.*

ASIG的整体框架如Figure 1所示，包含两个主要阶段：

**阶段1：球面神经场构建**。冻结VAE编码器，端到端训练球面神经场，包括球面残差块（Spherical Residual Blocks）和卷积潜采样器（Convolutional Latent Sampler），使用L1、LPIPS和GAN损失的加权组合进行优化。

**阶段2：球面潜空间扩散**。在球面潜空间上训练扩散模型，对噪声和带噪潜变量均应用接缝感知填充，实现跨补丁一致性。

生成流水线如Figure 3所示：从高斯噪声开始，带接缝感知填充的网格球面去噪UNet执行T步去噪，生成与文本条件对齐的完整场景球面潜变量；潜变量经VAE解码器产生多尺度特征，由球面残差块进行层次化精炼；最后，坐标条件化的卷积潜采样器生成高质量图像。



### 5.1 网格球面潜表示

基于L-细分二十面体构建球面潜表示。如Figure 2所示，从正二十面体（12个顶点、20个三角面、10个菱形面）开始，每次细分将每个面四等分并将新顶点重新投影到球面上。每个补丁p中三角面集合与其矩形特征图之间建立一一对应关系：

$$\mathcal { F } _ { L } ^ { p } \longleftrightarrow \mathbf { M } _ { p } \in \mathbb { R } ^ { H _ { L } \times W _ { L } \times d } , \quad p = 1 , \dots , 1 0$$

每个补丁的空间分辨率随细分级别L增长：

$$( H _ { L } , W _ { L } ) = ( 2 ^ { L } , 2 ^ { L } )$$

例如L=5时得到64x64，L=6时得到128x128。

### 5.2 接缝感知填充（SAP）

定义补丁p_i的网格相邻补丁集合（索引模10以尊重补丁的循环顺序）：

$$\mathcal N ( p _ { i } ) = \{ p _ { i - 2 } , p _ { i - 1 } , p _ { i + 1 } , p _ { i + 2 } \}$$

SAP操作为补丁p_i生成填充特征图：有效区域使用原始特征，填充区域使用来自相邻补丁的几何重映射特征：

$$\tilde { \mathbf { M } } _ { p _ { i } } ( u , v ) = \{ \begin{array} { l l } { \mathbf { M } _ { p _ { i } } ( u , v ) , } & { ( u , v ) \in \mathrm { v a l i d r e g i o n ~ o f ~ } p _ { i } , } \\\\ { \quad } & { \quad } \\\\ { \Pi _ { p _ { i }  p _ { j } } \bigl ( \mathbf { M } _ { p _ { j } } ( u ^ { \prime } , v ^ { \prime } ) \bigr ) , } & { ( u , v ) \in \mathrm { p a d d e d ~ r e g i o n } , \ p _ { j } \in \mathcal { N } ( p _ { i } ) , } \end{array}$$

SAP应用于扩散UNet和VAE解码器的所有卷积层，使卷积核在尊重球面几何的同时感知跨补丁边界的连续特征。

### 5.3 球面残差块与多尺度特征

给定球面潜变量Z_0，提取多尺度解码器特征D^(ℓ)(Z_0)。每个特征图由球面残差块精炼，其中感受野被重新映射到二十面体拓扑以减少球面失真。将来自级别6-9的上采样精炼解码器特征沿通道维度拼接，形成多尺度表示：

$$\mathbf{F} = \operatorname{Concat}_{\ell \in \{6,7,8,9\}} \Bigl( \operatorname{Upsample} \bigl( \operatorname{SphericalRes}^{(\ell)} ( D^{(\ell)}(\mathcal{Z}_0) ) \bigr) \Bigr)$$

### 5.4 坐标条件化渲染

给定目标视角(θ,φ)和FOV，在球面上定义采样区域Ω(θ,φ,FOV)。投影函数π(u,v;θ,φ,FOV)将每个输出像素(u,v)映射到球面潜变量上的对应坐标。通过在投影坐标处采样拼接特征，并经由轻量级网络映射到RGB值，渲染输出图像：

$$I(u,v) = f_\theta \Big( \operatorname{Sample} \big( [\mathbf{F}, D(\mathcal{Z}_0)], \pi(u,v;\theta,\phi,\mathrm{FOV}) \big) \Big)$$

### 5.5 训练目标

**阶段1**：球面神经场训练的加权组合损失：

$$\mathcal{L} = \lambda_1 \mathcal{L}_1 + \lambda_p \mathcal{L}_{\mathrm{LPIPS}} + \lambda_g \mathcal{L}_{\mathrm{GAN}}$$

**阶段2**：扩散训练损失，对噪声和带噪潜变量均应用接缝感知填充：

$$\mathcal{L}_{\mathrm{diff}} = \mathbb{E}_{t,\mathbf{z}_0,\epsilon} \Big[ \left. \mathrm{SeamPad}(\epsilon, L) - F_\theta( \mathrm{SeamPad}(\mathbf{z}_t, L), t, y ) \right. _2^2 \Big]$$

## 定位与知识库关联

ASIG属于扩散模型在非平面图像生成领域的创新工作。其方法谱系可追溯至：

- **任意分辨率图像生成**：INFD（Chen et al., 2024）和Kim & Kim (2024) 将神经场与扩散模型结合，支持任意尺度图像生成，但局限于平面透视图像。
- **全景图像生成**：PanFusion、SMGD、MVDiffusion等方法专注于全景图像生成，但缺乏对视角、FOV和分辨率的统一控制。
- **球面表示学习**：L-细分二十面体在计算机图形学中用于球面信号的失真自由表示，ASIG首次将其引入扩散模型的潜空间。

ASIG的核心贡献在于：将球面网格表示、接缝感知填充和球面神经场有机结合，首次实现了在一个统一框架内对视角、FOV和分辨率的精确控制，支持透视、全景和鱼眼等多种图像形状的高质量生成。该工作为扩散模型在沉浸式内容生成、虚拟现实和增强现实等领域的应用开辟了新路径。
