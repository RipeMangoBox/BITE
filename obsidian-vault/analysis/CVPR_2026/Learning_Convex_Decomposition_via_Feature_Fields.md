## 概述

**问题瓶颈**：凸分解是物理仿真、碰撞检测等几何处理任务的基础工具，但经典方法（如VHACD、CoACD）依赖启发式搜索，计算开销大且难以保证分解质量。基于学习的方法（如BSP-Net、Cvx-Net）受限于类别形状，无法泛化到开放世界数据。核心瓶颈在于缺乏一种可扩展的、几何驱动的学习范式。

**核心洞察**：本文将凸分解重新形式化为特征学习问题——学习一个连续表面特征场，使得特征空间中的距离直接编码点之间的凸性关系。该特征场通过一个纯几何的自监督对比损失进行训练，该损失源自凸性的经典定义：凸形状内任意两点连线完全位于形状内部。聚类后即可获得凸分解，无需显式优化凸原语参数或搜索分割平面。

**方法定位**：本文提出的方法（Convex Decomposition via Feature Fields）在方法谱系中处于**几何自监督特征学习**与**凸分解**的交叉点。与显式优化凸原语的BSP-Net、Cvx-Net不同，本方法通过特征场间接实现分解；与经典分割方法VHACD、CoACD不同，本方法无需手工调整凹度阈值或迭代搜索。与同为特征场方法的PartField相比，本方法的关键区别在于使用几何定义的凸对/非凸对采样替代语义/部件标注，从而获得凸性感知的特征。

**主要结果**：在VHCD、PartObjaverse-Tiny和ShapeNet三个数据集上，本方法在凹度（Concavity）和重建误差（Chamfer距离）两项指标上均显著优于所有基线方法（包括CoACD、VHACD、BSP-Net、Cvx-Net）。消融实验证实了硬负采样、半球正采样、递归聚类策略以及大规模前馈预训练对性能的关键贡献。

## 背景与动机

### 凸分解的核心地位与应用瓶颈

凸分解——将三维形状近似为一组凸原语的并集——是计算机图形学与几何处理中的基础算子。其核心价值在于将非凸几何转化为凸组件，从而显著降低碰撞检测、物理模拟、机器人抓取规划等下游任务的算法复杂度。例如，在物理引擎中，凸体间的碰撞检测速度可比原始非凸网格快数倍（Figure 9 显示单步仿真时间从 40ms 降至 8ms，约 **5 倍加速**）。

然而，获得高质量凸分解本身是一个极具挑战性的问题。经典方法（如 **VHACD** 和 **CoACD**）依赖启发式搜索或体素化策略，通过迭代切割平面来逼近凸组件。这类方法存在两个根本性缺陷：一是**计算量大**，需要在庞大的切割空间中进行搜索；二是**受限于轴对齐或固定方向的切割假设**，难以捕获倾斜的大型凸区域（Figure 12 定性对比揭示了这一失效模式）。更关键的是，这些方法无法从数据中学习先验，每个形状都需要从头优化。

### 现有学习方法的局限

近年来，基于深度学习的方法尝试从数据中学习凸分解。**BSP-Net** 通过拟合凸原语参数实现重建，**Cvx-Net** 则直接预测凸组件。但这些方法存在一个共同的瓶颈：**局限于类别形状，无法处理开放世界数据**。它们通常依赖重建误差（如 Chamfer 距离）作为监督信号，这要求训练数据中的形状具有相似的拓扑和部件结构。当面对训练分布之外的任意形状时，泛化能力急剧下降。

另一条相关路线是基于特征场的部件分割方法（如 **PartField**），它们学习表面特征场并通过聚类获得语义部件。然而，PartField 的特征学习目标与凸性无关，导致在平坦区域产生近乎均匀的特征分布，无法形成有意义的凸分解（Figure 11 显示 L 形表面几乎全红，分解质量显著劣于本文方法）。

### 核心瓶颈与本文动机

上述分析揭示了一个深层瓶颈：**凸分解的监督信号缺失**。凸性是一个纯粹的几何性质——根据经典定义，集合中任意两点连线完全位于集合内部——但如何将这一几何约束转化为可学习的损失函数，此前并无有效方案。显式优化凸原语参数（BSP-Net）或搜索分割平面（VHACD）都未能利用凸性定义本身来构建自监督学习框架。

本文的核心动机正是**将凸分解问题转化为特征学习问题**。关键洞察在于：如果能够学习一个连续特征场，使得特征空间中的距离编码了点之间的凸性关系（凸对距离近、非凸对距离远），那么通过简单的聚类即可获得高质量的凸分解。这一思路将凸分解从显式的几何搜索或参数优化中解放出来，转而利用凸性的几何定义构建**纯几何的自监督目标**，从而使得在开放世界数据上的可扩展学习成为可能。

## 核心创新

本文的核心创新在于**将凸分解问题从根本上重新形式化为特征学习问题**，而非沿用显式优化凸原语参数或搜索分割平面的传统范式。这一转变的关键洞察在于：利用凸性的经典几何定义构建自监督信号，引导模型学习一个连续表面特征场，使得特征空间中的距离直接编码了点之间的凸性关系——属于同一凸组件的点特征相近，非凸对点特征相远。聚类后即可获得凸分解，无需显式建模凸原语。

### 从显式建模到隐式特征学习

经典方法（如 **VHACD**、**CoACD**）依赖启发式搜索与体素化操作，计算量大且难以扩展；学习方法（如 **BSP-Net**、**Cvx-Net**）虽引入神经网络，但本质仍是显式拟合凸原语参数或分割平面，局限于类别形状，无法处理开放世界数据。本文的核心范式转换在于：**不再显式优化凸原语，而是学习一个连续特征场，将凸性关系编码为特征相似度**。这一设计使方法天然具备跨类别、跨模态的泛化能力——模型仅需理解“两点是否属于同一凸体”这一几何关系，而非特定物体的形状先验。

### 自监督几何对比损失：凸性定义的直接转化

方法的核心驱动力是**自监督几何对比损失**，其设计直接源自凸性的经典定义：形状中任意两点连线完全位于形状内部即为凸点对。基于此，损失函数将凸对点作为正样本拉近特征距离，非凸对点作为负样本推远，形式化为三元组对比学习目标：

$$\mathcal { L } _ { \mathrm { c c } } = - \frac { 1 } { 2 } \Bigg [ \log \frac { \sin ( f _ { x } , f _ { p } ) } { \sin ( f _ { x } , f _ { p } ) + \sin ( f _ { x } , f _ { n } ) } + \log \frac { \sin ( f _ { p } , f _ { x } ) } { \sin ( f _ { p } , f _ { x } ) + \sin ( f _ { p } , f _ { n } ) } \Bigg ]$$

这一损失函数的关键优势在于**完全自监督**——无需任何人工标注，仅依赖形状本身的几何结构即可生成训练信号，使得在开放世界大规模数据上的可扩展学习成为可能。

### 几何引导的采样策略

与损失函数配合的是两个精心设计的采样策略，均源自几何直觉：

- **正样本采样**：从源点沿表面法向反方向的半球内随机投射射线，取射线穿出形状的表面点作为正对。这保证了正对点之间的连线完全位于形状内部，严格满足凸性条件。
- **负样本采样**：采用距离加权的拒绝采样，优先选择空间上靠近源点但与其不构成凸对的表面点作为硬负样本。硬负样本位于凸性边界附近，对特征学习具有更强的判别性引导作用。

消融实验证实，移除硬负采样导致凹度从 0.0973 升至 0.0993、重建误差从 0.0180 升至 0.0186；移除半球正采样则使凹度升至 0.0999、重建误差升至 0.0219，验证了两者均为关键设计。

### 递归二分聚类：多粒度分解的统一框架

与固定数目聚类的传统策略不同，本文采用**递归二分聚类**策略：从整体形状开始，反复将特征聚类为两个子集，直至每个子集的凹度低于用户指定阈值。这一设计使得同一特征场可支持从粗到细的任意粒度分解（如 Figure 2 所示），无需重新训练模型。消融实验表明，递归聚类相比平坦聚类显著降低凹度（0.0973 vs 0.1292），证明递归策略能产生更紧致的凸近似。

### 与 PartField 的本质差异

与同样采用特征场学习的 **PartField** 相比，本文的核心区别在于**损失函数的几何根源**：PartField 的特征在平坦区域趋于均匀，无法感知凸性边界；而本文的几何对比损失迫使特征场在凸性边界处产生剧烈变化，使得聚类能准确捕捉凸组件边界（见 Figure 11）。这进一步验证了“将凸性定义直接转化为学习目标”这一创新路径的有效性。

## 整体框架

![[assets/figures/papers/paper_list_l14_https_arxiv_org_abs_2603_09285/figures/001_Figure_1.jpg]]
*Figure 1: Our method takes an input shape (top), infers features from an open-world model learned with our new self-supervised geometric loss (middle), and clusters those features to fit the shape with a collection of tight convex bounding proxies (bottom)*

本文提出一种基于特征场的凸分解学习框架，其核心思路是将凸分解问题转化为特征学习问题：学习一个连续的表面特征场，使得特征空间中的距离直接编码点之间的凸性关系，随后通过聚类即可获得凸分解。该框架无需显式优化凸原语参数或搜索分割平面，而是利用源自经典凸定义的纯几何自监督信号驱动特征学习。

### 模块组成与数据流

整体 pipeline 由以下模块串联构成（见 Figure 3）：

1. **PVCNN Encoder（点云编码器）**：以输入形状的点云采样作为输入，提取逐点特征。该编码器为后续 triplane 投影提供初始特征表示。
2. **Triplane Projection（三平面投影）**：将逐点特征沿三个正交方向（轴对齐）进行均值归约投影，生成三个 2D 特征平面，构成初始 triplane 表示。
3. **2D CNN & Transformer Processing（特征增强）**：对初始 triplane 依次进行 2D CNN 降采样、Transformer 模块增强、转置 2D CNN 上采样，重建为最终的特征 triplane。这一阶段通过空间压缩与全局注意力增强特征的表达能力。
4. **Feature Field Query（特征场查询）**：对于任意 3D 查询点，从最终特征 triplane 中聚合对应特征，形成连续的特征场。该特征场定义在整个形状表面，是后续聚类的直接依据。
5. **Surface Clustering（表面聚类）**：在形状表面密集采样特征，使用现成聚类算法进行划分。对于网格输入，采用基于面片特征的凝聚聚类；对于点云等其他模态，采用 K-means 聚类。聚类结果将表面划分为近似凸的组件。
6. **Convex Hull Generator（凸包生成）**：为每个聚类计算凸包，所有凸包的并集近似输入几何体，构成最终凸分解输出。

### 训练与推理流程分离

框架采用训练-推理分离的设计：

- **训练阶段**：特征场通过自监督几何损失进行拟合。损失函数基于对比学习范式，从表面采样三元组（锚点、正对、负对），利用凸性的几何定义构建正负样本：正对通过半球内射线采样获得（保证两点位于同一凸区域），负对通过距离加权的硬负采样获得（优先选择空间邻近但非凸的点对）。损失鼓励正对特征相似度大于负对（见 Eq. 6）。
- **推理阶段**：固定训练好的前馈模型，直接预测特征场，随后通过聚类获得凸分解。聚类采用递归二分策略：反复对当前组件进行二聚类，直至满足用户指定的凹度阈值，从而支持多粒度输出（见 Figure 2、Figure 6）。

### 关键设计选择

- **特征场替代显式参数化**：与 BSP-Net、Cvx-Net 等方法直接预测凸原语参数不同，本框架学习的是表面特征场，将凸分解的“分割”与“拟合”解耦——分割由聚类完成，拟合由凸包计算完成。
- **纯几何自监督**：无需任何凸分解真值标注，仅依赖凸性的经典定义（Eq. 1）构建训练信号，使得方法可扩展到开放世界数据。
- **递归分解策略**：相比平坦聚类一次性划分固定数目的组件，递归策略能产生更紧致的凸近似（消融实验中移除递归聚类后凹度从 0.0973 升至 0.1292，见 Table 2）。

## 核心模块与公式推导

### 问题形式化：从凸性定义到特征学习目标

本文的核心洞察在于将凸分解问题转化为特征学习问题。其数学起点是凸性的经典几何定义：一个形状 $\mathcal{M}$ 是凸的，当且仅当对于表面上任意两点 $x, y \in \mathcal{M}$ 和任意 $\lambda \in [0,1]$，连线上的点都位于形状内部：

$$\lambda x + ( 1 - \lambda ) y \in \mathrm { V o l } ( \mathcal { M } ) \quad \forall x , y \in \mathcal { M } , \quad \forall \lambda \in [ 0 , 1 ]$$

基于此定义，可以定义形状表面所有凸点对的集合：

$$\mathscr { C } ( \mathcal { M } ) = \{ ( x \in \mathcal { M } , y \in \mathcal { M } ) : \lambda x + ( 1 - \lambda ) y \in \mathrm { V o l } ( \mathcal { M } ) \quad \forall \lambda \in [ 0 , 1 ] \}$$

理想的凸分解应最大化每个分割区域内凸点对的数量。然而直接优化离散分割是困难的。本文的关键转折在于：**学习一个连续特征场 $f$，使得特征空间中的距离直接编码点之间的凸性关系**——凸点对的特征应相近，非凸点对的特征应远离。这引出了特征嵌入的平衡优化目标：

$$\operatorname* { m i n } _ { f } \int \int _ { x , y \in { \mathcal { C } } ( { \mathcal { M } } ) } d \bigl ( f _ { x } , f _ { y } \bigr ) \ - \int \int _ { x , y \notin { \mathcal { C } } ( { \mathcal { M } } ) } d \bigl ( f _ { x } , f _ { y } \bigr )$$

该目标函数驱动特征场将凸性相关的几何关系“压缩”到低维流形中，使得后续的简单聚类即可产生高质量的凸分解。

### 核心模块一：几何引导的对比学习采样

上述连续目标在实践中的核心挑战是**高效且正确地采样凸对（正样本）和非凸对（负样本）**。本文设计了纯几何驱动的采样策略，无需任何标注数据。

**正样本采样（半球射线法）**：对于锚点 $x$，在其表面法向的反方向半球内随机投射一条射线进入形状内部，射线穿出形状表面的交点 $p$ 即为正样本。该策略的几何直觉是：从 $x$ 出发向内穿透形状的射线，其出点 $p$ 与 $x$ 在绝大多数情况下构成凸对，因为连接它们的线段完全在形状内部。

**负样本采样（距离加权硬负采样）**：从形状表面所有点中以反比于欧氏距离的概率进行拒绝采样，优先选择空间上靠近 $x$ 的点作为负样本 $n$。这种“硬负采样”策略迫使特征场学习更精细的凸性边界——空间邻近但非凸的点对是最难区分的，因此提供最强的训练信号。

消融实验（Table 2）验证了这两种采样策略的关键作用：移除硬负采样后凹度从 0.0973 升至 0.0993，重建误差从 0.0180 升至 0.0186；移除半球正采样后凹度升至 0.0999，重建误差升至 0.0219。

### 核心模块二：三元组对比损失函数

基于采样的三元组 $(x, p, n)$，本文设计了自监督几何对比损失。与标准对比学习使用距离度量不同，本文采用**余弦相似度** $\sin(\cdot, \cdot)$（归一化特征的内积），目标是最小化以下对称损失：

$$\mathcal { L } _ { \mathrm { c c } } = - \frac { 1 } { 2 } \Bigg [ \log \frac { \sin ( f _ { x } , f _ { p } ) } { \sin ( f _ { x } , f _ { p } ) + \sin ( f _ { x } , f _ { n } ) } + \log \frac { \sin ( f _ { p } , f _ { x } ) } { \sin ( f _ { p } , f _ { x } ) + \sin ( f _ { p } , f _ { n } ) } \Bigg ]$$

其中 $f_x, f_p, f_n$ 分别为锚点、正样本、负样本的特征向量。该损失的结构含义：
- 第一项鼓励 $x$ 与正样本 $p$ 的相似度远大于 $x$ 与负样本 $n$ 的相似度；
- 第二项对称地鼓励 $p$ 与 $x$ 的相似度远大于 $p$ 与 $n$ 的相似度；
- 对数归一化形式确保梯度稳定，避免相似度绝对值差异过大导致的训练不稳定。

消融实验（Table 4）对比了简化的正负对距离差损失（Eq. 9），结果显示三元组对比损失显著更优（凹度 0.0973 vs 0.1243，重建 0.0180 vs 0.0260），验证了归一化对比框架对学习凸性特征的必要性。

### 核心模块三：递归二分聚类分解

推理阶段，在预测的特征场上密集采样表面点特征后，本文采用**递归二分聚类策略**生成最终凸分解，而非传统的一次性固定数目聚类。

具体流程：从整个形状开始，使用现成聚类算法（网格输入用凝聚聚类，点云输入用 K-means）将当前区域二分，对每个子区域计算其凸包并评估凹度。凹度度量定义为表面和内部点 Hausdorff 距离的最大值：

$$\operatorname { C o n c a v i t y } ( S ) = \operatorname* { m a x } { \big ( } H ( \partial S , \partial \operatorname { h u l l } ( S ) ) , H ( \operatorname { V o l } ( S ) , \operatorname { V o l } ( \operatorname { h u l l } ( S ) ) ) { \big ) }$$

若子区域的凹度超过用户指定的阈值 $\epsilon$，则递归对其继续二分，直至所有组件满足凹度要求。该策略的核心优势：
- **多粒度可控**：同一特征场只需调整 $\epsilon$ 即可输出不同精细度的分解，无需重新训练；
- **更紧致的凸近似**：递归策略相比平坦聚类显著降低凹度（Table 2：0.0973 vs 0.1292），因为它能针对性地细化高度非凸区域。

### 核心模块四：前馈特征场预测网络

为实现开放世界数据的可扩展推理，本文训练了一个前馈网络直接从输入点云预测特征场。网络架构采用 **PVCNN 编码器**提取逐点特征，通过**均值归约正交投影**到三个轴对齐的 2D 特征平面形成初始 triplane 表示，随后经 **2D CNN 降采样 → Transformer 增强 → 转置 2D CNN 上采样** 得到最终特征 triplane。对任意 3D 查询点，从最终 triplane 中聚合对应特征即得到其特征向量。

消融实验（Table 2）对比了单形状优化（Single opt.）与前馈模型：前馈模型凹度 0.0973 vs 单形状优化 0.1134，重建 0.0180 vs 0.0198，验证了大规模预训练带来的泛化优势。

## 实验与分析

### 主要定量结果

本文在三个数据集上与经典方法和基于学习的方法进行了系统对比：**VHCD**（标准凸分解评测集）、**PartObjaverse-Tiny**（开放世界形状集）和 **ShapeNet**（类别级形状集）。评测指标包括组件数量（#comp.）、凹度（Concavity ↓）和重建误差（Chamfer距离 ↓），所有指标均为越低越好。对比基线包括经典体素化方法 **VHACD**、碰撞感知方法 **CoACD**，以及基于学习的方法 **BSP-Net** 和 **Cvx-Net**。

**Table 1** 汇总了跨三个数据集的核心结果。本文方法在所有数据集上均以更少的凸组件数量实现了显著更低的凹度和重建误差：

- **VHCD 数据集**：凹度 0.0973，重建误差 0.0180，组件数 11.90。相较最优基线 CoACD（凹度 0.1073，重建 0.0200，组件数 12.41），本文在保持更少组件的同时实现了更低的凹度和重建误差。
- **PartObjaverse-Tiny 数据集**：凹度 0.1257，重建误差 0.0254，组件数 21.18。该数据集包含大量开放世界形状，本文方法展现出较强的泛化能力，凹度和重建均显著优于所有基线。
- **ShapeNet 数据集**：凹度 0.0656，重建误差 0.0142，组件数 12.63。在类别级形状上同样保持了一致的性能优势。

**Figure 7** 进一步展示了在 VHCD 数据集上不同粒度级别（通过调整组件数量）的对比曲线。本文方法的凹度-组件数曲线始终位于 CoACD 和 VHACD 的下方，表明在任意给定组件数量下，本文都能产生更紧致的凸近似。

**Figure 8** 的定性对比显示，经典方法（VHACD、CoACD）由于依赖轴对齐切平面假设，往往无法捕获倾斜的凸区域，导致不必要的过度分割；而本文方法能够更好地保留大型凸结构，产生的分解更符合几何直觉。

### 失败模式与局限性

尽管本文方法在多数形状上表现优异，仍存在以下已知失败模式：

- **极薄或复杂连接结构**：如风扇框架等具有细长连接件的形状，特征场难以可靠区分凸性边界，导致分解质量下降。
- **非水密输入**：方法依赖水密网格或干净点云进行表面采样和射线投射，对存在孔洞或严重噪声的输入需要额外预处理。
- **语义盲区**：当前方法完全基于几何凸性定义，未融入语义或功能信息，可能产生几何合理但语义不自然的分解（例如将功能相关的部件过度拆分）。

这些局限性指向了未来工作的方向，包括结合语义信息指导分解、处理非水密和场景级数据等。

## 方法谱系与知识库定位

### 问题瓶颈与范式转换

经典凸分解方法长期受困于两个核心瓶颈：**计算量大**与**泛化能力弱**。传统算法如 **VHACD**（体素化近似凸分解）和 **CoACD**（碰撞感知近似凸分解）依赖启发式搜索与迭代切割，每形状需数十秒至数分钟；基于学习的方法如 **BSP-Net** 和 **Cvx-Net** 虽提升了效率，但局限于类别形状，无法处理开放世界数据——其本质在于这些方法显式优化凸原语参数或搜索分割平面，模型容量与训练数据分布强绑定。

本文的关键洞察在于**将凸分解问题转化为特征学习问题**：不再直接预测凸组件，而是学习一个连续表面特征场，使得特征空间中的距离编码了点之间的凸性关系。这一范式转换的因果机制在于——利用凸性的经典几何定义（任意两点连线完全位于形状内部）构建自监督信号，通过对比学习引导特征聚类自然形成凸组件，从而将“如何分割”的难题外包给聚类算法，模型仅需学习“哪些点应属于同一凸体”的几何感知特征。

### 方法谱系定位

**相对于经典几何方法（VHACD, CoACD）**：本文方法在推理效率上取得数量级提升（单形状推理约0.5秒 vs 经典方法数十秒至分钟级，见Table 3），且不依赖轴对齐切割假设，能更好地保留倾斜的大尺度凸结构（Figure 12定性对比）。经典方法在凹度阈值调整时需要重新运行整个算法，而本文仅需调整聚类阈值即可从同一特征场获得多粒度分解（Figure 2）。

**相对于学习型凸分解方法（BSP-Net, Cvx-Net）**：这些方法通过重建损失端到端预测凸原语，本质上属于类别内插值。本文的特征学习范式使其具备了开放世界泛化能力——在PartObjaverse-Tiny这类大规模开放数据集上，本文方法在凹度（0.1257）和重建误差（0.0254）上均显著优于所有基线（Table 1），而BSP-Net等方法的性能在此设定下明显退化。

**相对于通用部件分割特征场方法（PartField）**：消融对比揭示了损失函数设计的决定性作用。PartField采用均匀表面采样和重建导向的目标，导致其在平坦区域产生近乎均匀的特征（Figure 11中L形表面几乎全红），无法感知凸性边界。本文的几何对比损失通过半球内射线采正对、距离加权硬负采负对，显式编码了凸性几何约束，这是特征场具备凸感知能力的关键。

### 核心创新点的因果链路

本文的四个关键设计形成了一条清晰的因果链路：

1. **半球正采样**：从表面点沿法向反方向（形状内部）投射射线，击中另一表面点作为正对。这保证了正对点之间的线段完全位于形状内部（满足凸性定义的充分条件），为特征学习提供了准确的几何监督。消融实验（Table 2）显示移除该设计后凹度从0.0973升至0.0999，重建误差从0.0180升至0.0219。

2. **距离加权硬负采样**：在表面点中按欧氏距离反比采样负对，偏好空间邻近的非凸点对。这迫使特征场学习精细的凸性边界——空间邻近但非凸的点对是最难区分的“硬负样本”。移除硬负采样后凹度升至0.0993（Table 2），证明其对特征判别力的贡献。

3. **三元组对比损失**：采用对数归一化形式（Eq. 6），鼓励正对相似度大于负对。消融实验（Table 4）对比了简单的正负对距离差损失，后者导致凹度从0.0973恶化至0.1243，表明三元组形式的对比学习对特征空间结构的形成至关重要。

4. **递归二分聚类**：相比平坦聚类一次性分割，递归策略在每步二分后评估凹度，直至满足用户指定阈值。这产生了更紧致的凸近似（Table 2中移除递归聚类后凹度从0.0973飙升至0.1292），且天然支持多粒度输出（Figure 6）。

### 适用边界与局限

**输入要求**：方法需要水密网格或干净点云作为输入预处理，无法直接处理带孔洞、缺失或严重噪声的几何。对于极薄结构（如风扇框架）或复杂连接结构，特征场可能无法可靠区分凸性边界，这是论文明确指出的失败模式。

**泛化边界**：虽然方法在开放世界数据上展现了强泛化能力，但训练数据仍以物体级形状为主。对于场景级数据（如室内场景、城市场景），点云密度不均、遮挡严重、几何尺度跨越大的特点可能使当前特征场设计面临挑战，该问题尚未验证。

**语义感知缺失**：方法完全基于纯几何凸性定义，未融入任何语义或功能信息。对于需要语义感知分解的下游任务（如机器人抓取、功能性部件分析），当前分解可能将语义上不应分割的区域切分，或将功能独立的部件合并。论文将此列为开放问题。

### 未解决的问题与后续方向

1. **动态场景扩展**：特征场学习能否扩展到4D数据（如动态网格序列），在保持时间一致性的同时进行凸分解？这涉及时空特征场的设计与训练。

2. **端到端物理模拟优化**：当前方法的评估指标（凹度、重建误差）是几何代理指标，与下游物理模拟性能的关系未完全建立。能否将碰撞检测效率或模拟稳定性直接纳入训练目标，实现端到端优化？

3. **语义引导分解**：如何将语义或功能性先验（如部件运动学约束、类别级部件知识）融入特征学习，产生既几何凸又语义合理的分解？这可能需要多模态监督或弱监督学习策略。

4. **大规模场景适配**：对于场景级数据，特征场架构（triplane分辨率512×512、特征维度448）的计算和存储开销是否可承受？是否需要层次化或多分辨率特征场设计？

5. **理论分析**：对比学习损失与凸性定义的数学联系尚未深入分析——特征空间的聚类结构在何种条件下严格对应凸分解？这关系到方法的理论完备性。
