## 概要

多模态大模型的主流范式通常将视觉编码器、连接器与语言模型分离训练，导致视觉与语言信号在优化过程中相互割裂。UVU 针对这一瓶颈，提出**统一自回归（Unified Autoregressive）训练范式**，使图像与文本的损失梯度从近乎正交甚至对立的状态，快速对齐至同一方向，从根本上解决优化冲突，让视觉监督成为多模态理解的正向驱动力。

核心结论是：**梯度对齐后的视觉监督能够一致且显著地提升多模态理解性能**。在相同骨架与训练数据下，引入视觉监督的 UVU 相比无视觉监督的消融版本 UVU*，在多个基准上取得大幅提升——MME 从 2056.6 升至 2201.9，HallusionBench 从 59.2 升至 66.6，CVBench-2D 从 68.4 升至 73.0，MMStar 从 52.9 升至 55.0（Table 1）。同时，UVU 仅使用 3B 参数规模的 Qwen2.5 骨架，在多数指标上仍领先于 7B–34B 量级的对比模型，展现出显著的参数效率优势。

方法上，UVU 通过两个关键模块实现统一自回归：**像素级视觉码本（Pixel-level Visual Codebook）**，利用大规模迭代层次聚类将图像 patch 量化为离散 token，保证高保真重建；**统一自回归 Transformer**，以同一目标同时处理文本与视觉 token 序列，使两类模态的优化梯度自然对齐。相比 Janus-Pro、Emu3、Chameleon 等同样引入视觉监督的统一模型，UVU 避免了因附加生成目标而损害理解能力的常见陷阱——实证表明，在后训练阶段引入大规模文生图数据集反而会削弱模型的核心理解与推理表现。

### 多模态统一模型的范式困境

当前的多模态统一模型普遍试图让单一模型同时具备视觉理解与视觉生成能力。主流实现路径是将图像量化为离散 token，再以自回归（AR）方式建模，形成“AR + VQ”范式。然而，大量实证表明，这一范式在优化层面存在根本性冲突：**图像生成损失与文本理解损失的梯度在训练过程中近乎正交甚至相互对立**。这意味着，模型在优化视觉生成目标时，其参数更新方向与优化语言理解目标所需的方向并不一致，甚至背道而驰。

这种梯度冲突的直接后果是，视觉监督信号非但不能辅助多模态理解，反而成为干扰项。多个统一模型（如 **Janus-Pro**、**Emu3**、**UniTok**、**UniCode2**、**MetaMorph**、**show-0**、**Harmon**、**UniToken**、**TokLIP**、**Chameleon** 等）在追求“生成+理解”统一的过程中，均面临理解性能受损的困境。论文进一步指出，在后训练阶段引入大规模文本到图像（T2I）数据集，甚至会**意外地削弱模型的核心理解与推理能力**——这从实证层面印证了生成目标与理解目标之间存在本质张力。

### 核心瓶颈：梯度冲突导致视觉监督失效

问题的本质并非视觉信息本身对理解无益，而是**现有的训练范式无法让视觉监督以“友好”的方式融入理解优化过程**。传统 AR+VQ 范式下，图像损失与文本损失各自驱动参数向不同方向更新，视觉信号的正向贡献被优化冲突所抵消。因此，核心瓶颈在于：**如何设计训练目标，使视觉与语言损失梯度从对立走向协同，从而将视觉监督转化为理解能力的正向驱动力。**

### UVU 的动机与核心思路

UVU 的提出正是为了从根本上解决上述梯度冲突。其核心洞察在于：**通过统一的自回归训练目标，使图像与文本的优化梯度自然对齐，从而让视觉监督成为多模态理解的“助推器”而非“绊脚石”**。具体而言，UVU 摒弃了传统范式下视觉与语言分离优化的做法，转而采用统一自回归范式（Unified AR），使图像 token 和文本 token 在同一目标下联合训练，迫使两者的梯度方向快速收敛至一致。

这一设计的因果调节变量（causal knob）是**视觉与语言损失梯度的一致性**。当梯度对齐后，视觉监督不再与理解目标冲突，而是能够为模型提供额外的结构化信息，从而在多个理解基准上带来一致且显著的提升。与那些因引入生成目标而牺牲理解性能的统一模型不同，UVU 试图证明：**视觉监督与多模态理解并非零和博弈，关键在于训练范式的设计能否让二者形成合力**。

## 核心方法与创新机理

UVU 的核心创新在于**通过统一自回归（Unified Autoregressive）训练范式，从根本上解决传统 AR+VQ 范式下视觉与语言优化目标冲突的问题**，从而将视觉监督转化为多模态理解能力的正向驱动力。

### 问题瓶颈：梯度正交性与优化冲突

在传统的自回归加向量量化（AR+VQ）范式中，图像生成损失与文本理解损失的优化方向存在严重冲突。分析表明，两者在训练过程中的梯度近乎正交甚至相互对立（Section 1.1）。这意味着，当模型同时优化图像重建和文本理解两个目标时，视觉信号的梯度不仅无法辅助语言理解，反而会干扰文本优化的方向，形成“此消彼长”的困境。这正是此前诸多统一多模态模型（如 **Janus-Pro**、**Emu3**、**Chameleon** 等）在引入视觉生成目标后，理解性能不升反降的深层原因。

### 关键机制：梯度对齐的统一自回归训练

UVU 的核心改变在于**视觉监督整合范式**的切换：从分离的图像生成目标或 AR+VQ 导致的梯度冲突，转变为统一自回归训练下的梯度自然对齐。具体而言：

- **统一目标函数**：UVU 将图像 patch 量化为离散 token 后，与文本 token 拼接成单一序列，以完全相同的自回归语言建模损失进行训练。这一设计消除了图像与文本损失之间的目标差异，使两者的优化梯度能够迅速收敛到同一方向。
- **梯度对齐的因果效应**：实验证实，传统 AR+VQ 范式在整个训练过程中梯度始终接近正交甚至对立，而 UVU 能快速将图像与文本梯度对齐至同一方向，从根本上化解优化冲突。这一机制使得视觉监督不再是理解的“干扰项”，而是成为增强理解的“助推器”。

### 关键组件支撑

梯度对齐的实现依赖于两个关键模块的配合：

1. **像素级视觉 Codebook**：通过大规模迭代层次聚类算法（Algorithm 1），从 100 万张图像（约 20 亿个 32×32×3 patches）中构建目标大小为 200,000 的 codebook，将连续图像信号高质量地量化为离散 token，为统一自回归建模提供基础。
2. **统一自回归 Transformer**：以 Qwen2.5 为 backbone，在嵌入层、中间层和输出层均以统一自回归方式同时处理文本和视觉 token 序列，确保两类模态共享完全一致的优化路径。

### 与同类方法的本质差异

与其他带视觉监督的统一多模态模型（如 **UniTok**、**UniCode2**、**MetaMorph**、**Harmon**、**TokLIP** 等）相比，UVU 的区别不在于“是否加入视觉监督”，而在于“如何加入”。这些方法大多在统一框架中直接叠加生成目标，反而因梯度冲突损害了理解性能——Table 1 的实证结果也印证了“单纯添加生成目标对多模态推理任务可能适得其反”这一发现。UVU 则通过梯度对齐机制，使视觉监督与理解目标形成合力而非对抗，从而在 3B 参数规模下即取得领先于诸多更大模型的理解性能。

UVU 的核心主张是：**视觉监督并非天然有害于多模态理解，而是传统 AR+VQ 范式下的优化冲突使其失效**。基于这一洞察，UVU 提出了一套“像素级视觉 Codebook + 统一自回归 Transformer”的端到端框架，使图像与文本的优化梯度自然对齐，从而将视觉生成目标转化为理解能力的正向驱动力。

### 框架总览

UVU 的整体 pipeline 由两个紧密耦合的模块构成：

1. **Pixel-level Visual Codebook（像素级视觉码本）**  
   通过大规模迭代层次聚类算法，将原始图像 patch 量化为离散视觉 token。该码本从 100 万张图像（约 20 亿个 32×32×3 的 patch）中构建，目标码本大小 $K = 200,000$，以实现高保真重建（见 Algorithm 1）。这一设计使视觉信号能以与文本 token 同构的离散序列形式进入后续处理。

2. **Unified Autoregressive Transformer（统一自回归 Transformer）**  
   以统一的自回归方式同时处理文本 token 序列和视觉 token 序列。与传统的 AR+VQ 范式不同，UVU 不对图像和文本施加分离的损失函数，而是让两者共享同一个自回归预测目标。这一设计的关键效应在于：**图像损失与文本损失的梯度在整个训练过程中迅速对齐至同一方向**，从根本上消除了传统范式下两者近乎正交甚至对立的优化冲突。

### 输入输出流

- **输入**：原始图像经 Pixel-level Visual Codebook 量化为离散视觉 token 序列，与文本 token 序列拼接后送入 Unified Autoregressive Transformer。
- **输出**：Transformer 以统一的 next-token prediction 方式自回归地生成输出序列，既可包含文本回答，也可包含重建或生成的图像 token。
- **训练目标**：单一的自回归交叉熵损失，同时覆盖视觉 token 和文本 token 的预测，无需额外的图像生成损失项或对比损失。

### 关键设计决策：为什么统一自回归能解决梯度冲突

传统 AR+VQ 范式通常为图像生成和文本理解设置独立的优化目标，导致两者的梯度在训练过程中保持近乎正交甚至相互对抗。UVU 的消融实验（UVU vs UVU\*）直接验证了这一假设：UVU\* 为去除视觉监督的版本，在所有多模态理解基准上性能一致且显著下降（如 MME 从 2201.9 降至 2056.6，HallusionBench 从 66.6 降至 59.2），证明**梯度对齐后的视觉监督确实增强了理解能力**，而传统范式下视觉监督的“副作用”本质上是优化冲突的产物，而非视觉信号本身的问题。

值得注意的是，UVU 仅使用 3B 参数量（基于 Qwen2.5 backbone），却在多数指标上超越了 7B、8B 甚至 34B 规模的对比方法（如 Janus-Pro、Emu3、Chameleon 等），展现出显著的参数效率优势。

UVU 的方法体系围绕一个中心命题展开：**如何让视觉监督成为多模态理解的“正向驱动力”而非“干扰项”**。传统 AR+VQ 范式下，图像生成损失与文本理解损失的梯度近乎正交甚至对立，导致联合优化时视觉信号非但无益、反而损害理解性能。UVU 通过两个核心模块——**像素级视觉码本**与**统一自回归 Transformer**——从根本上重塑了这一关系。

### 像素级视觉码本

该模块负责将连续图像信号转化为离散 token 序列，是视觉信息进入统一自回归框架的入口。其构建采用大规模迭代层次聚类算法（详见 Algorithm 1），关键参数如下：从 100 万张图像中提取约 20 亿个 32×32×3 的 patch，目标码本大小 K = 200,000。这一设计的直接目标是实现高保真重建——Figure 3 展示了原始图像与 UVU 重建图像的对比，验证了码本的表示能力。但更深层的意义在于：**离散化本身并不自动带来梯度对齐**；码本的质量决定了视觉 token 能否携带足够的信息密度，从而在统一训练中与文本 token 形成有效的梯度交互。

### 统一自回归 Transformer

UVU 将文本 token 与视觉 token 送入同一个自回归 Transformer 进行联合建模，输出层、中间层与嵌入层均共享。这与 Janus-Pro、Emu3、Chameleon 等统一多模态模型的表层架构相似，但关键差异在于**训练目标的设定**：UVU 不引入分离的图像生成损失，而是以统一的自回归损失同时覆盖文本与视觉序列。

这一选择背后是梯度层面的因果机制。分析表明，传统 AR+VQ 范式在整个训练过程中保持图像与文本梯度的近乎正交甚至对立，而 UVU 能迅速将两者对齐到同一方向。梯度对齐意味着视觉监督不再与理解目标“争抢”优化方向，而是协同贡献于同一损失下降路径。消融实验提供了直接证据：去除视觉监督的 UVU* 在所有多模态理解基准上性能显著下降（例如 MME 从 2201.9 降至 2056.6，HallusionBench 从 66.6 降至 59.2），证明对齐后的视觉监督确实转化为理解能力的增益，而非仅仅是生成能力的副产品。

一个值得注意的发现是，在后训练阶段引入大规模文本到图像（T2I）数据集可能反而削弱模型的核心理解与推理能力。这从反面印证了 UVU 设计逻辑的合理性：**视觉监督的有效性并非来自数据量的堆砌，而是取决于监督信号与理解目标在梯度空间中的一致性**。UVU 所采用的统一自回归训练，恰恰是在目标层面而非数据层面解决了这一一致性问题。

## 实验与关键发现

### 主实验结果

UVU在多个多模态理解基准上展现出显著的性能优势，且这一优势在仅使用3B参数量（Qwen2.5 backbone）的前提下取得，而对比方法中包含7B、8B甚至34B的更大规模模型。**Table 1** 汇总了各基准上的核心指标对比。

![[assets/figures/papers/paper_list_l2356_https_openaccess_thecvf_com_content_CVPR2026_html_Kan_UVU_Improving_Mult/figures/001_Table_1.jpg]]
*Table 1: Evaluation on multimodal understanding benchmarks. UVU* refers to the version without visual supervision*

在综合感知与推理基准MME上，UVU取得**2201.9**分，相较于无视觉监督的消融版本UVU*（2056.6分）提升**+145.3**分，提升幅度显著。在MMStar基准上，UVU达到**55%**准确率，较UVU*（52.9%）提升**+2.1**个百分点。在幻觉检测基准HallusionBench上，UVU达到**66.6%**准确率，较UVU*（59.2%）提升**+7.4**个百分点，表明视觉监督对减少幻觉有直接贡献。在视觉推理基准CVBench-2D上，UVU取得**73%**准确率，较UVU*（68.4%）提升**+4.6**个百分点。

上述结果一致表明：当视觉与语言损失梯度通过统一自回归训练实现对齐后，视觉监督能够正向转化为多模态理解能力的驱动力，而非如传统AR+VQ范式下因梯度冲突而成为优化负担。

### 消融实验

**视觉监督的核心作用。** 最关键的消融对比来自UVU与UVU*——两者共用相同的backbone（Qwen2.5）和训练数据，唯一区别在于UVU*完全移除了视觉监督信号。**Table 1** 中UVU在所有基准上均一致且显著地超越UVU*，直接验证了梯度对齐后的视觉监督对多模态理解的因果性正向贡献。

**生成数据集的潜在副作用。** 分析指出，在后训练阶段引入大规模文本到图像（T2I）数据集可能意外地损害模型的核心理解与推理性能。这一发现进一步突显了UVU所采用的监督方式的优势——它通过统一自回归目标使视觉监督服务于理解，而非像其他统一模型那样因引入生成目标而损害理解性能。

### 梯度冲突的实证分析

UVU的核心机制突破在于解决了传统AR+VQ范式下的梯度冲突问题。实证分析确认：传统AR+VQ范式在整个训练过程中，图像损失与文本损失的梯度保持近乎正交甚至对立的态势；而UVU能够迅速将两类梯度对齐至同一方向，从根本上化解了优化冲突，使视觉监督得以正向贡献于多模态理解。这一梯度对齐机制是UVU所有性能提升的因果基础。

### 参数效率与公平性说明

UVU仅使用3B参数量，在多数指标上仍领先于参数量更大的对比方法（如7B、8B乃至34B模型），展现出优异的参数效率。UVU与UVU*的对比在backbone和训练数据完全一致的条件下进行，仅视觉监督方式不同，消融结论具有高可信度。

## 定位与知识库关联

### 1. 核心创新与范式转换

UVU的核心贡献在于识别并解决了一个此前被忽视的**优化冲突瓶颈**：在传统自回归加矢量量化（AR+VQ）的统一多模态范式中，图像重建损失与文本理解损失的梯度在训练过程中近乎正交甚至相互对立。这一发现构成了UVU方法论的基石——视觉监督非但未能辅助理解，反而因梯度冲突成为优化的“噪声源”。

UVU的解决方案是**统一自回归训练目标**（Unified Autoregressive Paradigm）。通过将图像与文本序列置于同一自回归框架下联合优化，两者的梯度得以快速对齐至同一方向，从根本上消解了优化冲突。这一因果机制的扭转，使得视觉监督从理解性能的潜在拖累，转化为正向驱动力。

### 2. 与同类统一多模态模型的关系

UVU属于“视觉-语言统一自回归模型”这一前沿谱系，但与现有工作存在本质区别：

**带视觉监督的统一模型**（如 **Janus-Pro**、**Emu3**、**UniTok**、**UniCode2**、**MetaMorph**、**show-0**、**Harmon**、**UniToken**、**TokLIP**、**Chameleon** 等）普遍试图将图像生成能力整合进多模态框架，却往往面临一个两难困境：生成目标的引入会损害模型的核心理解与推理性能。UVU通过梯度对齐机制绕开了这一陷阱——它并非简单地“添加”生成目标，而是通过统一训练范式使两类目标在优化层面达成协同。

**无视觉监督的消融版本（UVU*）** 提供了最直接的对比基线：UVU*与UVU共享完全相同的backbone（Qwen2.5）和训练数据，唯一差异在于是否包含视觉监督。这一严格对照实验排除了架构与数据差异的干扰，使得性能增益可纯粹归因于梯度对齐后的视觉监督贡献。

### 3. 适用边界与参数效率

UVU以仅**3B参数量**（Qwen2.5 backbone）在多模态理解基准上取得具有竞争力的结果，而对比方法中不乏7B、8B甚至34B规模的模型。这一参数效率优势暗示，梯度对齐机制可能降低了对模型容量的依赖——当视觉信号真正服务于理解而非构成优化负担时，较小模型即可有效利用多模态信息。

然而，UVU的适用边界同样清晰：其优势集中在**多模态理解**场景。论文明确指出，大规模文本到图像（T2I）数据集的引入反而会损害核心理解与推理性能，这表明UVU所采用的视觉监督方式与大规模生成任务之间存在张力。该监督范式更适用于以理解为导向的场景，而非追求极致图像生成质量的通用多模态系统。

### 4. 局限与开放问题

当前分析证据存在以下局限，需读者在深入阅读原文时手动验证：

- **生成能力的上限**：论文虽提及UVU为“保持多模态理解的高保真图像生成提供了潜在路径”，但缺乏与专用生成模型（如扩散模型）在图像质量指标上的系统对比。其生成能力是否达到实用水平仍待确认。
- **视觉监督的粒度**：像素级codebook通过大规模迭代层次聚类构建（目标尺寸K=200,000，基于1M图像约2B个32×32×3的patch），但不同codebook规模与聚类策略对梯度对齐效果的影响未在已有证据中展开。
- **跨架构泛化性**：梯度正交性分析基于AR+VQ范式，该结论是否适用于其他视觉token化方式（如连续特征投影、稀疏注意力）尚不明确。
- **更大规模下的行为**：3B参数下的梯度对齐优势能否线性扩展至更大模型，以及视觉监督的边际收益是否随模型容量增加而递减，均为开放问题。

### 5. 知识库定位

UVU在多模态统一模型的知识谱系中占据一个独特位置：它并非提出新的架构组件，而是**重新定义了视觉监督与语言理解的优化关系**。这一视角将研究焦点从“如何设计更好的视觉编码器/连接器”转向“如何使视觉信号在优化层面与语言目标协同”，为后续工作提供了可操作的因果分析框架——即通过梯度方向一致性来诊断和校准多模态训练的有效性。
