## 概要

在合成3D数据上微调扩散模型以赋予其多视图可控性是当前3D生成的主流范式，但这一过程面临一个根本性瓶颈：控制信号（如法线图、相机位姿）的存在会被模型与合成域的视觉外观相关联，导致生成图像丧失真实感——这一现象被称为**域泄漏**。简单混合真实数据与合成数据进行联合微调无法有效解决此问题，因为模型无法区分“域身份”与“控制信号”这两个纠缠的因素。

**Realiz3D** 针对上述瓶颈提出了一个轻量级框架，其核心洞察在于：扩散模型的早期层和早期去噪步长主要决定图像的结构与布局，而后期层则负责外观细节的精细化；早期层相对域无关，因此可以安全地注入合成域的可控性，而后期层则可专注于保持真实域的照片级真实感。基于这一洞察，Realiz3D 通过三个关键机制实现域身份与控制信号的显式解耦：

1. **域移位器**：以低秩残差的形式学习并注入可学习的域嵌入，使模型能够独立地切换真实域与合成域，而不干扰控制信号的传递。
2. **两阶段训练**：第一阶段冻结扩散骨干网络，仅训练域移位器以区分真实与合成数据的视觉域；第二阶段解冻骨干网络并引入控制条件，通过表示绑定策略学习可控生成。
3. **表示绑定**：结合层感知训练与域重分配——在第二阶段处理真实样本时，冻结早期层以保留结构，仅更新后期外观相关层；同时在早期层中复用合成域模式，以增强控制信号向真实域的传递。

在定量评估中，Realiz3D 在保持3D一致性的前提下显著提升了真实感：在多视图纹理生成任务上，真实世界 FID 从纯合成微调基线的 218.29 降至 **200.24**（Table 1）；在文本到多视图生成任务上，FID 从 215.57 降至 **196.01**（Table 3）。消融实验进一步验证，两阶段训练相比联合训练将 FID 从 216.63 降至 198.44，而层感知训练与域重分配的组合达到了真实感与3D一致性的最佳平衡（Table 2）。

### 3D生成中的真实感困境

近年来，基于2D扩散先验的3D生成方法取得了显著进展，其核心范式是利用在大规模真实图像上预训练的文本到图像（T2I）扩散模型作为先验，通过分数蒸馏采样（SDS）或直接微调来实现3D感知的图像生成。然而，这一范式面临一个根本性的瓶颈：**预训练模型缺乏3D感知能力，无法直接生成多视图一致的图像**。

为了解决这一问题，现有方法通常采用合成3D数据进行微调，在这些数据上注入控制信号（如法线图、相机位姿）来赋予模型3D可控性。但这一策略引入了一个严重的副作用——**域泄漏（Domain Leakage）**：模型在微调过程中，将控制信号的存在与合成数据的视觉域（低真实感、渲染痕迹明显）建立了虚假关联。其结果是，模型虽然学会了遵循3D条件，但生成的图像丧失了预训练模型中固有的照片真实感，呈现出明显的合成渲染特征。

### 域差异的深层机制

Realiz3D通过深入分析扩散模型的内部表征，揭示了域差异形成的两个关键规律：

1. **时间步维度**：扩散模型的早期去噪步主要决定图像的全局结构和布局，而后期步则负责细化纹理和外观细节。合成域与真实域的分布差异在后期步中尤为显著。

2. **网络层维度**：扩散Transformer的浅层（早期块）主要编码结构信息，深层（后期块）则主导外观和纹理的生成。实验证据表明，浅层特征在不同域之间表现出更强的通用性，而深层特征则高度域特定。

基于上述观察，论文提出了核心洞察：**早期层和早期去噪步相对域无关（domain-agnostic），可以安全地注入合成域的可控性信号；而后期层和后期步则决定了生成结果的外观域身份，应保持对真实域的忠实**。

### 现有方法的缺口

现有解决域差异的尝试存在明显不足：

- **全参数微调**（Syn Only）：虽然在合成数据上获得了最强的3D一致性（PSNR 25.76），但真实感严重退化（FID 218.29）。
- **混合数据微调**（Syn + Real）：简单混合真实和合成数据无法解决域泄漏问题，因为模型仍然将控制信号与合成外观耦合。
- **轻量级适配器方法**（如LoRA、Domain Adapter）：通过低秩适配器限制模型容量来保留先验，但缺乏对域身份与控制信号的显式解耦机制，在真实感和一致性之间难以取得平衡。
- **免训练方法**（如SDEdit）：通过加噪-去噪过程增强真实感，但无法从根本上解决控制信号与域身份的纠缠，且计算开销大。

这些方法的共同缺陷在于：**未能显式建模和分离“视觉域身份”与“控制信号”这两个相互独立的因素**。Realiz3D正是针对这一缺口，提出了域感知学习的框架。

## 核心方法与创新机理

Realiz3D 的核心创新在于识别并解耦了“域泄漏”（Domain Leakage）这一关键瓶颈。当在合成3D数据上微调扩散模型时，控制信号（如法线图、相机位姿）会被模型与合成域的外观特征错误关联，导致生成图像丧失真实感。Realiz3D 通过三个相互协同的机制——**域移位器（Domain Shifters）**、**两阶段训练**和**表示绑定（Representation Binding）**——在保持3D一致性的前提下大幅提升照片真实感。

### 域移位器：域身份与控制信号的解耦

传统微调方法未显式建模域身份，导致域信息与控制信号纠缠。Realiz3D 引入域移位器，一种轻量级低秩残差适配器，在潜在特征上注入可学习的域嵌入：

$$
\tilde{X} = X + \mathcal{D}(\mathrm{domain}) = X + W_{\mathrm{left}} W_{\mathrm{right}} e_{\mathrm{domain}}
$$

该模块将“真实/合成”作为一种独立的域身份信号注入，而非与控制信号混叠。与 **Domain Switcher** 等方法不同，Realiz3D 既不修改现有条件机制，也不依赖配对数据（Sec. 4.1）。

### 两阶段训练：先解耦域，后学控制

与单阶段联合微调不同，Realiz3D 采用两阶段训练策略，显式分离域学习和控制学习：

- **阶段一**：冻结扩散骨干网络，仅训练域移位器。在空控制条件（$c = \emptyset$）下，使用真实和合成图像训练域移位器区分两种视觉域，建立独立的域身份表征。
- **阶段二**：冻结域移位器，解冻骨干网络，引入控制条件（仅合成数据可用）进行可控生成微调。

消融实验证实了这一设计的决定性作用：两阶段训练（DiT + DS, 2-Stage）相比联合训练（Joint）将真实世界 FID 从 216.63 降至 198.44（Table 2, #1 vs #3 ） 表明解耦域学习是提升真实感的关键。

### 表示绑定：层感知训练与域重分配

核心洞察在于：扩散模型的早期层和早期去噪步长主要决定结构，后期层决定外观；早期层相对域无关，可安全注入合成域的可控性。Realiz3D 据此提出表示绑定策略：

- **层感知训练（Layer-Aware Training）**：在阶段二使用真实样本时，仅更新后期 DiT 块（负责外观细化），冻结早期块以保持结构。这防止了真实数据对早期可控性表征的破坏。
- **域重分配（Domain Reassignment）**：在处理真实样本时，将早期 DiT 块的域模式强制设为合成模式（$e_{\mathrm{domain}} = e_{\mathrm{syn}}$），使早期层从合成域“借用”控制传递能力，而后期层保持真实域的外观生成。

消融实验表明，层感知训练结合域重分配达到了最佳平衡（FID 200.24, PSNR 24.78, Table 2 #7 ），域重分配单独将 3D 一致性从 PSNR 23.97 提升至 24.18 而不损害真实感（Table 2, #3 vs #5 ）。

### 推理时域切换

推理时采用部分、非随机的域重分配：预定义的早期层和去噪步长设为合成模式以增强控制遵循，后期层和步长保持真实模式以维持照片真实感。这一推理策略进一步提升了控制传递效果（Table 2, Sampling 行）。

### 与基线方法的关键差异

| 设计维度 | 基线方法 | Realiz3D |
|---------|---------|----------|
| 域身份处理 | 未显式建模 | 域移位器注入可学习域嵌入 |
| 训练阶段 | 单阶段或联合微调 | 两阶段：先解耦域，后学控制 |
| 真实数据使用 | 无或简单混合 | 阶段二引入，仅更新后期层 |
| 域重分配 | 无 | 训练和推理时早期层切换为合成模式 |

相比 LoRA（rank 32/128）和 Domain Adapter 等轻量级微调方法，Realiz3D 的域移位器不仅保留先验，更主动学习域身份分离；相比 SDEdit 等免训练方法，Realiz3D 通过训练获得了更强的控制遵循能力；相比 TRELLIS 等预训练3D原生模型，Realiz3D 从2D先验出发，在真实感上具有优势。

Realiz3D 的整体框架围绕一个核心洞察展开：扩散模型的不同层和去噪步长承担着不同的生成职责——早期层和早期去噪步主要决定图像的结构与布局，而后期层则主导外观与纹理细节。基于这一洞察，Realiz3D 设计了一条从域解耦到可控生成的两阶段训练管线，并辅以推理时的域感知采样策略，从而在保持真实感的同时注入 3D 可控性。

### 模块架构与数据流

框架由三个核心模块串联构成：**域移位器（Domain Shifters）**、**两阶段训练（Two-Stage Training）** 和 **表示绑定（Representation Binding）**，后者包含层感知训练（Layer-Aware Training）与域重分配（Domain Reassignment）两个子策略。

**域移位器**是整个管线的入口组件。它被设计为轻量级的低秩残差适配器，以可学习的方式注入域身份（真实域 vs. 合成域），其数学形式为：

$$\tilde{X} = X + \mathcal{D}(\mathrm{domain}) = X + W_{\mathrm{left}} W_{\mathrm{right}} e_{\mathrm{domain}}$$

其中 $X$ 为 DiT 块的潜在特征，$e_{\mathrm{domain}}$ 为可学习的域嵌入，$W_{\mathrm{left}}$ 和 $W_{\mathrm{right}}$ 构成低秩分解矩阵。该残差被添加到扩散 Transformer 的每一层中，使模型能够在同一个共享骨干上切换视觉域，而无需修改原有的条件注入机制。

**两阶段训练**将学习过程拆分为域身份学习与可控性学习两个独立阶段：

- **阶段一（域解耦）**：冻结扩散骨干的所有参数，仅优化域移位器。训练数据同时包含真实图像和合成图像，但控制信号被置为空（$c = \emptyset$）。此时模型唯一的学习目标是区分两个视觉域的身份特征，从而将域外观与控制信号彻底解耦。合成样本的损失函数为 $\mathcal{L} = \mathbb{E}_{z, \epsilon \sim \mathcal{N}(0,1), t} \left[ \| \epsilon - \epsilon_{\theta}(z_t, t, c=\emptyset, e_{syn}) \|_2^2 \right]$，真实样本同理使用 $e_{real}$。

- **阶段二（可控性学习）**：保持域移位器冻结，解冻扩散骨干进行微调。合成数据携带完整的控制信号（如法线图、相机位姿）以教授可控生成，真实数据则用于维护照片真实感。此阶段的核心挑战在于：直接微调会导致合成域的控制信号与合成域外观被联合编码，产生域泄漏。

**表示绑定**正是为解决阶段二的域泄漏而设计的策略组合：

- **层感知训练**：在处理真实样本时，仅更新 DiT 的后期块（负责外观细化），冻结早期块（负责结构生成）。这保留了早期层从合成数据中学到的结构先验，同时让后期层专注于真实域的外观建模。

- **域重分配**：在处理真实样本时，将早期 DiT 块的域移位器强制切换为合成模式（$e_{\mathrm{domain}} = e_{syn}$），使控制信号能够通过合成域路径传递到早期层，而后期层仍保持真实模式以确保外观真实感。

### 推理时域切换

训练完成后，推理阶段采用一种部分、非随机的域重分配策略：预定义的早期层和早期去噪步被设置为合成模式以增强控制信号的传递，而后期层和后期去噪步保持在真实模式以维持逼真外观。这一推理时域切换策略无需额外训练，即可在控制精度与真实感之间取得更优平衡。

### 输入输出规范

框架支持两类下游任务，共享同一套训练好的骨干：

- **多视图纹理生成**：输入为几何条件（法线图）和文本提示，输出为符合几何约束且具有照片真实感的纹理图像。
- **文本到多视图生成**：输入为 $V$ 个相机视点 $\{c_{view}\}_0^V$ 和文本提示，输出为 $V$ 张 3D 一致的 RGB 图像，学习条件分布 $q(\{x_{RGB}\}_0^V \mid \{c_{view}\}_0^V)$。相机视点信息通过位置编码注入潜在样本。

整个框架仅依赖标准的扩散去噪损失，无需成对数据或修改原有的条件机制，使其能够轻量地适配各类预训练扩散骨干。

Realiz3D 的核心设计围绕三个关键模块展开，其本质是通过显式建模“域身份”（domain identity）来解耦控制信号与视觉域的统计关联，从而在注入3D可控性的同时保持预训练模型的真实感先验。

### 域移位器（Domain Shifters）

域移位器是轻量级的低秩残差适配器，其设计目标是学习并注入“合成域”与“真实域”的视觉身份，使模型能够在两种域之间切换，而无需将控制信号与合成外观绑定。具体而言，域移位器在扩散Transformer（DiT）的潜在特征 $X$ 上添加一个域特定的低秩残差：

$$\tilde{X} = X + \mathcal{D}(\mathrm{domain}) = X + W_{\mathrm{left}} W_{\mathrm{right}} e_{\mathrm{domain}}$$

其中 $e_{\mathrm{domain}} \in \{e_{\mathrm{syn}}, e_{\mathrm{real}}\}$ 是可学习的域嵌入，$W_{\mathrm{left}}$ 和 $W_{\mathrm{right}}$ 构成低秩投影矩阵。这一设计的因果逻辑在于：域移位器仅注入“这是合成数据还是真实数据”的身份信息，而不与控制信号（如法线图、相机位姿）交互，从而在架构层面阻断域身份与控制信号的统计耦合——这正是导致“域泄漏”的瓶颈所在。

### 两阶段训练策略

两阶段训练是解耦域身份与控制信号的核心调度机制，其因果路径如下：

**阶段一：域身份孤立学习。** 冻结扩散骨干网络，仅训练域移位器。此时所有样本（合成与真实）均以空控制信号 $c = \emptyset$ 输入，训练目标为标准扩散去噪损失：

$$\mathcal{L} = \mathbb{E}_{z, \epsilon \sim \mathcal{N}(0,1), t} \left[ \| \epsilon - \epsilon_{\theta}(z_t, t, c=\emptyset, e_{\mathrm{syn}}) \|_2^2 \right]$$

真实样本对应 $e_{\mathrm{real}}$。此阶段强制域移位器仅学习两种域的视觉统计差异，而完全不受控制信号干扰，从而建立起纯净的域身份表征。

**阶段二：可控性学习与表示绑定。** 冻结域移位器，解冻扩散骨干网络，引入控制信号 $c$（仅合成数据有控制标签）。此时合成样本的损失函数为：

$$\mathcal{L} = \mathbb{E}_{z, \epsilon \sim \mathcal{N}(0,1), t} \left[ \| \epsilon - \epsilon_{\theta}(z_t, t, c, e_{\mathrm{syn}}) \|_2^2 \right]$$

真实样本则保持无条件（$c = \emptyset$），仅用于保持真实感。两阶段训练的消融实验（Table 2, #1 vs #3 ）提供了决定性证据：联合训练（Joint）的FID为216.63，而两阶段训练降至198.44，表明先解耦域身份再学习控制是提升真实感的关键因果操作。

### 表示绑定：层感知训练与域重分配

在阶段二中，表示绑定（Representation Binding）策略进一步利用扩散模型早期层/步决定结构、后期层/步决定外观的洞察。其包含两个互补操作：

1.  **层感知训练（Layer-Aware Training）**：处理真实样本时，仅更新后期DiT块（负责外观细化），冻结早期块。这保留了早期层从合成数据学到的结构可控性，同时让后期层专注于维持真实域的外观。
2.  **域重分配（Domain Reassignment）**：处理真实样本时，将早期DiT块的域模式强制切换为合成模式（$e_{\mathrm{domain}} = e_{\mathrm{syn}}$）。这相当于在特征层面将真实样本“伪装”成合成样本，使早期层能够将控制信号传递到真实域生成中，而后期层仍以真实模式运行以保证照片真实感。

推理时，采用非随机的部分域重分配：预定义的早期层和去噪步使用合成模式，后期层和步保持真实模式，以进一步增强控制传递。

消融实验（Table 2, #3 vs #5 vs #7 ）证实：添加域重分配将PSNR从23.97提升至24.18而不损害FID；层感知训练与域重分配的组合达到最佳平衡点（FID 200.24, PSNR 24.78），验证了“早期层注入控制、后期层保持真实感”这一核心洞察的有效性。

## 实验与关键发现

### 核心瓶颈与实验设计逻辑

Realiz3D的实验设计围绕一个根本瓶颈展开：在合成3D数据上微调扩散模型时，控制信号（如法线图、相机位姿）的存在被模型与合成域的视觉外观相关联，导致生成图像丧失真实感——这一现象被称为**域泄漏（Domain Leakage）**。实验的核心目标并非单纯追求某一指标的提升，而是验证**域身份与控制信号的解耦**能否打破真实感与3D一致性之间的固有权衡。

实验在两个代表性任务上进行：**多视图纹理生成（Multiview Texturing）**和**文本到多视图生成（Text-to-Multiview Generation）**。所有实验均在相同基座模型、训练轮次（10 epochs）、GPU配置（64×H100）、批次大小（8）和学习率（5e-5）下进行，确保了比较的公平性。

### 主实验结果

#### 多视图纹理生成

Table 1展示了多视图纹理生成的定量对比。Realiz3D在真实世界真实感（FID）上达到**200.24**，相比纯合成全参数微调基线（Syn Only）的218.29降低了**18.05**，提升幅度显著。与此同时，3D一致性指标PSNR为**24.78**，仅比Syn Only的25.76低0.98——这一小幅下降在定性结果中几乎不可察觉，表明Realiz3D在极大提升真实感的同时，保持了与合成基线可比的结构保真度。

值得关注的是，混合真实与合成数据的全参数微调基线（Syn + Real）在FID上表现更差（222.68），这揭示了简单混合数据的反直觉结果：真实数据的直接引入反而加剧了域混淆，因为模型未能区分“真实感”与“控制信号缺失”这两个纠缠的信号。轻量级微调方法如LoRA（rank 128, FID 216.09）和Domain Adapter（FID 217.14）虽有所改善，但仍远不及Realiz3D。

#### 文本到多视图生成

在文本到多视图生成任务上（Table 3），Realiz3D同样展现出跨任务的泛化能力：FID从Syn Only的215.57降至**196.01**（降低19.56），3D一致性指标（PSNR 23.96 vs 24.12）基本持平。这一结果验证了域感知学习的核心假设——早期层的结构控制与后期层的外观细化可以跨任务解耦——在仅依赖文本和相机位姿作为控制信号的场景下同样成立。

### 消融实验：因果机制的逐层验证

Table 2的消融实验是理解Realiz3D工作机制的关键证据链，揭示了各组件的因果贡献。

**两阶段训练 vs 联合训练。** 将域移位器（Domain Shifters）与扩散骨干联合训练（DiT + DS, Joint）时，FID为216.63，与纯合成基线（218.29）几乎无异，说明联合训练无法有效解耦域身份。而采用两阶段训练（DiT + DS, 2-Stage）后，FID降至**198.44**（降低18.19），PSNR仅从25.76微降至24.18。这确证了**先冻结骨干学习域分离，再解冻骨干学习控制**的阶段性策略是解耦成功的关键——第一阶段建立了域身份的独立表征，使第二阶段引入控制信号时不再与合成域外观混淆。

**真实数据与层感知训练。** 在第二阶段引入真实数据但仅更新全部层时（#4 ），FID为204.52，PSNR为23.97。当进一步采用层感知训练（Layer-Aware Training），即冻结早期DiT块、仅更新后期块时（#5 ），FID降至200.24，PSNR提升至24.18。这直接验证了核心洞察：扩散模型的早期层主要负责结构生成，后期层负责外观细化；真实数据对后期层的更新能注入真实感，而冻结早期层则保护了从合成数据习得的控制能力。

**域重分配与推理时切换。** 在层感知训练基础上添加域重分配（Domain Reassignment, #7 ），即在处理真实样本时将早期块的域模式切换为合成模式，进一步将PSNR从24.18提升至**24.78**，FID保持在200.24。推理时的域切换（Sampling）贡献了额外的0.06 PSNR增益（#7 vs #6 ）。这一机制的本质是：合成模式在早期层传递了更强的控制信号，而真实模式在后期层保持了外观的真实感，两者在不同层级上的“分工”实现了最优权衡。

### 失败模式与局限性

尽管Realiz3D大幅提升了真实感，实验也揭示了若干结构性局限：

1. **控制遵循度的微小损失。** 3D一致性指标（PSNR）始终略低于纯合成基线（-0.98），这是因为真实感细节的引入对像素级几何一致性提出了更高要求——高真实感图像中的纹理、光照变化可能轻微偏离输入几何条件。

2. **基座模型的光照偏差。** 论文指出预训练T2I模型存在光照偏差（如对平行光的偏好），导致不同视图间可能出现光照不一致。这是基座模型的固有问题，域感知训练无法完全消除。

3. **几何层面的域差异。** 合成数据与真实数据之间的域差异有时表现为几何层面的不匹配（如不真实的几何结构），使生成结果轻微偏离原始几何条件。当前方法主要处理外观域的差异，对几何域的泛化尚不充分。

4. **控制信号类型受限。** 当前方法仅支持域无关的控制信号（文本、几何信号），尚未扩展到图像条件等更复杂的控制类型。

### 定性结果的关键发现

Figure 3和Figure 4的定性对比为定量指标提供了视觉锚点。在多视图纹理生成中（Figure 3），Realiz3D生成的纹理在保持跨视图几何一致性的同时，展现出明显更丰富的材质细节和更自然的光照效果。红色虚线圆圈标注的不一致区域表明，混合微调基线在视图间存在明显的纹理漂移，而Realiz3D有效抑制了这一问题。在文本到多视图生成中（Figure 4），Realiz3D同样在保持3D一致性的前提下显著增强了照片真实感，红色标注框突显了基线方法在视角正确性和跨视图一致性上的失败。

### 小结

实验证据链形成了清晰的因果逻辑：域泄漏是真实感退化的根因 → 两阶段训练实现域身份与控制信号的解耦 → 层感知训练和域重分配在早期层保留可控性、在后期层保持真实感 → 推理时域切换进一步增强控制传递。这一机制在两项任务上均实现了真实感的大幅提升（FID降低18-20），同时将3D一致性损失控制在可忽略范围内。

## 定位与知识库关联

### 核心瓶颈：域泄漏与控制-真实感拮抗

在合成3D数据上微调扩散模型以注入可控性时，模型倾向于将控制信号（法线图、相机位姿等）与合成域的低真实感外观建立虚假关联。这导致一个结构性困境：**控制遵循度与照片真实感构成拮抗关系**——纯合成数据微调（Syn Only）可获得最佳3D一致性（PSNR 25.76），但真实世界FID高达218.29；引入真实数据混合微调（Syn + Real）虽将FID降至203.20，却使PSNR骤降至22.28（Table 1）。这一“域泄漏”现象是本文定位的核心瓶颈。

### 方法定位：域感知微调范式

Realiz3D提出了一种**域感知微调**策略，其核心洞察源自对扩散模型层级功能分工的观察：扩散Transformer（DiT）的早期层和早期去噪步主要决定结构布局，后期层和后期步则负责外观细化；更重要的是，早期层对域差异相对不敏感，而后期层高度域敏感（Figure 5, Sec. 3）。基于此，Realiz3D通过三个创新组件构建解耦机制：

1. **域移位器（Domain Shifters）**：以低秩残差形式注入可学习的域嵌入，将域身份建模为独立于控制信号的显式变量。其数学形式为 $\tilde{X} = X + W_{\text{left}} W_{\text{right}} e_{\text{domain}}$（Sec. 4.1），仅引入极少量参数。

2. **两阶段训练**：阶段1冻结扩散骨干，仅训练域移位器以区分真实与合成域（控制信号置空）；阶段2冻结域移位器，解冻骨干学习控制信号。消融实验表明，两阶段解耦（DiT + DS, 2-Stage）相比联合训练（Joint）将FID从216.63降至198.44，且PSNR从23.21升至23.97（Table 2, #1 vs #3 ），证实域身份与控制信号的分离学习是突破拮抗关系的关键。

3. **表示绑定（Representation Binding）**：在阶段2中结合层感知训练（Layer-Aware Training）与域重分配（Domain Reassignment）——真实样本仅更新后期DiT块以保持真实外观，同时将早期块的域模式随机切换为合成模式，使控制信号沿合成域路径传递至早期结构层。Table 2显示，添加域重分配后PSNR从23.97进一步提升至24.18（#3 vs #5 ），最终完整方案达到FID 200.24、PSNR 24.78的最佳平衡点（#7 ）。

### 与现有工作的关系

Realiz3D定位于**适配器微调**与**域适应**方法的交叉地带，但采取了独特的解耦路径：

- **LoRA（rank 32/128）**：作为轻量级微调基线，LoRA通过低秩适配器保留预训练先验，但未显式建模域差异。在Table 1中，LoRA（rank 128）的FID为207.14，PSNR为23.39，两者均弱于Realiz3D，表明单纯的参数高效微调不足以解决域泄漏。

- **Domain Adapter  与 Domain Switcher (2-Stage)：这两类基于适配器的域适应方法同样引入域特定模块，但Realiz3D与之的关键差异在于：（1）不修改现有条件机制，不依赖配对数据（Sec. 2）；（2）通过两阶段训练先孤立域身份再学习控制，而非联合优化；（3）利用层级功能分工实现控制信号在早期层的“合成模式”传递，而非简单地在域间切换。

- **SDEdit ：免训练基线，通过加噪-去噪过程提升真实感，但无法注入3D控制信号，其PSNR仅为20.24（Table 1），3D一致性显著劣于所有微调方法。

- **TRELLIS**：预训练的3D原生模型，在3D一致性上具有优势，但其训练范式与Realiz3D的域感知微调路径正交——Realiz3D旨在将预训练2D扩散模型适配为可控3D生成器，而非从头训练3D原生模型。

### 适用边界与局限

Realiz3D的设计假设存在明确边界：

1. **控制信号的域无关性**：当前方法仅支持域无关的控制信号（文本、几何信号如法线图/深度图），尚未扩展到图像条件等域敏感信号（Sec. 6）。若控制信号本身携带强域特征（如特定风格的参考图像），域移位器的解耦能力可能退化。

2. **基座模型的光照偏差**：预训练T2I模型存在隐式光照偏好（如平行光偏见），导致多视图生成中出现视图间光照不一致（Figure 14）。Realiz3D的域感知训练未直接建模光照变量，因此无法消除这一系统性偏差。

3. **几何域的残留差异**：域差异不仅体现在外观，有时也表现为合成数据中不真实的几何结构，使生成结果轻微偏离原始几何条件（Sec. 6）。这反映了域移位器仅作用于特征空间的局限——它解耦了外观域，但无法纠正输入几何信号本身的域偏差。

4. **控制遵循度的微小折损**：完整方案PSNR为24.78，略低于纯合成基线25.76（Table 1）。这是因为真实感细节的引入对像素级3D一致性提出了更高要求，在纹理边缘和细微几何处可能出现轻微偏离。

### 开放问题

1. **光照一致性的系统解决**：能否将重光照技术或显式光照条件注入域移位器框架，以消除基座模型的光照偏差，从而在保持真实感的同时提升跨视图光照一致性？

2. **向视频扩散模型的扩展**：域感知学习技术能否迁移至视频扩散模型，以弥合合成视频数据与真实视频数据之间类似的域差异？视频域的时间一致性约束可能为域移位器设计带来新的挑战。

3. **图像条件等复杂控制信号的泛化**：当控制信号本身携带域信息时，如何扩展域移位器的解耦能力？可能需要引入控制信号的域归一化或条件域嵌入的层级解耦机制。

4. **控制遵循度与真实感的极限平衡**：当前方案在PSNR上仍有约0.98的微小差距，是否存在更精细的层级分配策略或动态域混合机制，能够在不牺牲真实感的前提下进一步逼近纯合成基线的控制精度？
