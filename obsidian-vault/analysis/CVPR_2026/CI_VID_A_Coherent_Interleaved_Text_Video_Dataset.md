## 概要

现有大规模视频生成数据集由孤立的文本-视频对构成，模型仅学习单一片段的条件生成，缺乏对跨片段连贯性的建模能力。这一瓶颈导致模型无法支持**文本与视频联合驱动的多场景视频序列生成任务（T&V2V）**——即给定前置视频片段和文本指令，生成内容一致且可控的后续片段。

针对上述问题，本文提出**CI-VID**，一个**连贯交错文本-视频数据集**。其核心思路是：从长视频中提取叙事连贯但镜头多变的片段序列，并为每个片段提供细粒度个体字幕以及捕捉片段间过渡关系的联合字幕，从而赋予模型同时利用视觉上下文与文本指引的能力。CI-VID包含超过34万条交错文本-视频序列样本，每个样本平均包含3.1个片段，并提供个体与联合字幕。

在CI-VID上微调后，模型在VLM评估的六个维度上平均得分从3.14提升至3.80；人类评估显示，微调模型在连贯性、叙事性和事实正确性上分别以90.0%、80.9%和78.3%的胜率显著超越基线模型。

### 现有视频生成数据范式的瓶颈

当前大规模视频生成模型（如文本到视频 T2V 模型）的训练数据几乎全部由**孤立的文本-视频对**组成——每个样本仅包含单一片段及其对应的描述文本，片段之间不存在任何关联信息。这种数据结构从根本上限制了模型的能力边界：模型学会的是“根据文本生成一个独立视频片段”，而非“在已有视觉上下文的基础上，根据文本指引生成连贯的后续片段”。

由此产生的核心瓶颈是：**现有数据集无法支持文本和视频联合驱动下的多场景视频序列生成任务（T&V2V）**。在实际应用中，用户往往希望模型能够基于前一个视频片段的内容，结合新的文本指令，生成视觉上一致且叙事上连贯的后续片段——例如，一个角色从室内走到室外，场景发生变化但角色外观和身份保持不变。孤立文本-视频对的数据范式完全缺失了这种跨片段连贯性建模所需的关键信号。

### 现有数据集的结构性缺口

主流的视频-文本数据集，如 InternVid 和 Panda-70M，虽然在规模上达到了千万甚至亿级样本量，但其设计目标始终围绕 T2V 任务展开。这些数据集的典型特征是：

- **单片段结构**：每个样本仅包含一个视频片段和一段描述文本，片段之间彼此独立。
- **缺乏过渡信息**：字幕仅描述当前片段的内容，不包含片段之间的内容延续、场景变化或实体关联信息。
- **无法提供视觉上下文**：训练时模型仅接收文本条件，无法学习如何利用前置视频作为额外的生成条件。

这种结构性缺口使得即使是最先进的 T2V 模型，在面对多场景序列生成需求时，也只能将每个片段视为独立生成任务，导致片段之间出现角色外观突变、场景跳脱、叙事断裂等问题。

### 本文动机与核心思路

针对上述瓶颈，本文的核心动机是：**构建一种全新的数据集，使模型能够学习“给定前置视频和文本指令，生成一致且可控的后续片段”的能力**。

实现这一目标的关键在于数据结构的根本性变革。CI-VID 数据集的设计围绕三个核心原则展开：

1. **交错序列结构**：每个样本由多个具有内容关联但视觉多样的视频片段序列组成，而非孤立的单一片段。
2. **联合字幕描述**：不仅为每个片段提供细粒度的个体字幕（涵盖视频内容、机位、运动、背景），还提供捕捉片段间过渡关系的联合字幕（包括内容延续/变化、背景延续/变化等）。
3. **连贯性与多样性兼顾**：通过相似度与实体驱动的分割方法，从长视频中提取既保持叙事连贯性又具有镜头多样性的片段序列。

通过这种数据结构，模型在训练时可以同时利用视觉上下文（前置视频片段）和文本指引（联合字幕），从而学习到跨场景的连贯视频生成能力。这一设计将视频生成的任务范式从孤立的 T2V 拓展到了**文本与视频联合驱动的视频生成（T&V2V）**，为多场景叙事视频的自动生成提供了数据基础。

## 核心方法与创新机理

CI-VID的核心创新在于将视频生成的数据范式从“孤立的文本-视频对”重构为“连贯的交错文本-视频序列”，从而解锁了文本与视频联合驱动的多场景视频生成任务（T&V2V）。这一转变通过以下三个关键槽位的系统性改变实现：

### 1. 数据结构：从孤立单片段到交错多片段序列

现有大规模视频-文本数据集（如InternVid、Panda-70M）的基本单元是孤立的单片段视频-文本对，模型仅学习从文本到单一视频片段的映射。CI-VID将数据结构重新定义为**交错的多片段视频序列**，每个样本包含平均3.1个视频片段，并配有两层字幕：描述各片段内部细节的**个体字幕**（涵盖视频内容、机位、运动、背景四个维度）和刻画片段间过渡关系的**联合字幕**（涵盖内容延续/变化、背景延续/变化等视角）。这一设计使模型能够同时感知片段内部的视觉细节和片段之间的叙事连贯性，为跨场景生成提供了结构化的监督信号。

### 2. 任务支持：从T2V到T&V2V的范式跃迁

基线模型（如NOVA-0.6B）仅支持文本到视频（T2V）的单条件生成。CI-VID的序列化数据结构天然支持**文本与视频联合条件**的生成范式——给定前置视频片段和文本指令，生成视觉连贯且叙事一致的后续片段。这一任务跃迁的核心机理在于：联合字幕显式地编码了片段间的因果过渡关系（如“镜头切换至特写”“背景从室内变为室外”），使得模型能够同时利用视觉上下文和语言指引来约束生成过程，而非仅依赖文本进行开放式生成。

### 3. 片段序列构建：从简单分割到语义连贯性保障

传统数据集通常基于镜头边界检测或简单时间顺序切分视频，难以保证片段间的语义关联性和视觉多样性。CI-VID提出了**两阶段分割流水线**：

- **相似度分割**：利用ImageBind提取片段嵌入，基于余弦相似度阈值$(T_l, T_h) = (0.6, 0.8)$将长视频划分为内容相关但视觉有别的片段序列——低阈值确保序列边界处的视觉变化，高阈值维持序列内部的内容关联。
- **实体分割**：通过Qwen2.5-VL提取主实体并验证片段间实体一致性，辅以GPT-4o复审，确保序列在保持共同叙事主体的同时具备足够的镜头变化。这一步骤弥补了纯相似度方法可能产生的语义断裂，是序列构建质量的关键保障。

### 4. 字幕粒度：从单一片段描述到双层结构化描述

基线数据集仅提供单一片段的内容描述，缺乏对片段间动态关系的建模。CI-VID采用**两步字幕生成策略**：先用顺序帧输入策略生成细粒度个体字幕，再用联合帧输入策略生成捕捉连续性与变化的联合字幕。个体字幕平均218.6词，联合字幕平均215.8词，这种双层描述结构为模型提供了从微观细节到宏观叙事的完整监督链条。

### 创新点的因果逻辑

上述四个改变槽位构成了一条清晰的因果链：**语义连贯的片段序列构建**（槽位3）产生了高质量的交错视频数据，**双层结构化字幕**（槽位4）为这些序列提供了精确的语言锚点，二者共同支撑了**交错多片段数据结构**（槽位1）的建立，最终使**T&V2V任务**（槽位2）成为可能。实验证据表明，在CI-VID上微调后，模型在VLM评估的六个维度上平均得分从3.14提升至3.80（+0.66），人类评估中连贯性、叙事性和事实正确性的胜率分别达到90.0%、80.9%和78.3%，验证了这一创新路径的有效性。

CI-VID 的构建围绕一个核心瓶颈展开：现有视频生成数据集由孤立的文本-视频对组成，缺乏跨片段连贯性建模，无法支持文本和视频联合驱动下的多场景视频序列生成任务（T&V2V）。为解决这一问题，论文提出了一套从长视频中提取叙事连贯但镜头多变的片段序列，并为其生成细粒度单体与联合字幕的完整流水线。

整体构建过程由三个主阶段构成（见 Figure 2）：**源视频收集与过滤**、**视频片段序列构建**、以及**字幕生成**。其中，视频片段序列构建是整个流水线的关键控制节点，通过相似度分割与实体分割两步递进，确保生成的片段序列既保持内容关联，又具备足够的视觉多样性。字幕生成则采用两阶段策略，先为每个片段生成详细的个体字幕，再为相邻片段生成捕捉过渡关系的联合字幕，从而赋予下游模型同时利用视觉上下文和文本指引的能力。

### 源视频收集与过滤

源视频来自手工筛选的 4,068 个高质量 YouTube 频道，这些频道从 Emu3 的训练数据中提取并经过人工审核。下载的视频需经过严格的过滤流程：首先进行场景分割，去除不完整的场景片段；随后通过光流运动检测和文字覆盖率过滤，仅保留运动充分且文字占比低的片段。最终，不到 20% 的原始视频片段进入后续处理阶段。

### 视频片段序列构建

片段序列构建是 CI-VID 区别于传统孤立数据范式的核心环节，包含两个递进步骤：

- **相似度分割**：利用 ImageBind 提取每个片段的嵌入向量，基于余弦相似度阈值 $(T_l, T_h) = (0.6, 0.8)$ 将原始视频划分为内容相关且视觉有别的片段序列。低于 $T_l$ 的片段被视为内容变化点，高于 $T_h$ 的片段被认为过于相似而需合并，介于两者之间的片段则构成具有适度变化的序列。

- **实体分割**：为弥补纯相似度方法可能遗漏的语义连贯性，引入基于实体的验证机制。通过 Qwen2.5-VL 提取每个片段的主实体，验证片段间是否存在共同实体；若实体一致，则认为片段具有内容关联性。GPT-4o 进一步复审实体一致性，确保序列在视觉差异与内容相关性之间取得平衡。这一步骤使相邻片段在保持强关联的同时，展现出足够的视觉区分度。

### 字幕生成

字幕生成采用 GPT-4o 执行的两步流水线。第一步使用**顺序帧输入策略**生成个体字幕，覆盖视频内容、机位、运动、背景四个关键维度，平均长度达 218.6 词。第二步采用**联合帧输入策略**生成联合字幕，从内容延续/变化、背景延续/变化等视角捕捉片段间的连续性与过渡关系，平均长度为 215.8 词。这种双层字幕结构使模型能够同时理解单一片段的细粒度内容和跨片段的叙事逻辑。

### 数据流与最终产出

经过上述流水线，CI-VID 最终产出超过 34 万条交错文本-视频序列样本，每个样本平均包含 3.1 个片段，并配有完整的个体字幕和联合字幕。这一数据结构将传统 T2V 任务中孤立的“单片段视频-文本对”替换为“交错多片段视频序列 + 双层字幕”，从而原生支持 T&V2V 任务——即给定前置视频和文本指令，生成一致且可控的后续片段。

### 1. 相似度分割 (Similarity-Based Segmentation)

该模块的核心目标是从原始长视频中提取内容相关但视觉有别的片段序列。其工作机制建立在两个关键阈值之上：

- **片段嵌入提取**：利用 ImageBind 为每个候选片段生成多模态嵌入向量。
- **相似度阈值筛选**：设定低阈值 $T_l = 0.6$ 和高阈值 $T_h = 0.8$。相邻片段间的余弦相似度需落在区间 $(T_l, T_h)$ 内，以确保片段既非完全重复（相似度过高），也非毫无关联（相似度过低），从而在叙事连贯性与镜头多样性之间取得平衡。

这一经验性阈值设定是该模块的瓶颈所在——其泛化性在不同视频类型上可能存在波动，属于需要人工验证的环节。

### 2. 实体分割 (Entity-Based Segmentation)

实体分割作为相似度分割的补充模块，旨在增强片段序列的内容相关性。其流程如下：

- **主实体提取**：采用 Qwen2.5-VL 从每个片段中提取主要实体（如人物、动物、特定物体）。
- **实体一致性验证**：检查相邻片段是否共享共同的主实体。若共享，则判定为内容相关，保留该序列；否则进行拆分或过滤。
- **复审机制**：引入 GPT-4o 对实体一致性结果进行二次审核，降低单模型误判风险。

该模块的因果作用在于：它将“视觉差异”与“内容关联”两个看似矛盾的目标统一起来——通过实体纽带保证叙事连贯性，同时允许镜头、场景、机位等视觉元素发生显著变化。

### 3. 字幕生成 (Caption Generation)

字幕生成采用两步流水线，由 GPT-4o 驱动：

- **个体字幕生成**：使用顺序帧输入策略，为每个独立片段生成涵盖四方面内容的详细描述：视频内容、机位角度、运动模式、背景环境。
- **联合字幕生成**：使用联合帧输入策略，将相邻片段的帧同时输入模型，生成捕捉片段间过渡关系的描述，包括：内容延续/变化、背景延续/变化、镜头切换方式等。

这种双层字幕结构是 CI-VID 区别于传统孤立文本-视频对数据集的核心设计，它使模型能够学习“在给定前置视觉上下文和文本指令的条件下，如何生成连贯的后续片段”。

### 4. 扩散损失函数

CI-VID 的模型训练基于扩散范式。给定条件 $\boldsymbol{z}_n$（包含前置视频片段和文本指令），样本 $\boldsymbol{x}_n$ 的扩散损失定义为：

$$\mathcal { L } ( \boldsymbol { x } _ { n } \mid \boldsymbol { z } _ { n } ) = \mathbb { E } _ { \boldsymbol { \varepsilon } , t } \left[ \left\| \boldsymbol { \epsilon } - \boldsymbol { \epsilon } _ { \boldsymbol { \theta } } \left( x _ { n } ^ { t } \mid t , \boldsymbol { z } _ { n } \right) \right\| ^ { 2 } \right]$$

其中：
- $\boldsymbol{\epsilon}$：从标准高斯分布采样的真实噪声。
- $\boldsymbol{\epsilon}_\theta$：参数为 $\theta$ 的噪声预测网络。
- $x_n^t$：在时间步 $t$ 对原始样本 $x_n$ 注入噪声后的含噪版本。
- $\boldsymbol{z}_n$：条件信息，包含前置视频片段和文本指令。

### 5. 噪声注入与去噪推理

训练时的噪声注入过程为：

$$x _ { n } ^ { t } = \sqrt { \bar { \alpha } _ { t } } x _ { n } + \sqrt { 1 - \bar { \alpha } _ { t } } \epsilon$$

其中 $\bar{\alpha}_t$ 为累积噪声调度参数，控制信号与噪声的比例。

推理时的去噪步骤为：

$$x _ { n } ^ { t - 1 } = \frac { 1 } { \sqrt { \alpha _ { t } } } \left( x _ { n } ^ { t } - \frac { 1 - \alpha _ { t } } { \sqrt { 1 - \bar { \alpha } _ { t } } } \epsilon _ { \theta } ( x _ { n } ^ { t } \mid t , z _ { n } ) \right) + \sigma _ { t } \epsilon$$

该公式描述了从纯噪声逐步去噪直至生成清晰视频片段 $x_n^0$ 的完整过程。训练阶段采用 Nichol 和 Dhariwal 的掩码与扩散调度器，掩码比例范围为 0.7 至 1.0；推理阶段掩码比例按余弦调度从 1.0 递减至 0。

## 实验与关键发现

### 评估设置与基准

为全面衡量CI-VID数据集对T&V2V生成任务的实际增益，作者设计了三维度评估体系：人类评估、基于VLM的自动评分和相似度指标评估。评估采用统一的提示模板（Table 3），该模板包含六个相互关联的场景描述，要求模型以前置视频片段和文本指令为条件，生成连贯的后续片段序列。基线模型为未在CI-VID上微调的NOVA-0.6B（NOVA ），微调模型则在该基线基础上使用CI-VID数据集进行训练。

### 主实验结果

**人类评估结果。** Table 4展示了人类评估的Win/Tie/Loss百分比。在连贯性（Consistency）、叙事性（Narrativity）和事实正确性（Correctness）三个维度上，CI-VID微调模型分别以90.0%、80.9%和78.3%的胜率显著超越基线模型。这一结果表明，CI-VID的交错文本-视频序列训练范式有效提升了模型对跨片段时序依赖和内容一致性的建模能力。

**VLM自动评估结果。** Table 5给出了基于VLM的六维度评分（0-5分制）。基线模型在风格一致性（2.93）、实体一致性（2.84）、背景视角一致性（2.80）、文本提示一致性（3.02）、过渡质量（3.99）和视觉合理性（3.25）上的平均得分为3.14；CI-VID微调后，各维度得分分别提升至3.83、3.73、3.75、3.81、4.07和3.62，平均得分达到3.80，提升幅度为+0.66。值得注意的是，与交错生成直接相关的维度（风格一致性、实体一致性、背景视角一致性、文本提示一致性）提升尤为明显，而过渡质量维度（3.99→4.07）提升幅度较小——这可能是由于基线模型本身在该维度已有较高表现，边际增益空间有限。

**相似度评估结果。** Table 6从CLIP相似度、逆LPIPS和SSIM三个客观指标衡量生成片段与真实片段的相似性。CI-VID微调模型在所有指标上均取得更高分数（↑表示越高越好），进一步验证了数据集对生成质量的客观提升。

**定性对比。** Figure 5展示了使用同一评估提示（Table 3）时，基线模型与CI-VID微调模型的生成结果对比。微调模型生成的视频序列在场景过渡的自然度、实体外观保持和背景一致性方面明显优于基线，直观印证了定量评估的结论。

### 关键发现与机制分析

CI-VID带来的性能增益可归因于其数据结构的核心设计：通过相似度与实体双重分割构建的片段序列，迫使模型学习从前置视觉上下文和文本指令中提取双重条件信号。具体而言：
- **视觉条件**：前置视频片段提供实体的外观、运动模式和场景布局等隐式约束；
- **文本条件**：联合字幕明确编码了片段间的延续或变化关系（如“the background changes from indoors to outdoors”），为模型提供了显式的过渡指引。

这种双重条件机制使得微调后的模型在生成后续片段时，能够同时保持与前置片段的内容连贯性和对文本指令的忠实响应，从而在实体一致性、背景视角一致性等维度上获得显著提升。

### 失败模式与局限性

尽管CI-VID在多个维度上展现了显著增益，但分析中也暴露出若干值得关注的局限：

1. **长序列生成的退化风险。** 当前CI-VID样本的平均片段数为3.1个（Figure 3b），评估中使用的是六场景提示。当片段序列长度进一步增加（如超过10个片段）时，生成模型的连贯性是否能够保持尚需验证。扩散模型的误差累积效应可能导致后期片段的内容漂移加剧。

2. **分割阈值的经验依赖性。** 相似度分割使用的阈值$(T_l, T_h) = (0.6, 0.8)$为经验设定，其在不同视频类型（如快节奏动作片与静态纪录片）上的适用性未经验证。阈值设置不当可能导致片段序列要么过于同质（缺乏视觉多样性），要么过于离散（丧失内容关联性）。

3. **VLM依赖带来的误差传播。** 实体分割环节依赖Qwen2.5-VL和GPT-4o进行实体提取与一致性验证，字幕生成环节同样依赖GPT-4o。这些大型VLM的固有误差（如实体误识别、字幕幻觉）会直接传播至数据集质量，影响下游模型的训练效果。

4. **过渡维度的提升瓶颈。** VLM评估中过渡质量维度（3.99→4.07）的增益有限，可能暗示当前数据集对片段间过渡关系的建模仍有改进空间——联合字幕虽然描述了变化类型，但未提供过渡动态的细粒度时序标注。

### 评估公平性说明

作者在评估设计中采取了以下措施以降低偏差：数据收集阶段不对视频内容施加主题限制，保持了数据集的多样性（Figure 4词云展示了广泛的主题分布）；评估结合人类判断、VLM评分和客观相似度指标三个互补维度，避免了单一评估方法的系统性偏差。然而，VLM评估本身可能对某些视觉特征存在偏好，人类评估的样本量和评估者背景也未详细披露，这些因素在解读结果时需要纳入考量。

## 定位与知识库关联

### 与主流视频生成数据范式的对比

当前大规模视频生成数据集（如 **InternVid**、**Panda-70M**）普遍采用“孤立文本-视频对”的数据组织方式：每个样本由单一片段及其对应的文本描述构成，训练出的模型仅支持文本到视频（T2V）的单次生成。这种范式在底层假设上忽略了视频叙事中的跨片段连贯性——即前后场景之间在内容、实体、背景和运镜上的承接与变化关系。

CI-VID 的核心贡献在于将数据结构从“孤立对”升级为“交错序列”：每个样本包含多个在内容上关联、在视觉上变化的视频片段，并配备两类字幕——描述单一片段内部细节的个体字幕，以及捕捉片段间过渡关系的联合字幕。这一设计使模型能够同时以“前置视频片段”和“文本指令”为条件，生成与视觉上下文一致且符合文本指引的后续片段，即文本与视频联合驱动的视频生成（T&V2V）。从知识库定位看，CI-VID 填补了现有视频文本数据集中“跨片段连贯性建模”的结构性空白，为多场景视频序列生成提供了首个大规模训练资源。

### 构建方法的技术谱系

CI-VID 的数据构建流水线融合了多个技术传统，并在关键环节做出了针对性设计：

**视频分割技术**：传统视频数据集通常依赖简单的镜头边界检测或固定时间窗口切分片段，这类方法无法保证片段间的语义关联性。CI-VID 引入了两阶段分割策略——相似度分割与实体分割的级联，其设计思想可以追溯到多模态嵌入对齐和视觉实体追踪两条技术路线。相似度分割利用 **ImageBind** 提取片段级嵌入，通过余弦相似度阈值 $(T_l, T_h) = (0.6, 0.8)$ 将原始视频划分为内容相关但视觉有别的片段序列。实体分割则借助 **Qwen2.5-VL** 提取主实体并验证片段间实体一致性，辅以 **GPT-4o** 复审，确保序列在保持内容关联的同时具备足够的视觉差异。这种“粗筛-精验”的级联架构在数据质量与计算成本之间取得了平衡，但其阈值设定为经验性参数，对不同视频类型的泛化性尚需验证。

**字幕生成技术**：CI-VID 采用两阶段字幕生成策略，这与多模态大模型在视频理解中的“逐帧-联合”推理范式一致。第一阶段使用顺序帧输入策略，让 GPT-4o 逐片段生成涵盖视频内容、机位、运动和背景四方面细节的个体字幕；第二阶段使用联合帧输入策略，将相邻片段的帧同时输入模型，生成捕捉内容延续/变化、背景延续/变化等过渡信息的联合字幕。从统计数据看（Table 2），CI-VID 的个体字幕平均 218.6 词，联合字幕平均 215.8 词，显著长于现有数据集的字幕长度，为模型提供了更丰富的监督信号。

### 模型训练与评估的定位

在实验验证中，CI-VID 以 **NOVA-0.6B** 作为基线模型进行微调。NOVA 本身是一个 T2V 扩散模型，其训练使用 Nichol 和 Dhariwal 提出的掩码与扩散调度器（masking ratio 0.7 到 1.0），推理阶段掩码比率按余弦调度从 1.0 递减至 0。CI-VID 并未改变模型架构或训练算法，而是通过数据结构的革新——将交错视频序列和联合字幕注入训练——使原有 T2V 模型获得了 T&V2V 的能力。这种“数据驱动能力扩展”的思路与当前大模型领域“通过数据工程解锁新能力”的趋势高度一致。

评估体系的设计同样值得关注。CI-VID 采用了三维评估框架：人类评估（连贯性、叙事性、事实正确性的 Win/Tie/Loss 对比）、VLM 评估（六个维度的 0-5 分评分）和相似度评估（CLIP 相似度、逆 LPIPS、SSIM）。这种多维度评估降低了单一方法的偏差，为 T&V2V 任务建立了初步的评估基准。

### 适用边界

CI-VID 的设计假设和构建流程定义了其适用边界：

1. **视频来源的局限性**：源视频来自 4068 个经人工筛选的 YouTube 频道，虽然保证了基础质量，但可能引入内容分布偏差。数据集主题词云（Figure 4）显示了一定的主题多样性，但非英语内容和文化背景差异较大的视频类型的覆盖度未知。

2. **序列长度的约束**：CI-VID 样本的平均片段数为 3.1，序列长度分布（Figure 3b）集中在较短范围。当生成任务需要更长的片段序列（如超过 10 个片段）时，模型在 CI-VID 上学到的连贯性建模能力能否保持，是一个开放问题。

3. **分割阈值的刚性**：相似度分割的阈值 $(0.6, 0.8)$ 为固定经验值，对于快节奏剪辑、长镜头或纪录片等不同视频类型，该阈值可能无法最优地捕捉内容关联与视觉变化的平衡点。

### 局限与开放问题

**已知局限**：

- **实体分割对大型 VLM 的依赖**：实体提取和一致性验证环节依赖 Qwen2.5-VL 和 GPT-4o，这不仅引入了较高的 API 调用成本，还受限于这些模型的固有识别误差。当视频中出现罕见实体或复杂交互场景时，实体分割的准确性可能下降，进而影响序列构建质量。
- **分割阈值的经验性**：$(0.6, 0.8)$ 的阈值设定缺乏理论依据或大规模消融验证，在不同视频领域（如体育、动画、新闻）的表现可能存在显著差异。

**开放问题**：

1. CI-VID 的构建流水线如何适应非英语视频或文化背景差异较大的内容？多语言实体识别和跨文化视觉理解能力是当前流水线的薄弱环节。
2. 当片段序列长度进一步增加时，生成模型的连贯性是否能够保持？现有的 3.1 平均片段数可能不足以训练出长程叙事能力。
3. 能否通过自动化方法（如更轻量的视觉编码器或自监督实体匹配）进一步降低对昂贵 VLM 的依赖，从而支持更大规模的数据集扩展？
4. 联合字幕中描述的片段间过渡关系（内容延续/变化、背景延续/变化等）是否足够细粒度？是否存在更结构化的过渡建模方式（如显式的因果关系或时间逻辑）可以进一步提升生成质量？

> **注意**：上述部分基线工作的具体会议/年份信息（如 InternVid、Panda-70M、NOVA 的原始发表信息）在本文提供的分析材料中未完整给出，建议读者查阅原始文献以获取准确的引用元数据。
